## 一、主角设计分析 — 多主角轮换+meta层叙事者

### 1.1 主角类型

**多主角轮换——每个人=一个诅咒石的故事**。Paranormasight有多个可操控主角——兴家彰吾(Shogo)、约子(Yoko)、春惠(Harue)、津诘(Tetsuo)、八子(Yakko)——每个持有一种诅咒石。他们在并行的时间线中与不同的"本所七大不可思议"诅咒对抗。

**最独特的设计**：游戏有一个meta层的"叙事者"（故事讲述者）——一个屏幕前的人正在对你（玩家）讲述这些故事。"叙事者的存在暗示'这些事件是被讲述的——不一定是正在发生的'"。这让玩家始终在"相信"和"怀疑"之间悬置。

### 1.2 多主角弧线类型

| 主角 | 诅咒石 | 核心冲突 | 弧线类型 |
|:--:|------|------|:--:|
| **兴家彰吾** | 低语渠 | 朋友约子被杀——"我会用一切手段让她复活——即使杀人" | **悲伤驱动**——"因爱堕入黑暗" |
| **春惠** | 太鼓诅咒 | 儿子被绑杀——"我儿子死了——我丈夫不付赎金——我要让害他的人烧死" | **复仇驱动**——"母亲的愤怒。最炽热的复仇是最冷的等待" |
| **津诘** | 不使用诅咒石 | 警察——"我不会用诅咒石——即使这让我永远无法达成好结局" | **道德坚守**——"选择不杀人——即使代价是自己的幸福。他的'好结局'里他的生活不完整——他牺牲了自己" |
| **八子** | 愚者游行 | 高中生——调查朋友Michiyo的"自杀"——被朋友灵魂附身逼到杀人边缘 | **纯真被污染**——"最年轻=最容易被操控。她的善良是她的弱点" |

## 二、角色属性与能力设计 — 诅咒石=道德属性

| 诅咒石 | 触发条件 | 道德困境 |
|:--:|------|------|
| **低语渠** | 受害者转身离开→溺死 | "我杀的人——我没看到他们的脸——这让我更容易吗？" |
| **太鼓诅咒** | 受害者身上有火焰→烧死 | "烧死一个人——不需要碰他——只需要火——但他死前的尖叫——你听到了" |
| **愚者游行** | 歌曲触发——受害者转身→中断 | "杀人是仪式——但仪式可以被中断——如果你选择不完成" |
| **单侧芦苇** | 必须知道受害者的全名/年龄/脸/地址/职业/位置 | **"最残忍的诅咒——需要最亲密的了解——这不是'杀戮'——这是'背叛'"** |
| **足洗邸**(祖传·Ashino) | 听到触发声音→无法逃脱的死亡 | **约子的祖传诅咒——"在我出生前——它就属于我的家族"** |
| **诱灯**(祖传·Seinen) | 本能/自卫触发——杀死**诅咒者自己** | **"诅咒的反噬——你用的'武器'最终指向你自己"** |

**诅咒石=道德属性**：每个诅咒石不是"武器"——它是**"杀人需要什么条件——以及你能承受什么代价"的伦理问题**。低语渠="不看被害者的脸=道德distancing"。太鼓="火不是你点的——你是按按钮的人——但这个人还是你杀的"。单侧芦苇="最亲密的背叛——需要知道一个人的一切才能杀他。"

### Story Chart系统——叙事选择=属性切换

与传统VN的连续叙事不同，Paranormasight使用**Story Chart**系统——一个可视化的叙事流程图。你可以在不同主角的路线间切换——一个路线被卡住时——切换到另一条路线推进——解锁前一条路线的进展。这不是"选择分支"——是**"多条并行时间线——你的认知跨线累积"**。

## 三、角色魅力分析

### 3.1 兴家彰吾 — "平凡人堕入黑暗"

**魅力来源：他不是英雄——他是"如果我的朋友死了——我也会这样做"的普通人。**

- 普通上班族——冲动——不成熟——但被悲伤驱动。"我想让她复活——我会做任何事——即使我知道她在天之灵不会同意。" 他的堕落不是"邪恶"——是**"悲伤让人不再在乎对错"**。

### 3.2 约子 — "受害者的另一面"

约子是游戏中最复杂的角色——表面是"被杀的朋友"——实质是**诅咒游戏的幕后策划者**（Ashino的后裔——拥有祖传的"足洗邸"诅咒）。她在游戏开始之前就杀了Hajime（Seinen的后裔）——用一个复杂的心脏病诅咒。

她的魅力来自"受害者=加害者"的双重身份。"我想要复活某个人——所以我策划了这一切——包括我自己的'假死'——来让其他人进入诅咒游戏。"

> 与**《极限脱出999》茜**对比：茜=Zero——为了自我保存设计了整个游戏。约子=为了复活某人——也是为了自我。但茜的动机是"9岁的我在焚化炉里——不这样做就会死"——约子没有同等程度的紧迫性——她的动机更"冷"。茜让人心疼——约子让人不寒而栗。

### 3.3 春惠 — "母亲的愤怒是最炽热的火焰"

她的太鼓诅咒=烧死。她的儿子被绑杀——丈夫拒绝付赎金。"我的儿子死了——让我告诉你——母亲的火——烧得比任何火都久。"

### 3.4 八子 — "最年轻——最容易被操控"

高中生——调查朋友Michiyo的"自杀"。被死去的朋友灵魂附身——被逼到杀人边缘。"Michiyo说'帮我报仇'——但我不知道——我该听她的——还是该让她安息？"

## 五、反派/对手设计 — 诅咒本身=反派

Paranormasight没有单一的人格化反派——"反派"是**诅咒石系统本身**。诅咒石不区分"好人"和"坏人"——它给任何人杀人的能力——然后等待被使用。"系统的恶"不是"操纵人们做坏事"——是**"给人们做坏事的能力——然后不做任何事来阻止他们"**。

这一点与《苏丹的游戏》的卡牌系统同源——但苏丹的游戏是"卡牌被强塞给你——你被迫使用它们"——Paranormasight是**"诅咒石在你手中——你不需要用——但你想用"**。

```
       约子(Ashino后裔/策划者)
       /  |  \
      /   |   \
  彰吾  春惠  八子
  (悲伤) (愤怒) (纯真)
    |      |     |
  低语渠 太鼓  愚者
    |      |     |
  都想复活  都想复仇  都被附身
       \    |    /
        \   |   /
```

津诘是唯一的"旁观者"——他不使用诅咒石——但他看着其他人一个个被诅咒吞噬。"我的'不行动'=我在承担别人行动的所有后果。"

## 七、设计启示

### 7.1 meta叙事层——"谁在讲这个故事？"

Paranormasight的"叙事者"框架——暗示整个游戏可能是一本"讲述中的故事"——为"诅咒是否真实"提供了终极的模糊性。与《幽灵诡计》的一夜框架对比——幽灵诡计的"一夜"是物理的——Paranormasight的"故事=被讲述中"是meta的。前者压缩时间——后者质疑现实。

### 7.2 Story Chart——"跨线认知"

Story Chart系统让"在不同主角路线间切换"成为一个机制化的叙事工具。你被卡在彰吾的路线→切换到八子的路线→获取新信息→回到彰吾的路线解锁进展。**"认知是跨角色的——信息在你脑中——不在任何单个角色的脑中"**。

### 7.3 跨游戏对比总结

| 维度 | Paranormasight | 极限脱出999 | 人狼村之谜 |
|:--:|:--:|:--:|:--:|
| **主角结构** | 多主角轮换+Story Chart | 单主角(淳平)+密室组队 | 单主角(房石)+轮回 |
| **核心机制** | 诅咒石=道德工具 | 数字根=数学锁定 | 狼人杀角色=社会规则 |
| **meta层** | 叙事者框架——"故事被讲述" | 形态形成场——"你=跨时间连接" | 无meta——直接轮回 |
| **反派** | 诅咒系统本身 | 受害者=反派(茜) | "正确性"=人造的信仰 |
| **核心情感** | "你会用诅咒石吗？" | "我被我想保护的人操纵" | "规则是假的——人性是真的" |
