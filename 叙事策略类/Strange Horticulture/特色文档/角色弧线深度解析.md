# 角色弧线深度解析 — Strange Horticulture

> 游戏版本: Strange Horticulture v2022 (PC/Switch/macOS/Xbox) | 开发商: Bad Viking (兄弟二人团队) | 销量: 75万 | Steam: 95% | IGF最佳设计提名
> 数据来源: [GameDeveloper设计访谈](https://www.gamedeveloper.com/design/finding-right-plant-job-strange-horticulture), [TechRaptor评测](https://techraptor.net/gaming/reviews/strange-horticulture-review), [Nintendo Life](https://www.nintendolife.com/reviews/switch-eshop/strange-horticulture), [Wikipedia](https://en.wikipedia.org/wiki/Strange_Horticulture)

## 一、主角设计分析 — "功能性空白园艺师"

### 1.1 主角类型

**极致功能化空白主角**。你不被给予名字、面孔、性别、声音——你是"园艺师"——你继承了叔叔在Undermere镇的植物店。你的身份由你的**行动**定义：你鉴定77种植物——你给谁什么植物——你选择毒死谁——选择救谁。

与Papers Please相同原理："空白"=最大化道德投射。但区别在于：检查员在**体制内**被限制（规则每天更新，罚款处罚偏离行为）——园艺师在**店内**拥有完全的知识权力和控制。**"你不知道我是谁——但你来找我——因为我知道哪株植物能救你——或杀你。你来求助——我决定你的命运。"**

### 1.2 Want vs Need

| 层面 | 内容 |
|:--:|------|
| **表层欲望** | 经营植物店——帮顾客找到正确的植物——解开叔叔留下的谜团 |
| **深层需求** | **在知识=权力的世界中——定义'我是为了保护还是为了控制？'** 每一株植物可以是药或毒——每一次递给顾客=你选择了"帮他们"还是"利用他们"或者"摧毁他们" |
| **玩家投射** | 你不是"扮演园艺师"——你是**"在镜子里看到自己的道德选择"**。8种结局——每一种反映了你是什么样的园艺师 |

## 二、角色属性与能力设计 — 植物图鉴=唯一的成长系统

### 2.1 77种植物——识别=知识=力量

| "属性" | 机制 | 叙事意义 |
|:--:|------|------|
| **植物知识** | 图鉴逐渐填满——从几株到全部77株。每株有标签/素描草图/嗅觉线索/描述文字——你需要交叉比对来识别 | 你的"智力"不是等级——是**你翻了多少页图鉴、你记住了多少植物的特征、你能在多模糊的线索中找出正确的那一株** |
| **标签系统** | 你**手动**为每株植物创建标签——组织你自己独有的知识体系 | **"知识管理=核心玩法"**——你的组织能力=你的最强属性。没有自动排序——你的混乱或秩序是你的选择 |
| **地图探索** | 谜题→地图坐标→新地点→新植物/新图鉴页面 | 植物发现=空间推理。你从不离开店铺——但你的**认知**覆盖了整个Undermere |
| **调制药剂** | 多植物混合——需要同时识别多种植物 | 复杂药剂的调配=高级"技能检定"——错误=药剂无效或副作用 |

### 2.2 "你从不离开店铺"——空间作为属性约束

全部游戏在植物店内发生。地图、信件、访客——是世界的全部呈现方式。设计意图：
- **"一窗之隔=整个世界"**——Papers Please的检查亭——你看到的是"面孔+文件"。这里是"植物+面孔+信件"。
- **知识的不移动=权力的不移动**——你不需要移动——因为所有人都需要来找你——你是Undermere信息的交汇点
- **"静"让你有更多时间观察**——不是观察窗外——是**观察每一株植物的细节**。"这张花瓣的曲线——像不像图鉴上那一株？"

### 2.3 "空白主角+具体工具"范式

与Papers Please的"空白检查员+印章"同样的设计范式：**角色越空白——赋予角色的工具越具体——工具本身承载了所有的角色表达**。印章=APPROVED/DENIED——植物=治愈/毒杀/控制/解放。

## 三、角色魅力分析

### 3.1 园艺师 — "沉默的点灯人"

**魅力来源：你不说话——但你的植物说了所有的话。**

| 魅力要素 | 具体表现 | 为什么有效 |
|:--:|------|------|
| **视觉缺席** | 没有面孔/名字/声音——你只有一双手+植物架+一盏灯 | 最大的投射空间——没有预设外表——你的样子是你心中的自己 |
| **核心魅力** | 你是一个"信息节点"——每个人来店里**需要你**——但不是因为你"厉害"——是因为**你的叔叔留下了这些植物的知识——而你是他选定的继承人** | "继承知识=继承责任"——你不是因为"强"而被需要——是因为"知道" |
| **道德孤独** | 你独自在店里做所有决定。没有人看你——没有人审判你。**"给植物=给命运"——然后下一个人来敲门** | 最深的孤独不是"没有人"——是**"有人——但没有人知道你做了什么"** |

### 3.2 Hellebore — "店里唯一的常驻灵魂"

Hellebore是植物店的猫——你可以抚摸它（它会打呼噜）。在一个充满性命攸关选择的游戏中——有一只猫——只是存在——不在乎你做了什么。"Hellebore不是角色——它是**见证者**。它是唯一知道每一株植物给了谁的东西——但它只是一只猫。"

### 3.3 访客群像 — "每个叩门=一道道德题"

| 访客 | 代表的选择类型 |
|------|------|
| **Simone**（图书管理员） | 知识的盟友——"帮她=帮自己获取更多信息" |
| **Faye**（通灵师） | 超自然vs理性——"她的幻觉是真实的吗？" |
| **Ennis Aleford**（"救赎种子"教派的隐士） | 狂热信仰——"给他毒草=他在尝试召唤邪物——不给他=他会找别人" |
| **Reuben Ward**（调查员） | 秩序vs正义——"他在查同一件事——但他是执法者——你信任执法者吗？" |
| **翡翠面具女人** | 谜团本身——"她是谁？她想要什么？给她想要的——后果是什么？" |
| **Bethany Coleman**（阿杜因娜姐妹会） | 姐妹情谊——"她们是好人吗？还是另一个教派？" |

## 四、关键配角分析

**Arduinna姐妹会 vs "救赎种子"教派**——Undermere的两大势力。你的植物可以在两者间"倾斜"——一株治伤的植物给姐妹会="她们多了一个战士"——一株毒草不交给调查员="凶手多跑了24小时"。**你选谁=你在Undermere的权力网络中选择了立场。**

---

## 五、反派/对手设计 — "没有反派——有无知"

Strange Horticulture没有传统反派。"对手"不是个人——是**"知识的不完整"**。你不知道哪株植物正确——你不知道访客的真实意图——你不知道叔叔为什么留下这些植物。"无知=你唯一的敌人——知识=你唯一的武器。"

与Papers Please的"体制之恶"和苏丹的游戏的"暴君系统"不同——Strange Horticulture的"恶"是**不确定性本身**。"如果这个人真的是好人——我拒绝帮助他=我害了他。如果他是坏人——我帮助他=我害了更多人。**我不知道——我只能猜。**"

## 六、角色关系网络 — "以店为中心的全镇星图"

```
        园艺师(店铺中心)
        /  |  |  |  \
       /   |  |  |   \
  Simone Faye Ennis Reuben 翡翠面具
 (知识) (直觉) (狂热) (秩序) (谜)
```

所有关系=**"谁来找你——你要给他们什么植物"**。没有"好感度系统"——没有"对话树"。关系由**植物传递**——"我给了你一株治头痛的草——你是感激还是失望？"

## 七、设计启示

### 7.1 "知识=权力的唯一形式"——店铺作为叙事空间

Strange Horticulture证明了：**"从不离开一个房间"可以承载完整的叙事世界**。77种植物+地图+信件+访客=整个Undermere。"不需要3D开放世界——只需要一扇门——和愿意来敲门的人。"

### 7.2 "识别=叙事选择"——将物品鉴定做成道德系统

在大多数游戏中——"识别物品"是纯机制操作（鉴定卷轴→物品名称出现）。在Strange Horticulture中——鉴定一株植物=**"你现在知道了它能做什么——接下来你决定用它做什么"**。识别=道德能力——不是机制buff。

### 7.3 跨游戏对比总结

| 维度 | Strange Horticulture | Papers, Please | 苏丹的游戏 |
|:--:|:--:|:--:|:--:|
| **主角类型** | 极致功能化空白 | 完全空白 | 半空白 |
| **核心工具** | 77种植物=药/毒 | 印章=通过/拒绝 | 四种卡牌=道德驱动力 |
| **空间设计** | 从不离开店铺——店内=世界 | 从不离开检查亭——窗口=世界 | 宫廷/城内——多地点移动 |
| **属性系统** | 植物图鉴=知识积累 | 规则书=每天更新 | 卡牌品级=社会阶级 |
| **道德机制** | "给谁什么植物——你就是什么人" | "盖章决定命运——不解释" | "你可以作恶——善才有意义" |
| **反派** | 无知/不确定性 | 体制（你是体制一部分） | 去角色化暴君 |
