# 角色弧线深度解析 — 珊瑚岛(Coral Island)

> 游戏版本: Coral Island v1.0 (PC/PS5/Xbox, 2023正式版) | 开发商: Stairway Games(印尼团队) | Kickstarter: $160万(目标$7万) | 星露谷精神继承者
> 数据来源: [Screen Rant评测](https://screenrant.com/coral-island-pc-review/), [eXputer评测](https://exputer.com/reviews/coral-island/), [Cozy Game Reviews](https://cozygamereviews.com/coral-island-review/), [Vulcan Post](https://vulcanpost.com/808700/review-coral-island-indonesian-farming-simulator-game/), [UC学术期刊](https://journal.uc.ac.id/index.php/VCD/article/download/5618/3271/19844)

## 一、主角设计分析 — "热带空白农夫"

### 1.1 主角类型：空白主角——星露谷的3D热带延伸

继承星露谷的空白农夫模板——但加入了显著更多样的自定义选项：**性别选项包括非二元——身体形状/发型/肤色——比矿石镇更接近现代标准。"你是厌倦城市生活的人——来到珊瑚岛继承一片荒地——然后海洋召唤你去清理它。"** [源：Screen Rant](https://screenrant.com/coral-island-pc-review/)

### 1.2 海洋保护=角色的道德驱动力

与星露谷的社区中心不同——珊瑚岛的核心叙事=**海洋保护**。"你不只是'种田'——你在'清理海洋垃圾/恢复珊瑚礁'。Kickstarter活动中游戏捐赠了$87,500给真实的珊瑚恢复慈善组织Coral Guardian——将'环保叙事'延伸到'真实世界的影响'。" [源：eXputer](https://exputer.com/reviews/coral-island/)

## 二、角色属性与能力设计

### 2.1 70+NPC——28位可攻略(含2位人鱼)

Cozy Game Reviews：**"28位可攻略角色包括2位Merfolk（人鱼）——居住在海底的人鱼王国——20位人鱼NPC——有自己的语言和任务线。"** [源](https://cozygamereviews.com/coral-island-review/)

### 2.2 身体多样性——品类中罕见的包容性

Screen Rant记录：**"角色显示妊娠纹、伤疤、腋毛、不同的身体形状/尺寸——在品类中是罕见的。手绘角色肖像——季节更换服装（可攻略对象=每年4套）。"** [源](https://screenrant.com/coral-island-pc-review/)

### 2.3 印尼文化——被低估的"隐性"呈现

UC学术期刊对印尼玩家进行了调查：**"90.6%的印尼玩家识别了文化元素——建筑/景观最被注意(56.3%)——角色设计(21.9%)。但外国玩家经常错过这些线索——因为游戏的'微妙'、非显式的方法——被视为优势（普适吸引力）也是劣势（遗产价值在翻译中丢失）。"** [源](https://journal.uc.ac.id/index.php/VCD/article/download/5618/3271/19844)

## 三~七、设计启示

### "海洋维度=品类中最独特的'第二空间'"

珊瑚岛的最大贡献是在传统牧场品类的"地面+矿井"双层空间上——增加了**第三层：水下**。"潜水的体验—清理垃圾—恢复珊瑚礁—解锁更深水域—最终到达人鱼王国—水下耕作。这不是'捕鱼小游戏'——这是一个独立的第二世界。" [源：Vulcan Post](https://vulcanpost.com/808700/review-coral-island-indonesian-farming-simulator-game/)
