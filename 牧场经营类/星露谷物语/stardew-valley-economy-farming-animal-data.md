# 经济、种植与畜牧历史汇总迁移索引

> 状态：**历史迁移索引，不是数值数据源**
>
> 审计基线：PC v1.6.15；本页不再维护价格、作物、动物、机器、工具或职业的数值副本。

## 一、为什么迁移

旧稿把经济、作物、加工、畜牧、工具和职业数据混在同一文件中，存在三个无法验收的问题：

1. 使用阶段推荐、收益示例和部分对象表代替全集定义；
2. 没有固定版本、预计条目数、实际条目数、字段完整率和来源 revision；
3. 与机制分析及数值数据目录重复维护，同一条数据可能产生多个不同答案。

因此，旧数据正文已停止维护并从当前阅读路径移除。历史版本仍保留在 Git 记录中；需要追溯旧稿时应查看文件历史，不应复制旧表恢复为现行数据。

## 三、阅读规则

- 查具体对象、数值或字段时，只使用上表中的数值数据文档。
- 查流程、公式语义和系统关系时，使用对应机制文档，再通过文内链接进入唯一数据源。
- 当前入口标记为“采集中”时，不得用本历史索引或 Git 旧稿填补结论。
- 新增数据域时，应更新游戏概览、审计记录和对应专用审计器，而不是重新扩写本文件。
