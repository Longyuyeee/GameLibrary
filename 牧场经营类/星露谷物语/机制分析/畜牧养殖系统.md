# 星露谷物语畜牧养殖系统

> 适用版本：PC v1.6.15
>
> 数据边界：本文解释动物照料、产出判定和经营流程，不重复维护动物名册、产品价格或逐动物参数。完整数据见[动物与动物产品数据总览](../数值数据/动物数据总览.md)，加工结果见[加工配方数据总览](../数值数据/加工配方数据总览.md)。
>
> 机制来源：[Animals revision 193812](https://stardewvalleywiki.com/mediawiki/index.php?title=Animals&oldid=193812)、[Modding:Animal data revision 188878](https://stardewvalleywiki.com/mediawiki/index.php?title=Modding:Animal_data&oldid=188878)

## 1. 系统边界与数据入口

畜牧循环由六个相互独立的判定组成：

1. 动物是否已经成年；
2. 当天是否满足生产间隔；
3. 是否进食、心情是否允许生产；
4. 是否进入“大型/高级产品”判定；
5. 产品品质判定；
6. 收集、加工或出售。

完整数据按唯一归属拆分：

| 数据集合 | 唯一入口 | 本文是否重复列全表 |
|---|---|:--:|
| 14 个农场动物展示变体、11 个动物类型详情 | [动物数据总览](../数值数据/动物数据总览.md#快速索引) | 否 |
| 15 个原始动物产品、全部品质/售价/用途 | [动物数据总览](../数值数据/动物数据总览.md#快速索引) | 否 |
| 宠物礼物 3 个池、48 条概率记录 | [Animals 主名册与规则原文](../数值数据/动物数据总览.md#animals-主名册与规则原文) | 否 |
| 蛋黄酱、奶酪、布料、松露油等加工结果 | [加工配方数据总览](../数值数据/加工配方数据总览.md) | 否 |
| 动物数据字段、默认值和可扩展参数 | [Animal data 字段定义](../数值数据/动物数据总览.md#animal-data-字段定义) | 否 |

这样可以避免旧文档中同一个价格、产出间隔或公式出现多个互相冲突的版本。

## 2. 好感度

鸡舍与畜棚动物的好感度范围为 0–1,000；每半颗心对应 100 点，五颗心为 1,000 点。它会影响大型/高级产品、品质和出售价格。

### 2.1 每日变化

| 行为 | 好感度变化 | 说明 |
|---|---:|---|
| 抚摸 | +15 | 对应鸡舍/畜棚职业生效时为 +30 |
| 挤奶或剪毛 | +5 | 未挤奶、未剪毛本身没有额外惩罚 |
| 户外吃普通草 | +8 | 蓝草为 +16 |
| 未进食 | -20 | 日终结算 |
| 被关在室外过夜 | -20 | 日终结算 |
| 当天未抚摸/交谈 | `-(10 - 好感度 / 200)` | 日终结算；当前好感越高，损失越小 |

宠物使用另一套好感规则：上限同为 1,000，每日抚摸 +12；给宠物碗加水会在次晨 +6（次晨下雨时不触发）；没有独立宠物碗时每晚 -10。猫、狗和乌龟的完整礼物概率见[宠物礼物数据](../数值数据/动物数据总览.md#animals-主名册与规则原文)。

## 3. 心情

心情范围是 0–255，只在每天开始计算动物产品时参与产出类型和品质判定。

| 对话状态 | 心情范围 |
|---|---:|
| “今天看起来非常开心” | 200–255 |
| “看起来还好” | 30–199 |
| “看起来很伤心” | 0–29 |

主要变化如下：

- 户外吃到草会把心情直接设为 255。
- 抚摸增加 32–36，具体值取决于动物类型；对应职业会使该增量翻倍。
- 冬季在有加热器的区域且心情至少 150 时，18:00 后玩家每保持清醒 10 分钟增加 4–8，最高 255。
- 进食在睡眠结算时增加 4–16，具体值取决于动物类型。
- 雨雪、冬季仍在室外或 19:00 后仍在室外，每 10 分钟降低 4–8。
- 室外过夜会在睡眠结算时损失当前心情的一半；未抚摸损失 20–40；未进食损失 100。

具体动物的 `HappinessDrain`、生产间隔和职业字段见[动物类型详情](../数值数据/动物数据总览.md#快速索引)。

## 4. 生产判定

### 4.1 基础门槛

动物必须成年并达到自己的生产间隔。随后依次检查：

- 未进食：不生产。
- 心情低于 70：仍可能生产，概率为 `心情 / 70`。
- 心情至少 150：获得参与品质和大型/高级产品判定的资格。
- 心情低于 150：仍可能获得上述资格，概率为 `心情 / 150`。

有一个容易遗漏的特殊情况：需要多天生产一次的动物，如果当天满足生产间隔、但没有获得品质/大型产品判定资格，游戏不会登记这次生产；它次日会立即再次尝试，而不是重新等待完整间隔。

### 4.2 心情修正值

大型/高级产品判定先计算心情修正值：

```text
心情 > 200：心情修正值 = 心情 × 1.5
100 < 心情 <= 200：心情修正值 = 0
心情 <= 100：心情修正值 = 心情 - 100
```

### 4.3 大型产品

只有好感度至少 200 的动物能生产大型产品。

```text
大型产品分数 = (好感度 + 心情修正值) / 1200
```

每次用该分数与 `[0, 1)` 随机数比较；分数更大则产生大型产品，分数达到或超过 1 时必定成功。

### 4.4 鸭毛与兔子的脚

鸭和兔的高级产品额外受每日运气影响：

```text
鸭毛分数       = (好感度 + 心情修正值) / 4750 + 每日运气
兔子的脚分数   = (好感度 + 心情修正值) / 5000 + 每日运气
```

每次同样与 `[0, 1)` 随机数比较。产品自身的完整价格、用途和来源见[鸭毛](../数值数据/动物数据总览.md#page-duck-feather)与[兔子的脚](../数值数据/动物数据总览.md#page-rabbit-s-foot)。

## 5. 品质判定

获得品质判定资格后，计算：

```text
品质分数 = (好感度 / 1000) - (1 - 心情 / 225)
```

鸡舍大师对鸡舍动物、牧羊人对畜棚动物额外增加 `0.333`。判定顺序不能打乱：

1. 分数大于 0.95 时，若 `分数 / 2` 大于随机数，得到铱星。
2. 未得到铱星时，若 `分数 / 2` 大于新的随机数，得到金星。
3. 未得到金星时，若分数大于新的随机数，得到银星。
4. 其余情况为普通品质。

这不是一个把四种品质百分比直接相加的单次抽签，因此不能用旧文档中的经验分布表代替逐级判定。

金色动物饼干可以永久把大多数农场动物的正常产量翻倍；猪不能食用。每个动物类型是否允许使用由 `CanEatGoldenCrackers` 字段决定。

## 6. 喂食、住房与外出

- 鸡舍和畜棚动物每天需要一个“食物份额”，可来自鲜草或干草。
- 鸡舍动物吃普通草需要 2 簇，蓝草 1 簇；畜棚动物分别需要 4 簇和 2 簇。
- 新购、刚孵化或刚出生的动物到达当天不需要进食；幼崽之后若未进食，当天不会成长。
- 冬季以及雨、雷暴、雪天不会主动外出。豪华鸡舍/畜棚的自动喂食器只负责把干草放上饲料槽，不等于自动抚摸或自动收集。
- 史莱姆屋的史莱姆不吃饲料；水槽有水时，次日生成史莱姆球。宠物和马不需要进食。

完整建筑、购买要求和每种动物的住房字段随动物固定页保留在[动物数据总览](../数值数据/动物数据总览.md)。

## 7. 室外过夜、野兽袭击与繁殖

动物通常在 18:00 前返回建筑。门已关闭且动物留在室外时，才进入野兽袭击候选：没有其他夜间事件时，游戏有 50% 概率尝试袭击，再按农场建筑数量逐栋筛选；一旦选中建筑，会移除其中第一只留在室外的动物。

繁殖也只在没有其他夜间事件时以 50% 概率进入尝试。目标必须是未满员的升级畜棚；通过建筑筛选的概率为建筑内动物数乘以 `0.55%`，随后从可怀孕、已成年的动物中选择。

这两种事件都不是简单的“每天固定概率”，不能忽略夜间事件、门状态、建筑和动物条件。

## 8. 出售与自动化

农场动物出售价格为：

```text
出售价格 = 数据中的基础出售值 × (好感度 / 1000 + 0.3)
```

因此倍率从零好感的 0.3 逐步增加到满好感的 1.3。各动物固定页同时保留购买价和五心出售值，见[动物快速索引](../数值数据/动物数据总览.md#快速索引)。

自动化设备承担不同职责：自动喂食器放置干草，自动采集器收取符合条件的产品，自动抚摸机处理每日自动互动。它们不会把所有手动收益和判定合并为一个“全自动无损”状态；具体获得方式和效果应回到对应设备固定页，而不是在本文复制易过期价格表。

## 9. 经营阅读路径

1. 先在[动物名册](../数值数据/动物数据总览.md#animals-主名册与规则原文)确认住房、购买条件和直接产物。
2. 点击动物详情页核对成熟时间、生产间隔、收集方式和高级产品门槛。
3. 点击产品详情页核对全部品质价格、用途和任务/收集需求。
4. 需要加工时跳转到[加工机器全集](../数值数据/加工配方数据总览.md)，不要用原料价替代加工产值。
5. 最后根据好感、心情、喂食和生产间隔设计每日流程。
