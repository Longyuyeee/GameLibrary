## 1. 时间流速与昼夜机制

### 1.1 时间流速

| 项目 | 数据 |
|------|------|
| 1游戏分钟(1 Game Minute) | ≈ 0.7现实秒(Real Seconds) |
| 1游戏小时(1 Game Hour) | ≈ 42现实秒 |
| 全天(6:00 AM ~ 2:00 AM) | ≈ 13.5~14现实分钟 |
| 游戏内每日开始时间 | 6:00 AM |
| 强制昏倒时间 | 2:00 AM |
| 每日总时长 | 20游戏小时(1,200游戏分钟) |
| 存档时机 | 仅睡觉后 |

### 1.2 时间消耗参考

| 活动 | 时间消耗 |
|------|---------|
| 使用工具(锄/镐/斧/水壶) | 约2-3秒/次 |
| 钓鱼(上钩-完成) | 约15秒~2分钟 |
| 进入/离开建筑 | 约2-3秒 |
| 购买物品(商店界面) | 时间暂停 |
| 菜单操作 | 时间暂停 |
| 对话/剧情 | 时间暂停 |
| 节日活动 | 多数封闭式节日停止流逝；沙漠节、鳟鱼大赛、鱿鱼节和夜市继续走时 |
| 矿洞/骷髅洞穴 | 时间与外界同步 |
| 火山地牢 | 时间与外界同步 |

### 1.3 昏倒机制

| 触发 | 本页保留的时间口径 | 完整数值规则 |
|------|------------------|-------------|
| 2:00 AM仍未入睡 | 当天被强制结束；若角色在农舍外，按“迟睡/精力透支昏倒”规则结算金币 | [精力固定源：昏倒条件与金币上限](../数值数据/角色属性战斗数据总览.md#source-energy) |
| 当前精力降到 −15 | 立即昏倒；它与2:00 AM强制结束共用精力页的昏倒结算，不应写成“无金币损失” | [精力固定源](../数值数据/角色属性战斗数据总览.md#source-energy) |
| 当前生命值降到 0 | 属于战斗失去意识，不属于时间昏倒；物品与金币惩罚也不同 | [生命固定源：失去意识规则](../数值数据/角色属性战斗数据总览.md#source-health) |

> 本页只说明时间触发关系；生命、精力、疲惫、金币与物品惩罚的完整规则以[角色属性战斗数据总览](../数值数据/角色属性战斗数据总览.md#关键数值闭合与旧稿纠错)为唯一数据源。

## 2. 精力、疲惫与睡眠恢复

本页只保留精力与时间推进之间的关系，不再复制会随数据审计更新的角色数值表。

| 时间系统关注点 | 口径 | 唯一数据源 |
|--------------|------|-----------|
| 当前精力与最大精力 | 工具行动消耗当前精力；最大精力、临时上限与恢复值属于角色数据 | [精力固定源](../数值数据/角色属性战斗数据总览.md#source-energy) |
| 疲惫与昏倒 | 精力到 0 进入疲惫，继续降到 −15 昏倒；准确惩罚见固定源 | [疲惫、昏倒与恢复规则](../数值数据/角色属性战斗数据总览.md#source-energy) |
| 入睡时间 | 12:10 AM起按固定档位降低次日精力；12个时间档位不得用约数代替 | [完整睡眠惩罚表](../数值数据/角色属性战斗数据总览.md#source-energy) |
| 恢复方式 | 睡眠、食物、饮料、温泉及升级工具消耗的精确规则均由精力固定源维护 | [精力固定源](../数值数据/角色属性战斗数据总览.md#source-energy) |
| 星之果实 | 永久最大精力的增量与闭合结果见角色数据；具体获取对象由相应节日、矿洞、关系、商店、钓鱼和博物馆文档维护 | [关键数值闭合](../数值数据/角色属性战斗数据总览.md#关键数值闭合与旧稿纠错) |

> 数据边界：时间系统负责“何时触发”；角色属性文档负责“触发后的完整数值与公式”；可烹饪料理/饮料的恢复量由烹饪数据文档维护，非配方消耗品与工具的逐件数值由道具装备数据文档维护。

## 3. 四季系统

### 3.1 四季总览

| 季节 | 天数 | 日落时间 | 特色采集物 | 可种植作物 | 节日数 |
|:----:|:----:|:--------:|:----------:|:----------:|:------:|
| 春季(Spring) | 1-28 | 7:00 PM | 6种(含树莓季) | 12+种 | 3(含1.6新增) |
| 夏季(Summer) | 1-28 | 7:00 PM | 5种 | 14+种 | 3 |
| 秋季(Fall) | 1-28 | 6:00 PM | 7种(含黑莓季) | 12+种 | 2 |
| 冬季(Winter) | 1-28 | 5:00 PM | 5种 | 3种(仅冬季种子) | 4（共 7 个活动日） |

### 3.2 季节特色事件

| 季节 | 特色事件 | 时间 |
|:----:|---------|:----:|
| 春季 | 美洲大树莓(Salmonberry)采集季 | 春15-18 |
| 春季 | 第1年春3必定雨天(剧情) | 春3 |
| 夏季 | 避雷针收集电池组旺季(暴风雨多) | 夏13和26必定暴风雨 |
| 秋季 | 黑莓(Blackberry)采集季 | 秋8-11 |
| 秋季 | 罗宾/刘易斯特殊任务板解锁 | 第1年秋2 |
| 冬季 | 无法种植常规户外作物 | 全季 |
| 冬季 | 冬季之星(Winter Star)庆典准备 | 全季 |
| 冬季 | 夜市(Night Market) | 冬15-17 |

### 3.3 季节经济影响

| 季节 | 主要收入来源 | 经济建议 |
|:----:|------------|---------|
| 春季 | 采集(树莓)、钓鱼、草莓种植 | 春13蛋蛋节大量购买草莓种子 |
| 夏季 | 农耕(蓝莓/杨桃/啤酒花)、钓鱼 | 大规模种植，工匠设备加工 |
| 秋季 | 农耕(蔓越莓/南瓜)、采集(黑莓) | 温室解锁前最后一季户外种植 |
| 冬季 | 采矿、钓鱼、畜牧、温室/姜岛作物 | 集中资源进行矿井探索和工具升级 |

### 3.4 跨季作物

以下作物可跨季节存活：

| 作物 | 生长季节 | 种植策略 |
|------|---------|---------|
| 玉米(Corn) | 夏季+秋季(14天生长期，每4天复收) | 夏1种植可持续到秋28 |
| 上古水果(Ancient Fruit) | 春季+夏季+秋季(28天生长期，每7天复收) | 温室/姜岛最佳，户外春1种植 |
| 咖啡豆(Coffee Bean) | 春季+夏季(10天生长期，每2天复收) | 春1种植可持续到夏28 |
| 小麦(Wheat) | 夏季+秋季(4天生长期) | 夏1或秋1种植均可跨季 |

## 4. 年份机制

### 4.1 各年份新增内容

| 年份 | 新增内容 | 说明 |
|:----:|---------|------|
| **第1年** | 基础体验 | 春季第3天固定下雨，逐步解锁所有区域，社区中心建设 |
| **第2年** | **肯特(Kent)回归** | 春季第4天出现在镇上(战后回家) |
| | 作物价格变化 | 部分作物种子价格调整，皮埃尔出售更多种类 |
| | 木料/石材涨价 | 木材10g→50g，石材20g→100g(罗宾处购买) |
| | 新的作物种子 | 大蒜(Garlic)、红叶卷心菜(Red Cabbage)、洋蓟(Artichoke)等解锁 |
| | 混合种子(Mixed Seeds)可产出更多品种 | — |
| **第3年** | **爷爷的评分(Grandpa's Evaluation)** | 春季第1天鬼魂出现进行评估 |
| **无年份上限** | 游戏可无限进行 | 第3年后无额外新增内容 |

### 4.2 游戏阶段划分

| 阶段 | 时间范围 | 特征 |
|:----:|---------|------|
| **前期** | 第1年春季~夏季 | 熟悉游戏，基础工具升级，初期资金积累 |
| **中期** | 第1年秋季~第2年夏季 | 社区中心完成，工匠设备投产，温室解锁，矿井探索 |
| **后期** | 第2年秋季之后 | 骷髅洞穴深入，姜岛探索，大规模自动化生产，完美追求 |
| **终局** | 100%完美(Perfection) | 全部技能10级+精通，完全体农场，所有成就 |

| 机制组 | 活动 | 时间与日常规则 | 完整数据入口 |
|---|---|---|---|
| 封闭式节日 | 复活节、花舞节、夏威夷宴会、月光水母起舞、星露谷展览会、亡灵节、冰雪节、冬日星盛宴 | 进入独立活动场景后时间不再推进；商店与住宅按节日规则关闭，动物不需要喂食 | [全年活动名册](../数值数据/节日活动数据总览.md#全年活动名册12-个活动-18-个日期) |
| 连续世界活动 | 沙漠节、鳟鱼大赛、鱿鱼节、夜市 | 世界时间照常推进；商店与住宅不因活动统一关闭，动物仍需喂食 | [连续活动例外原文](../数值数据/节日活动数据总览.md#source-festivals) |

## 7. 天气系统

### 7.1 天气类型总表

| 天气类型 | 英文名 | 出现季节 | 出现概率 | 效果 |
|---------|--------|:--------:|:--------:|------|
| **晴天** | Sun | 全年 | 基础天气 | 无特殊效果，默认天气 |
| **雨天** | Rain | 春/夏/秋 | 春约18.3%/夏约13%/秋约18.3% | 地面湿润(自动浇灌)，可钓雨天才有的鱼(鲶鱼/鳗鱼等)，触发人鱼吊坠购买条件 |
| **暴风雨** | Storm/Thunder | 春夏为主 | 低于雨天概率 | 同雨天效果+闪电(可被避雷针收集→**电池组**)，**夏13和26必定暴风雨** |
| **雪天** | Snow | **冬季** | 约63% | 地面覆盖积雪，冬季特有采集物出现 |
| **风天** | Wind | 春/秋 | 春约16.6%/秋约49.8% | "部分多云，微风"，可触发特殊采集事件 |
| **绿色雨天** (1.6新增) | Green Rain | **夏季特定日期** | 低 | 绿色天空，生成绿色雨树(Green Rain Tree)和苔藓(Moss) |
| **活动场景** | Festival/Event | 按活动日期 | 由具体活动定义 | 封闭式节日与四项连续世界活动遵循不同的时间、营业和喂食规则，见[第 6 节](#6-节日与多日活动) |
| **婚礼** | Wedding | 婚后第3天 | 必定晴天 | 全天无特殊天气效果 |

### 7.2 固定天气日期

| 日期 | 固定天气 | 原因 |
|:----:|---------|:----:|
| 春1(第1年) | 晴天 | 游戏开始 |
| 春2(第1年) | 晴天 | 剧情需求 |
| **春3(第1年)** | **必定雨天** | 剧情日(遇见威利、解锁鱼竿) |
| 春4(第1年) | 晴天 | 剧情需求 |
| 夏1 | 晴天 | 季节转换 |
| 秋1 | 晴天 | 季节转换 |
| 冬1 | 晴天 | 季节转换 |
| **夏13** | **必定暴风雨** | 固定天气事件 |
| **夏26** | **必定暴风雨** | 固定天气事件 |
| 封闭式节日场景 | 采用活动场景规则 | 不得外推为四项连续世界活动的世界天气 |
| 婚礼日 | 晴天 | 结婚机制 |

### 7.3 天气对游戏的影响

| 天气 | 游戏影响 | 策略建议 |
|:----:|---------|---------|
| **雨天** | 自动浇灌，节省浇水时间；特定鱼类出现(鲶鱼Catfish/鳗鱼Eel/西鲱Shad/红鲷鱼Red Snapper/狗鱼Pike) | 最适合矿井探索或社交送礼(村民更多在室内) |
| **暴风雨** | 闪电击中作物/树木(概率)，避雷针收集→**电池组(Battery Pack)**；同时有雨天钓鱼效果 | 确保有足够避雷针(建议10-20个)，电池组是高级制作的核心材料 |
| **雪天** | 冬季特有采集物出现，户外行走速度略微下降 | 适合采矿和钓鱼 |
| **风天** | 秋季49.8%高概率发生 | 不影响正常活动 |
| **绿色雨天** | 生成苔藓(Moss)和绿色雨树，1.6新增 | 特定采集机会 |

### 7.4 天气预知与操控

| 方式 | 说明 |
|------|------|
| **电视天气预报** | 每晚7:00播出，告知第2天天气 |
| **雨图腾(Rain Totem)** | 采集9级制作，使用后**第2天必定下雨**(但沙漠不会下雨) |
| **求雨图腾(Totem of Rain)** | 同上 |
| **魔法天气预报** | 法师塔可查看一周天气(1.6新增？) |

### 7.5 天气与特殊事件联动

| 天气+条件 | 事件 |
|-----------|------|
| 雨天 + 持有人鱼吊坠购买资格 | 可去海滩找老水手(Old Mariner)购买人鱼吊坠(Mermaid's Pendant) |
| 暴风雨 + 避雷针 | 收集电池组 |
| 雨天 + 矿井特定层 | 可钓特定鱼类 |
| 冬季雪天 | 解锁冬季采集物(冬根/雪山药等) |
| 第1年春3雨天(固定) | 触发威利送鱼竿剧情 |
