## 1. 战斗定位与概览

战斗在星露谷物语中约占 **15-20%** 的游戏内容，主要集中在矿井/骷髅洞穴/火山地牢的探索和战斗中。

### 1.1 战斗核心机制

| 项目 | 说明 |
|:----|:----|
| **生命值(HP)** | 初始100；战斗等级仅在1–4、6–9级各加5，永久最大值205。完整推导与失去意识规则见[生命固定源](../数值数据/角色属性战斗数据总览.md#source-health) |
| **精力(Energy)** | 与生命分离；初始270、永久最大508，食物与饮料临时上限最高588。疲惫、昏倒与恢复见[精力固定源](../数值数据/角色属性战斗数据总览.md#source-energy) |
| **攻击伤害** | 武器基础伤害、攻击属性、职业、暴击、附魔与怪物防御按固定顺序计算，见[战斗公式固定源](../数值数据/角色属性战斗数据总览.md#source-combat-mechanics) |
| **暴击率** | 武器、锻造、戒指/固有属性、祝福、侦察兵与运气依次生效；完整顺序见[暴击率固定源](../数值数据/角色属性战斗数据总览.md#source-crit-chance) |
| **暴击威力** | 基础倍率与暴击威力属性按公式合并，不使用近似“流派”估算，见[暴击威力固定源](../数值数据/角色属性战斗数据总览.md#source-crit-power) |
| **防御** | 减伤受攻击随机波动及高防御衰减影响，最低承伤1；见[防御固定源](../数值数据/角色属性战斗数据总览.md#source-defense) |
| **免疫** | 每点按9.1%叠加减少可预防减益的命中概率，+11达到完全免疫；见[免疫固定源](../数值数据/角色属性战斗数据总览.md#source-immunity) |

| 区域 | 难度 | 推荐等级 | 主要战利品 |
|:----:|:----:|:--------:|-----------|
| 矿井1-39层 | 低 | Lv1-30 | 铜矿、绿宝石、初期装备 |
| 矿井40-79层 | 中 | Lv31-60 | 铁矿、钻石、冰封晶球 |
| 矿井80-120层 | 中高 | Lv61-90 | 金矿、岩浆晶球、黑曜石之刃 |
| 骷髅洞穴 | 高 | Lv90+ | 铱矿、银河之魂、宝藏 |
| 火山地牢 | 高 | Lv90+ | 火山晶石、龙牙、矮人武器 |
| 秘密森林 | 低 | 任意 | 桃花心木、史莱姆 |
| 下水道/突变虫穴 | 中 | Lv30+ | 特殊鱼类 |
| 危险矿井(齐先生挑战) | 极高 | 满级+顶级装备 | 放射性矿石、铱针 |

## 3. 骷髅洞穴系统

### 3.1 基础信息

| 属性 | 数值 |
|:----|:----|
| **位置** | 卡利科沙漠(Calico Desert)北部 |
| **解锁条件** | 获得头骨钥匙(矿井120层)后进入沙漠 |
| **楼层机制** | **无限层**，随机生成，**无电梯**，每次从头开始 |
| **时间流逝** | 比外界慢(每游戏小时54秒 vs 外界43秒) |
| **下降方式** | 楼梯(Staircase，99石头合成1个)或竖井(Shaft) |
| **竖井概率** | 打破石头20%概率出现，一次跳3-15层 |
| **竖井伤害** | 每跳过1层受到3倍伤害(最少保留1HP) |

### 3.2 铱矿产出公式

```
铱矿节点出现概率 = 0.15% × 当前层数
```

| 深度 | 铱矿出现概率 | 实际感受 |
|:----:|:-----------:|---------|
| 10层 | 1.5% | 几乎看不见 |
| 50层 | 7.5% | 偶尔出现 |
| 100层 | 15% | 开始常见 |
| 200层 | 30% | 大量铱矿 |
| 500层 | 75% | 遍地铱矿 |

### 3.3 宝藏房间公式

| 参数 | 公式/数值 |
|:----|:----------|
| **基础概率** | 0.01(1%) |
| **每日运气影响** | +每日运气(范围-0.1~+0.1)÷10 |
| **运气增益影响** | +运气增益等级÷100 |
| **最终概率公式** | P = 0.01 + (dailyLuck÷10) + (luckLevel÷100) |
| **最佳情况** | 约0.01+0.01+0.06=0.03(3%) |
| **出现条件** | 10层以上，从石头中打开(非挖地) |

### 3.4 史前楼层(Prehistoric Floor)

| 属性 | 数值 |
|:----|:----|
| **出现概率** | 约2.2% |
| **特征** | 长满野草和树木的史前风格楼层 |
| **特有怪物** | 霸王龙(Pepper Rex) |
| **采集品** | 特有的史前植物 |

### 3.5 骷髅洞穴怪物

骷髅洞穴与危险骷髅洞穴使用不同名册，且 Bats、Slimes 等聚合页内部还有层级变体。完整 HP、伤害、防御、经验、掉落和危险变体见[官方区域与危险模式名册](../数值数据/怪物数据总览.md#官方区域与危险模式名册)，本文不再维护重复数值表。

### 3.6 重要里程碑

| 里程碑 | 奖励 | 条件 |
|:------:|:----:|:----:|
| 到达100层 | 遇到齐先生(Mr. Qi) | 阅读秘密笔记#10后 |

## 4. 火山地牢与锻造系统

### 4.1 基础信息

| 属性 | 数值 |
|:----|:----|
| **位置** | 姜岛北部火山内 |
| **层数** | 10层(随机生成，第5层和第10层固定) |
| **解锁** | 到达姜岛北部 |
| **通关后** | 解锁电梯+第10层到入口的快捷通道 |
| **重置** | 可反复探索 |

### 4.2 各层功能

| 楼层 | 功能 |
|:----:|:----|
| 1-4 | 随机生成层：怪物、宝箱、矿石、熔岩阻挡 |
| **5** | **固定层：矮人商店(Dwarf Shop)+水池(可装水)** |
| 6-9 | 随机生成层：怪物密集，含铱矿及火山晶石(Cinder Shard) |
| **10** | **固定层：锻造台(Forge)** |

### 4.3 锻造台系统

锻造台是火山地牢第10层的装备变更入口；宝石锻造、战斗附魔、固有附魔、工具附魔、无限武器、外观转移、戒指合并、取消锻造和钓鱼交互的完整规则统一见[锻造与附魔固定源](../数值数据/道具装备数据总览.md#source-forge)。该固定源保留 6 张关系表、34 行数据及全部规则事实，本页不再复制推荐附魔或不完整材料表。

锻造后的 Attack、暴击、防御、免疫等属性如何进入最终结算，见[角色战斗公式](../数值数据/角色属性战斗数据总览.md#公式索引)。

## 12. 危险模式与齐先生挑战

### 12.1 危险矿井(Danger in the Deep)

| 属性 | 说明 |
|:----|:----|
| **解锁** | 完成齐先生特殊任务"深处的危险"(Danger in the Deep) |
| **效果** | 矿井怪物变成更强版本，新增特殊怪物 |
| **激活** | 在齐先生的核桃房(Qi's Walnut Room)激活挑战 |
| **奖励** | 特殊掉落(放射性矿石、铱针等) |
