# 债务驱动的生存压力设计 - 露塞提娅:道具屋经营妙方(Recettear)

> 游戏版本: Recettear: An Item Shop's Tale v1.0+ (PC, 2007/2010年)

> **还款校订**：以[剧情模式五期还款表](#21-剧情模式五期还款表)为准：Day 36 结清，总计 **820,000 Pix**。旧档的 30 天 / 620,000 Pix 与「第四周即清债」均是误记，保留作校订对照。

## 一、概述

露塞提娅是所有商店/牧场经营游戏中**最激进的生存压力设计**。不是"慢慢来总会成功"的开放节奏，而是"30天内必须还清62万Pix否则Game Over"。这种债务倒计时机制创造了一种任何其他经营游戏都无法比拟的紧迫感。

## 二、还款压力曲线

> **旧表留档（勿作攻略）**：下方四期模型漏掉第 29 天的 200,000 Pix，并写错了还款日。

```
第7天: 10,000  —— 入门(轻松)
第14天: 30,000 —— 压力初显(需要学会讨价还价)
第21天: 80,000 —— 压力显著(需要地牢+商店双线效率)
第30天: 500,000 —— 极限挑战(需要掌握全部经营技巧)
```

### 压力曲线分析

- 前两周=教学期(还款额相对容易)
- 第3周=转折点(还款额从3万跳到8万→必须效率化)
- **第4周=终极考验**(50万!几乎是前3周总额的4倍)

### 2.1 剧情模式五期还款表

范围：原版英文 PC 剧情模式。[发行方的 Steam 补丁说明](https://store.steampowered.com/oldnews/4476)确认 v1.108；日期和还款值以[完整实玩攻略](https://games.jayisgames.com/review/recettear-an-item-shops-tale.php)、[GameFAQs 实玩问答](https://gamefaqs.gamespot.com/pc/604893-recettear-an-item-shops-tale/answers/225273-how-big-is-the-total-debt)和[剧情模式资料](https://recettear.fandom.com/wiki/New_Game_%28Story_Mode%29)交叉核对。第 1 天是教程，第 2 天进入自由经营；表中是游戏日历编号，不是经营了多少天。

| 期数 | 到期日 | 本期应付（Pix） | 累计已付（Pix） |
|---|---:|---:|---:|
| 1 | 8 | 10,000 | 10,000 |
| 2 | 15 | 30,000 | 40,000 |
| 3 | 22 | 80,000 | 120,000 |
| 4 | 29 | **200,000** | 320,000 |
| 5 | 36 | **500,000** | **820,000** |

第 3、4、5 期是 80,000 → 200,000 → 500,000，两次各扩大到 2.5 倍。末期账单比前四期合计的 320,000 多 56.25%，约占总还款的 61%，并非旧文所说的「前几期总额四倍」。[实玩录像](https://www.youtube.com/watch?v=zOiElhxztYU&t=9735s)可核对第 29 天 200,000 Pix 的还款事件。

### 2.2 第 29 天：库存不计入还款现金

[剧情模式资料](https://recettear.fandom.com/wiki/New_Game_%28Story_Mode%29)用手头 Pix 判断是否足以还当期账单。假设到期日有 205,000 Pix，尚未结算：

| 到结算前的选择 | 手头现金 | 还款结果（算例） |
|---|---:|---|
| 不再采购 | 205,000 | 付 200,000，剩 5,000 留给第 5 周 |
| 花 10,000 采购、来不及再卖 | 195,000 | 差 5,000；新货再值钱也不算已收现金 |

若选择采购，必须在当期结算前再收至少 5,000 Pix 才回到门槛。这也解释了为什么临近到期的好折扣未必值得拿：剩余营业时段决定货能不能变成现金。可与[《魔药经济学》的到账时点](../../魔药经济学/机制分析/药水熟成与库存管理.md#52-400-g-药水的两种现金期限)对照，两个系统都要分开记库存价值与已到账金币。

### 2.3 失败循环和结算边界的复测口径

剧情资料记载，选择重开时回到第 2 天，现金重置为 1,000 Pix，而物品、商人等级与冒险者进度可保留。顾客好感等细项可独立复测；不要把失败回档当作通关后的 [Endless 或 Survival](https://store.steampowered.com/app/70400/Recettear_An_Item_Shops_Tale/)，也不要混用主动开 New Game+ 的继承规则。

- 在英文 Steam v1.108 到期日前复制同一存档；最低成本先用 Day 8，让两组分别在 10,000 Pix 和略低的现金结束当天。若用 Day 29，可选上述 195,000 / 205,000 算例，记录最后一项活动、日历、Tear 的还款事件和余额。
- 成功组记录实际扣款和下一天余额；失败组记录重开日现金、同一库存物品、商人及冒险者等级，并用相同顾客比较购买预算或已有好感线索。此处仅整理资料和测试设计，未记录实机的最后可操作时段。

## 三、Bad End≠永久失败

| 失败后果 | 保留什么 |
|------|------|
| 游戏从第2天重新开始 | ✓ 物品/装备 |
| Tear说"这只是一场梦..." | ✓ 商人等级/冒险者等级 |
| — | ✓ 顾客好感度 |

> 这个设计巧妙——不是全部重来(保留了大量进度)，但从叙事上解释为"梦"——优雅的Roguelite式循环

## 四、与星露谷/传统牧场的时间压力对比

| 游戏 | 时间压力 | 失败后果 |
|------|:--:|------|
| 星露谷 | 无(无限年) | 无 |
| 月夜人(Moonlighter) | 无(无限天) | 无 |
| 珊瑚岛 | 无(无限年) | 无 |
| **露塞提娅** | **30天硬截止** | **Bad End+重来(保留进度)** |

## 五、生存压力驱动的玩法效率

| 低压力玩法 | 高压力玩法 |
|------|------|
| 随便定价→慢慢测试 | 精准Pin→最大化经验+好感 |
| 每天卖几件 | 每天必须清空库存 |
| 偶尔下地牢 | 必须定期下地牢获取高价值物品 |
| 自动售货机清库存 | 手动定价获取更高利润+经验 |
| Alouette偶尔来→随便卖 | 必须主动吸引Alouette→高价卖出最贵物品 |

> **阅读提示**：下方原分析中的「30 天」统一视为旧模型；实际压力点是上文的五个到期日。

## 六、设计分析

1. **债务=最原始的动机**: 不是为了"更好的生活"或"赚钱买好东西"，而是"不还钱就失去家"——生存压力>>成长动力
2. **30天=完美的时间窗口**: 太长则无压力(60天)/太短则不可能(15天)——30天足够学会全部系统但又不会太松弛
3. **"梦"的叙事化失败**: Bad End不是"Game Over"而是"从梦中醒来"→减少挫败感+提供重试动力
4. **50万=机制检查**: 如果你没有掌握讨价还价/市场波动/地牢宝箱/Alouette高价策略→无法在30天内凑齐50万→强制学会全部系统
5. **与月夜人(Moonlighter)的差异**: 月夜人无债务压力→可以无限天→节奏自定；露塞提娅有30天硬截止→节奏被债逼着——两种完全不同的经营体验设计
