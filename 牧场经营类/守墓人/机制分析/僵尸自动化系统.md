# 僵尸自动化系统 - 守墓人(Graveyard Keeper)

> 游戏版本: Graveyard Keeper v1.0+ (Breaking Dead DLC/免费更新)
> 数据来源: Steam Community, NeoSeeker Zombies 101, TrueAchievements

## 1. 概述

守墓人的**僵尸工人**是品类中最独特的"自动化"系统——不是洒水器/传送带，而是**复活尸体成为劳动力**。僵尸可用于采矿/伐木/搬运/农耕/炼金——将游戏从手动劳动转变为自动资源流水线。

## 2. 僵尸复活流程

```
与Gerry(会说话的头骨)对话
  → 建造复活台(Resurrection Table): 4木板+4复杂铁件
  → 制作僵尸汁(Zombie Juice): 生命粉+血液(炼金台I)
  → 复活尸体: 1僵尸汁+10信仰→复活台
```

## 3. 僵尸效率

> **数值校订**：下表及第七节的效率梯度是旧档误记，不用于配置。每个白骷髅对应 2.5 个百分点；12 白是 30%，65% 对应 Better Save Soul 的 26 白路线。见[版本化对照](#8-白骷髅效率与搬运瓶颈)。

| 尸体白骷髅 | 效率 |
|:--:|:--:|
| 1白骷髅 | ~15-20% |
| 5白骷髅 | ~25-35% |
| 10-12白骷髅 | **~40-65%** |

- **白骷髅少的尸体=用作僵尸**(不是埋葬!)
- **高白骷髅尸体=最高效的僵尸工人**

## 5. 采石场自动化(推荐设置)

```
最佳配置:
  2×僵尸铁矿 + 1×僵尸采石场
  + 铁储存器 + 石储存器
  + 1×僵尸搬运工(把所有东西搬回家)
  → "设置后忘记"的完全自动矿物流水线
```

> **物流校订**：采集、搬运、收货是三段。上图不是无条件「设置后忘记」：搬运站需选对货物，家中也要有该类材料可用的收货空间。

## 6. 僵尸的局限性

| 限制 | 说明 |
|------|------|
| 僵尸炼金**不享受科学家Perk** | 手动炼金有+1加成→手动做高端/僵尸做批量 |
| 效率与白骷髅直接相关 | 低品质尸体=慢速僵尸 |
| 需持续提供僵尸汁+信仰 | 每次复活成本 |

## 7. 设计分析

1. **尸体→劳动力**: 不是"雇工人"而是"复活尸体"——黑暗幽默贯穿系统设计
2. **效率梯度**: 1白骷髅=15%到12白骷髅=65%——驱动寻找更好的"僵尸原料"
3. **搬运工=物流革命**: 采石场资源→自动运送家中——无需手动往返
4. **僵尸=终局自动化**: 手动时代→僵尸时代——游戏体验从"劳动"变为"管理"

## 8. 白骷髅效率与搬运瓶颈

> **范围**：Windows Steam [公开分支 Build 26588610](https://steamdb.info/app/599140/depots/)为复测基准，不表示这个补丁更改了效率。[Breaking Dead 发布公告](https://store.steampowered.com/news/posts/?enddate=1540832619&feed=steam_community_announcements)确认工人和搬运工加入 Steam PC 本体；[Better Save Soul](https://store.steampowered.com/app/1788370/Graveyard_Keeper_Better_Save_Soul/)是另一项扩展。下文区分攻略数据、用数据做的模型及未实测项。

### 8.1 加工速度看白骷髅，留意 DLC

[僵尸效率资料](https://graveyardkeeper.fandom.com/wiki/Zombie)以玩家加工速度为参照，常规口径是每个白骷髅对应 2.5 个百分点；资料表将 0/1 白都显示为 2%，其余也可能用取整后的百分比显示。红骷髅不是加工效率加成，墓地评分也不能套用这条公式。

| 白骷髅 | 模型加工效率 | 适用说明 |
|---:|---:|---|
| 1 | 2%（资料显示） | 不能套用旧档 15–20% |
| 5 | 约 12.5%（资料显示 12%） | 不能套用旧档 25–35% |
| 10 | 25% | 旧表 10–12 白范围的下端 |
| 12 | 30% | 常规对照工人 |
| 16 | 40% | 不依赖 Better Save Soul 的高白路线；核对本身的 DLC 配置，不等同于本体墓碑上限 |
| 26 | 65% | [Better Save Soul 器官改造路线](https://steamcommunity.com/sharedfiles/filedetails/?id=2275207503)，不是本体 12 白的表现 |

同一工位、同一配方且供料和收货持续畅通时，26 白对 12 白的长期加工量比值为 0.65 ÷ 0.30 ≈ **2.17 倍**。以玩家加工用时 6 个单位的工作量为例，30% 名义用时 20 单位，65% 约 9.23 单位。此式不含缺料、取货、阻塞或计时取整，更不代表整条生产线都会快 2.17 倍。

### 8.2 搬运不吃这项加工加成，收货处会堵线

[搬运站资料](https://graveyardkeeper.fandom.com/wiki/Porter_station)与[实玩搬运说明](https://allthings.how/graveyard-keeper-how-to-build-a-porter-station/)将搬运与加工速度分开：高白骷髅不会让搬运工走得更快或一次多搬。大件要去对应料堆，小件进合适储物处；[贸易箱路线](https://www.neoseeker.com/graveyard-keeper/locations/Trade_Office)还要查贸易办托盘有没有空位。贸易办的配置容量不是「每趟搬运量」，送达的箱数也不等于已结算的收入。

| 观察到的现象 | 先检查 | 高白工人能否解决 |
|---|---|---|
| 来料充足，成品缓慢出现，收货处仍有空位 | 加工台效率及持续供料 | 可比较更换加工台工人前后产量 |
| 产地堆货，但目标处已满 | 目标处是否有正确储物格或空托盘 | 不能；先腾空接货位置 |
| 产地堆货，目标处仍有空位 | 搬运筛选、匹配料堆、路线及单趟数量 | 不按白骷髅数推断搬运速度 |

与[《史莱姆牧场 2》的无人机路线](../../史莱姆牧场2/机制分析/牧场管理与自动化.md#72-给收集器选终点前先确定需要现金还是库存)相比，这里的典型问题不是任意改送市场或精炼厂，而是预定收货处塞满后，产量增加也无法提高交付。

### 8.3 同一工位、同一路线分别复测

1. 记录版本、DLC 和界面效率；用 12 白、16 白工人依次跑同一持续加工队列，固定配方、供料和观测时长，分别记完成数。26 白只在启用 Better Save Soul 时另测。
2. 把两名工人依次换到同一搬运站，固定物品筛选、源库存、目标空位和路径。记录趟数与每趟搬运量，不把生产还没做完的等待算成走路。
3. 固定搬运工，仅占满目标托盘，再腾出一个位置观察是否恢复交付。出货与结算另记。此轮未进游戏执行这些测试。
