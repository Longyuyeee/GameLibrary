# 工坊自动化与工厂系统 - 沙石镇时光(My Time at Sandrock)

> 游戏版本: My Time at Sandrock v1.0+ (PC/Switch/PS5/Xbox)
> **校订范围**：下文第八节以 PC Steam 单人 Build 18623106 为复测目标，保留原表与流程图；「20+20」「固定加速 50%」和绝对品质结论按校订说明阅读。

## 一、概述

沙石镇时光的工坊从**手动操作**逐步进化到**工厂自动化**。这不仅是QoL升级，而是整个游戏节奏的转变——从"亲手操控每台机器"到"设置生产策略→机器自动执行"。

## 二、机器运作逻辑

### 2.1 机器独立性

每台机器是**独立的运作单元**:
- 有自己的生产队列(可排队多个订单)
- 消耗**水(Water)**作为冷却/运转介质
- 消耗**燃料(Fuel)**(木头/动力石等)提供动力
- 缺水/缺燃料→停机→不生产

### 2.2 时间连续性

机器在游戏时间中**持续运作**:
- 不因睡觉而"跳过"
- 睡前排队→睡觉期间→早上产出
- Feather Duster可加速机器速度(+50%)

> **校订**：鸡毛掸清除积沙，作用是恢复受损效率，不是给干净机器固定加速 50%。见 [8.3](#83-积沙抵消产能而非清洁叠加速度)。

## 三、自动化演进三阶段

### 阶段一: 手动时代(初期)

```
所有机器手动操作
玩家: 采集→放入机器→等待→取出→重复
限制: 需要时刻在工坊附近
```

### 阶段二: 排队优化(中期)

```
知识技能+高级机器+多台并行
玩家: 批量设置生产队列→外出做委托→回来收获
关键技能: Time Management(机器+20%速度)、Water Conservation(节水)
```

### 阶段三: 工厂自动化(终局)

```
主线"Sandrock Strikes Back"后解锁
工厂(Factory):
  - 20制造批次+20回收任务同时
  - 需火力发电机供电
  - 产出自动送入交付箱
  - 代价: 不享受品质加成
```

## 四、工厂vs手动: 策略抉择

| 维度 | 手动(工坊庭院) | 工厂(Factory) |
|------|:---------:|:--------:|
| 操作量 | 高(每台机器单独操作) | 低(中控面板批量设置) |
| 生产速度 | 基准+技能加成 | 基准 |
| 品质加成 | **享受全部品质技能** | **不享受** |
| 容量 | 每台机器独立容量 | 20+20批量 |
| 供电 | 每台独立燃料 | 集中火力发电机 |
| 最佳用途 | 高品质委托物品 | 批量生产基础材料 |

> **校订**：上表及流程图中的「20+20」是旧档案口径，不能当成已核实的并行总量。「不享受品质加成」在本轮只指设备品质及精炼词条不计入工厂计算，不代表所有知识加成或成品品质都已核实。

**策略结论**: 高品质关键物品→手动；基础材料/回收→工厂。两者互补而非替代。

## 五、机器品质与精炼

### 5.1 机器品质

| 品质 | 效果 |
|------|------|
| 普通 | 基准产出 |
| 优秀 | 概率更高品质产出 |
| 完美 | 更高概率+额外产出概率 |

- 高品质机器通过组装站技能加成获得

### 5.2 精炼(Refining)装备

- 精炼机(Refiner)消耗材料提升装备属性
- 可重复精炼(无上限但消耗递增)
- Advanced Refining: 5%免费/5%双倍效果

## 七、设计分析

1. **从小到大**: 手动→排队→工厂——自动化是"成长"的一部分，而非初始就有
2. **品质vs效率的交易**: 工厂快但不出品质——保留了手动操作的价值
3. **水=能效**: 用水而非电力驱动机器——沙漠设定中的资源约束设计
4. **Feather Duster加速**: 主动技能加速机器——保留玩家"手动干预"的快感
5. **火力发电机**: 终局工厂需要独立供电设施→促使玩家建造完整工业链

### 8.2 先验证并行，再算产能

**订单已接受、计时正在推进、产品已交付是三种状态。** [社区工厂资料](https://mytimeatsandrock.fandom.com/wiki/Factory)列出制造（Craft）、回收（Recycle）、烹饪（Cooking）三栏各 20，并举出四台回收机提供 20 个回收任务位的例子；[2023 年玩家操作记录](https://www.reddit.com/r/MyTimeAtSandrock/comments/18hrp2o)则观察到跨机器只有 20 条同时工作，其余可以提交但会暂停。两者不能合并成确证的 40 或 60；四台回收机的例子也只说明单类设备容量。

复测时记录标题页版本、机器类别和数量、对应配方、提交时刻、开始推进与交付时刻：

1. **先做空载对照**：确认一条回收单和一条烹饪单各自能启动。材料及供水、燃料留够，确认退出中控界面后游戏时间继续前进。
2. **做混合队列**：用足量机器把制造栏填到 20 条同时推进的单件任务，不是把 20 件合在一单。再提交与对照相同的回收单和烹饪单，选较长的制造配方留出足够观察时间。
3. **判读**：只要额外一条和原有 20 条同时推进，就排除「共享 20」；即使两条都推进，也只能断言至少 22。如果额外单暂停，保持设备、原料、供给不变，观察是否在制造单结束后立即接替；再交换提交先后顺序，区分共享上限与页签优先级。

### 8.3 积沙抵消产能，而非清洁叠加速度

[工业熔炉资料](https://mytimeatsandrock.fandom.com/wiki/Industrial_Furnace)记录重度积沙时效率减半，青铜锭（Bronze Bars）名义耗时 1 小时 30 分；[游戏提示的社区转录](https://mytimeatsandrock.fandom.com/wiki/Game_options)将鸡毛掸的功能写作清除积沙。按全程保持同一档位的简化模型：干净时 90 游戏分钟，重度积沙时 90 ÷ 0.5 = 180 分钟。清洁后相对受损速率恢复为 2 倍，但只是回到原来的速度。社区记录工厂内设备不积沙；庭院建议对同一熔炉测干净、出现积沙警示、清理后三组，任务中途跨阈值要另记。

### 8.4 批量工序与品质委托可以分开

[社区工厂资料](https://mytimeatsandrock.fandom.com/wiki/Factory)指出的是放入工厂的加工站本身的品质及其精炼词条（如 Production Quality、Yield Chance）不生效；不据此认定工厂必定只出一种品质。批量底材可以走工厂，要求特定品质的委托则比较庭院生产与成品处理：[精炼机](https://mytimeatsandrock.fandom.com/wiki/Refiner)可用对应宝石提升支持精炼的成品。比较两条路线时固定输入品质、配方、知识和机器类型，分别记产物件数、品质分布、宝石消耗，别把这三项合成一个「品质加成」。
