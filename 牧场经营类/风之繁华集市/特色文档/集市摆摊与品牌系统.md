# 集市摆摊与品牌系统

> **已校订范围：** Marvelous 2025 年重制版，以[官方 Switch 集市手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/03/)与[城镇手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/02/)为基础。未运行游戏；精确钟点、定价和升阶数据不作全量验收。[返回游戏概览](../游戏概览.md)

## 一、摆摊是集市成长引擎，不是唯一销售途径

同一批商品可以有不同去处：官方手册说明镇上的 Miguel’s Mercantile 提供买卖；周六则可以自己参展，为集市提升知名度。两者不是简单的“能否卖掉”二选一。前者可在对应店铺营业时作为补充渠道；后者让备货、货品趋势、陈列与顾客交互集中发生。官方未给出两种渠道的全商品价差，也未证实可任意改价，不能用固定倍率解释哪种渠道必胜。[城镇篇](https://www.storyofseasons.com/grandbazaar/manuals/nsw/02/) · [集市篇](https://www.storyofseasons.com/grandbazaar/manuals/nsw/03/)

| 环节 | 官方确认 | 设计上的区别 |
| --- | --- | --- |
| 生产 | 可以采集、耕种、饲养、风车加工。 | 关注哪些原料能在营业前转成计划销售的货品。 |
| 周内调货 | 杂货店提供买卖，各店营业时间不同。 | 有第二条销售路径，但不能据此假定它推进集市指标。 |
| 开店准备 | 将背包货物登记到摊位库存，营业前可调整。 | 把仓储、摊位备用库存与台面陈列分开。 |
| 周六经营 | 有上午、下午两个场次；开场后从摊位库存挑商品上柜。 | 两次营业窗口为对照备货策略提供自然分段。 |
| 顾客交互 | 顾客要求指定商品及数量，在对应商品处完成销售；铃铛能吸引注意。 | 有订单不等于已成交，缺货与操作来不及应分开记录。 |
| 反馈 | 每场后有销售小结，次晨才有集市评审。 | 单场收入与长期升级是不同反馈，不可合并。 |

## 二、趋势、装饰、声援和等级各自做什么

| 系统 | 手册确认的效果 | 不由该项推出的结论 |
| --- | --- | --- |
| 当季趋势 | 流行品卖得更快，售价更高。 | 没有可引用的通用加成百分比。 |
| 摊位装饰 | 不同装饰可以影响销售速度或快乐能量；与帐篷同系列可产生系列效果，官方手册上限为 3 项。 | 不意味着任意装饰都提高成交价。 |
| 精灵声援 | 销售积累声援量，在开启声援时可快速销售并用备用库存补货；不同精灵的效果不同。 | 不用“暂停时钟”或“所有商品倍率相同”解释该效果。 |
| 集市等级 | 评审看集市总销售额和摊位总数。等级上升会吸引更多顾客与潜在新摊商。 | 不能只凭一笔订单或单日流水推断必升阶。 |
| 旧档中的品牌数值 | 本次来源未核实旧稿中的具体认证门槛、固定售价倍率和奖项清单。 | 不把“趋势”“装饰”“品牌”当成同一个可互换的加成。 |

依据：[官方 Switch 手册：集市准备、集市日、升阶](https://www.storyofseasons.com/grandbazaar/manuals/nsw/03/)。

## 三、复盘场景：有畅销品，为什么没有升阶？

这是未实机的对照方案，不是公布的固定公式。取同一版本、同一周次的两个分支存档，保持相同的摊位与装饰。一份主备当季流行品，另一份使用可比品质的常规商品。不要把销量差异直接当作升阶差异。

1. 营业前分别记录背包与摊位备货；开场后再记台面陈列。
2. 分上午、下午记录顾客要货次数、缺货次数、实际成交情况和每场小结。如果库存未售完但多次断陈列，先检查补货或操作，而不是先改生产。
3. 用次晨评审单独观察是否达到营业额和摊位数目标。若流水达标但摊位数不足，先检查潜在摊商与进驻条件，不重复用同一种畅销品解决两个约束。
4. 另开对照记录杂货店买卖，登记商品、品质、报价、营业时段和实际到账。未确认前，不把商店出售并入集市销售额。

**待实机：** 在平台、版本和语言固定后截录两个场次的实际始末、客流与补货时点、各等级完整条件、不同销售渠道的报价、品牌认证的实际触发和价格关系。版本和地区发行差异见[团队与开发历程](./团队与开发历程.md)。
