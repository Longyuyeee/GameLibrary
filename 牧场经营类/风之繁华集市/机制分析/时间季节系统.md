## 一、日内框架：时间和 GUTS 是两个约束

| 系统 | 官方可以确认 | 不应推导 |
| --- | --- | --- |
| 日期及天气显示 | 界面分别显示时刻/日期、天气与风量；住宅日历可查看最长两年范围内的生日、节日及特殊活动。 | 仅凭宣传图的一组日期，不能定整个年度天数或固定节日日历。 |
| 平日活动 | 农作、采集、钓鱼会消耗 GUTS；归零立刻原地昏倒，下一天从自宅醒来。 | 不存在依据支持归零后按 50% 效率继续作业。 |
| 跨夜 | 持续至次日 05:00 会昏倒，睡不够会使次晨恢复较少；提早上自家床也会恢复并推进下一天。 | 05:00 和耗尽是不同触发条件，不是次日 06:00；不承诺固定恢复百分比或次日上限减半。 |
| 恢复 | 进食、洗澡、就寝有效；洗澡用 30 分钟，两次洗澡之间要等一段时间；主菜恢复较多，其他料理也可能有额外效果。 | 不能从主菜一般说明推出每份食物的固定点数、浴缸冷却时间或独立疲劳等级。 |
| 商店与节目 | 各店营业时段不同；镇杂货店提供买卖；住宅收音机有三个直播频道，节目随日期和时刻而异。 | 收音机不等于旧表假设的家用 TV 天气节目，不确认任何固定预报准确率。 |

依据：[Switch 手册首页界面](https://www.marv.jp/onlinemnl/kaze/jp/switch/) · [农场篇](https://www.storyofseasons.com/grandbazaar/manuals/nsw/01/) · [城镇篇](https://www.storyofseasons.com/grandbazaar/manuals/nsw/02/)。[官方「普通一天」演示](https://www.storyofseasons.com/grandbazaar/farm/)把 06:00 早餐、07:00 照料动物、08:00 农作、10:00 风车、11:00 交流、12:00 午餐、13:00 采集、15:00 和宠物玩、19:00 晚餐、21:00 收回放牧动物、21:59 就寝作为一个示范，不等于开门时间、固定 NPC 排班或另一时刻操作会失败。

## 二、四季、天气、风与生产安排

| 决策 | 官方规则 | 设计与实际排程 |
| --- | --- | --- |
| 播种前 | 按适宜季节选种；早晚可各浇一次，雨天不用浇水；每天可施肥一次。 | 每种作物单独核对季节、成熟与续收规则，不能用旧稿的「全冬无户外种植」排除任何作物。 |
| 果树 | 幼苗需要 3×3 空间，不需浇水也不会枯萎；成年树只在结果季持续结果；可用斧头起出另植。 | 树没结果不是死树；换季要分清存活、成长及季节性采收。 |
| 放牧 | 天气适宜可让动物吃牧场鲜草，当天不用另喂；不同动物需要不同饲料，饲料可购买或风车生产；忽视动物不利于健康、亲密和副产品。 | 根据当天实际天气和是否吃草决策，不按未经证实的秋16日、80%、70%季节表。宠物可帮忙放牧不等于台风自动收容。 |
| 加工、出行 | 风量随日变化；风较强时风车加工较快，顺风有助滑翔距离、逆风不利。风车各有不同品类；早期要修复风车。 | 天气类别、风量、产线和路径分别记，别用雨雪名称替代实际风量。风力好的日子优先推进会错过下次集市的批次。 |
| 跨季与经营 | 四季有不同作物和镇活动；官方给出南瓜节和跨年倒数等活动例子。 | 把春季基础、夏季扩产、秋收或冬季加工当作经营方案，不作受系统强制的收入顺序。 |

依据：[农场手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/01/) · [Switch 2 日版农场手册](https://www.marv.jp/onlinemnl/kaze/jp/switch2/01/) · [城镇手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/02/) · [官方农场介绍](https://www.storyofseasons.com/grandbazaar/farm/)。

## 三、集市一周：两场营业和次晨评审

| 阶段 | 官方确认的顺序 | 建议记录 |
| --- | --- | --- |
| 周内到开店前 | 主周期是周六；从背包加入摊位库存，可在开店前调整；当季趋势商品销售更快、售价更高，部分摊位装饰也提供效果。 | 看趋势、库存、预计加工完成和替代品；制作人确认售价由系统设定，玩家不能自己开价。 |
| 上午、下午场 | 常规周六分别在 10:00、15:00 开始；到集市东北的自己摊位开张；每场开始后从库存选陈列品，顾客要求特定品种及数量。铃铛可以吸引注意；售货积累应援，应援时柜台可从储货补充。 | 以两场分别记录开店、补货和需求；可利用空档逛其他摊位。所引官方材料未给两场精确结束时间，不将八小时连续营业及单一中午客流峰写成规则。 |
| 每场结束 | 各自有销售小结。 | 同时看销量、缺货、尚未卖掉的品种；将顾客行为作为样本，暂不采信六类顾客的固定排程及价格敏感度。 |
| 次日上午 | 评审考虑总销售额和总摊位数；达标可升阶，新摊主另有开张诉求。 | 次日核对评审，不用未证实的「18:00 计算集市经验」代替。 |

依据：[Switch 集市手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/03/) · [官方集市页](https://www.storyofseasons.com/grandbazaar/bazaar/) · [Marvelous 日版发布稿：开场时刻](https://prtimes.jp/main/html/rd/p/000002019.000016719.html) · [开发组说明：两场与空档采购](https://news-bokumono.marv.jp/article/31094) · [集市专题](../特色文档/集市摆摊与品牌系统.md)。官方手册的“每周六”是通常规则；遇事件冲突是否顺延及其条件，应优先查当前年份游戏内日历，旧稿“跳过一次”未验证。

## 四、节庆、存档与证据边界

官方城镇手册确认作物、动物比赛会看品质和亲密；Horse Derby 是一年两次的赛事，手册的操作建议是**先有自己的马**再训练，不能把赛事写成普遍的首匹马解锁。宠物大赛考查默契和提示操作；优胜者有奖杯与奖品，可将奖杯陈列于自宅。宣传页命名南瓜节与跨年倒数；官方未列所有年份固定公历式日期、奖励 G 数或参赛门槛，也未证明所有店铺和风车在节日统一停摆。[城镇篇](https://www.storyofseasons.com/grandbazaar/manuals/nsw/02/) · [农场介绍](https://www.storyofseasons.com/grandbazaar/farm/)。

**存档与睡眠分开。** 农场手册确认睡眠推进日期；官方 FAQ 另确认 Switch／Switch 2 Edition 存档可共用，但两者都没有在本文引用段落证明“睡一次自动存档、每天 06:00 自动存或在任意状态均手动存”。给想复盘的玩家：记录平台、版本、存档选项是否可见和恢复后日期，再分床、菜单、跨天及营业中分别核查。[农场篇](https://www.storyofseasons.com/grandbazaar/manuals/nsw/01/) · [日版官方 FAQ](https://news-bokumono.marv.jp/article/30895)。

## 五、保留原作息方案：这是玩家分工，不是时段限制

下面的旧作息建议保留做选项。段落内的钟点只表示计划块，不表示操作解锁时刻；旧表的“设定价格”不符合重制版定价设计，实际可做的是选货、关注趋势与估算售价。见[制作人定价访谈](https://www.gematsu.com/2025/03/story-of-seasons-grand-bazaar-interview-with-series-manager-hikaru-nakano-reimagining-wind-and-sales-system)。全年可按季节及现场天气调整，而不是固定周一必须开工。

|:---:|:-----------|:-----------|:-----------|:-----------|

| 冬 | 采矿+畜牧 | 风车加工 | 珠宝制作 | 社交+料理 |

### 5.2 集市周的时间规划

| 星期 | 高效利用法 |
|:---:|:----------|
| 周日 | 收获/浇水 → 风车加工（利用全天风力） |
| 周一 | 集中加工日：把本周要加工的全放入风车 |
| 周二 | 社交+委托日：接任务，刷好感 |
| 周三 | 采矿日：补充矿石库存 |
| 周四 | 最终加工+备货日：完成所有加工品 |
| 周五 | 定价策略日：检查流行趋势，设定价格 |
| 周六 | 集市日：销售+采购物资 |

## 六、值得优先复核的矛盾与实验

| 旧稿点 | 核查结论 | 如何闭合 |
| --- | --- | --- |
| 1 游戏分钟 2 秒、1 游戏小时 60 秒、1 游戏日 24 分钟；帧率当作时基 | **旧稿内部不一致**：若每游戏分钟 2 秒，则 1 游戏小时应为 120 秒，24 小时即 48 分钟；不能同时采用。帧刷新不等于模拟步。 | 同一平台/版本持续录制一段不打开菜单的时间序列，再逐个测试室内、过场、菜单及集市是否停钟。 |
| 00:00–06:00 强制睡眠、06:00 强制昏倒 | **与手册冲突**：到 05:00 昏倒；手册可随时主动就寝，GUTS 归零也立即昏倒。 | 在非剧情的可控存档逐步截取午夜和 04:59→05:00，对照剩余 GUTS 和翌日状态。 |
| 全天摊位经营、18:00 单次结算 | **与官方流程冲突**：10:00 和 15:00 开场、每场小结、次晨评审；结束时间待证。 | 和同一年的集市日历核对，并分别观察进场、每班营业、自由休息/转场与评审。 |
| 统一营业 08:00–18:00、两套精确浇水窗口 | **不得当作统一规则**：商店各自有营业时段；手册只确认早/晚均可浇水。 | 多店、多日型独立采样；固定作物与第一次浇水时刻测试第二次条件。 |
| 30 日/季、120 日/年、固定节庆／越冬全无户外种植其余假设 | **主资料未验证**；与用户需核对的日历、实际作物、天气相区分。 | 截取连续换季及不同年份同节庆；录下“当天日期”“工作日/休息日”和条目报名界面。 |
| 先赢赛马领马、归零减效、恢复表有疲劳值 | 归零减效直接冲突；赛马说明先自有马，不能当作首得触发；疲劳等级、各食物点数仅历史线索。 | 赛马比较无马及已领马状态；料理固定食物品质、版本和初始 GUTS，对照食前后，不把更替效果混入。 |
| 天气概率、预报准确率与恶劣天气特殊采集 | **待证**。分母缺失；冬季限定概率与全年概率不可相加，天气名不能推出风量。 | 按季与每次刷新逐日登记；区分种子/读档、时间和观察次数。普通昆虫手册是接近后按键捕捉，不支持必须备“捕虫网”的旧提示。 |

#### 三、每周集市节奏（Saturday Bazaar Rhythm）

集市是本作时间设计的**核心节拍器**。整个游戏节奏围绕"6+1"模式运行：

| 星期数 | 名称 | 活动重点 |
|:-----:|:----|:--------|
| Sun（日曜） | 准备日 | 浇水、收获、备料 |
| Mon（月曜） | 加工日 | 风车加工、采集 |
| Tue（火曜） | 社交日 | NPC互动、委托 |
| Wed（水曜） | 集中加工日 | 批量风车加工 |
| Thu（木曜） | 最终备货日 | 确认库存、补充生产 |
| Fri（金曜） | 集市前日 | 摊位规划、商品定价策略 |
| **Sat（土曜）** | **集市日** | **摆摊销售（6:00-18:00）** |

##### 3.1 集市日流程

| 时间 | 活动 | 说明 |
|:----|:----|:----|
| 6:00 | 集市开放准备 | 将商品从仓库取出 |
| 6:00-8:00 | 摊位布置 | 摆放商品、设置价格、放置招牌 |
| 8:00-16:00 | 营业时间 | NPC顾客陆续到来，进行销售 |
| 12:00-13:00 | 客流高峰 | 最多顾客时段 |
| 16:00-18:00 | 收摊 | 未售出商品自动回收 |
| 18:00 | 结算 | 统计当日销售额，集市经验增加 |

##### 3.2 集市日顾客行为

| 顾客类型 | 到访时段 | 购买偏好 | 价格敏感度 |
|:--------|:--------|:--------|:---------|
| 普通村民 | 8:00-14:00 | 日常食品/用品 | 中等 |
| 旅行商人 | 10:00-15:00 | 稀有品/加工品 | 低（高价品也会买） |
