## 一、系统概述

**适用范围：2025 年重制版。** 制作人确认本作取消传统出货箱，但不是只能在周六卖货：镇上的 Miguel’s Mercantile 也有买卖功能。集市是周度经营、成长与新增摊商的主轴；周内可以备货，也可以选用店铺变现。两条渠道的结算与是否计入集市评审不可混为一谈。[制作人访谈：出货箱与集市](https://www.siliconera.com/interview-preparing-story-of-seasons-grand-bazaar/) · [Switch 城镇手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/02/)

制作组曾讨论玩家自行定价，最终采用**系统定价**。官方手册说流行品卖得更快、售价更高；制作人也举过季节或游客影响售价的例子，不能把“系统定价”理解成“所有时间、所有顾客的成交价恒定”。玩家实际可调的是选品、备货量、陈列、装饰和声援时点，而不是输入一个价格倍率。[制作人定价访谈](https://www.gematsu.com/2025/03/story-of-seasons-grand-bazaar-interview-with-series-manager-hikaru-nakano-reimagining-wind-and-sales-system) · [Switch 集市手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/03/)

## 二、集市系统（Bazaar System）

### 2.3 系统定价与选品（旧自由定价表备查）

用相同品种、品质和季节对比不同出售渠道；再固定渠道，分别记录趋势、顾客类型、摊位装饰及是否开启声援。把实际成交单价、成交件数、售罄时间分别记录，才能判断是价格、需求还是操作效率变了。**下方 80%–300% 是旧稿假定的可手填价格，不是可操作策略**；旧表的购买概率、加成叠乘与品牌关系也没有实机依据。[集市摆摊专题](../特色文档/集市摆摊与品牌系统.md) · [制作人定价访谈](https://www.gematsu.com/2025/03/story-of-seasons-grand-bazaar-interview-with-series-manager-hikaru-nakano-reimagining-wind-and-sales-system)

<details>
<summary>展开旧版影响因素及 80%–300% 定价表（自由定价已否定）</summary>

> 下方为旧稿原样备查，其中数值、触发或收益均未经版本核验；不可直接当作 2025 重制版规则。

这是本作经济系统的核心特色之一。玩家为每件商品设定售价，系统根据以下因素动态影响顾客购买意愿：

| 影响因素 | 效果 |
|:--------|:----|
| 商品基础价值 | 系统参考价，定价过低则利润减少 |
| 定价偏离度 | 高于系统参考价越高，顾客购买概率越低 |
| 商品品星（★） | 高星级商品可接受更高溢价 |
| 品牌认证 | 有品牌认证的商品顾客接受溢价空间更大 |
| 流行趋势 | 流行商品即使定价较高也容易售出 |
| 集市等级 | 高等级集市顾客购买力更强 |

**定价策略参考：**

| 策略 | 定价倍率 | 说明 |
|:---|:--------:|:----|
| 低价快销 | 80%-100% 参考价 | 快速清仓，适合低星商品 |
| 标准定价 | 100%-120% 参考价 | 平衡策略 |
| 品牌溢价 | 120%-150% 参考价 | 有品牌认证时适用 |
| 精品高价 | 150%-200% 参考价 | 配合流行趋势+品牌+高星 |
| 奢侈品定价 | 200%-300% 参考价 | 仅限珠宝、饰品等高价值加工品 |

</details>

## 三、品牌系统（Brand System）

本次不把旧稿的赛事认证级别、可认证品类、有效期或倍率当成现行事实。先固定平台与版本，分别记录比赛结果、得奖物品和售价，再对照非得奖批次。参赛资格或奖杯不自动等于同类商品永久加价。[城镇手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/02/) · [集市摆摊与品牌系统](../特色文档/集市摆摊与品牌系统.md)

<details>
<summary>展开原始表格与例子（历史口径，待逐项核查）</summary>

> 下方为旧稿原样备查，其中数值、触发或收益均未经版本核验；不可直接当作 2025 重制版规则。

### 3.1 品牌认证流程

1. 参加各类**节日大赛**（作物祭、畜牧祭、料理祭等）
2. 在比赛中获得**金奖项**
3. 该产品获得**品牌认证**（Brand Certified）
4. 所有同类型产品在集市出售时享受**价格乘数**

### 3.2 品牌价格乘数

| 认证等级 | 获得条件 | 价格乘数 |
|:-------:|:--------:|:--------:|
| 无品牌 | 未参赛 | ×1.0 |
| 铜牌品牌 | 大赛获铜奖 | ×1.15 |
| 银牌品牌 | 大赛获银奖 | ×1.30 |
| 金牌品牌 | 大赛获金奖 | ×1.50 |
| 传说品牌 | 同一作物多次获金奖 | ×1.80 |

### 3.3 品牌维护

- 品牌认证并非永久有效，需定期在比赛中卫冕
- 若连续两年（游戏内）未在该品类获奖，品牌等级下降一级
- 不同品类独立计算品牌（作物品牌 ≠ 畜牧品牌 ≠ 加工品品牌）

</details>

## 四、流行趋势系统（Trend System）

官方证据支持**当季趋势影响销售速度和售价**，没有给出旧稿的每月抽取数、固定 +30% 或购买概率。记录趋势 UI、具体商品与当场销售数据；不要从季节分类推断稳定的月度抽签模型。[官方集市手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/03/)

<summary>展开原始表格与例子（历史口径，待逐项核查）</summary>

### 4.1 月度流行

每月初，系统随机选定 **2-3 种商品** 为该月流行商品。

| 月份 | 季节 | 流行品类示例 |
|:---:|:---:|:-----------|
| 春1月 | 春 | 春季蔬菜、花类、蛋制品 |
| 春2月 | 春 | 叶菜类、加工点心、羊毛制品 |
| 夏1月 | 夏 | 夏季水果、乳制品、冷饮类 |
| 夏2月 | 夏 | 瓜类、鱼类、果汁类 |
| 秋1月 | 秋 | 根茎类、蘑菇类、加工肉类 |
| 秋2月 | 秋 | 谷物类、酿酒类、坚果类 |
| 冬1月 | 冬 | 乳制品、毛绒制品、珠宝首饰 |
| 冬2月 | 冬 | 加工食品、暖饮类、矿石制品 |

### 4.2 流行效果

- 流行商品在集市出售时 **售价 +30%**
- 流行商品顾客**购买意愿大幅提升**（约提升40%-60%）
- 流行商品即使大量铺货也不易滞销
- 可通过与NPC对话获取流行趋势情报（情报准确度约70%）

</details>

## 五、小矮人应援团（Little Sprite Support）

官方手册区分售货累积的 **Cheer Gauge（声援量表）**与精灵商店收取的 **Happy Energy（快乐能量）**。启动声援的量表规则不是旧表的 50–200 快乐能量档位。声援时柜台可从库存补货；不同精灵效果及等级有区别，精确加成和持续时间待核。[官方集市手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/03/)

## 六、收入策略分析（Income Strategies）

### 6.1 邪修流——牧草种子循环（Hay Seed Loop）

**原理：** 利用粉碎风车将牧草加工成牧草种子，利用肥料和饲料加速生长，形成高效循环。

| 步骤 | 操作 | 成本/收入 |
|:---:|:----|:---------:|
| 1 | 购买牧草种子 ×2 | -80G |
| 2 | 种植并施肥 | 肥料成本约20G |
| 3 | 收获牧草 | - |
| 4 | 粉碎风车加工 → 牧草种子 ×6 | 加工时间约2小时 |
| 5 | 集市出售多余种子 | 约1,120G |

**循环收益率：** 约 1,020G 利润/周期（投入80G，产出1,120G），收益率约 **1,275%**。

### 6.2 年糕流（Mochi Rice Cake Loop）

**原理：** 从咖啡馆购买大米，用粉碎风车制作年糕，利用冬季流行趋势高价出售。

| 步骤 | 操作 | 成本/收入 |
|:---:|:----|:---------:|
| 1 | 咖啡馆购买大米 ×1 | -150G |
| 2 | 粉碎风车 → 年糕 | 加工费约10G |
| 3 | 年糕基础售价 | 约300G |
| 4 | 冬季流行趋势加成（+30%） | 约390G |
| 5 | 品牌认证加成（金牌×1.5） | 约585G |

**单品利润：** 约425G/个，批量生产效益显著。

### 6.3 珠宝加工流（Jewelry Processing）

**原理：** 采集矿石 → 黄色加工风车 → 制成饰品，高价值出售。

| 饰品名称 | 所需材料 | 加工时间 | 基础售价 | 金牌品牌价 |
|:--------:|:--------:|:--------:|:--------:|:--------:|
| 玛瑙项链 | 玛瑙矿石×3 + 金锭×1 | 6小时 | 15,000G | 22,500G |
| 水晶耳环 | 水晶矿石×2 + 银锭×1 | 5小时 | 18,000G | 27,000G |

| 翡翠手镯 | 翡翠矿石×3 + 铜锭×2 | 6小时 | 22,000G | 33,000G |
| 珍珠项链 | 珍珠×3 + 银锭×2 | 4小时 | 28,000G | 42,000G |

### 6.4 台风送蛙流（Typhoon Frog Catching）

**原理：** 台风天特定区域出现稀有黑色青蛙（Black Frog），捕获后可高价出售。

| 项目 | 数据 |
|:---|:----|
| 出现条件 | 台风天气 |
| 出现地点 | 河流沿岸、瀑布下方 |

| 台风天可捕获数量 | 3-5只 |
| 额外收益 | 台风天风力极强，风车加工速度大幅提升 |

## 七、风力与经济的关系

可确认的是：日风力有差异，强风能缩短风车加工时间。精确倍率与天气映射待测；对照同一风车、配方、数量、增益和版本，记录进出料及加工时刻，勿只按晴雨归类。[官方农场手册](https://www.storyofseasons.com/grandbazaar/manuals/nsw/01/) · [风车工坊与风力系统](../特色文档/风车工坊与风力系统.md)

<summary>展开原始表格与例子（历史口径，待逐项核查）</summary>

> 下方为旧稿原样备查，其中数值、触发或收益均未经版本核验；不可直接当作 2025 重制版规则。

### 7.1 风力等级对加工速度的影响

风车加工是本作经济的重要环节，而风力直接影响加工速度：

| 风力等级 | 天气条件 | 加工速度倍率 |
|:-------:|:--------:|:----------:|
| 0（无风） | 晴朗无风 | ×0.5（极慢） |
| 1（微风） | 晴朗 | ×1.0（标准） |
| 2（和风） | 多云 | ×1.5 |
| 3（强风） | 阴天/雨前 | ×2.0 |
| 4（暴风） | 暴风雨 | ×3.0 |
| 5（台风） | 台风 | ×5.0（极快） |

**策略启示：** 台风天应优先使用风车加工批量商品，同时外出捕蛙；无风天则安排农活、采矿等不受风力影响的活动。

## 十、总结

经济决策不是自由开价，而是把**生产、加工、渠道选择与两场摆摊**接成一条有时间约束的链。选品和库存会影响有没有货卖，趋势与顾客会影响卖得怎样，集市销售与摊位数又是不同的升阶约束。旧倍率、成本和解锁表没有删掉，已在各节就地保留，方便对照截图逐项修订。
