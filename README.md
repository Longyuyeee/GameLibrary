## 怎么读一份档案

1. 先看**版本、平台和适用范围**，避免把重制版、补丁或 DLC 的规则混在一起。
2. 再看**系统循环、数据表和复盘场景**。区分官方规则、示例假设和实测结果。
3. 最后看**设计取舍与待补充项**，用[跨品类对比](./跨品类对比/_index.md)找另一个解决同类问题的案例。

正式归档通常由 `游戏概览.md` 串联 `机制分析/`、`数值数据/` 与 `特色文档/`；尚未覆盖完整维度的专题档案收在品类的 `首版设定集/` 下。数值要可追溯，无法证实的内容标待补充，不凭空填表。既有档案校订以增补为主：保留表格、图、案例与来源；发现错误就更正并标明版本，未核实的旧值做历史记录，不把正文改成摘要。具体要求见[全局采集守则](./采集策略/GameDocs采集守则.md)和[品类采集策略](./采集策略/)。
