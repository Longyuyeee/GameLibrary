## 采集规则速览

> 📄 **全局强制规范**: [GameDocs 采集守则 v2.8](./采集策略/GameDocs采集守则.md) —— 采集前必读。

### 六条铁律

| # | 规则 | 说明 |
|:--:|------|------|
| 1 | **每个数字必须有来源URL** | 没有来源的数据不允许写入文档 |
| 2 | **文档深度 > 文档数量** | 一篇 5KB 详细数据表胜过三篇 1KB 空壳 |
| 3 | **真实数据 > 善意推测** | 无法验证的数据标注"待补充"，不凭空捏造 |
| 4 | **P0/P1/P2 仅决定顺序，不决定深度** | 所有游戏一律按最高标准采集 |
| 5 | **逐款串行采集** | 一次一款，验收通过后才能开始下一款 |
| 6 | **数据全量列出** 🆕 | 同类条目必须全部列出，不允许选择性节选 |

### 质量三级制

| 等级 | 机制文档 | 数据文档 |
|:--:|------|------|
| **A ⭐** | ≥10KB + 5+数据表 + 设计意图分析 + 跨游戏对比 | ≥5KB + 全结构化表格 + 策略分析 |
| **B** | ≥3KB + 3+数据表 + 设计特点分析 | ≥2KB + 表格主体 + 来源标注 |
| **C ⚠** | <3KB 或纯文字无表格（红线——不可接受） | <2KB 或数据稀疏 |

### 来源优先级

```
官方Wiki(L1) → 社区Wiki(L2) → Steam指南(L3) → 视频攻略(L4) → 社区讨论(L5) → 评测分析(L6) → 数据挖掘(L7)
```
