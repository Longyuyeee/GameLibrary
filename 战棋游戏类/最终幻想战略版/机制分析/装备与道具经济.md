# 装备与道具经济 — 最终幻想战略版 (FFT)

> 游戏版本: FFT (PS1, 1997) | 数据来源: [FFT Wikia](https://finalfantasy.fandom.com/wiki/Final_Fantasy_Tactics), [GameFAQs](https://gamefaqs.gamespot.com/ps/197339-final-fantasy-tactics/faqs)

## 一、装备系统

### 1.1 装备槽

| 装备槽 | 内容 | 说明 |
|------|------|------|
| **右手武器** | 剑/刀/斧/枪/锤/棒/杖/弓/自动弓/手里剑/骑士剑/忍者刀等 | 主手攻击力 |
| **左手武器/盾** | 盾牌(回避+物防)/副手武器(Ninja Doublehand要求) | — |
| **头盔** | 帽子/头盔/发饰 | HP+少量防御 |
| **铠甲** | 衣服/铠甲/袍 | HP上限+物理防御 |
| **饰品** | 戒指/靴子/斗篷/护符 | 特殊属性——移动/Speed/状态免疫 |

**5个装备槽**——介于风花雪月(3槽)和皇骑(7槽)之间。

### 1.2 武器类型与职业绑定

FFT的武器不是"任何职业可用"——**每种武器只能被特定职业使用**：

| 武器类型 | 可用职业 | 核心特点 |
|------|------|------|
| 剑(Sword) | 侍从/骑士/圣骑士等 | 最广泛可用 |
| **骑士剑(Knight Sword)** | **仅骑士/圣骑士/剑圣** | **最强物理武器——WP高+Buff/Holy属性** |
| 刀(Katana) | 侍(Samurai)独有 | 刀术(Iaidou)——范围/破防 |
| 忍者刀(Ninja Sword) | 忍者独有 | WP×Speed公式——高速度=高伤害 |
| 枪(Spear) | 龙骑士独有 | Jump攻击相关 |
| 斧(Axe) | 部分战士系 | 伤害随机化——最低1×PA到最高WP×PA |
| 锤(Flail) | 部分战士系 | 同斧——随机化伤害 |
| 弓(Bow) | 弓箭手独有 | 远程——蓄力Charge |
| 自动弓(Crossbow) | 特定职业 | 固定伤害——不依赖PA |
| 杖(Staff) | 法师系 | 魔法攻击力加成 |
| 棒(Rod) | 法师系 | 同杖但更偏向状态魔法 |

**关键设计**：武器-职业绑定意味着**改变武器类型需要改变职业**——不像风花雪月可以"任何职业拿任何武器"。这是FFT追求"职业定位清晰化"的结果。

### 1.3 盾牌与回避

| 盾牌 | 物理回避% | 魔法回避% | 物防 |
|------|:--:|:--:|:--:|
| 小盾 | +10 | 0 | 0 |
| 中盾 | +20 | 0 | +1 |
| 大盾 | +30 | 0 | +2 |
| **艾斯库盾(Aegis Shield)** | +10 | **+50%** | +1 |
| **源氏盾(Genji Shield)** | +30 | +15 | +2 |

披风(Cape)/斗篷(Cloak)饰品也提供物理/魔法回避。

## 二、装备与Speed的关系

这是FFT装备系统最核心的设计：**装备不影响行动速度**——与皇骑"重量→WT惩罚"完全相反：

| 维度 | FFT | 皇骑 |
|------|------|------|
| 装备→行动速度 | **不影响Speed**——穿重甲也不会变慢 | 重量直接加入WT——重=慢 |
| 代价方式 | 占用装备槽(不能同时穿重甲和饰品) | 重装备→高WT→行动间隔长 |
| 设计哲学 | "装备是纯增益——选择在'用什么'而不在'放弃什么'" | "每件装备都有代价——选择是'值得吗'" |

## 三、道具系统

### 3.1 消耗品

| 道具 | 效果 | 道具士专属？ |
|------|------|:--:|
| ポーション (Potion) | 恢复30HP | 否——全员可用 |
| ハイポーション (Hi-Potion) | 恢复70HP | 否 |
| エクスポーション (X-Potion) | 恢复150HP | 否 |
| エーテル (Ether) | 恢复20MP | 否 |
| フェニックスの尾 (Phoenix Down) | 复活(1-20HP) | 否 |
| 解毒薬 (Antidote) | 消除中毒 | 否 |
| 目薬 (Eye Drop) | 消除黑暗(Blind) | 否 |
| 聖水 (Holy Water) | 消除Undead/僵尸 | 否 |

**全员可用道具**是FFT的重要设计——不像火纹需要职业或技能才能用特定道具。

### 3.2 道具士的独有价值

道具士（最初期职业）有两个独特能力：
- **Auto-Potion（反应技）**：受到伤害后自动使用最低阶治疗药——Brave%触发率。这是游戏中最可靠的生存技能之一
- **Move-Find Item（移动技）**：移到特定地图格会发现隐藏宝物——全游戏最低Brave(≤20)才能发现最好宝物

## 四、金币经济

| 金币来源 | 量级 |
|------|:--:|
| 主线战斗 | 稳定增长——数量有限 |
| 随机战斗（地图上的红色地点） | 可无限刷 |
| 出售不需要的装备 | 主要——因章节推进而淘汰装备 |

| 消费 | 优先级 |
|------|:--:|
| 购买新装备（每章更新） | ★★★★★ |
| 购买消耗品 | ★★★ |
| 购买技能学习道具 | ★★（少量——大多数技能靠JP学） |

装备是FFT经济的主要驱动力——每章结束后商店更新一批新装备，购买这些装备是最必须的花费。

## 五、设计特点总结

1. **武器-职业绑定创造"装备选择=职业选择"**：你不能"让一个忍者装备骑士剑"——必须转成骑士才能使用骑士剑。这让装备选择与职业选择紧密耦合。
2. **Speed不受装备影响——鼓励"穿最好的"**：不像皇骑需要考虑重量惩罚，FFT鼓励玩家始终穿最好的装备。
3. **Auto-Potion=早期最重要投资**：一个250JP的反应技——可以让非治疗职业拥有内置的自愈能力。这体现了FFT"跨职业技能组合"的设计核心。
