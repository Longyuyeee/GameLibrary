# 招募与永久死亡 — 最终幻想战略版 (FFT)

> 游戏版本: FFT (PS1, 1997) | 数据来源: [FFT Wikia](https://finalfantasy.fandom.com/wiki/Final_Fantasy_Tactics), [GameFAQs](https://gamefaqs.gamespot.com/ps/197339-final-fantasy-tactics/faqs)

## 一、招募系统——品类最早的"说服加入"

FFT的招募是SRPG中最早将"敌方单位在战斗中叛变加入己方"作为核心系统的游戏之一。

### 1.1 话术士的Invite(劝说)

话术士(Orator/Mediator)拥有Invite技能——**直接说服敌方人类单位加入你的队伍**：

| 参数 | 说明 |
|------|------|
| 成功率 | 基于目标Faith——低Faith更难成功 |
| 星座修正 | 好匹配+50%成功率 / 恶匹配-50% |
| 目标限制 | 仅限人类单位——不能招募怪物/剧情角色 |
| 加入后 | 装备=原始装备+职业=原始职业——全部可用 |

### 1.2 偷心(Steal Heart)

盗贼的Steal Heart——**魅惑状态**（不是永久招募）：

| 参数 | 说明 |
|------|------|
| 效果 | 目标变为友方1-3回合 |
| 成功率 | 基于目标Faith+星座 |
| 战术用途 | 临时获得敌方单位控制权 |

### 1.3 怪物驯服

怪物无法被"招募"——但可以被**养在队伍中**：

| 方法 | 说明 |
|------|------|
| 话术士的Entice | 战斗中说服从敌人中招募怪物 |
| 孵蛋(Monster Breeding) | 获得怪物蛋→孵化→获得幼体 |
| 怪物技能 | 怪物通过升级自动学习技能——不需要JP |
| 怪物产蛋 | 高等级怪物可在特定条件产蛋 |

**对比**：
- 火纹的"说得"——需要特定角色+特定对话
- 皇骑的Recruit——基于目标HP/忠诚/技能
- FFT的话术士——基于目标Faith+星座+说话

FFT的方式给了一个专门的"招募职业"——话术士的唯一存在意义之一就是招募。这是"社交"在FFT中的战斗化表现——话说服一个人不是在过场中进行的，是在刀刃相交的战场上进行的。

## 二、永久死亡系统

### 2.1 死亡机制

| 状态 | 说明 |
|------|------|
| HP=0 | 角色倒下——进入**濒死(KO)状态** |
| **倒计时=3** | 角色头顶出现3→2→1倒计时 |
| 倒计时=0 | **永久死亡**——角色从游戏中永远消失 |
| 在此前被不死鸟尾巴/白魔法Raise治疗 | 恢复——倒计时清除 |

这与皇骑的三连倒计时完全相同——FFT从皇骑继承了这一设计。

### 2.2 死亡变成水晶/宝箱

FFT的永久死亡有独特的后续机制：

| 倒计时归零后 | 效果 |
|------|------|
| **变成水晶(Crystal)** | 相邻单位可"读取"水晶→**立即学会目标已学的一个技能** |
| **变成宝箱(Treasure)** | 较低概率——可拾取→获得随机道具 |

**设计深意**：死亡不只是"失去"——是"遗留给队友的最后的礼物"。一个死去同伴的水晶可以让生者学会他生前掌握的一个技能。这在游戏机制层面完成了一句叙事："死去的人不会完全消失——他们留下的东西会继续影响活着的人"。

### 2.3 剧情角色保护

剧情角色(拉姆扎/阿格里亚斯/奥兰多等)在HP归零时不会永久死亡——他们变为"濒死"状态但倒计时永远不会到0。设计上这是为了"保护故事完整"，但在一个永久死亡系统中，它对"死亡的真实性"是一种妥协。
