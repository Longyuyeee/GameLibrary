# Brave信仰与星座系统 — 最终幻想战略版 (FFT)

> 游戏版本: FFT (PS1, 1997) | 数据来源: [FFT Wikia](https://finalfantasy.fandom.com/wiki/Final_Fantasy_Tactics), [GameFAQs 勇气信仰详解](https://gamefaqs.gamespot.com/ps/197339-final-fantasy-tactics/faqs)

## 一、Brave与Faith——战棋品类最独特的角色数值

FFT有两个在任何其他战棋中都没有的属性——**Brave(勇气)**和**Faith(信仰)**。它们不是常规的战斗属性——它们是**人格数值**，直接定义了角色在战斗中"如何行动"以及"对外界的反应"。

### 1.1 Brave（勇气）

| Brave值 | 效果 | 角色行为 |
|:--:|------|------|
| **0-9** | 极其胆小——**会因恐惧而变成小鸡(Chicken状态)**——无法控制 | 战斗中可能逃跑 |
| 10-39 | 胆小——反应技能触发率低 | 正常战斗 |
| 40-60 | 正常——多数角色在此范围 | 正常战斗 |
| 61-80 | 勇敢——反应技能触发率高 | 高伤害输出 |
| **81-96** | 极其勇敢——**最强物理技能可发动(Brave≥97=无伤害?)** | 反应技能近乎必触发 |
| **97-100** | 终极勇气——部分终极武器属性收益最大化 + **战斗中永久可行动** | 无视任何恐惧效果 |

**Brave的核心机制**：
```
反应技能触发率 = Brave%（如Auto-Potion——Brave 70 = 70%概率自动喝药）
物理伤害修正 = Brave×武器修正(部分武器有此公式——如骑士剑)
Brave降至0 → 角色变成小鸡(Chicken) → 永久无法控制(除非恢复)
```

**Brave的永久改变**：
- 战斗中Brave临时变化（受技能影响）
- 每场战斗后，**Brave永久改变的1/4被保留**
- 例如：战斗中Brave +20 → 战斗结束后永久Brave +5
- 话术士的Praise(赞美)+4 Brave/次 → 可以"培养"角色的勇气

### 1.2 Faith（信仰）

| Faith值 | 效果 | 角色行为 |
|:--:|------|------|
| **0** | **完全无神论者**——魔法免疫（不吃任何魔法伤害和治疗！） | 魔法完全无效于该角色 |
| 1-30 | 微弱信仰——魔法效果大幅降低 | 少受魔法伤害但也不受治疗 |
| 40-60 | 正常——多数角色在此范围 | 标准魔法反应 |
| 61-80 | 虔诚——魔法效果增强 | 高魔法输出/治疗接收 |
| **81-94** | 极其虔诚——魔法威力极大 | 可能获得隐藏魔法 |
| **95-100** | 绝对信仰——魔法效果最大化 | **但——Faith 100时角色永久离开队伍加入教会！** |

**Faith的核心机制**：
```
魔法伤害修正 = 施法者Faith × 目标Faith / 10000
魔法命中率 = 基础命中 + 施法者Faith × 目标Faith修正
Faith≥95 → 角色可能在战后永久离开（去加入教会）——永久丢失！
Faith=0 → 魔法免疫——不吃任何魔法（包括治疗和复活！）
```

**Faith=0的设计深意**：一个"完全不信仰任何东西"的角色——在FFT的魔法世界中，这意味着他/她与"神"完全切断。叙事上这是一个人格设定，战斗上这是"物理纯主义"的终极形态。

## 二、勇气的双重性——战斗与叙事的统一

Brave和Faith最独特的设计不是它们的战斗效果——而是它们**同时也是叙事属性**：

| 属性 | 战斗维度 | 叙事维度 |
|------|------|------|
| **Brave** | 反应触发率 + 物理修正 | "这个角色面对危险时如何反应？" |
| **Faith** | 魔法效果 + 命中率 | "这个角色信仰神（和世界）的程度？" |

**Brave=0的故事**：一个Brave降到0的角色变成小鸡——不是被魔法变成小鸡，而是"被恐惧压垮到失去人形"。在FFT的政治黑暗叙事中，这是一个角色在战争的压力下崩溃的叙事回响。

**Faith=100的结局**：当Faith达到100，角色会离开军队去加入教会——是对"绝对信仰=失去自我"的叙事陈述。FFT的整个故事是关于**教会如何用信仰操控和剥削人类**的，Faith=100=离开的机制是将这个主题直接写入战斗系统。

## 三、星座(Zodiac)兼容性——隐藏的"天生相性"

FFT中每个角色出生时带一个固定的**星座**（12星座+蛇夫座=13th），这是游戏中唯一的**不可改变的属性**：

| 星座配对 | 兼容性 | 伤害修正 | 命中修正 |
|------|:--:|:--:|:--:|
| **最佳匹配** | 《好》 | +25%伤害 | +50%命中/魔法成功率 |
| **最差匹配** | 《恶》 | -25%伤害 | -10%命中 |
| 同星座 | 《中立(好)》 | +12% | +10% |
| 一般配对 | 《中立》 | 0 | 0 |

星座兼容性是**隐藏的**——玩家不能直接查看两个角色之间的星座关系（必须查表或通过反复试错感知）。

**设计深意**：星座兼容性是有意识地用"出生时就决定的、不可改变的关系"来制造角色之间天生的协同或摩擦。这与Brave/Faith的"可通过培养改变"形成对比——星座是你生来就是的，勇气/信仰是你成为的。

## 四、星座兼容的"残酷"随机性

松野在1997年访谈中特别提到——他不喜欢"100%可预测"。星座系统的"好/恶匹配"在一个"你可能无法改变"的层面上引入了不可预测性：

- "我最喜欢的角色是《恶》匹配对最终BOSS——在不知道的情况下，这将是多么困难的一战"
- 但正是这种"不可预见的相性"创造了独特的记忆——"那场战斗中我的盗贼竟然对BOSS造成了毁灭性伤害——因为他们是《好》匹配"

**与风花雪月/皇骑对比**：

| 游戏 | 角色永久属性 | 可改变属性 |
|------|------|------|
| **FFT** | **星座**——天生、不可变 | Brave/Faith——可通过技能改变 |
| 风花雪月 | 固有技能——不可变 | 全属性+技能等级——可培养 |
| 皇骑 | 角色元素——不可变 | 忠诚度/装备——可改变 |

## 五、设计特点分析

1. **Brave/Faith是"人格=数值"设计的先驱**：在1997年，将一个角色的"勇气"和"信仰"作为可量化的战斗属性，并将其与战斗性能直接挂钩——这不是"属性影响性格"（如D&D），而是"性格直接影响属性"。这是松野对"SRPG可以如何深刻"的回答。
2. **Faith=100=永久离开的极端规条**：设计师用这个规则告诉玩家——"绝对信仰是有代价的"。在FFT的叙事中，教会利用信仰控制人民——而Faith 100角色离开去"加入教会"是叙事直接吞噬战斗机制。
3. **星座隐藏兼容性是"玩家无可掌控的命运"**：松野刻意不让玩家可视化星座兼容性——因为他相信"玩家无法掌控一切"是让战斗变得有趣的要素。这与他"不喜欢100%可预测"的设计哲学一致。
