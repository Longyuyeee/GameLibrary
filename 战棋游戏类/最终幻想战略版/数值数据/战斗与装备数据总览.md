# 战斗与装备数据总览 — 最终幻想战略版 (FFT)

> 游戏版本: FFT (PS1, 1997) | 数据来源: [FFT Wikia](https://finalfantasy.fandom.com/wiki/Final_Fantasy_Tactics), [Caves of Narshe](https://www.cavesofnarshe.com/fft/jobs.php)

## 一、属性面板

| 属性 | 作用 | 来源 |
|------|------|------|
| **HP** | 生命值(≈50-500+) | 职业+等级+装备 |
| **MP** | 法力值(≈10-200+) | 职业+等级+装备 |
| **PA** | 物理攻击力(≈3-25) | 职业+等级+装备 |
| **MA** | 魔法攻击力(≈3-28) | 职业+等级+装备 |
| **Speed** | CT累积速度(≈4-15) | 职业+装备+部分技能 |
| **Move** | 移动格数(≈3-6) | 职业+装备+移动技 |
| **Brave** | 反应触发率(0-100) | 初始固定+可培养 |
| **Faith** | 魔法互动倍率(0-100) | 初始固定+可培养 |

## 二、CT系统速查

| 参数 | 公式/值 |
|------|------|
| CT每Tick累积 | CT + Speed |
| 行动触发 | CT ≥ 100 |
| 行动后重置 | CT → 0(或保留溢出) |
| 等待(Wait) | CT → 20-40(而非重置为0) |
| 咏唱时间 | Fire=4CT, Bolt3=7CT, Haste=6CT, Bahamut=20CT |
| Charge+1~20 | 弓箭手咏唱——+1~20CT后自动射击 |

## 三、伤害公式速查

| 类型 | 公式 |
|------|------|
| 物理伤害 | PA × WP(武器威力) × 物理AT |
| 忍者刀伤害 | (PA+Speed)/2 × WP |
| 骑士剑伤害 | PA × WP × Brave/100 |
| 斧/锤伤害 | PA × (随机1~WP)——随机化！ |
| 魔法伤害 | MA × 魔法威力 × (施法Faith×目标Faith)/10000 |
| 物理命中 | 武器基础命中 + 星座修正 − 目标回避 |
| 魔法命中 | 基础命中 + 施法Faith×目标Faith/10000 + 星座修正 |
