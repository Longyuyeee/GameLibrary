# 故事背景与世界观分析 — 最终幻想战略版 (FFT)

> 游戏版本: FFT (PS1, 1997) | 数据来源: 游戏内剧情+阿鲁卡兹拉姆旁白, [松野泰己1997/1999/2025开发者访谈](https://web.archive.org/web/20160607155523/http://shmuplations.com/fft/)

## 一、世界地理——伊瓦利斯(Ivalice)

FFT的世界是**伊瓦利斯王国(Kingdom of Ivalice)**——这个设定后来被FFXII和FFTA系列沿用：

| 区域 | 说明 |
|------|------|
| **王都** | 伊瓦利斯的政治中心——但国王死后被功能性地弃置 |
| **加拉多纳(Gariland)** | 军事学院所在地——拉姆扎和迪利塔的起点 |
| **多特(Dorter)** | 商都——经济枢纽，狮子战争中沦为战场 |
| **拉奥涅吉(Lionel)** | 格列巴德斯大圣堂所在地——教会的政治中心 |
| **泽尔蒂尼亚(Zeltennia)** | 黑狮子戈尔塔纳公爵的领土——南方势力 |
| **伊格罗斯(Igros)** | 白狮子拉格公爵的领土——北方势力 |
| **地底寺院(Deep Dungeon)** | 隐藏地牢——卢卡维最深的巢穴 |
| **穆兰多(Mullonde)** | 教会总部——最终战役地点 |

## 二、历史——狮子战争

### 历史背景

| 时期 | 事件 |
|------|------|
| 远古 | 卢卡维(Lucavi)战争——远古的恶魔之战 |
| ？ | 圣阿乔拉(St. Ajora)出现——建立格列巴德斯教 |
| 约50年前 | 五十战争(50 Years' War)——伊瓦利斯与邻国奥尔达利亚(Ordalia)的长期战争 |
| 游戏开始前 | 欧姆多利亚三世国王去世——留下幼子奥里纳斯(Orinas) |
| 游戏开始时 | **狮子战争爆发**——白狮子(支持幼王) vs 黑狮子(支持奥维莉亚公主) |

### 狮子战争——核心叙事背景

```
已故国王欧姆多利亚三世
    ├─ 幼王奥里纳斯 (Orias) —— 2岁婴儿
    ├─ 女王鲁维莉亚 (Ruvelia) —— 幼王的母亲→代理执政
    ├─ 奥维莉亚公主 (Ovelia) —— 国王的义妹(非亲生)
    │
    ├─ 白狮子·拉格公爵 (Duke Larg) —— 支持幼王/女王
    └─ 黑狮子·戈尔塔纳公爵 (Duke Goltana) —— 支持奥维莉亚公主
```

**两个公爵不是为了"谁是对的"而战斗**——他们是为了**摄政权**。而教会在这场战争之下**正在秘密操纵一切**：战争的持续时间越长，产生的死亡越多，越接近"用人类的鲜血复活卢卡维"的条件。

### 卢卡维——不是"恶魔"
松野在访谈中说他不认为卢卡维是"通常意义上的恶魔"。他们是**远古战争中失败后被压制的存在**——他们的"邪恶"是战败方的视角。这个"连反派都是历史的受害者"的设计是松野的标志。

## 四、格列巴德斯教(Glabados Church)

### 真实的本质
- **表面**：信仰圣阿乔拉的一神论教会——伊瓦利斯的国教
- **真相**：圣阿乔拉是Ultima(卢卡维之首)的背叛者/容器——整个教会的历史叙事是**故意编造的**
- **运作方式**：用信仰控制民众→利用政治分裂制造战争→用战争的死亡作为复活卢卡维的祭品
- **为什么没人发现**：教会的骑士团(圣殿骑士)消灭任何发现真相的人——奥兰(Orran)被烧死在火刑柱上即是因此

**松野的宗教批判来源**：他在大学时期研究政治学，特别受到欧洲宗教裁判所和"异端"迫害史的影响。格列巴德斯教不是"某个坏人的阴谋"——是一个**用信仰作为政治控制工具的、在制度层面上腐败的机构**。

## 五、核心主题

| 主题 | 体现 |
|------|------|
| **阶级的无法跨越** | 拉姆扎的贵族出身=他有选择"放弃"权力。迪利塔的平民出身=他必须"夺取"权力 |
| **历史由胜者书写** | 阿拉兹拉姆在几个世纪后发现被压制的真相——"真正的英雄被历史擦除了" |
| **体制的暴力** | 不是"某个坏人的暴力"——是制度性的、由社会结构驱动的暴力 |
| **信仰作为政治工具** | 教会=整个游戏中最成功的"反派"——不是因为它邪恶，是因为它**有效** |
| **道德勇气vs政治成功** | 拉姆扎=道德勇气但被遗忘；迪利塔=政治成功但被自己憎恨 |

## 六、设计——1997年的突破性叙事

| 叙事要素 | 在那个时代(1997)有多突破 |
|------|------|
| 宗教机构=反派 | 极其罕见——尤其是FF系列的"水晶/光之战士"传统 |
| 阶级冲突 | 极其罕见——RPG中的"阶级"通常是"矮人vs精灵"而非"贵族vs平民" |
| 被历史擦除的英雄 | 极其罕见——happy ending的替代是"胜利但不被记住" |
| 无"最终魔王"式反派 | 罕见——最终Boss是Ultima但她不是"邪恶意志"，是被释放的复仇 |
