# 团队与开发历程 — 最终幻想战略版 (FFT)

> 开发商: Square (现Square Enix) | 发行: 1997年6月20日(日本) / 1998年1月28日(北美) | 平台: PlayStation
> 开发团队: 约30-40人核心团队

## 1. 开发团队

### 核心成员
| 角色 | 姓名 | 主要贡献 |
|------|------|------|
| **导演/编剧/系统设计** | **松野泰己** (Yasumi Matsuno) | 故事+世界观+职业系统——游戏的核心创造者 |
| **战斗系统设计** | 伊藤裕之 (Hiroyuki Itou) | CT战斗系统——从FF主系列的ATB改编而来 |
| **角色设计** | 皆川裕史 (Hiroshi Minagawa) | 所有角色的视觉设计+美术方向 |
| **音乐** | 崎元仁 (Hitoshi Sakimoto) + 岩田匡治 (Masaharu Iwata) | 管弦乐风格——与FF主流Uematsu形成对比 |
| **制片人** | 坂口博信 (Hironobu Sakaguchi) | "Final Fantasy Tactics"这个名字是他定的——1993年就注册了商标 |

### 坂口博信的"早期创意"
坂口在1993年就起草了一份5-6页的设计文档，并将"Final Fantasy Tactics"注册为商标。但松野和伊藤接手项目后，**几乎放弃了坂口的所有原稿想法**——松野的Quest/皇骑背景和伊藤的ATB系统经验共同塑造了最终产品。

### 松野的Quest遗产
松野带着从Quest(皇骑的开发公司)的所有经验来到Square——团队的约一半成员来自Quest。他们是SRPG开发者，而不是传统RPG开发者——这解释了FFT与FF系列完全不同的DNA。

## 2. 开发历程

### 时间线与关键节点

| 时间 | 事件 |
|------|------|
| 1993年 | 坂口注册"Final Fantasy Tactics"商标 |
| 1995年(约) | 松野离开Quest加入Square——带着皇骑的经验 |
| 1996年 | FFT主要开发期——伊藤加入负责战斗系统 |
| **1997年6月20日** | **日本发售** |
| 1998年1月28日 | 北美发售 |
| 2007年 | PSP增强版《狮子战争》(War of the Lions)发售——新过场+新职业+新角色+联机 |

### 关键设计决策

**1. 松野与伊藤的"意外合作"**
伊藤裕之本来不是战棋游戏设计者——他是FF系列ATB战斗系统的创造者。他加入FFT项目是因为团队人手不足。伊藤在后来的访谈中坦承他**个人不喜欢战略游戏**——他无法忍受管理一大堆单位然后一个个操作。但他的解决方案不是"简化"——而是"让它变得足够刺激以至于我自己也愿意玩"。

**2. 60fps的不可妥协**
松野坚持地图必须保持60fps——这是他在皇骑时就有的标准。团队因此将战斗地图锁定在16×16格——任何更大的地图都无法保持60fps。松野在访谈中说：如果CD-ROM游戏的流畅度不如卡带游戏，那将是开发团队的耻辱。

**3. 约30%的"超出完成所需的内容"**
坂口后来评价FFT有"比通关所需多出约30%的额外内容/能力"——这是有意为之。松野设计了深度的职业系统，使休闲玩家能在正常流程中通关，而完成主义者能在通关后继续探索隐藏职业(算术士)和地牢(Deep Dungeon)。

**4. 被删除的DPS角色和额外内容**
松野在早期设计了一个额外的DPS类角色，但在开发后期被砍掉。地图编辑器(在皇骑中可用)被考虑过但从未实现。

## 3. 技术与工具

- **引擎**：Square内部PS1引擎——来自《最终幻想》系列的技术积累
- **画面**：等角3D战场 —— 可360°旋转 + 缩放。松野意在创造"盆景(diorama)"般的视觉感受
- **音频**：CD音质BGM——崎元仁和岩田的管弦乐配乐，与Nobuo Uematsu的FF主系列形成音乐风格分界
- **CG过场**：PS1版仅有少量CG——《狮子战争》PSP版新增动画风格过场+全程语言

## 4. 市场表现

| 指标 | 数据 |
|------|------|
| 日本上半年(1997) | **约82.5万份** |
| 日本年末(1997) | **约124万份** |
| 日本累计(2007年截止) | 约135万份 |
| **全球累计** | **超过240万份** |
| 评価 | IGN 1998: 8.5/10 —— 后续被评为"史上最伟大的PS1游戏之一" |
| 媒体地位 | 常年在"史上最伟大游戏"各类榜单中出现 |

**商业意义**：240万份在1997-98年的PS1平台上是不错的成绩，但它真正的意义在于**品类影响**——FFT证明了SRPG在主流市场上可以成功，为后续的FFTA系列和火纹觉醒等铺平了道路。

## 5. 设计启示

1. **当ATB设计师做战棋时**：伊藤裕之的CT系统是"一个不喜欢战棋的人如何让战棋变好玩"的答案——快速节奏、魔法咏唱可被打断、Speed=最高属性。
2. **松野的"政治性"设计哲学**：游戏不是"好vs坏"——是不同政治立场的人在任何战争中都相信自己是对的。这个哲学在1997年是罕见的，在今天的SRPG品类中仍然被风花雪月等游戏继续探索。
3. **职业系统=无法停止挖掘的深井**：22职业+JP经济+4槽自由组合——这是SRPG品类中至今仍未被超越的培养自由度。风花雪月继承了"职业技能精通后可装备"的理念，但FFT的"任何已学技能=副技能槽可用"的自由度更宽。
