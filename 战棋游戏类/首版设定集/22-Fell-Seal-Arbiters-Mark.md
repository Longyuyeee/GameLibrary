## 2. 战术层：一格不是一个数字

按[官方手册](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/699170/manuals/fellseal_manual_dtp_english.pdf?t=1736373773)战斗章节（印刷页 5–8）：

| 对象 | 规则 | 实战要记什么 |
| --- | --- | --- |
| 移动与行动 | 普通回合可在行动前或后移动，不把“先走再打”当成唯一顺序 | 出手格、行动后可抵达格、回合结束朝向 |
| 远程目标 | 水平距离和高度差分别判定；普通远程攻击在两项均合规时，不因中间有障碍就自动失效 | 分开存水平射程、垂直上限、技能例外，不沿用 XCOM 的掩体或视线逻辑 |
| 侧背与预测 | 普通攻击和许多能力受侧背伤害影响，法术通常例外；命中后通常按预测伤害结算，暴击和特殊效果另计 | 固定攻击者、装备与技能再对照三种朝向；记录命中与伤害两个字段 |
| 范围技能 | 部分区域效果也会作用于队友 | 记录中心格、受影响格和实际受影响的阵营 |
| MP | 战斗从 0 MP 开始，单位自己的回合开始时补 10 MP | 区分全局回合与各单位行动；带着消耗、额外回蓝与上限记录 |

**纸面读图**：同一名远程单位已有合法目标时，可以先出手再离开暴露格；若先移动才满足水平或高度要求，则比较新格能否取得侧背、打完后是否还暴露在下一个敌方单位的行动范围内。记录两条走法各自的射程与伤害预测，不用「站得越高就一定打得越痛」代替判定。相同角色、攻击但改变朝向的三组截图，比换三个职业来举例更能验证侧背规则。

## 3. 从倒地到下一战：复活位置、伤势与替补 AP

[官方手册](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/699170/manuals/fellseal_manual_dtp_english.pdf?t=1736373773)印刷页 8 的关键点不是「能复活」本身，而是**可在复活物品或技能的范围内选择合法格，不必回到原倒地格**。伤势设置为 Default 时，普通盟友降到 0 HP 获得一层伤势；同一战中救起后再次倒地可再加一层。不出战并完成一场战斗，消除一层。这里的 Default 是「伤势系统」设置，不代表所有难度预设都相同；选择 AP 惩罚或关闭伤势后不能套用此例。伤势所影响的精确属性、叠加和取整另测，不把社区的概括写成固定公式。

| 默认设置对照 | 路线 A：救起后存活 | 路线 B：救起后再次倒地 |
| --- | --- | --- |
| 起点 | 同一名非 Kyrie、无伤普通盟友首次倒地 | 同左 |
| 复活 | 用道具把盟友放在范围内另一个合法格 | 同一复活手段，之后令其再次降至 0 HP |
| 本战后预期 | 1 层伤势 | 2 层伤势 |
| 下一场巡逻坐替补、队伍完成后预期 | 剩 0 层 | 剩 1 层 |
| 需要同时记录 | 最初倒地格、实际复活格、剩余复活次数、替补前后各职业 AP | 同左，不把第二次倒地的其他影响误判成替补惩罚 |

Kyrie 是单独的规则分支：她不受伤势惩罚；剧情战中如果她曾降到 0 HP，即便胜利前复活，也拿不回「Kyrie 全程未倒」才有的参战者 AP 奖励。验证时另做两支固定参战名单、固定职业的剧情战存档，不把这项额外奖励和后备学习混算。相比[《最终幻想战略版 A2》](./21-Final-Fantasy-Tactics-A2.md)违规则失去本场复活权，Fell Seal 更关注**救到哪里、会不会再倒、下一场要不要换人**。这不是两作都采用同一种惩罚。

## 4. 职业与成长：拆开装备、成长、能力槽和 AP

按[官方手册](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/699170/manuals/fellseal_manual_dtp_english.pdf?t=1736373773)职业与部队章节（印刷页 14、23–25）：

| 层级 | 已证规则 | 采集时不要混记 |
| --- | --- | --- |
| 当前主职 | 确定装备权限、升级时的属性成长、主要 AP 归属，自动使用已学主职主动与被动 | 当前等级的属性、升级增量、转职后的装备变化分开 |
| 副职 | 从另一已学职业带入其已学主动套组 | 不是逐个混搭多个副职主动，也不因此获得主职业装备权限 |
| 额外能力 | 另装两个已学被动和一个已学反击 | 不把主职自动生效的被动视为占用两个自选槽 |
| 职业解锁 | 花各自职业的 AP 学能力；每学一项令该职业等级加一，满足新职业的前置要求 | 人物等级与职业等级不同；记录前置职业、所需等级、AP 消耗和已学技能 |
| 旁听学习 | Vicarious Learning 能让部队其他角色（含未出战人员）获得相关职业 AP，部分尚未解锁的职业也能累积；实战人员的主职收益与替补收益分列 | 先保存全员各职业 AP，再控制出战名单与主职。不要把参战主职、替补主职和旁听增长当成同一基数 |

**配装实例**：手册画面展示 Kyrie 主职 Knight、副职 Mercenary，主职栏为 Chivalry，自定义栏为 War Craft，并可装 Counterattack。可复制的不是某种唯一最优配法，而是「换哪项会改变即时动作、哪项会影响装备和今后升级」。先验证只换副职时装备权限是否保持，再换主职记录装备与动作差异。职业 AP 旁听亦见[开发者在 Class AP 讨论中的说明](https://steamcommunity.com/app/699170/discussions/0/1733216261942741196/)；具体分配比例、级差折扣及取整留待实测。剧情战与巡逻的 AP 不能当作同基准样本。

**EXP 不等于 AP。** 手册把 EXP 记在战斗中的有效行动上：空走、未命中和没有产生效果的行动不计；击倒敌人和有效治疗的经验收益有独立调整。AP 是战后职业成长，坐替补有学习收益不等于能拿到同样的行动 EXP。本体的特殊怪物角色另循怪物职业成长规则，不能纳入人类旁听比例样本。

## 5. 物品经济：升级容量，不是消耗存货

战斗道具为队伍共用，每场有有限次数，下一战恢复；制作解锁新道具种类，或提高效果与每场可用次数。装备购买和制作材料是战外配置，道具本战余量是战内预算。来源：[官方手册](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/699170/manuals/fellseal_manual_dtp_english.pdf?t=1736373773)印刷页 9–11。

以复活道具为例，团队剩最后一次使用时，可比较「现在把前排救到远离敌方近战范围的合法格」与「保留次数防止稍后失去高价值单位」。道具补满并不意味着伤势清零：连续两战间，材料、次数、伤势位于不同的记录周期。采样时记 `道具类型 / 制作档 / 开战可用数 / 动作扣除 / 次战可用数`，不要用背包库存替代战斗容量。

## 7. 待验字段

1. **战斗**：战斗名、剧情／巡逻、游戏版本、难度和伤势设置、坐标和高度、能力预测与实际结算；把暴击及状态异常样本另存。
2. **培养**：保存三个对象（主职参战者、同职业替补、未解锁该职业的学习者）的前后 AP；再分别改变队伍等级和同主职人数，检查是否改变旁听分配。
3. **伤势**：同一个角色用同等级、主职和装备记录 0／1／2 层前后 ATK、DEF、MND、RES，并对照 HP、MP、速度；区分百分比取整、装备和设置差异。先做无自动复生样本，再单独记录 Rebirth。
4. **扩展**：只在已启用 DLC 的存档记录怪物族群、可选副职及派遣条件；补丁新增任务标注版本。各职业全表、地图格况与伤势精确数值尚未采齐。
