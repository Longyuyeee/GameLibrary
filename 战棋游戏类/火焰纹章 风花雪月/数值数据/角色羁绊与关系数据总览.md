## 一、支援等级战斗效果

| 支援等级 | 命中加成 | 回避加成 | 必杀回避加成 | 副官触发率 |
|:--:|:--:|:--:|:--:|:--:|
| 无 | 0 | 0 | 0 | 基础值 ~20% |
| C | +3 | +3 | 0 | ~25% |
| B | +5 | +5 | 0 | ~30% |
| B+ | +6 | +6 | 0 | ~35% |
| A | +7 | +7 | +5(特定组合) | **~40%** |
| A+ | +8 | +8 | +5 | ~50% |
| S (主角) | +10 | +10 | +5 | 剧情——终章后CG |

**规则**：支援加成仅在友军位于3格以内生效。邻接时(距离1格)加成×1.5。

## 五、配对结局规则

| 规则 | 说明 |
|------|------|
| 最大配对 | 每角色最终仅与1人达成配对结局 |
| 配对优先级 | 最高好感度对象(多等→首个达到A级的) |
| 独立系统 | 主角S支援不影响其他角色配对 |
| 跨学级配对 | 可能（如莉丝缇亚+梅尔赛德司） |
| 无配对 | 好感度不足→角色结局为"独自一人" |
