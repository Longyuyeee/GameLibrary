# 战斗公式与概率数据总览 — 火焰纹章：风花雪月

> 游戏版本: 火焰纹章：风花雪月 v1.2.0 (Nintendo Switch, 2019)
> 数据来源: [fe3h.com](https://www.fe3h.com/calculations), [Fire Emblem Wiki](https://fireemblemwiki.org), [GameRes](https://www.gameres.com/876165.html)

## 一、全战斗公式

| 公式名 | 公式 | 备注 |
|------|------|------|
| **攻速(AS)** | Speed − (武器重量 + 装备重量 − Str/5) | 结果不能超过Speed |
| **追击判定** | 攻速差 ≥ 4 → 双击 | 门槛=4（风花雪月） |
| **物理命中** | 武器命中 + Dex + 支援 + 技能 + 骑士团 − 弓射程惩罚 | — |
| **魔法命中** | 魔法命中 + (Dex+Lck)/2 + 支援 + 技能 + 骑士团 − 弓射程惩罚 | — |
| **物理回避** | AS + 地形 + 支援 + 技能 + 装备 + 骑士团 | — |
| **魔法回避** | (Spd+Lck)/2 + 技能 + 装备 + 骑士团 | 地形不影响魔法回避 |
| **物理伤害** | Str + 武器威力 + 特效 + 技能/骑士团 − 目标Def | 最小0 |
| **魔法伤害** | Mag + 魔法威力 + 特效 + 技能/骑士团 − 目标Res | 最小0 |
| **暴击率** | 武器暴击 + (Dex+Lck)/2 + 技能 + 装备 + 骑士团 + 战技 | — |
| **暴击回避** | Lck + 技能 | — |
| **计策命中** | 计策基础命中 + (使用者Cha − 目标Cha)×5 | — |
| **计策伤害** | 计策基础威力 + (使用者Cha − 目标Cha) | — |
