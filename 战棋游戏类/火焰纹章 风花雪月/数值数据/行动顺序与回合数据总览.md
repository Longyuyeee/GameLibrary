# 行动顺序与回合数据总览 — 火焰纹章：风花雪月

> 游戏版本: v1.2.0 | 数据来源: [fe3h.com](https://www.fe3h.com/calculations), [Fire Emblem Wiki](https://fireemblemwiki.org)

## 一、回合模式

| 参数 | 值 |
|------|------|
| 回合模式 | **PPEP**（Player Phase / Enemy Phase） |
| 我方可行动单位 | 全部存活单位（任意顺序） |
| 动作模型 | 移动 + 攻击/道具/待机（每单位每回合仅此一组动作） |
| 第三方行动 | 特定关卡有友军/第三军回合 |

## 三、副官（Adjutant）触发概率

| 副官类型 | 效果 | 触发概率（无支援） | 支援A触发概率 |
|------|------|:--:|:--:|
| 攻击型 | 追加攻击 | ~20% | ~40% |
| 防御型 | 减半追击伤害（可留1HP） | 100%（必定触发） | 100% |
| 治愈型 | 回合开始恢复HP | ~20% | ~50% |

## 四、天刻之脉动

| 参数 | 数值 |
|------|:--:|
| 初始次数 | 3 |
| 最大次数 | 13（剧情推进增加） |
| 回溯范围 | 本场战斗任意前一回合 |
| 充能 | 每场战斗重置 |

## 五、回合模式品类对比

| 游戏 | 回合模式 | 动作模型 |
|------|------|------|
| 风花雪月 | PPEP | 移动+攻击一次 |
| 皇骑重生 | WT/CTB | 按速度排序，混合行动 |
| FFT | CT | 按速度计累积值→到100→行动 |
| XCOM 2 | PPEP(双动) | 移动+射击 | 每单位2AP自由组合 |
| 陷阵之志 | PPEP(确定) | 移动+攻击(可交换顺序) |
