# 武器克制与兵种数据总览 — 火焰纹章：风花雪月

> 游戏版本: 火焰纹章：风花雪月 v1.2.0 (Nintendo Switch, 2019)
> 数据来源: [Serenes Forest](https://serenesforest.net/three-houses/), [游民星空](https://www.gamersky.com/handbook/201908/1210965.shtml)

## 一、Breaker技能（武器三角替代）

| 技能 | 来源职业系 | 效果(命中+20, 回避+20) |
|------|------|------|
| **剑杀** (Swordbreaker) | 斧系（勇士/飞龙骑士精通） | 对持剑敌人 |
| **枪杀** (Lancebreaker) | 剑系（刀剑将领/暗杀者精通） | 对持枪敌人 |
| **斧杀** (Axebreaker) | 枪系（圣骑士/飞马骑士精通） | 对持斧敌人 |
| **弓杀** (Bowbreaker) | 飞行系（飞龙/飞马精通） | 对持弓敌人 |
| **格斗杀** (Fistbreaker) | 部分高级职业精通 | 对持格斗敌人 |
| **魔法杀** (Tomebreaker) | 部分物理系职业精通 | 对持魔法敌人 |

**设计关键**：Breaker不内置——占用1个能力槽(共5槽+1独有)。选择装哪个Breaker = 主动战前规划。
