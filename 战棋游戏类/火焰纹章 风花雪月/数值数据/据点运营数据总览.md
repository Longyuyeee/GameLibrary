# 据点运营数据总览 — 火焰纹章：风花雪月

> 游戏版本: v1.2.0 | 数据来源: [游侠攻略组](https://gl.ali213.net/html/2019-7/351891_2.html), [游民星空](https://www.gamersky.com/handbook/201907/1207284.shtml), [腾讯篝火](https://gouhuo.qq.com/guide/detail/2649575555145792)

## 一、日历行动类型

| 行动 | 功能 | 可执行频率 |
|------|------|:--:|
| **散步** | 修道院自由活动+设施+对话+挖角 | 每周日可选 |
| **讲习** | 教官授课→批量学生技能经验 | 每周日可选 |
| **出击** | 自由战斗/外传/支线 | 每周日可选 |
| **休养** | 恢复学生干劲+少量经验 | 每周日可选（极少使用） |

## 四、干劲系统

| 参数 | 值 |
|------|:--:|
| 最大干劲 | 100 |
| 每次授课消耗 | 25（成功） |
| 干劲=0时 | 授课无法提升技能 |
| 完美教学 | 不消耗干劲(+25恢复) |
| 最有效恢复 | 邀请用餐（+100到2人） |

## 五、温室种植关键数据

|------|------|------|
