# 战斗间运营 — 火焰纹章：风花雪月

> 游戏版本: 火焰纹章：风花雪月 v1.2.0 (Nintendo Switch, 2019)
> 数据来源: [游侠攻略组修道院指南](https://gl.ali213.net/html/2019-7/351891_2.html), [游民星空上手指南](https://www.gamersky.com/handbook/201907/1207284.shtml), [腾讯篝火营地修道院行动指南](https://gouhuo.qq.com/guide/detail/2649575555145792), [Serenes Forest - Monastery](https://serenesforest.net/three-houses/monastery/)

## 一、品类独有：日历制运营

风花雪月的"战斗之间"不是菜单，是一个**3D可探索区域内有独立活动经济**的完整运营层。这在战棋品类中是独一无二的——只有if的"マイキャッスル"（My Castle）有类似结构，但规模远小于此。

### 1.1 时间单位

| 时间单位 | 内容 | 玩家选择 |
|------|------|------|
| **周一至周五** | 授课（自动进行）——学生按设定的目标技能自动成长 | 仅在周末可选择目标技能 |
| **周末** | 自由行动日——4选1 | **散步 / 讲习 / 出击 / 休养** |
| **月底** | 主线战斗（强制） | 必须出战 |

### 1.2 周日活动选择对比

| 选择 | 效果 | 最优场景 |
|------|------|------|
| **散步** (Explore) | 修道院自由行动+活动+对话+挖角 | 培养好感度/招募/收集 |
| **讲习** (Seminar) | 讲师带领提升特定技能+干劲 | 批量快速提升技能等级 |
| **出击** (Battle) | 自由战斗/外传/支线 | 刷级/刷金币/刷道具 |
| **休养** (Rest) | 恢复所有学生干劲+少量经验 | 懒惰法（极少使用） |

## 二、散步系统——修道院行动经济

### 2.1 行动力（Activity Points）
- 每次散步提供**行动力点数**（初始1-3→教授等级提升后最多10）
- 使用设施活动需要消耗行动力（NPC头顶沙漏图标=消耗）
- 普通移动/对话/拾取/送礼**不消耗**

### 2.2 活动效能对比

| 活动 | 消耗点数 | 主要效果 | 性价比评级 |
|------|:--:|------|:--:|
| **邀请用餐** | 1 | 恢复2名学生干劲+提升支援度 | ⭐⭐⭐⭐⭐ 最佳 |
| **合唱练习** | 1 | 提升信仰(白魔法)+主角指挥+支援度 | ⭐⭐⭐⭐ |
| **教职员研修** | 1 | 主角技能等级提升（从教员学习） | ⭐⭐⭐⭐ |
| **茶会** | 1 | 大幅提升主角与一名角色的支援度 | ⭐⭐⭐（有限次数） |
| **烹饪** | 1 | 制作料理→下月战斗获得BUFF | ⭐⭐⭐ |
| **武斗大会** | 1 | 获取装备/奖金（连胜递增） | ⭐⭐⭐ |
| **钓鱼** | 0 | 获取素材/鱼（不消耗行动力） | ⭐⭐⭐⭐⭐ 免费 |
| **种植** | 0 | 收获作物/花卉/属性果实 | ⭐⭐⭐⭐ |
| **归还失物** | 0 | 寻找蓝色闪光+归还→提升支援 | ⭐⭐⭐⭐ |
| **送礼** | 0 | 选对礼物→好感度大幅提升 | ⭐⭐⭐⭐ |
| **查看信件** | 1 | 好感度提升 | ⭐⭐ |

### 2.3 干劲（Motivation）机制
```
干劲最大值 = 100
每次授课消耗 = 25（成功）或 0（完美=恢复25）
干劲 = 0时 → 授课无法提升技能
恢复方法 = 用餐（+100）/ 送礼 / 休养
```

**设计意图**：干劲系统创造了一个"散步活动→用餐恢复干劲→授课获得技能→战斗验证能力"的**周级循环**。这不是一个可有可无的副系统——它是风花雪月核心loop的第2步（共4步循环）。

## 三、教授等级系统

### 3.1 教授等级效果
```
教授等级 = 指导经验累积（散步+战斗+授课均会增加）
```

| 教授等级 | 解锁效果 | 行动力 |
|:--:|------|:--:|
| E | 基础教学 | 1-2 |
| D | 副官1人 | 3 |
| C | 副官2人+最上级职业解锁 | 4-5 |
| B | 副官3人+更多活动 | 6-7 |
| A | 教学次数大幅增加 | 8-9 |
| A+ | 全部教学和活动解锁 | 10 |

### 3.2 教授等级是全局进度条
教授等级不随章节重置——它是玩家在整个游戏过程中积累的"运营能力等级"。这意味着玩家在游戏后半段拥有比前半段多得多的行动力和培养能力，与角色等级成长形成双增长曲线。

## 四、授课系统

### 4.1 授课机制
每周一至周五自动进行授课，玩家决定每个学生的**目标技能**（最多2项）：
- 目标技能=学生每周自动快速成长的技能
- 根据学生的强项/弱项(Strengths/Weaknesses)，成长效率不同：
  - 强项（蓝箭头）：1.5x经验
  - 普通：1x经验
  - 弱项（红箭头）：0.5x经验
  - 才能绽放（Budding Talent，三颗星）：需12次授课完全解锁→变为强项+解锁独有战技

### 4.2 每周授课事件
授课期间可能发生：
- 学生学习请求（随机）→选对建议提升干劲+经验
- 学生提问→不同的回答导致不同的技能经验
- 目标技能变更请求→学生可能想换主修方向

## 五、挖角/招募系统

### 5.1 招募条件
从其他学级挖角学生需要满足：
- **特定属性值**（如菲力克斯需速度15）+ **特定技能等级**（如剑B+）
- 或：提升好感度→降低需求→B支援时有机率自动加入（10%/周）

### 5.2 支援减需求
```
支援C → 技能需求-1级，属性需求-20%
支援B → 技能需求-3级，属性需求-60%
支援A → 自动加入（0需求）
```

**设计意图**：挖角不是一道"属性门槛"而是"关系投资"的问题——你可以用吃饭/喝茶/送礼来提升关系从而绕过属性门槛。这让挖角从"数值门槛"变成了"社交策略"。

## 六、核心循环

风花雪月的完整游戏循环：

```
周末散步（运营）
  → 用餐/教学/关系建设
  → 周一至周五授课（培养）
  → 技能等级/支援提升
  → 周末选择（第二次运营节点）
  → 月末战斗（验证）
  → 战斗结果决定下个月的资源/可用角色
  → 回到散步
```

**这个循环在战棋品类中的独特性**：
- XCOM 2的基地运营是全局连续的非日历化（建造→研究→扫描→任务→回到基地）
- 皇骑/FFT是线性章节→战斗→过场→战斗
- 火纹历代是线性章节→战斗→整备→战斗

风花雪月的日历制是品类中**唯一让"时间"本身成为运营资源**的设计。

## 七、设计特点分析

### 7.1 "50%修道院+50%战斗"的品类实验
风花雪月将游戏时间分配大幅向运营倾斜——玩家约一半时间在修道院而非战场上。这引发了火纹社群的分裂：新玩家热爱角色互动和培养自由；核心玩家批评修道院"日常任务化了SRPG"。

### 7.2 修道院作为"角色关系的物理空间"
修道院不是一个菜单——它是一个有物理空间、有角色位置、有昼夜变化的3D地点。角色不在战场上时仍然"存在"于修道院中（你可以在特定位置找到他们）。这是叙事与运营的有意识融合——"战斗角色"也是你在学院里一起吃饭的"同学"。

### 7.3 与Engage的对比
Engage的Somniel取代了修道院但规模大幅缩水——说明IntSys也意识到修道院过于庞大而影响节奏。但Somniel失去了修道院的"空间感"，变成了一个迷你游戏集合。
