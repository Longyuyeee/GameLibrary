# 战斗公式与概率系统 — 火焰纹章：风花雪月

> 游戏版本: 火焰纹章：风花雪月 v1.2.0 (Nintendo Switch, 2019)
> 数据来源: [fe3h.com Combat Calculations](https://www.fe3h.com/calculations), [Fire Emblem Wiki - Avoid](https://fireemblemwiki.org/wiki/Avoid), [Fire Emblem Wiki - Critical hit](https://fireemblemwiki.org/wiki/Critical_hit), [GameRes战斗计算公式研究](https://www.gameres.com/876165.html)

## 一、核心战斗参数

风花雪月使用10项角色能力值，在战斗中各有分工：

| 属性 | 英文 | 战斗作用 |
|------|------|------|
| **HP** | HP | 生命值，归零=死亡/撤退（取决于模式） |
| **力量** | Strength (Str) | 物理伤害基数；每5点减1武器重量 |
| **魔力** | Magic (Mag) | 魔法伤害基数 |
| **技巧** | Dexterity (Dex) | 物理命中；物理+魔法暴击率 |
| **速度** | Speed (Spd) | 攻速(AS)基数；物理回避基数 |
| **幸运** | Luck (Lck) | 魔法命中/回避；暴击；降低敌方暴击率 |
| **防守** | Defense (Def) | 减免物理伤害 |
| **魔防** | Resistance (Res) | 减免魔法伤害 |
| **魅力** | Charm (Cha) | 计策(Gambit)的命中/伤害/回避 |
| **移动** | Movement (Mov) | 每回合可移动格数 |

**属性设计特点**：火纹10属性是日式战棋中最经典的属性面板——8战斗属性+1社交属性+1移动属性的拆分，比皇骑（仅STR/VIT/INT/MND/AGI/DEX 6项）更细粒度，比魔界战记（ATK/DEF/INT/RES/HIT/SPD 6项再将装备拆出独立系统）更内聚。

## 二、攻击速度（AS）与追击

### 2.1 攻速公式
```
AS = Speed − (武器重量 + 装备重量 − ⌊Strength / 5⌋)
```
- 力量减重：每5点力量减少1点总重量惩罚
- 武器重量不可降至负数（最低AS = Speed）
- 装备重量包括副手盾牌和饰品的重量

### 2.2 追击判定
```
攻速差 ≥ 4 → 追击发生（攻击方攻击两次）
```
**追击规则**是火纹战术的核心——它不是简单的"速度快多打一次"，而是**4点速度差的门槛设计**，意味着把速度从+3提升到+4的战斗价值远大于从+4到+5。

火纹系列追击门槛对比：
| 作品 | 追击门槛 |
|------|:--:|
| 风花雪月 | 4 |
| Engage | 5 |
| if | 5 |
| 觉醒 | 5 |
| GBA三作 | 4 |

**设计意图**：风花雪月的4点门槛是系列最低之一——设计师刻意让追击更易发生，使速度属性在战术决策中的权重更高（某种程度上与"取消武器三角"呼应：用更激进的追击频率替代克制的保守战斗）。

## 三、命中公式

### 3.1 物理命中
```
Hit = 武器命中 + 技巧(Dex) + 支援加成 + 技能加成 + 装备加成 + 骑士团加成 − 弓射程惩罚
```

### 3.2 魔法命中
```
Hit = 魔法命中 + (技巧 + 幸运) / 2 + 支援加成 + 技能加成 + 装备加成 + 骑士团加成 − 弓射程惩罚
```

魔法命中将幸运纳入公式——这是火纹的经典设计：魔法依赖"天赋运气"多于"精确技巧"，与D&D的法术命中逻辑一脉相承。

### 3.3 弓射程惩罚
```
射程惩罚 = 20 × (距离 − 2)
上限 = 60 (Normal/Hard) / 70 (Maddening)
```
3格以上射击每多一格减20命中——限制了弓箭手在超远距离的精确度。

## 四、回避公式

### 4.1 物理回避
```
Avoid = 攻速(AS) + 地形加成 + 支援加成 + 技能加成 + 装备加成 + 骑士团加成
```

### 4.2 魔法回避
```
Magic Avoid = (速度 + 幸运) / 2 + 技能加成 + 装备加成 + 骑士团加成
```
**地形不加成魔法回避**——这是关键设计：你用森林躲弓箭但不能用森林躲火球。这让"物理坦克站森林"和"魔法回避靠装备/技能"形成了两套独立的生存策略。

## 五、随机数机制

### 5.1 双随机系统（True Hit / 2-RN）
风花雪月使用**双随机数系统（2-RN）**计算命中率：

```
实际命中 = (RN1 + RN2) / 2
```
- 游戏生成两个0-99的随机数，取平均值
- 然后与显示命中率比较
- 显示值 > 50% → 实际概率**高于**显示值（如显示80%→实际92.2%）
- 显示值 < 50% → 实际概率**低于**显示值（如显示20%→实际8.2%）

| 显示值 | 实际概率（2-RN） | 心理效果 |
|:--:|:--:|------|
| 90% | 98.1% | "几乎必中" |
| 80% | 92.2% | "很可靠" |
| 70% | 82.3% | "大概率" |
| 60% | 68.4% | "偏向命中" |
| 50% | 50.0% | "对称点" |
| 40% | 31.6% | "偏向闪避" |
| 30% | 17.7% | "大概率闪" |
| 20% | 8.2% | "很难命中" |
| 10% | 1.9% | "近乎不可能" |

**设计意图**：2-RN系统是一个"心理保底"机制——让玩家感知到的命中率更接近"常识概率"。显示90%→实际98%意味着玩家几乎不会因为90%MISS而发怒（虽然仍然可能）。

### 5.2 暴击：单随机系统（1-RN）
```
Displayed Crit = 攻击方Crit − 防御方Crit Avo
Crit Avo = 幸运(Luck) + 技能加成
```
暴击使用**1-RN系统**（真实概率），不做任何平滑处理——显示10%暴击就是10%概率。这让暴击成为一个"不可靠的惊喜"而非"可计算的资源"。

### 5.3 乱数表与凹点
风花雪月使用**固定乱数表**（Random Number Table）而非真随机：
- 进战斗地图时，整场战斗的乱数序列已经确定
- 这意味着：在同一场战斗中重复同样的操作序列，结果完全一致
- **升级加点在此乱数系统下也已确定**——但可通过改变操作顺序来消耗不同的乱数

**凹点文化**：日式战棋的独有现象——玩家读档重来以改变随机结果。风花雪月的天刻之脉动（时间回溯）**无法改变升级加点**——这是有意识的设计：允许你纠正战术错误但不允许你"完美培养"。

与XCOM 2对比：XCOM使用**伪随机隐藏保底**——连续MISS后系统暗中提高命中率。火纹的2-RN是"透明的概率弯曲"，XCOM的隐藏保底是"不透明的慈悲"。

## 六、伤害公式

```
物理伤害 = 力量 + 武器威力 + 特效修正 + 技能/装备/骑士团加成 − 目标防守
魔法伤害 = 魔力 + 法术威力 + 特效修正 + 技能/装备/骑士团加成 − 目标魔防

最短伤害 = 0（不打负数——没有"负伤害治疗"）
```

**特效修正**：
- 武器克制修正（如斩马刀对骑兵×3）
- 飞行系被弓克制（弓+飞行特效武器=额外×3伤害）
- 计策无反击（Gambit命中后敌无法反击，且造成范围伤害）

## 七、计策（Gambit）独立计算

计策的命中/伤害**不依赖角色战斗属性**，而是用**魅力(Charm)**独立计算：

```
计策命中 = 计策基础命中 + (使用者魅力 - 目标魅力) × 5
计策伤害 = 计策基础威力 + (使用者魅力 − 目标魅力)
```

**设计意图**：在属性面板中嵌入"魅力"这一看似RP的属性，并将其绑定到一个独立于物理/魔法的战术维度——这是火纹的叙事-战术融合设计。大学院中最有魅力的人（级长）同时也是最强计策使用者，这就是"人格=战力"的数值化。

## 八、设计特点分析

### 8.1 双RN的心理工程
2-RN系统设计不是"让概率更公平"——是**让玩家感受更好**。高命中率更可靠=玩家信任系统。低命中率更不可靠=玩家不依赖运气。这是日式战棋与西方战术游戏（XCOM的"95%还MISS"愤怒）在概率哲学上的根本分岐。

### 8.2 速度的"门槛经济"
追击门槛AS差≥4意味着+1速度在从+3到+4时价值跃升。这创造了属性投资的"门槛效应"——培养角色不只是堆速度，而且是在具体敌人面前精确计算"我能不能追他"。

### 8.3 暴击的"不可计算性"
暴击用1-RN（真随机）而非2-RN——意味着10%暴击真的是10%。设计师刻意保留了不可计算性：暴击不是一种"资源"，而是一种"bonus惊喜"——保留玩家刷出1%暴击时的心跳加速。
