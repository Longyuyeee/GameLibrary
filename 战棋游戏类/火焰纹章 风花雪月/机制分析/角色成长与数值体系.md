# 角色成长与数值体系 — 火焰纹章：风花雪月

> 游戏版本: 火焰纹章：风花雪月 v1.2.0 (Nintendo Switch, 2019)
> 数据来源: [Serenes Forest - growth rates](https://serenesforest.net/three-houses/characters/growth-rates/), [游民星空全角色数值详解](https://www.gamersky.com/handbook/201908/1209739.shtml), [A9VG成长率攻略](https://bbs.a9vg.com/thread-8750345-1-1.html), [GameRes战斗计算](https://www.gameres.com/876165.html)

## 一、角色属性面板

### 1.1 10属性+技能等级

| 属性 | 作用域 | 成长率意义 |
|------|------|------|
| **HP** | 生存 | 血量基数——约20-65%成长率 |
| **力量(Str)** | 物理伤害/减重 | 每点=1物理伤害，每5点=1减重 |
| **魔力(Mag)** | 魔法伤害 | 每点=1魔法伤害 |
| **技巧(Dex)** | 命中/暴击 | 影响物理命中+所有暴击 |
| **速度(Spd)** | 回避/追击 | AS基数——决定追击/被追击 |
| **幸运(Lck)** | 魔法命中/暴击规避 | 降低被暴击概率+魔法系命中 |
| **防守(Def)** | 物理减伤 | 每点=1点物理伤害减免 |
| **魔防(Res)** | 魔法减伤 | 每点=1点魔法伤害减免 |
| **魅力(Cha)** | 计策攻击/命中/回避 | 独立于战斗属性的社交战力 |
| **移动(Mov)** | 位移 | 固定值（由职业决定，非成长） |

### 1.2 技能等级系统
除10属性外，每个角色有**技能等级**（武器/理学/信仰/指挥/重装/马术/飞行），从E→E+→D→D+→...→S+，共**11级**：

| 技能 | 影响 |
|------|------|
| 剑/枪/斧/弓/格斗 | 可使用更高级武器+学习战技+影响职业考试 |
| 理学(Reason) | 可使用更高级黑魔法+影响魔法职业考试 |
| 信仰(Faith) | 可使用更高级白魔法+影响治疗职业考试 |
| 指挥(Authority) | 可装备更高级骑士团+影响计策威力 |
| 重装/马术/飞行 | 影响对应职业考试+移动型辅助技能 |

## 二、成长率系统

### 2.1 成长率公式
```
最终升级成长率 = 角色成长率(%) + 当前职业成长率(%)
```

每升一级，每个属性独立掷骰（随机数0-99，若<成长率则该属性+1）。

**举例**：主角（力45%）+ 土匪（力10%）= 55%力成长率 → 每级55%概率力量+1

## 三、凹点系统

### 3.1 凹点机制（RNG Scumming）
火纹的"凹点"是指玩家通过读档重来以获得更好的升级加点：
- 风花雪月中，进入战斗时整场战斗的**乱数序列已固定**
- 升级加点是基于乱数的——同一操作序列下结果相同
- 凹点方法：改变行动顺序来消耗不同位置的乱数，使升级时获得不同加点
- 天刻之脉动**无法改变升级加点**（设计师有意为之）

### 3.2 设计师对凹点的态度
为什幺设计师不直接移除凹点（如改为固定成长）？
- 凹点是火纹社区文化的一部分——它创造了一种"用自己的耐心和智慧培养完美角色"的满足感
- 但如果太简单（如觉醒无限刷级），凹点会变成枯燥的重复劳动
- 风花雪月的做法是：允许凹点但设置"天刻不能改变加点"的限制——平衡了两种需求

## 四、数值上限与等级设计

### 4.1 等级上限
- 等级上限：**Lv60**
- 一周目正常通关等级：约Lv35-45
- 满级需要大量额外刷级——非必要

### 4.2 属性上限
各属性有职业依赖的上限值（因职业而异），典型范围：
- HP: 70-100（要塞/英勇骑士可破百）
- Str/Mag: 40-60（取决于职业修正）
- Spd: 35-50（速度型职业上限高）
- Def/Res: 30-50

**对比魔界战记**：火纹的"有限成长"vs魔界战记的"无限膨胀"(9999级+亿级伤害)代表了战棋品类中两种极端的数值哲学——火纹选择"可控的平衡"，魔界战记选择"失控的狂欢"。

## 五、设计特点分析

### 5.1 成长率作为角色叙事
角色的成长率不只是战斗数值——它们承载了角色性格的叙事映射：
- 杜笃（Def 50%/Spd 20%）：忠诚的大盾守护者→"永不倒下，从不后退，但也不必追"
- 莉丝缇亚（Mag 60%/HP 20%）：天才但身躯脆弱的少女→"一击毁灭世界，但也承受不了一击"
- 英古利特（Spd 60%/Str 35%）：追求骑士道的女性→"能追上任何目标但未必能一击打倒"

### 5.2 技能等级的"第二成长层"
风花雪月的双轨成长（属性+技能等级）让培养有两个维度：属性决定战力强度，技能等级决定可能性边界（可用什么武器/战技/职业）。这与培养模拟类（如美少女梦工场）的"数值+课程"双轨有共通之处。
