# 关卡与胜利条件设计 — 火焰纹章：风花雪月

> 游戏版本: 火焰纹章：风花雪月 v1.2.0 (Nintendo Switch, 2019)
> 数据来源: [Serenes Forest](https://serenesforest.net/three-houses/), [Fire Emblem Wiki](https://fireemblemwiki.org), [Jeuxvideo开发者访谈](https://serenesforest.net/2019/07/05/three-houses-jeuxvideo-interview-developers-80-hours-per-route-koei-tecmos-involvement/)

## 一、全路线关卡结构

风花雪月分**四条故事路线**（银雪/翠风/红花/苍月），每条路线22章（+序章+终章），总关卡数：

| 路线 | 独占关卡 | 共享关卡 | 总计 |
|------|:--:|:--:|:--:|
| **银雪之章**（教会） | ~4章 | ~18章 | **21-22章** |
| **翠风之章**（金鹿/库罗德） | ~5章 | ~17章 | **21-22章** |
| **红花之章**（黑鹫/艾黛尔贾特） | ~6章 | ~12章（比其它路线少6章） | **18章** |
| **苍月之章**（青狮/帝弥托利） | ~5章 | ~17章 | **21-22章** |

**非对称路线设计**：红花是唯一"较短"的路线——只有18章。这是对叙事内容的有意识限制——艾黛尔贾特的革命故事不需要额外4章的铺垫/收尾。

## 二、关卡结构模板

风花雪月（及火纹全系列）的关卡遵循一个隐式模板：

```
[出击准备] → [战场部署] → [阶段1: 初始接敌] → [阶段2: 中期推进]
→ [阶段3: 增援/转折] → [阶段4: BOSS战] → [战后结算]
```

### 2.1 章节级结构
每个章节由"学园周（日历活动）+ 周末选择（出击/散步/讲习/休养）+ 主线战斗"组成：

| 时间节点 | 内容 |
|------|------|
| **周一至周五** | 授课（自动）——提升学生技能等级 |
| **周末** | 玩家选择：散步（修道院活动）/ 讲习 / 出击 / 休养 |
| **月末** | 主线战斗（强制出击） |

## 三、胜利条件类型

### 3.1 胜利条件分布

| 胜利条件 | 频率 | 典型关卡 |
|------|:--:|------|
| **敌全灭**（Rout） | ★★★★★ 最常用 | 大部分主线章节 |
| **击杀BOSS**（Defeat Commander） | ★★★★ 第二常用 | 中期加速节奏用 |
| **防守N回合**（Defend for X Turns） | ★★ | 特定守城关卡 |
| **逃脱**（Escape） | ★ | 剧情撤退关卡 |
| **到达特定格**（Arrive） | ★ | 护送/突入关卡 |
| **限时击杀**（Kill within X turns） | ★ | 支线/外传 |

### 3.2 胜利条件的设计节奏
Rout（全灭）是最常用的胜利条件，但设计师在关键剧情节点使用条件切换来控制节奏：
- 连续几关Rout后→突然一个BOSS击杀关→加速节奏
- 剧情中的撤退→逃脱关→创造"无力感"
- 防守关→在"压力"中测试玩家的培育成果

**与品类内对比**：
- 皇骑同样以全灭/BOSS击杀为主，但增加了"说得"（招募）作为可选副目标
- 陷阵之志每关5回合的固定胜利条件——完全不同：火纹没有回合限制（大部分关卡），陷阵之志每关都有
- XCOM 2增加了VIP护送/黑客/拆弹等多种胜利条件——更偏"任务型"

## 四、地图设计规模

### 4.1 地图规模分类

| 规模 | 格数 | 部署人数 | 典型关卡 |
|------|:--:|:--:|------|
| 小规模 | 12×15 | 5-7人 | 序章、早期章节 |
| 中规模 | 18×25 | 8-10人 | 大部分中期关卡 |
| 大规模 | 25×35 | 10-12人 | 终章、特殊战役 |
| 极大（Gronder Field） | 30×35 | 12人+三方混战 | 古隆达兹会战（三方战役） |

### 4.2 三方混战设计
风花雪月的古隆达兹会战（Gronder Field）是品类罕见的**三方共战**——玩家军队+另外两学级军队+敌军在同一地图上互相攻击：
- AI之间也会互相攻击——不仅玩家在战斗
- 提供了"利用一方消耗另一方"的战术选择
- 这种设计在日式战棋中极其罕见（皇家骑士团有少量三方混战，但规模小得多）

## 五、增援机制

### 5.1 增援触发类型

| 触发方式 | 说明 | 设计效果 |
|------|------|------|
| **回合触发** | 第X回合在指定位置出现增援 | 创造时间压力——不推进会被消耗 |
| **位置触发** | 我方到达某个位置后出现增援 | 防止玩家安然集结——推进有代价 |
| **BOSS血量触发** | BOSS血量降到阈值后增援 | 反制"集火秒BOSS"策略 |
| **无预警增援**（Maddening） | 同回合出现+立即行动 | 强迫玩家记忆OR承受突袭 |

### 5.2 Maddening难度的增援重构
Maddening模式的增援与Normal/Hard有根本性差异：
- Normal/Hard：增援出现后下一回合才行动（有预警）
- Maddening：**同回合出现并立即行动**——等同于"不需要预警，玩家应该记下来"
- 这种设计把"观察"变成了"记忆"——核心玩家需要预先知道增援位置

与皇骑的对比：皇骑的增援从城堡/据点出兵（符合世界观），火纹的增援从地图边缘/指定格凭空出现（纯游戏机制）。火纹选择"机制可预测性"而非"叙事合理性"。

## 六、战场招募——说得（Recruitment in Battle）

火纹独一档的"战场上招募"机制是关卡设计的关键变量：

| 招募条件 | 说明 |
|------|------|
| **需要特定角色** | 通常需要用级长或主角去"说"（如需要帝弥托利去与某角色对话） |
| **需要在存活状态下** | 招募目标不能被提前击杀 |
| **可能影响关卡流程** | 招募后该角色从敌方变友军——改变战场力量对比 |
| **可能影响故事** | 有些角色不招募=永远不可获得 |

**设计意图**：将"招募"从菜单操作变为战术目标——你必须计划好如何让特定人物接近敌方特定单位而不被其他敌人截杀。这与皇骑、FFT的战后加入形成鲜明对比。

## 七、难度设计的分层哲学

### 7.1 难度层级

| 难度 | 核心差异 |
|------|------|
| **Normal** | 无永久死亡压力+敌人属性基础值+增援有预警+EXP/金币充裕 |
| **Hard** | 经典模式可选+敌人属性提升+增援数量增加 |
| **Maddening** | 敌人全属性大幅提升+同回合增援立即行动+敌人技能组合重设计+EXP获取大幅减少 |

### 7.2 Maddening不是"数值调高"
Maddening模式的设计哲学是**重写战术条件**而非缩放数值：
- 敌人获得Normal/Hard没有的技能组合（如多个敌人有Breaker技能）
- 增援规则完全改变（同回合行动）
- EXP获取大幅降低→"刷级"策略失效→必须精打细算

这类似于XCOM 2的Legend/Ironman——不是让敌人血更厚，而是让战场条件更严苛。

## 八、设计特点分析

1. **章节制+日历制的双层关卡结构**：战棋品类中唯一把"关卡之间"本身变成一个完整运营层的设计。XCOM 2有基地运营但是全局连续的，风花雪月的日历制让每个月的"战前准备"有一套完整的活动选择树。

2. **四条路线的关卡复用策略**：22×4=88个关卡位，但其中约60%是路线共享的。这降低了开发成本但同时导致多周目玩家的重复疲劳——"打了30%新内容，70%是相同的"。

3. **战场招募的叙事-战术融合**：风花雪月降低了战场招募的比例（相比封印/烈火之剑），大多数角色通过修道院挖角而非战斗中说得好——这与学院主题一致（招募通过教学互动而非战场对峙）。
