# 行动顺序与回合体系 — 火焰纹章：风花雪月

> 游戏版本: 火焰纹章：风花雪月 v1.2.0 (Nintendo Switch, 2019)
> 数据来源: [fe3h.com Combat Calculations](https://www.fe3h.com/calculations), [Fire Emblem Wiki](https://fireemblemwiki.org), [Serenes Forest](https://serenesforest.net/three-houses/)

## 一、回合模式

### 1.1 我方全动-敌方全动（PPEP）

风花雪月使用经典的**Player Phase / Enemy Phase（PPEP）**回合制，这是火纹系列一贯的回合结构：

| 阶段 | 内容 | 战略定位 |
|------|------|------|
| **我方回合（Player Phase）** | 所有玩家单位逐一行动（移动+攻击/使用道具/待机） | 进攻/部署阶段 |
| **敌方回合（Enemy Phase）** | 所有AI敌军逐一行动 | 防御/承受阶段 |
| **友军/第三军回合** | 中立/第三势力单位行动（特定关卡） | 变量/干扰 |

**与其他回合模式的对比**：

| 模式 | 代表游戏 | 核心特点 |
|------|------|------|
| **PPEP** | 火纹全系列 | 我方集中规划→敌方集中执行，节奏清晰 |
| **WT/CTB** | 皇骑：重生、FFT | 按速度排序混合行动，速度快者多动 |
| **双动（每单位2AP）** | XCOM 2 | 移动+射击或其他组合，每个单位独立资源 |
| **完全确定性** | 陷阵之志 | 每回合先看到所有敌方的行动再决定我方 |

PPEP的设计哲学是"给我方完美的信息整合窗口"——我方回合不需要考虑敌方在中间插手的可能。

### 1.2 我方回合的动作模型

每个单位在己方回合可以执行：

```
基础动作 = 移动 + 攻击（一次，含战技/魔法/道具）
```

| 附加动作 | 说明 |
|------|------|
| **交换武器** | 在攻击前免费切换装备的武器 |
| **使用道具** | 替代攻击——消耗一个消耗品 |
| **使用计策** | 替代普通攻击——使用骑士团计策（次数有限） |
| **待机** | 不攻击，仅移动——可触发待机后事件 |
| **交换** | 与相邻友军交换携带道具 |
| **救出/放下** | 特定单位Pick Up/Drop同伴（仅部分职业） |

**动作模型的设计哲学**：移动+攻击一次——简单但不简陋。火纹拒绝"AP制"的多动作选择（如XCOM 2的Run&Gun或双射），保持每个单位的决策空间精准控制在"移动到哪→打谁"。

## 二、反击系统

### 2.1 反击规则

反击是火纹战术层的核心交互机制——在己方回合之外的大量战斗发生在敌方回合：

| 反击条件 | 说明 |
|------|------|
| **射程匹配** | 被攻击方射程覆盖攻击方（近战打近战=反击；弓打近战=无反） |
| **存活** | 在承受敌方攻击后仍存活才能反击 |
| **武器可用** | 装备的武器可反击（武器耐久>0） |
| **未被封印** | 没有受到"禁止反击"的debuff |

### 2.2 反击与武器射程表

| 攻击方武器 | 目标武器 | 反击发生？ | 说明 |
|------|------|:--:|------|
| 剑/枪/斧/格斗（近战） | 剑/枪/斧/格斗（近战） | ✅ | 正常反击 |
| 剑/枪/斧/格斗（近战） | 弓（远程） | ❌ | 弓手近身无法反击近战（除装备近身反击技能） |
| 弓/魔法（远程） | 剑/枪/斧（近战） | ✅（仅1格时） | 远程打近战在1格内→近战可反击；2格以上→不能 |
| 弓（远程） | 弓/魔法（远程） | ✅ | 射程重叠时互相反击 |
| 魔法（远程） | 魔法（远程） | ✅ | 魔法对轰 |

**核心规则**：近战无法反击射程外的攻击。这是远程单位的核心优势——无伤输出。

### 2.3 追击反击

如果被攻击方的AS比攻击方高4以上，在**承受攻击后**可以追击反击——即在敌方回合内反击两次。这使高速度单位在防御时间样可怕。

**敌方回合威胁评估的复杂之处**：一个单位在敌方回合可能遭受的不只是一次攻击，而是"被多敌围攻+每次都有反击/追击的可能"——这是PPEP回合最需要玩家预估的地方。

## 三、行动顺序与速度经济

### 3.1 PPEP内的行动顺序
在我方回合内，**玩家自由决定所有单位的行动顺序**——这是PPEP最大的战术自由度。与WT系统（固定顺序）不同，玩家可以：
- 先用计策破魔兽护甲→再用高输出角色输出
- 先用远程削血→再近战收割
- 先用飞马骑士吸引敌人→再用主力突破

### 3.2 速度的战术价值
在PPEP中，速度的价值体现在两点：
1. **我方回合**：高速度→可以追击（自己的攻击之外多打一次）
2. **敌方回合**：高速度→可以追击反击（在承受敌方攻击后多打一次）

这意味着速度属性在PPEP中的价值是"双向"的——高速度单位不仅在进攻时能双动，在防守时也是双动。与CTB/WT系统（速度快=多回合）形成不同的速度哲学。

## 四、连携与支援攻击

### 4.1 支援攻击（Linked Attack / Adjutant Follow-Up）
风花雪月引入了两个层次的连携：

| 连携类型 | 触发条件 | 效果 |
|------|------|------|
| **连携攻击**（Linked Attack） | 友军在攻击方3格内 | 命中+3~10（取决于支援等级） |
| **副官追击**（Adjutant Follow-Up） | 装备副官+支援等级触发 | 副官进行额外追击（概率取决于支援） |
| **副官防御**（Adjutant Guard） | 装备防御型副官 | 减少敌方追击伤害（可减至1HP不死） |
| **副官治疗**（Adjutant Heal） | 装备治疗型副官 | 回合开始时恢复HP |

### 4.2 副官系统与行动点数
副官不占用独立回合——它们在主单位行动时自动触发：
- 副官不影响主单位的"移动+攻击一次"基础动作
- 副官不增加操作复杂度，但增加了战前配置的策略深度
- 副官也可以获得经验，等于"不占用回合地培养后备队员"

**设计特点**：副官系统是风花雪月对"多单位战场但只操作有限单位"问题的创新解答——让剩余队员不是"坐板凳"而是有实际战术贡献。

## 五、天刻之脉动（Divine Pulse）

### 5.1 时间回溯机制
风花雪月在传统回合制中嵌入了时间回溯：

| 参数 | 数值 |
|------|:--:|
| 初始可用次数 | 3次（随剧情增加到最高13次） |
| 回溯范围 | 回溯到本场战斗的任意前一回合 |
| 使用时机 | 任何时间（战斗中/战斗前/我方回合/敌方回合） |
| 消耗 | 消耗一次充能（用完后需完成关卡或放弃重开） |
| 充能恢复 | 每场战斗重置 |

### 5.2 设计意图
天刻之脉动是火纹从"惩罚→挫败"到"容错→学习"的重大哲学转变：
- 经典火纹：死一个角色=不可逆损失→读档整个关卡=30分钟白打
- 风花雪月：走错一步=回溯3回合→保留大部分学习收益+减少重复劳动
- 对比：陷阵之志同样允许回溯但限制每关一次→火纹更慷慨

天刻与火纹难度层级的关系：
- 休闲模式（无永久死亡+天刻）= "完全没有惩罚"——新手友好
- 经典模式（永久死亡+天刻）= "有惩罚但有二次机会"——系列玩家最舒服的模式
- Maddening经典模式（永久死亡+限制天刻）= "最小容错+最大惩罚"——核心玩家最大挑战

## 六、设计特点总结

1. **PPEP的战术清晰度**：与CTB/WT的"实时感"不同，PPEP为玩家提供完整的计划窗口——这是在战棋品类中选择"清晰"而非"模拟真实"的自觉设计。
2. **反击的双重压力**：风花雪月的反击+追击反击机制意味着一个单位在敌方回合可能造成比己方回合更大的输出——这鼓励激进的阵地战而非保守阵型。
3. **天刻的"学习工具"定位**：天刻不是"降低难度"——是"把重复劳动换成学习效率"。玩家回溯的不是"侥幸"，而是"这次我该换一种打法"。
