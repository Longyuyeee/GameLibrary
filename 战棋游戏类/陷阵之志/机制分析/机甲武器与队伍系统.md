# 机甲、武器与队伍系统 — 陷阵之志 (Into the Breach)

> 游戏版本: Into the Breach v1.2 (2022) | 数据来源: [ITB Wikia](https://intothebreach.fandom.com/wiki/Squads), [GameSkinny机甲指南](https://www.gameskinny.com/tips/into-the-breach-mechs-guide/), [GDC 2019设计复盘](https://gdcvault.com/play/1026333/-Into-the-Breach-Design)

## 一、3机甲×3武器——最小单位的战术团队

陷阵之志的"战斗单位"是**三台机甲**——不多不少，永远三台。这与传统SRPG的4-12人队伍形成鲜明对比。

### 1.1 3机甲的设计哲学
Davis在GDC中解释：3这个数字是从"每回合你控制的有限行动次数"的反推而来。更多的机甲=更多的行动=谜题可以通过暴力解决（而非智慧）。3台机甲意味着每回合恰好**3个行动**——你必须在"防御/进攻/位移/准备"之间精确分配。

**与品类对对比**：

| 游戏 | 部署单位数 | 每单位行动次数 |
|------|:--:|:--:|
| 陷阵之志 | **3** | **1次/单位/回合** |
| 风花雪月 | 8-12 | 1次/单位/回合（PPEP） |
| 皇骑 | 8-12 | WT决定频率 |
| FFT | 5-6 | CT决定频率 |

陷阵之志的3=**最少的部署数**和**最严格的行动预算**。

### 1.2 机甲类型

每台机甲属于五种类型之一——类型决定可装备的武器：

| 机甲类型 | 定位 | 代表武器类型 |
|------|------|------|
| **Prime（近战）** | 近距离高伤害+位移 | 拳头/武器臂/推力器 |
| **Brute（攻坚）** | 中距离大范围+特殊效果 | 加农炮/波动/岩石 |
| **Ranged（远程）** | 远距离单点/范围伤害 | 火炮/激光/冰霜 |
| **Science（支援）** | 位移/控制/维修——无（或极少）直接伤害 | 传送/烟幕/引力/护盾 |
| **Any（任意）** | 可装备任何类型武器 | 极其灵活 |

## 三、武器系统——每台机甲最多3把武器

### 3.1 武器槽与升级

| 参数 | 说明 |
|------|------|
| 初始武器 | 每台机甲2把（1主武+1副武） |
| 最大武器 | 3把——第3把通过商店购买/任务奖励 |
| 武器升级 | 使用反应堆核心(Reactor Core)——每个核心可升级一把武器 |
| 核心来源 | 任务奖励+完美岛屿奖励+商店购买 |

**关键的稀缺性**：反应堆核心是最稀有的资源。一个标准4岛通关仅获得约10-15个核心——用于为三台机甲分配约6-9把武器的升级+HP/移动力提升。

### 3.2 武器设计约束——三种攻击类型

Subset Games将攻击可视化简化为三种基本模式：

| 类型 | 描述 | 视觉表现 |
|------|------|------|
| **火炮(Artillery)** | 从远距离打击一个格子+邻近四格 | 弹道+爆炸范围 |
| **近战(Melee/Body)** | 机甲直接与相邻单位互动 | 撞击/推/拉 |
| **导弹(Missile)** | 直线或射线攻击 | 直线轨迹 |

**关键设计决策**（Davis GDC复盘）：
- 所有范围攻击仅使用**直角模式**（上下左右，无对角线）
- 因为对角线AOE在8×8网格上对玩家来说**不可直观阅读**
- "我们有一些真正酷炫的武器想法和攻击模式...但我们砍掉了它们因为玩家测试者根本看不懂"

## 四、"破坏 > 伤害"的设计哲学

陷阵之志最核心的战斗设计：**不追求杀死敌人——追求让敌人攻击错误的目标**。

| 战术 | 机制 | 优于直接伤害的原因 |
|------|------|------|
| 推(Push) | 将敌人移动1格 | 敌人的攻击从一个目标转移到另一个（或空地） |
| 拉(Pull) | 将敌人拉近1格 | 同上 |
| 翻转(Flip) | 把敌人翻到机甲背后 | 同上——且造成伤害 |
| 冻住(Freeze) | 敌人下回合无法行动 | 等于"消灭一个敌方行动" |
| 烟雾(Smoke) | 敌人下回合无法攻击 | 同上 |
| 护盾(Shield) | 目标建筑承受下一次攻击完全免疫 | 完美防御——消耗资源 |
| 传送(Teleport) | 交换任何两个单位的位置 | 最强位移——"把两个敌人互换=两个都被干扰" |

**设计核心**：杀死一个敌人只能消除一个威胁。但推一个敌人=可能**同时消除它对建筑A的威胁、让它撞到敌人B、并把它推到危险地形**——一个行动达成三个战术目标。这就是"操纵而非毁灭"的更深层满足感。
