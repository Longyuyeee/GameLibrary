# 网格、地形与位移系统 — 陷阵之志 (Into the Breach)

> 游戏版本: Into the Breach v1.2 (2022) | 数据来源: [ITB Wikia](https://intothebreach.fandom.com), [GDC 2019设计复盘](https://gdcvault.com/play/1026333/-Into-the-Breach-Design)

## 一、8×8网格——微型战场

### 1.1 最小战场的极致密度
陷阵之志的战斗在**8×8的棋盘**上进行——战棋品类中最小的战场之一。

| 游戏 | 战场大小 | 格数 |
|------|------|:--:|
| 陷阵之志 | **8×8** | **64格** |
| 高级战争 | 约15×20 | 300格 |
| FFT | 16×16 | 256格 |
| 风花雪月 | 约20×28 | 560格 |

**为什么是8×8？** Davis在GDC中解释：8×8不是一开始就选定的——是从"预知攻击+3机甲+4-5回合"的反推中自然定下来的。更大的地图会让敌人过于分散，玩家不需要在"更好的行动"之间做出艰难选择。8×8意味着**高密度遭遇**——每场战斗约6-8个敌人占据64格中的10-15%，核心冲突区没有"空闲空间"。

### 1.2 没有Z轴、没有高度差、没有地形回避
陷阵之志的地形是**纯平二维**的——没有高度差、没有地形回避加成、没有"高地优势"。这是有意识的设计简化：
- 在确定性战斗中，"高台+20%命中"没有意义——因为命中已经是100%
- 地形回避被**地形效果**替代——水/火/烟雾/冰面影响移动而非概率

## 二、地形类型——以效果替代概率

### 2.1 环境地形

| 地形 | 效果 | 如何创造 |
|------|------|------|
| **水面/深渊** | 任何单位被推进去→**立即死亡/消失** | 地图固有 + 部分机甲可创造裂缝 |
| **火焰** | 回合结束站在火焰上→受到1伤害。持续1-3回合 | 火焰系武器/敌方火虫 |
| **冰面** | 任何单位被推进去→**滑动1格**（无法控制方向） | 冰系武器/寒冰泰坦 |
| **烟雾** | 任何单位在烟雾中→**下回合无法攻击** | 烟雾系武器/烟幕弹 |
| **电网(ACID)** | 单位站在电网上→受到双倍伤害 | 部分敌方地图特有 |
| **建筑(城市)** | 不可站立——被摧毁→-1~2电力 | 地图随机分布 |
| **山脉/森林** | 部分地图阻挡移动——可被机甲/敌人从背后撞击=+1伤害 | 地图固有 |
| **裂缝(Chasm)** | 创造——任何单位推进去=**秒杀**（包括BOSS） | 大灾变队伍/特定武器 |
| **传送门** | 单位站上去→传送到随机位置 | 特定任务 |

**核心设计**：地形不是"buff你的单位"——在陷阵之志中，地形是**你用来消灭/控制敌人的武器**。一个单位站在水面旁边=一个可以被"推杀"的单位。

### 2.2 地形交互公式

```
推(Push/Flip) → 目标移动1格 → 如果目标格是：
  ├─ 水面/深渊 → 秒杀（任何HP无视）
  ├─ 山脉/其他单位 → 目标+1额外伤害（碰撞伤害）
  ├─ 火焰/电网 → 额外+1伤害
  ├─ 冰面 → 目标继续滑动1格
  └─ 空地 → 仅位移（但可能改变敌方攻击目标）
```

## 三、位移——推/拉/翻/换

### 3.1 四种基础位移

| 位移类型 | 效果 | 伤害 | 代表武器 |
|------|------|:--:|------|
| **推(Push)** | 将目标推离机甲1格 | 通常有（1-3） | Titan Fist, Titanite Blade, Wind Torrent |
| **拉(Pull)** | 将目标拉向机甲1格 | 通常有（1-2） | Gravity Well, Hook Mech |
| **翻(Flip)** | 将目标翻到机甲背后 | 1-2 | Judo Mech(Vice Fist), Flip Mech |
| **换/传送(Swap/Teleport)** | 交换任意2格位置 | 0或无 | Swap Mech, Teleporter, Bombermechs |
| **推/拉全行全列** | 推/拉整行或整列所有单位 | 0-1 | Wind Torrent, Control-Alt-Delete |

### 3.2 位移的战术经济——"一石三鸟"
Davis在GDC中特别强调了INTO THE BREACH最深的满足感来源：
> *"A single action that simultaneously: kills one Vek, blocks another's attack, and protects a building — that's the perfect puzzle solution."*

（一个行动同时：杀死一只Vek、阻挡另一只的攻击、和保护一栋建筑——这才是这个游戏的完美谜题解答。）

## 四、建筑与电力网格

### 4.1 建筑类型

| 建筑 | HP | 被摧毁效果 | 保护优先级 |
|------|:--:|------|:--:|
| 普通建筑 | 1-2 | 电力-1 | 高 |
| 电厂 | 2 | **电力-2** | 最高 |
| 特殊建筑（任务目标） | 2 | 任务失败（或电力额外减少） | **绝对必须保护** |
| 机甲部署点（非目标） | — | 无直接影响但少了一个部署点 | 低 |

### 4.2 电力网格(Power Grid)

每场战斗开始时的电力值 = 该岛屿的集体供电。电力=你可以承受多少栋建筑被摧毁而不失败：
- 标准难度岛屿：7点电力（可承受7栋普通建筑或3-4栋电厂）
- 硬难度岛屿：4-6点
- 电力降至0=**该时间线失败**→必须选择一名驾驶员传送到新时间线（或完全重新开始）

**电力抗拒(Power Grid Resist)**：每栋建筑有一个小概率在被击毁时"幸存"——这是游戏中仅有的随机元素。Davis在GDC中坦承这个系统"让部分玩家不满"，但被视为防止"必败局面"的"最不坏的选项"。

## 五、设计启示——8×8的密度美

1. **小网格=高密度=每个决定都重要**：8×8意味着你无法"退后重来"——必须立刻面对面前的威胁。
2. **位移系统替代概率回避**：没有"闪避率"——你必须**物理上移动敌人**来改变他们的攻击目标。
3. **地形是武器**：水/深渊=所有单位的"绝对秒杀点"——但谨慎使用，因为你的机甲掉进去也会死。
