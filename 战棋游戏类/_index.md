## 品类简介

战棋游戏(Tactical RPG/SRPG)——玩家在网格战场上指挥有独立身份、可成长的单位进行回合制战术战斗。**三核心结构**：战术层(网格/地形/命中/行动顺序)、培养层(职业/技能/转职/装备)、叙事层(剧情分支/角色关系/永久死亡后果)。

## 子类型

| 子类型 | 玩法重心 |
|------|------|
| 角色养成驱动 | 职业树/技能继承/转职/凹点 |
| 战术解谜型 | 关卡设计/地形/胜利条件——每关是独立谜题 |
| 叙事选择驱动 | 剧情分支/角色生死/派系选择 |
| 资源生存型 | 永久死亡/资源稀缺/失败惩罚 |
| 大规模会战型 | 大数量单位/阵地推进/兵种协同 |
| 养成×战术双核 | 自由转职+深度战术 |
