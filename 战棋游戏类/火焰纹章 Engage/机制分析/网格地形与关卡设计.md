# 网格、地形与关卡设计 — 火焰纹章 Engage

> 游戏版本: 火焰纹章 Engage (Nintendo Switch, 2023) | 数据来源: [Nintendo Ask the Developer Vol.8](https://www.nintendo.com/en-gb/News/2023/January/Ask-the-Developer-Vol-8-Fire-Emblem-Engage-Chapter-3-2329633.html), [Serenes Forest](https://serenesforest.net/engage/), [Fire Emblem Wiki](https://fireemblemwiki.org)

## 一、网格与地形——回归传统+纹章士拓展

### 1.1 网格基础

| 参数 | 数值 |
|------|------|
| 网格类型 | 正方形4向（经典火纹网格） |
| 典型地图 | 18×22 到 25×30 |
| 高度差 | 二元（高低）——与风花雪月一致 |

### 1.2 地形效果与兵种修正
Engage的地形回避系统比风花雪月更复杂——**兵种类型修正地形收益**：

| 地形 | 基础回避 | 移动消耗 | 隐秘(Covert)修正 | 飞行(Flying)修正 | 神秘(Mystical)修正 |
|------|:--:|:--:|:--:|:--:|:--:|
| 平地 | 0 | 1 | 0 | 0 | 0 |
| 森林 | +30 | 2(步兵)/3(骑马) | **+60(×2)** | **0(不享受)** | +30 |
| 茂密森林 | +40 | 2/4(骑马) | **+80(×2)** | 0 | +40 |
| 高地/台地 | +20 | 1 | +40(×2) | 0 | +20 |
| 要塞/王座 | +30+HP恢复 | 1 | **+60(×2)+HP恢复** | 0 | +30+HP恢复 |
| 水域/河流 | — | ×(仅飞行可) | — | 1(飞行无视) | × |
| 沙漠 | 0 | 2(步兵) | 0 | 1(飞行无视) | 2(法师无额外惩罚) |
| 火焰地形 | — | 3 | — | — | — |
| 治疗地板 | 0 | 1 | 0 | 0 | 0 |

**兵种类型定义**：
| 兵种类型 | 代表职业 | 地形加成修正 |
|------|------|:--:|
| **隐秘(Covert)** | 狙击手、盗贼、暗杀者 | **×2——森林中回避+60** |
| **飞行(Flying)** | 飞马骑士、飞龙骑士、飞龙将领 | **×0——不享受任何地形回避** |
| **骑马(Cavalry)** | 圣骑士、弓骑士、英勇骑士 | ×1 |
| **重装(Armored)** | 要塞、将军 | ×1——森林高移动消耗(3-4) |
| **神秘(Mystical)** | 术士、主教、格莫瑞 | ×1——但面对法师攻击时×0 |
| **龙(Dragon)** | 琉尔独有 | ×1——可使用所有地形加成 |
| **气(Qi)** | 格斗系职业 | ×1 |

### 1.3 纹章士对地形的额外影响
部分纹章士的同步技能或Engage技能可以改变地形：
- **卡姆伊(Corrin)**：**龙脉(Dragon Vein)**——根据琉尔当前兵种类型创造不同地形效果——"神龙=全地形创造"
- **艾克(Ike)**：Great Aether——大范围AOE——可摧毁/改变地形
- **西格尔特(Sigurd)**：Override——直线贯穿——可跨越河流/障碍物

## 二、关卡设计——"单一主线非复用"

### 2.1 章节结构
与风花雪月四条路线=80+章节不同——Engage是**26章的单一主线**：

| 阶段 | 章节 | 关键事件 |
|------|:--:|------|
| 序幕 | 序章-第2章 | 琉尔觉醒——首次获得纹章士戒指 |
| 早期 | 第3-8章 | 收集各国戒指——建立同盟 |
| 中期转折 | **第10-11章** | **失去戒指**——绝望——"无戒指=无力量" |
| 重新收集 | 第12-16章 | 夺回戒指+新纹章士加入+最终备战 |
| 终局 | 第17-26章 | 邪龙费尔的大军→四国联合→终章 |
| DLC | 6个神圣外传(Divine Paralogue) | 每关=获得1枚新的DLC纹章手镯 |

### 2.2 胜利条件

| 条件 | 频率 |
|------|:--:|
| 敌全灭(Rout) | 最常用 |
| 击杀BOSS | 中期+终局频繁 |
| 到达指定格 | 逃脱/突入 |
| 防守N回合 | 特定关卡 |
| 双重目标(如"先击杀X→然后到达Y") | 终局大量使用 |

### 2.3 遭遇战与训练

| 类型 | 说明 |
|------|------|
| **遭遇战(Skirmish)** | 世界地图上的随机战斗——敌人等级跟随主线——可无限刷EXP/SP/金币 |
| **训练(Training)** | 索姆尼尔竞技场——3连战——无死亡风险——获得奖励 |
| **外传(Paralogue)** | 纹章士外传——每个纹章士有1个外传地图——复刻原作经典战场 |

### 2.4 DLC神圣外传
7枚DLC纹章手镯各有自己的外传地图——这些地图复刻了DLC角色原作的标志性战场：
- 提卡(Tiki)：龙之祭坛
- 三房三人组：加尔古·玛库大修道院
- 赫克托尔(Hector)：奥斯迪亚城
- 索伦(Soren)：格雷尔雇佣兵基地
- 卡米拉(Camilla)：暗夜王国城堡
- 库洛姆&路弗雷(Chrom/Robin)：命运之门
- 维罗妮卡(Veronica)：阿斯克王国

## 三、可部署单位

| 游戏阶段 | 可部署单位数 |
|:--:|:--:|
| 序章-第4章 | 4-6 |
| 第5-10章 | 8-10 |
| 第11-16章 | 10-12 |
| 第17-26章(终局) | 12-14 |

与风花雪月一致的12-14人部署量——但加上纹章士戒指=约8-10个Engage单位的变化。

## 四、设计特点分析

1. **兵种×地形修正=Engage的战术微调层**：隐秘兵种在森林中+60回避——这使得兵种选择不仅影响"武器选择"——更影响"你能在哪里安全站位"。
2. **纹章士创造地形的能力**：卡姆伊的龙脉是战棋品类中少数允许玩家**主动改变战场地形**的能力——类似陷阵之志的裂缝创造，但在日式战术游戏中罕见。
3. **单一线性的章节结构=每个关卡都是独特的**：没有路线重复/复用——26章=26个独特的战场——开发资源更集中。
