# 战斗公式与概率系统 — 火焰纹章 Engage

## 二、全战斗公式

### 2.1 命中(Hit)
```
基础命中 = 武器命中 + (Dex × 2) + (Lck × 0.5) + 支援加成 + 技能加成
最终命中 = 攻击方基础命中 − 防御方回避(Avoid)
```

### 2.2 回避(Avoid)
```
回避 = (Spd × 2) + (Lck × 0.5) + 地形加成 × 兵种修正 + 支援加成 + 技能加成
```

**兵种类型对地形加成的修正**：
| 兵种 | 地形回避修正 | 说明 |
|------|:--:|------|
| **隐秘(Covert)** | **×2** | 回避翻倍——"森林中的狙击手几乎无法被击中" |
| 普通兵种 | ×1 | 标准地形回避 |
| **神秘(Mystical)** | ×0（被魔法攻击时） | 法师系对法师攻击无地形回避加成 |
| 飞行(Flying) | **×0** | 飞行单位永远不享受地形回避 |

### 2.3 暴击(Crit)
```
暴击率 = 武器暴击 + (Dex ÷ 2) + 技能加成
最终暴击 = 攻击方暴击率 − 防御方暴击规避(Dodge)
暴击规避(Dodge) = 武器闪避 + Lck
```
暴击使用**1-RN**（真随机）——与风花雪月一致。

### 2.4 伤害(Damage)
```
物理伤害 = 武器威力(Mt) + Str − 目标Def
魔法伤害 = 武器威力(Mt) + Mag − 目标Res
最短伤害 = 0（无负伤害）
```

### 2.5 攻击速度(AS)与追击
```
AS = Spd − (武器重量 − Bld)  [若Bld ≥ 武器重量 → AS = Spd——无惩罚]
追击条件 = AS ≥ 目标AS + 5
```

**追击门槛=5**（与风花雪月门槛=4相比——Engage略微更难追击）。

### 2.6 2-RN双随机（True Hit）
Engage使用与风花雪月相同的**2-RN系统**：

| 显示值 | 实际概率(2-RN) |
|:--:|:--:|
| 90% | 98.1% |
| 80% | 92.2% |
| 70% | 82.3% |
| 60% | 68.4% |
| 50% | 50.0% |
| 30% | 17.7% |
| 10% | 1.9% |

### 2.7 法杖命中(Staff Hit)
```
Staff命中 = 法杖命中 + Mag + Dex − 目标Staff回避
Staff回避 = (Res × 1.5) + (Lck × 0.5) + 地形加成 × 兵种修正
```

## 三、支援加成

| 支援等级 | 命中 | 回避 | 暴击规避 |
|:--:|:--:|:--:|:--:|
| C | +10 | +3 | +3 |
| B | +10 | +5 | +3 |
| A | +10 | +7 | +5 |
| S | +10 | +10 | +7 |

**琉尔独有**：对所有友方提供C级支援命中加成（+10命中）——这是"纽带之王"身份的数值化表达。

## 五、Build（体格）——Engage最关键的公式革新

此前所有火纹使用"力量/5"作为减重公式——但Engage将减重完全分离为独立的**体格(Build)**属性：

| 对比 | 风花雪月 | Engage |
|------|------|------|
| 减重公式 | Str/5 | **Build属性——1:1抵消武器重量** |
| 高力量角色自动减重？ | 是 | **否**——需要高Build |
| 法师的攻击速度 | 受力量影响（不直观） | 受Build影响（独立于Mag） |
| 体格如何成长 | 无此属性 | **通过纹章士羁绊——特定纹章士+Build继承技能** |

**设计意图**：将"谁能承受重武器"从力量中解耦——一个法师可以通过与艾克或利夫纹章士建立羁绊来获得高Build——即使他的力量很低。
