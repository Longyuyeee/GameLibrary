# 职业系统与角色成长 — 火焰纹章 Engage

> 游戏版本: 火焰纹章 Engage (Nintendo Switch, 2023) | 数据来源: [Nintendo Ask the Developer Vol.8](https://www.nintendo.com/en-gb/News/2023/January/Ask-the-Developer-Vol-8-Fire-Emblem-Engage-Chapter-3-2329633.html), [Serenes Forest](https://serenesforest.net/engage/), [Fire Emblem Wiki](https://fireemblemwiki.org)

## 一、职业体系——回归经典+纹章士拓展

### 1.1 三层职业树

Engage回归了经典火纹的双层转职模型（基础→高阶）——但通过纹章士的武器熟练度继承增加了第三层自由度：

| 层级 | 数量 | 说明 |
|:--:|:--:|------|
| **基础职业(Base)** | ~15 | 每个角色的起始职业——如剑客、枪兵、战士、僧侣等 |
| **高阶职业(Advanced)** | ~20+ | 使用大师之证(Master Seal)升格——如刀剑将领、圣骑士、勇士等 |
| **特殊职业(Special)** | ~10+ | 特定角色独有——如琉尔的神龙之子(Divine Dragon)、舞者等 |
| **DLC职业** | ~5 | 附魔师(Enchanter)等——扩展内容 |

### 1.2 转职系统

| 参数 | 说明 |
|------|------|
| **大师之证(Master Seal)** | 基础→高阶——等级≥10可使用 |
| **转职证(Second Seal)** | 在同一层级内切换职业（高阶↔高阶） |
| **纹章士武器熟练度继承** | 与纹章士建立羁绊→角色获得该纹章士的武器熟练度→解锁原本不可用的职业路径 |
| **等级不重置** | 转职后保留等级——与风花雪月一致 |

**纹章士的转职拓展示例**：
- 一名弓箭手与马尔斯(剑)建立羁绊→获得剑熟练度→可以从弓箭手转职为**刀剑将领**
- 一名枪兵与琳(弓)建立羁绊→获得弓熟练度→可以转职为**弓骑士**

## 二、角色成长数值——SP+属性双轨

### 2.1 属性面板

Engage使用与风花雪月相同的10属性面板，但有一些关键调整：

| 属性 | 变化(与风花雪月对比) |
|------|------|
| **体格(Build)** | **新增属性**——替代了"力量/5减重"公式——Build=角色可承受的武器重量上限 |
| **力量/魔力** | 不再影响减重——减重完全由Build决定 |
| **魅力(Charm)** | 无计策系统——魅力功能改变——影响部分技能 |

### 2.2 Build——影响武器重量+攻速的门槛属性

```
攻速(AS) = 速度(Spd) + (体格(Build) − 武器重量)

如果武器重量 > Build → AS惩罚 = 差距值
如果武器重量 ≤ Build → 无AS惩罚
```

这是Engage最关键的微调之一——Build成为决定"谁能有效使用重武器"的核心属性。低Build角色(如法师)即使有高速度也会被重武器惩罚。

### 2.3 成长率

与风花雪月一致——角色成长率+职业成长率=每级实际成长率。但Engage中：
- **纹章士被动加成**也影响成长——装备特定戒指提供持续的属性成长修正
- 炼成(锻造)武器不改变角色的成长率

## 三、技能系统——2继承槽的精简约束

### 3.1 技能来源

| 来源 | 说明 | 槽位需求 |
|------|------|:--:|
| **职业自带技能** | 每个职业有1-2个固定技能——无需占用槽位 | 0 |
| **纹章士继承技能** | 用SP从纹章士处永久购买——占1个继承槽 | **1/2** |
| **纹章士同步技能** | **仅当装备该戒指时**——同步技能被动生效——不占用槽位 | 0 |

### 3.2 2继承槽的核心限制

只有**2个继承槽**=每个角色最多只能装备2个从纹章士永久学会的技能（+职业自带技能+当前装备戒指的同步技能）。这创造了非常有约束的构建空间：

**示例Build——"坦克"**：
- 继承槽1：艾克的"Resolve+"(HP低时+防御/魔防)
- 继承槽2：西格尔特的"Canter+"(攻击后可移动剩余步数)
- 当前戒指：艾克(提供同步技能"Laguz Friend"——半减伤害+反射)

**设计意图**：2槽约束强迫专业化——与FFT(4槽自由)和皇骑(4槽全类型共享)和风花雪月(5槽+1独特)相比——Engage是最严格的技能约束。

## 四、与风花雪月/皇骑/FFT的成长系统对比

| 维度 | Engage | 风花雪月 | 皇骑重生 | FFT |
|------|------|------|------|------|
| 属性数 | 10+Build(新增) | 10 | 8 | 6+2(Brave/Faith) |
| 成长方式 | 升级(角色+职业+纹章士修正) | 升级(角色+职业) | 升级(单位独立+职业倾向) | 升级(隐藏职业修正) |
| 转职 | 大师证+转职证→不重置等级 | 考试+合格证→不重置等级 | 转职证→不重置等级 | JP解锁→不重置等级 |
| 技能槽 | **2继承槽**(最严约束) | 5+1(中道) | 4槽全类型共享(紧约束) | 5槽分类型(自由) |
| 技能来源 | 职业+纹章士继承+戒指同步 | 职业精通+技能等级 | 职业+JP购买 | JP购买(跨职业) |
| 武器耐久 | **无耐久**——武器永不破 | 有耐久→消耗→替换 | 有耐久→需要更换 | 无耐久(除特定物品) |
| 凹点 | 存在(固定乱数) | 存在 | 无意义(接近固定) | 无意义 |

## 五、设计特点分析

1. **Build="体格门槛"替代"力量减重"**：这是一个微妙但重要的改变——将"谁能使用重武器"从属性公式中分离为独立的体格属性。一个高力量角色不再自动获得减重——他需要专门的高Build。
2. **2继承槽=最严格的培养约束**：在12+纹章士=数百个可选技能的巨大空间中——你只能选2个永久携带。这是Engage最令人沮丧也最令人满意的设计决定。
3. **纹章士=职业拓展的第三维度**：传统上转职路径受限于角色基础和职业树——纹章士打破了这层限制——允许任何角色通过学习获得新武器熟练度。
