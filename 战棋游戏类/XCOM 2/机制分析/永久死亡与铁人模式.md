# 永久死亡、铁人模式与士兵羁绊 — XCOM 2: War of the Chosen

> 游戏版本: XCOM 2: War of the Chosen (PC, 2017) | 数据来源: [Ufopaedia](https://www.ufopaedia.org/index.php/XCOM_2), [PCGamesN Jake Solomon访谈](https://www.pcgamesn.com/xcom-2/xcom-jake-solomon-interview), [XCOM Wikia](https://xcom.fandom.com/wiki/War_of_the_Chosen)

## 一、永久死亡——XCOM的情感核心

### 1.1 永久死亡的基本规则

| 情况 | 后果 | 可恢复？ |
|------|------|:--:|
| HP=0 | **流血out(Bleeding Out)**——3回合倒计时 | ✅ 可用急救包+医疗协议延长→有时间去找医生 |
| 3回合后无人救援 | **永久死亡**——士兵消失 | ❌ |
| 被灵能爆炸/手雷暴击直接炸死 | **即死**（无倒计时） | ❌ |
| 被天选者绑架(Capture) | 士兵**被俘虏**——从兵营中消失 | ✅ 可在数周后通过秘密行动"解救" |
| 全队覆灭(Squadwipe) | 失去所有6名士兵——失去所有装备 | ❌ 装备不可回收 |

### 1.2 "不可替代的投资"——XCOM的永久死亡为何如此之痛

与火纹的"失去了我花20小时培养的角色"不同，XCOM的永久死亡损失更复合：

| 损失维度 | 具体损失 |
|------|------|
| **时间投资** | 从新兵到Colonel=约15-20场战斗=数小时的时间 |
| **职业独特性** | 每个士兵选择的是不可逆的"二选一"技能路径——失去的不仅仅是等级，是技能组合 |
| **装备投资** | 身上的顶级武器/护甲随尸体一起消失——除非你成功回收尸体（稀有+困难） |
| **羁绊投资** | 失去羁绊伙伴→另一位士兵陷入悲伤——可能触发狂战士状态(不可控) |
| **叙事投资** | 即使XCOM士兵是"随机生成的"，你在战斗中与他经历的事——那次他侧击杀死了一只Sectopod、那次他挡住了天选者的攻击——创造了"涌现式角色" |

### 1.3 与火纹/皇骑的永久死亡对比

| 维度 | XCOM 2 | 风花雪月 | 皇骑重生 |
|------|------|------|------|
| 死亡类型 | 3回合流血out OR 即死 | HP=0=死亡(经典模式) | 三连倒计时→永久死亡 |
| 救援窗口 | **3回合**——可用医疗延长 | 无——HP=0=死亡(经典) | 3轮WT |
| 装备回收 | 需要回收尸体——困难且有限 | 装备留在仓库(不损失) | 装备留在仓库 |
| 情感损失 | 中等——士兵"涌现式角色"可替代性高于火纹角色 | **高**——"这个角色有名字、故事和支援关系" | 中等 |
| 志愿者vs随机 | 随机生成→自己"创造"名字 | 预设角色→不可替代 | 随机大众脸=可替代/剧情角色=不可替代 |

## 二、铁人模式(Ironman)——永久死亡的"强制力"

### 2.1 Ironman的规则

| 参数 | 说明 |
|------|------|
| **单一存档** | 自动保存——不能手动存档 |
| **即时保存** | 每次行动后自动保存——**不可逆转** |
| **已死亡=永久** | 无法"读档回去"——死亡就是死亡 |
| **错误不可撤回** | 走错一格→你的士兵可能被侧击→可能就此死去 |

### 2.2 设计师对Ironman的意图
Jake Solomon解释了为什么Firaxis坚持将Ironman作为"不应该关闭的默认模式"：
> *"Without Ironman, XCOM isn't XCOM. The tension comes from knowing you can't take it back. When a soldier dies in Ironman, that's real—you can't reload. That's the experience we designed."*（没有Ironman，XCOM就不是XCOM。张力来自知道你不能撤消。当一名士兵在Ironman中死亡时，那是真实的——你不能读档。这就是我们设计的体验。）

### 2.3 玩家行为与实际
社区数据显示约60-70%的玩家**不使用Ironman**——而是通过手动存档来模拟"软Ironman"。但Solomon坚持Ironman的存在本身就让即使是非Ironman的玩家也"知道有一个更真实的体验在那里"——这种认知本身就影响着游戏感受。

## 三、WotC新增：士兵羁绊系统

### 3.1 羁绊机制

| 参数 | 说明 |
|------|------|
| **兼容性** | 每对士兵有隐藏的兼容性数值——某些士兵"更配" |
| **羁绊建立** | 共同执行战斗任务→累积羁绊XP |
| **羁绊等级** | Level 1→Level 2→Level 3（最高） |
| **羁绊一对一** | 一旦建立羁绊——士兵无法与其他人配对（"至死不渝"） |
| **羁绊死亡** | 失去羁绊伙伴→存活一方进入悲伤——可能触发狂暴/恐慌 |

### 3.2 羁绊能力

| 等级 | 能力 | 效果 |
|:--:|------|------|
| **Lv1** | **Teamwork(团队协作)** | 给羁绊伙伴1个**额外行动**——CD 3回合 |
| **Lv2** | **Spotter(观察员)** | 与羁绊伙伴攻击同一目标时——**+10 Aim** |
| **Lv3** | **Advanced Teamwork(高级团队协作)** | Teamwork升级为**每个任务可用2次** |
| **Lv3** | **Dual Strike(双重打击)** | 羁绊伙伴在你的射击后立即进行一次自由攻击 |

### 3.3 羁绊的战术含义
羁绊不是"好感度数字"——是**有质量的战术选择**。你需要决定：
- 把最珍贵的羁绊配对放在一起=最大化的协同效应——但如果他们一起覆灭→双倍损失
- 分开他们=失去羁绊技能的战术优势——但减少了"一起死亡"的风险
- 送他们一起执行秘密行动=加速羁绊建设——但这消耗了他们的战力(秘密行动期间不可用于战斗)

## 四、疲劳系统(Will Fatigue)

| 状态 | 效果 |
|------|------|
| **正常** | 正常战斗能力 |
| **疲倦(Tired)** | Will降低——恐慌门槛降低——建议休息 |
| **极度疲劳(Exhausted)** | Will大幅降低——**强制不能部署**——必须休息 |
| **动摇(Shaken)** | 极低Will——无法部署——可能发展出**负面特性** |
| **负面特性(Negative Traits)** | 如"对Muton恐惧"→见到Muton时自动恐慌 / "强迫症弹药检查"→每次行动可能触发额外的填弹时间 |

**恢复**：将士兵留在复仇者号上休息——不派遣执行任务=自动恢复Will。医院设施可加速恢复。

**设计意图**：疲劳系统迫使你轮换队伍——你不能用同一个"A-team"连续执行每个任务。这让你需要培养一个**更广泛的士兵池**（而不仅仅是最强6人），从而增加了永久死亡的潜在损失范围。
