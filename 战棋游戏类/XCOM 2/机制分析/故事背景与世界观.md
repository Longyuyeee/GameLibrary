# 故事背景与世界观 — XCOM 2: War of the Chosen

> 游戏版本: XCOM 2: War of the Chosen (PC, 2017) | 数据来源: [Polygon Jake Solomon采访](https://www.polygon.com/e3/2017/6/14/15796992/xcom-2-dlc-war-of-the-chosen-e3-2017/), [XCOM Wikia](https://xcom.fandom.com/wiki/XCOM_2_story), [Game Developer](https://www.gamedeveloper.com/design/a-deep-dive-into-xcom-and-xcom-2)

## 一、世界观——"如果我们输了..."

### 1.1 核心设定
XCOM 2的故事始于一个颠覆性的前提：**XCOM在第一场战争中失败了**。

| 时间线 | 事件 |
|------|------|
| 2015年(XCOM: Enemy Unknown) | 外星人入侵地球——XCOM成立——国际联盟共同对抗 |
| **"官方时间线"（外星人编造）** | XCOM在几个月内被摧毁——各国投降——外星人以"ADVENT联盟政府"的形式"和平管理"地球 |
| **真相** | XCOM转入地下——以游击队的形式存活了20年——在移动基地"复仇者号"上运作 |
| 2035年(游戏时间) | 玩家从零重建XCOM——在Advent城市中心进行游击战——目标：推翻整个外星统治 |

### 1.2 "如果我们是游击队"的设计哲学
Jake Solomon解释了为什么从"国际军事组织"变成"地下抵抗运动"：

> *"In XCOM: Enemy Unknown, you were the world's last hope—a UN-backed military force with bases around the globe. In XCOM 2, you're a guerrilla movement operating from a stolen alien ship. Everything about the design—from the concealment mechanic at the start of missions to the limited resources—comes from this single story premise."*

## 二、主要势力

| 势力 | 性质 | 目标 |
|------|------|------|
| **XCOM** | 地下抵抗运动——玩家控制的势力 | 推翻ADVENT——解放地球 |
| **ADVENT联盟政府** | 外星人控制的傀儡人类政府 | 维持外星统治——控制人口 |
| **上古长者(Elders)** | 外星统治者的最高层级——隐藏在幕后 | 完成Avatar计划——重新获得不朽的身体 |
| **化身(Chosen)** | Elder创造的三个超能力"后裔"——WotC新增 | 消灭XCOM——证明自己是"值得继承长者之位"的勇士 |
| **抵抗军(Resistance)** | 散落在世界各地的平民抵抗派系 | 协助XCOM——提供资源/情报/士兵 |
| **死神(Reapers)** | 荒野生存者——WotC英雄阵营 | 猎杀ADVENT——他们吃外星人尸体来存活 |
| **散兵(Skirmishers)** | 叛逃的ADVENT士兵——WotC英雄阵营 | 利用他们对外星系统的内部知识来摧毁外星人 |
| **圣殿骑士(Templars)** | 灵力使用者结社——WotC英雄阵营 | 崇拜灵力——XCOM 1的灵力士兵吉斯特(Geist)是他们的创始人 |

## 三、化身计划——世界的倒计时

外星人来到地球不是为了"征服"——是为了**生存**：

| 层面 | 内容 |
|------|------|
| **长者的真相** | 上古长者是一种**濒临灭绝的物种**——他们的身体正在因老化而衰败 |
| **Avatar计划的目标** | 收集人类的基因多样性→创造一个**完美的混合身体**→将长者的意识转移到新身体中→重新获得不朽 |
| **为什么是人类** | 人类的基因具有"独特"的多样性——长者经过数千种物种测试后选择了人类 |
| **代价** | 一旦Avatar计划完成——人类将被**基因重组**——本质上变为一个新的物种——不再是"人类" |

**设计意图**：Solomon说他的目标是创造一个"不是想毁灭地球，而是想用地球来拯救自己的外星威胁"——这让敌人不是"纯恶"，而有了悲剧性的维度。

## 四、WotC——失落与被遗弃的城市

WotC扩展引入了新的战场类型——**失落之城(Lost Cities)**：

| 元素 | 内容 |
|------|------|
| **失落者(Lost)** | 被外星人实验遗留下来的**人类变异体**——不是僵尸，而是"基因实验的废弃品" |
| **失落之城规则** | ADVENT遗弃了这些城市——失落者在其中漫无目的地游荡 |
| **与失落者的战斗** | 失落者是被声音吸引的——每声枪响→吸引更多失落者。它们攻击**所有人**——你的士兵和ADVENT |
| **三方混战** | XCOM vs ADVENT vs Lost——使命中开始混乱且不可预测 |

**设计意图**：Jake Solomon特别提到他想创造一种"让ADVENT和XCOM都想要远离的威胁"。失落者是双方共同的"环境威胁"——将二方战斗转化为三方混战——"你永远不知道下一波失落者会从哪个方向来"。

## 五、叙事主题

| 主题 | 体现 |
|------|------|
| **失败的重量** | 游戏开始于"我们已经输了"——这创造了一种独特的悲观底色 |
| **抵抗→希望** | 从零开始重建——从一艘偷来的飞船到一支全球抵抗力量 |
| **"人类的火花"** | XCOM 2反复强调"不是科技让你变得强大——是人性" |
| **长者作为悲剧对手** | 他们不是为了邪恶——是为了生存——这让"敌人"有了情感复杂性 |
| **战争的代价** | 每一个死去的士兵不是一个数字——是他/她与队友建立的联系的断裂 |

## 六、XCOM 2 vs 风花雪月/皇骑的世界观对比

| 维度 | XCOM 2 | 风花雪月 | 皇骑 |
|------|------|------|------|
| 设定 | 近未来科幻(2035年) | 中世纪奇幻 | 中世纪低奇幻 |
| 冲突性质 | 人类vs外星统治者 | 三个学派之间的内战 | 三民族独立战争 |
| 敌人属性 | 外星人——有悲剧性动机 | 另一个学派——道德模糊 | 另一个民族——同是人类 |
| 胜利意义 | 解放地球——恢复人类自由 | 以你选择的意识形态重塑世界 | 实现你选择的价值观——但代价沉重 |
| 失败后的世界 | **游戏开始于此**——XCOM在1995年输了 | 不会"输"——你换个路线 | 不会"输"——你换个路线 |

**关键差异**：XCOM 2是战棋品类中唯一开始于"我们已经输了"的游戏。你不是在"试图赢"——是在"试图不输第二次"。
