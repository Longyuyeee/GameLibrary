## 二、高度差详细规则

| 高度差 | 命中修正 | 伤害修正 | 弹道要求 |
|:--:|:--:|:--:|------|
| +2层+ | +20% | +20% | **需要无阻挡的直线视线** |
| +1层 | +10% | +10% | 需要无阻挡视线 |
| 同高度 | 0 | 0 | — |
| -1层 | -10% | -10% | 视线可被建筑物阻挡 |
| -2层+ | -20% | -20% | 视线几乎必然被阻挡 |

**关键规则**：
- 弓箭/魔法弹道是**直线**的——中间有障碍物→无法攻击
- 投掷武器(枪/斧远程技)是**抛物线**——可越过障碍但命中降低
- 翼人(飞行)无视所有地形移动惩罚——但**降雨/暴风雨中移动-1**

## 三、天气系统

| 天气 | 触发条件 | 效果 |
|------|------|------|
| **晴天** | 默认 | 无影响——标准战斗条件 |
| **雨** | 特定关卡/随机 | 水+雷魔法威力+20%；**火魔法-20%**；无移动影响 |
| **暴风雨** | 特定关卡 | 雷魔法+30%；**飞行单位移动-1**；火魔法-30% |
| **雪** | 特定关卡 | 冰魔法+20%；**所有步兵移动-1**(雪地=额外移动消耗) |
| **雾** | 特定关卡 | 远程命中-15%(弓/十字弓/火枪) |
| **多云/阴** | 随机 | 无战斗影响 |

## 四、八元素相克链

```
风(Wind) → 土(Earth) → 雷(Thunder) → 水(Water) → 火(Fire) → 冰(Ice) → 风(Wind)
                         光(Light) ↔ 暗(Dark)——互相克制(+30%伤害)
```

| 攻击元素 | 克制目标 | 被抵抗目标 |

| 雷 | 水(+20%) | 土(-20%) |
| 水 | 火(+20%) | 雷(-20%) |
| 火 | 冰(+20%) | 水(-20%) |
| 冰 | 风(+20%) | 火(-20%) |
| 光 | 暗(+30%) | — |
| 暗 | 光(+30%) | — |
