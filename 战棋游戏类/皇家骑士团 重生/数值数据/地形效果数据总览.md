## 三、元素相克链

```
风 → 土 → 雷 → 水 → 火 → 冰 → 风
光 ↔ 暗（互克）
```

| 攻击元素 | 克制目标元素 | 被目标元素抵抗 |
|------|:--:|:--:|
| 风 | 土(+20%伤害) | 冰(-20%伤害) |
| 土 | 雷(+20%) | 风(-20%) |
| 雷 | 水(+20%) | 土(-20%) |
| 水 | 火(+20%) | 雷(-20%) |
| 火 | 冰(+20%) | 水(-20%) |
| 冰 | 风(+20%) | 火(-20%) |
| 光 | 暗(+30%) | 光(0) |
| 暗 | 光(+30%) | 暗(0) |

## 四、天气影响

| 天气 | 效果 |
|------|------|
| 雨 | 水+雷魔法+20%威力；火魔法-20%威力 |
| 暴风雨 | 雷魔法+30%；飞行单位移动-1；火魔法-30% |
| 雪 | 冰魔法+20%；所有步兵移动-1 |
| 晴天 | 无影响 |
| 多云/阴 | 无影响 |
