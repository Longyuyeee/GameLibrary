# WT行动顺序数据总览 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 | 数据来源: [游侠攻略](https://gamemad.com/guide/212413), [A9VG](https://bbs.a9vg.com/thread-8877464-1-1.html)

## 一、WT公式

```
总WT = 角色固有WT + 职业WT + 装备重量 + 上次行动WT增加值
```

| 组成部分 | 说明 |
|------|------|
| 角色固有WT | 每个角色有固定基础WT值(主角~10, 翼人~8, 龙族~15) |
| 职业WT | 忍者最快(0-2), 恐怖骑士最慢(10-15) |
| 装备重量 | 所有装备的重量直接加入WT(全套重装=+20~30WT) |
| 行动WT值 | 等待(~10) < 移动(每格+6~10) < 单手剑(+18) < 魔法(+20~50) |

## 二、行动WT消耗

| 行动 | WT增加值 | 备注 |
|------|:--:|------|
| 等待 | +8~12(因职业) | 最短——如果什么都不做 |
| 单格移动 | +6~10(因职业+种族) | 翼人每格+6, 重装每格+10 |
| 单手剑攻击 | +18 | — |
| 枪攻击(射程2) | +24 | 因射程额外+6 |
| 双手剑攻击 | +28 | — |
| 弓射击 | +22 | — |
| 锤攻击 | +30 | 重武器 |
| 火枪射击 | +36 | 最重攻击 |
| 小魔法(Fire等) | +20~25 | — |
| 大魔法(Ragnarok等) | +35~50 | — |
| 禁咒(最高魔法) | +50~70 | — |
| 使用道具 | +12 | — |
| 使用招募技 | +30~40 | — |

## 三、职业WT基准

| 职业 | 基础WT | 排序 |
|------|:--:|:--:|
| 忍者/女忍 | 0-2 | **最快** |
| 弓箭手/盗贼 | 2-4 | 很快 |
| 战士/狂战士 | 4-6 | 快 |
| 巫师/教士 | 4-6 | 快 |
| 骑士 | 6-8 | 中 |
| 龙骑士 | 6-8 | 中 |
| 术士 | 6-8 | 中 |
| 恐怖骑士 | 10-15 | **最慢** |

## 四、装备重量对WT的影响

| 装备类型 | 轻量级 | 中等 | 重量级 |
|------|:--:|:--:|:--:|
| 武器 | 匕首(1-2) | 单手剑(4) | 双手剑/锤(7-10) |
| 头盔 | 布帽(1) | 锁甲兜(3-4) | 全盔(6-8) |
| 铠甲 | 布衣(1-2) | 锁甲(5-7) | 板甲(10-14) |
| 手套 | 布手(1) | 锁手套(2-3) | 铁手套(4-6) |
| 鞋子 | 布鞋(1) | 皮鞋(2-3) | 铁靴(4-6) |
| 盾牌 | 小盾(2) | 中盾(4) | 大盾(6-8) |

**极轻配置**(忍者): 1+2+1+1+1+0 = 6(额外WT)
**极重配置**(恐怖骑士): 10+8+14+6+6+8 = 52(额外WT)

这就是为什么忍者每回合可能行动2-3次而恐怖骑士可能只行动1次——WT系统最纯粹的装备->行动顺序映射。

## 五、调隙（Turn Manipulation）速算

| 策略 | 实现方式 | WT效果 |
|------|------|------|
| 快速双动 | 等待(WT+10)→等待(WT+10)=2次极短WT | 连续两行动 |
| 延迟爆发 | 等待→等待→等待→大魔法(WT+50) | 积攒MP+单次爆发 |
| 集火连攻 | 忍者(双动) + 战士(短WT) + 弓箭手(短WT) | 3-4单位连续攻击同一目标 |
