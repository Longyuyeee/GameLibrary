## 三、忠诚度数据

### 3.1 忠诚度阈值

| 范围 | 效果 |
|:--:|------|
| 80-100 | 完全忠诚——绝不出问题 |
| 50-79 | 基线——正常运作 |
| 30-49 | 低——小概率拒绝指令 |
| 10-29 | 危险——高概率拒绝指令/脱离战斗 |
| 0-9 | **背叛**——角色永久离开队伍 |

### 3.2 忠诚度影响因素量化（估算）

| 行为/选择 | 影响值 |
|------|:--:|
| L/C关键选择与角色价值观一致 | +10~20 |
| L/C关键选择与角色价值观冲突 | **-15~30** |
| 同民族角色的特殊选择 | ±20 |
| 角色多次战斗中重伤倒地 | -2~5/次 |
| 使用该角色击倒特定敌人 | +1~3(取决于角色价值观) |
| 角色长时间(约5场战斗)不上场 | -1~3(被忽视感) |

## 四、招募成功率因素

| 因素 | 效果权重 |
|------|:--:|
| 目标HP = 1 | **最高成功率** |
| 目标HP < 30% | 高成功率 |
| 目标HP > 80% | 极低成功率(几乎不可能) |
| 招募方与目标距离 = 1格 | 最大加成 |
| 距离 = 2格+ | 成功率大幅降低 |
| 目标忠诚度低 | 成功率高 |
| 招募方等级 > 目标等级 | 每级+约2-5% |
| 同民族 | +20%基础成功率 |
