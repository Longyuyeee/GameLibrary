# 战斗公式与元素数据总览 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (2022) | 数据来源: [dojo.cn](https://www.doyo.cn/article/501391), [NGA攻略](https://ngabbs.com/read.php?tid=34425790)

## 一、属性公式

### 1.1 伤害公式

| 伤害类型 | 公式 |
|------|------|
| **物理伤害** | (STR + 武器STR) × 攻击类型修正 − (目标VIT + 防具VIT + 目标STR/2) |
| **魔法伤害** | (INT + 魔法INT) × 元素修正 × 卡片修正 − (目标MND + 目标RES) |
| **远程伤害** | (STR×0.7 + DEX×0.3 + 武器STR) × 射程修正 − 目标防御 |
| **固定伤害** | 十字弓/火枪——固定伤害值(不受STR/DEX影响) |

### 1.2 命中公式

| 类型 | 公式 |
|------|------|
| **物理命中** | 基础90% + AGI修正 + DEX修正 − 目标AVD − 地形回避 |
| **魔法命中** | 基础95% + MND修正 − 目标RES |
| **实际命中率** | 重生命中率极高(~95%+)——AGI/DEX/AVD实战影响有限 |

### 1.3 WT公式

```
总WT = 角色固有WT + 职业WT + 装备重量 − 减重效果 + 上次行动WT增加值

行动WT增加值 = 基础行动WT(移动/等待) + 武器攻击WT + 魔法/技能WT
```

| 行动 | WT增加值 |
|------|:--:|
| 等待(无移动无攻击) | +8~12 |
| 移动1格 | +6~10(因职业/种族而异) |
| 移动3格 | +18~30 |
| 单手剑攻击 | +18 |
| 双手剑攻击 | +28 |
| 枪攻击(射程2) | +24 |
| 魔法(小) | +20~25 |
| 魔法(大) | +35~50 |
| 使用道具 | +12 |

## 二、属性面板速查

| 属性 | 主要作用 | 次要作用 |
|------|------|------|
| **STR** | 物理攻击力+物理防御力 | — |
| **DEX** | 远程物理攻击加成+命中 | — |
| **VIT** | 物理防御 | — |
| **INT** | 魔法攻击力(约两倍于MND的贡献) | — |
| **MND** | 魔攻(次要)+魔防+魔法命中 | — |
| **RES** | 魔法防御 | — |
| **AGI** | 命中率(不影响WT/行动顺序!) | — |
| **AVD** | 回避率 | — |
