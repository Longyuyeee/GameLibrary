# 关卡设计与战斗间运营 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (2022) | 数据来源: [Gematsu战场详解](https://www.gematsu.com/2022/10/tactics-ogre-reborn-details-skills-battlefield), [A9VG攻略](https://bbs.a9vg.com/thread-8877464-1-1.html), [DualShockers指南](https://www.dualshockers.com/tactics-ogre-reborn-law-chaos-neutral-route-guide/)

## 一、主线章节结构

皇骑重生主线分**4章**——结构与绝大多数战棋不同，不是分"关"而是分"章"，每章内含多个连续战斗：

| 章 | 内容 | 大约战斗次数 | 关键事件 |
|------|------|:--:|------|
| **第1章** | 瓦尔斯塔独立战争 | 8-10 | **巴拉姆斯大屠杀**——L/C路线的第一个分歧点 |
| **第2章** | 内乱与权力的代价 | 10-12 | 内部矛盾升级+关键角色命运决策 |
| **第3章** | 三方势力的角力 | 12-15 | L/C/N路线分歧后的独立故事 |
| **第4章** | 决战与终局 | 12-16 | 结局路线+通关后CODA解锁 |

总战斗次数约**40-55场**（含支线）——比风花雪月普通路线(22章)多出一倍战场数量。

## 二、胜利条件和战场规模

### 2.1 胜利条件

| 条件 | 频率 | 说明 |
|------|:--:|------|
| **敌全灭** | 最常用 | 击杀所有敌方单位（主要条件） |
| **击杀BOSS** | 第二常用 | BOSS血量≤0即胜利 |
| **到达指定格** | 部分关卡 | 特定逃脱/突入关卡 |
| **生存N回合** | 少量 | 防御战 |

与风花雪月类似——以全灭和击杀BOSS为主的传统设计。

### 2.2 战场规模

| 规模 | 格数 | 可部署人数 | 出场情况 |
|------|:--:|:--:|------|
| 小 | ~12×15 | 6-8 | 狭窄巷道/室内战 |
| 中 | ~16×22 | 8-10 | 主力战斗 |
| 大 | ~20×28 | 10-12 | 平原会战/攻城战 |
| 特大型 | ~25×32 | 12 | 最终战/要塞攻防 |

### 2.3 增援机制
- 增援从特定位置出现（城堡/营地——符合叙事逻辑）
- 部分关卡增援触发条件=玩家推进到特定区域
- BOSS增援——类似火纹，BOSS血量降到阈值后召唤

## 三、战斗间运营

皇骑重生在"战斗之间"保持简洁——这与风花雪月的修道院完全不同。

### 3.1 战斗间可操作内容

| 功能 | 说明 | 深度 |
|------|------|:--:|
| **商店** | 购买武器/防具/消耗品/转职证/魔法书 | 标准——武器防具随章节更新 |
| **锻造** | 武器强化(+1~3)+元素附魔 | 深——素材收集驱动 |
| **转职** | 消耗转职证+满足条件 | 深——~40职业选择 |
| **技能配置** | 4槽位配置+技能升级 | 深——强迫专业化 |
| **队伍调配** | 选择12人出击阵容(100人总池) | 中 |
| **训练模式** | 可选战斗——无永久死亡+无掉落+快速EXP | 重生回归的新功能 |
| **WORLD塔罗**(通关后) | 跳到任意锚点体验其他路线 | 深——多周目体验的核心 |

### 3.2 与风花雪月运营对比

| 维度 | 皇骑重生 | 风花雪月 |
|------|------|------|
| 运营深度 | 浅——菜单操作 | 深——3D探索+活动经济 |
| 时间结构 | 无日历——线性章节 | 日历制(12×4周) |
| 战斗频率 | 高——每章多次连续战斗 | 中——每月1次主线战斗 |
| 角色关系建设 | 仅通过战场和剧情 | 修道院全系统(用餐/茶会/送礼) |
| 设计哲学 | "战斗是主体——菜单是配套设施" | "战斗和运营同等重要" |

皇骑重生的设计选择了**纯战术焦点**——不把"战斗间"变成第二个游戏。这是与风花雪月截然不同的选择，反映了SRPG品类内部"运营vs战斗"的光谱。

## 四、训练模式

重生重新引入的训练模式是PSP版没有的新功能：

| 参数 | 说明 |
|------|------|
| 触发 | 菜单中选择——随时可用 |
| 敌人 | 玩家当前等级±匹配的AI敌军 |
| 死亡 | **无永久死亡**——倒下的单位训练后恢复 |
| 掉落 | **无掉落**——训练模式不给装备/素材 |
| EXP | 快速获取——但有联盟等级上限 |
| AI | 可让AI自动控制——松野参与调校的AI会做出合理决策 |

**设计意图**：训练模式让玩家尝试新职业/新技能配置，不受"浪费经验"的心理阻碍。联盟等级上限确保训练不会使主线失去挑战。

## 五、特殊关卡设计

### 5.1 地形垂直性
皇骑的等角3D视角使**高度差关卡**成为品类中最具视觉冲击力的一类：
- 塔楼关卡：需要一层一层向上推到塔顶
- 城墙攻防：进攻方从墙外爬梯/从城门突破
- 地下室/地牢：狭窄通道+黑暗+埋伏

### 5.2 水战与雨战
- 雨天增强雷/水魔法+减弱火魔法
- 飞行单位在暴风雨中移动力减少
- 水域无法通行（除飞行/翼人）
