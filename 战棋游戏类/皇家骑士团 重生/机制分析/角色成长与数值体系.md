# 角色成长与数值体系 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (2022) | 数据来源: [dojo.cn属性详解](https://www.doyo.cn/article/501391), [A9VG攻略](https://bbs.a9vg.com/thread-8877464-1-1.html), [开发者访谈](https://screenrant.com/hiroaki-kato-interview-tactics-ogre-reborn/)

## 一、单位等级制

### 1.1 从职业等级到单位等级
这是重生最重要的系统变革：

| 版本 | 等级系统 | 体验 |
|------|------|------|
| SFC原版 | 单位独立等级 | 每个角色独特 |
| PSP版(2010) | **职业等级制**——全同职业共享等级 | 换职业=角色回到该职业的等级 |
| **重生(2022)** | **回归单位等级制** | 每个角色独立Level→等级跟随人而非职业 |

**开发者的理由**（加藤弘彰/制作人）：
> "玩家反馈更喜欢单位等级的SNES风格——这让他们对每个单位都有更个人的连接感。"

### 1.2 联盟等级（Union Level）——重生新增

为了防止刷级破坏游戏平衡，重生引入了"联盟等级"上限：

| 参数 | 说明 |
|------|------|
| **联盟等级** | 随主线剧情推进的等级上限 |
| **单位等级上限** | 必须≤联盟等级 |
| **超出经验** | 达到联盟等级上限后不再获得EXP |
| **何时提升** | 完成特定主线章节后自动提升 |
| **训练模式** | 可选战斗——快速获取EXP但有联盟等级限制 |

**设计意图**：允许玩家自由训练（训练模式回归），但不能通过过度刷级使战斗失去挑战。

## 二、数值成长体系

### 2.1 升级成长
- 升级时各属性随机增长（类似火纹凹点但幅度更小）
- 职业对成长率有影响（战士→STR倾向，巫师→INT倾向）
- 重生中成长率更加可控——因为有绿色卡片（击杀敌人掉落，永久微幅提升属性）

### 2.2 绿色卡片——属性能永久成长
重生新增的永久成长机制：

| 来源 | 效果 |
|------|------|
| 击杀敌人 | 概率掉落绿色卡片 |
| 绿色卡片 | 永久+0.1~0.3到特定属性 |
| 累积上限 | 理论上无上限（受限于总战斗次数） |

这类似于火纹的"凹点"但完全基于战场掉落——你不需要靠运气，需要靠"杀更多敌人"。

### 2.3 道具属性提升
- 力量之果、魔力之果等消耗品可永久+1属性
- 来源：商店购买+支线奖励+战斗掉落
- 与火纹一脉相承的"可刷"属性增强

## 三、等级上限对比

| 游戏 | 等级上限 | 是否可刷 | 限制机制 |
|------|:--:|:--:|------|
| 皇骑重生 | Lv50(随联盟等级分阶段解锁) | 有上限(联盟等级) | Union Level |
| 风花雪月 | Lv60 | 可无限刷(自由出击) | Maddening减少EXP |
| FFT | Lv99 | 可无限刷 | 无 |
| 魔界战记 | Lv9999 | 可无限刷 | 无(这就是游戏内容) |

皇骑的联盟等级是**可控成长**的设计哲学——给你训练自由但设天花板。

## 四、重生特定角色数据亮点

### 4.1 主角德尼姆
君主职业是游戏最强——原因不在于属性，而在于**技能自由性**：
- 可记忆所有转过职业的技能（即"曾经会过的技能永远能用"）
- 可装备所有武器+使用所有魔法
- 游戏唯一全能型角色

### 4.2 姐姐卡秋娅
- 公主职业=最强圣魔法输出+治疗混合
- 但职业解锁需要特定路线条件（她在L路线可能离开/死亡）
- 她的存活=职业的获取——这是"在乎角色"和"职业配置"之间的叙事-玩法绑定
