# 忠诚度与角色关系 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (2022) | 数据来源: [Gematsu系统详解](https://www.gematsu.com/2022/10/tactics-ogre-reborn-details-skills-battlefield), [ScreenRant招募指南](https://screenrant.com/tactics-ogre-reborn-how-to-recruit-all-story-characters/), [A9VG攻略](https://bbs.a9vg.com/thread-8877464-1-1.html)

## 一、忠诚度系统——东方式的"关系数值"

皇骑的角色关系不是通过"支援对话"（火纹模式）来表现的——而是通过**忠诚度**这个隐藏/半隐藏数值来管理的。

### 1.1 忠诚度机制

| 忠诚度范围 | 效果 |
|:--:|------|
| 高(80-100) | 角色稳定——战场上不会逃跑，服从所有指令 |
| 中(40-79) | 基线——正常表现 |
| 低(20-39) | 风险区域——可能拒绝执行特定指令 |
| 极低(<20) | **背叛风险**——角色可能在战斗中离开阵营 |

### 1.2 影响忠诚度的因素

| 因素 | 效果 | 方向 |
|------|:--:|:--:|
| 主角的L/C选择 | 大幅影响 | L偏向角色不喜欢C选择(+反之) |
| 民族冲突 | 重要因素 | 同民族角色对针对该民族的选择高度敏感 |
| 战斗中击杀特定敌人 | 累积影响 | 角色的"正义感"参数 |
| 角色是否受伤过多 | 微降低 | 你让角色不断去死=不重视他们 |
| 被招募的角色 | 初始忠诚度较低 | 刚被说服加入的敌人需要时间建立信任 |

**设计意图**：忠诚度是将LNC路线选择转化为**实际战术后果**的机制——你选择了C路线，你队伍中的L倾向角色将逐渐失去忠诚。这不是"他们不喜欢你"——是"你们的价值观不再一致，他们无法继续站在你这边"。

### 1.3 与火纹支援系统的对比

| 维度 | 皇骑忠诚度 | 火纹支援系统 |
|------|------|------|
| 关系方向 | 单向(角色→主角) | 双向(所有角色之间) |
| 表现形式 | 数值——影响"是否背叛" | 对话+战斗加成 |
| 叙事表达 | 通过行为和后果——"他离开了" | 通过对话——"他们关系变好了" |
| 设计哲学 | **政治性**——忠诚是道德选择的结果 | **人际性**——关系是个体之间的纽带 |

这是东西方(及不同时代)战棋设计差异的一个缩影：1995年的皇骑用"忠诚度"模拟了一个政治-军事组织的内部张力，2019年的风花雪月用"支援对话"构建了一个学园的人际关系网络。

## 二、招募系统——战场说服

### 2.1 战场招募

皇骑的招募是**在战斗中**完成的——与火纹的"说得"一脉相承但更系统化：

| 招募技能 | 目标种族 | 拥有职业 |
|------|------|------|
| **Recruit** (说服) | 人类、翼人 | 教士/骑士/圣骑士/游侠/白骑士 |
| **Coax** (劝诱) | 蜥蜴人、拉米亚 | 巫师/海盗/女族长 |
| **Subdue** (降伏) | 兽类 | 驯兽师 |
| **Tame** (驯服) | 龙族 | 驯兽师 |
| **Control Golems** (支配) | 魔像/南瓜头 | 术士/女巫/巫女 |
| **Master Undead** (不死支配) | 骷髅/幽灵 | 死灵法师 |

### 2.2 招募成功率因素

| 因素 | 效果 |
|------|------|
| 目标HP | **越低越好**——不能是100% |
| 距离 | **邻接(1格)=最大成功率** |
| 目标忠诚度 | 低忠诚敌人更容易被说服 |
| 招募方等级 | 比目标高=成功率提升 |
| 战车塔罗 | 失败后可回溯——改变位置后重试 |

**招募的设计意义**：不是战后加入——是战斗中倒戈。这在叙事上比战后加入更戏剧化：一个在你面前的敌人放下武器说"我跟你走"。

### 2.3 剧情角色招募
部分剧情角色只在特定条件下招募：
- 需要特定路线（L/C/N）
- 需要特定对话选择
- 需要在特定战斗中"说"他们

这是皇骑多周目玩法的主要驱动力之一——不同路线有不同的军队构成。

## 三、民族关系系统

皇骑的世界中有多个民族，你的选择会影响与每个民族的关系：

| 民族 | 代表角色 | 政治倾向 |
|------|------|:--:|
| **瓦尔斯塔** (Walister) | 德尼姆(主角)、卡秋娅(姐姐) | 独立运动——混沌倾向 |
| **加尔加斯坦** (Galgastan) | 多个敌对角色 | 旧体制维护——秩序倾向 |
| **巴库拉姆** (Bakram) | 骑士团 | 中立/外部势力 |
| **洛迪斯** (Lodis) | 暗黑骑士团 | 外部威胁——帝国 |

**民族好感度的游戏影响**：
- 影响招募成功率——同民族角色更容易招募
- 影响商店价格——在特定民族区域
- 影响部分关卡的敌人行为

## 四、设计启示

1. **忠诚度是一种"政治关系模拟"**：在1995年，很少有游戏尝试让"角色是否留在你队伍中"不仅取决于你对他好不好，还取决于你的政治选择是否符合他的价值观。
2. **战场招募=戏剧性时刻**：不是一个菜单操作，而是一个需要战术计划（"如何让教士安全地走到那个低HP敌人旁边"）的战场目标。
3. **与风花雪月挖角的差异**：风花雪月的挖角是"在修道院中喝茶吃饭培养好感度"——社交化；皇骑的招募是"在战场上打服对方然后说服加入"——军事化。同一设计问题（"如何让非起始角色加入"），两种截然不同的解答，反映了两个时代的设计价值观。
