# 战斗公式与元素系统 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (2022) | 数据来源: [A9VG攻略](https://bbs.a9vg.com/thread-8877464-1-1.html), [NGA攻略心得](https://ngabbs.com/read.php?tid=34425790), [dojo.cn属性详解](https://www.doyo.cn/article/501391)

## 一、属性面板

皇骑使用8属性面板——比火纹10属性更精简：

| 属性 | 英文 | 战斗作用 | 评价 |
|------|------|------|:--:|
| **HP** | HP | 生命值 | — |
| **STR** | Strength | 物理攻击力 + 物理防御力 | ⭐⭐⭐⭐⭐ 物理职业最重要 |
| **DEX** | Dexterity | 远程物理攻击加成(+命中) | ⭐⭐⭐ |
| **VIT** | Vitality | 物理防御 | ⭐⭐⭐ |
| **INT** | Intelligence | 魔法攻击力加成最大(约为MND两倍) | ⭐⭐⭐⭐⭐ 法师最重要 |
| **MND** | Mind | 魔攻+魔防+魔法命中 | ⭐⭐⭐ |
| **RES** | Resistance | 魔法防御 | ⭐⭐⭐ |
| **AGI** | Agility | 影响命中率，**不影响行动顺序**(重生) | ⭐ 基本无用 |
| **AVD** | Avoid | 回避率 | ⭐ 基本无用 |

**与火纹的关键差异**：
- 皇骑没有独立的"技巧(Dex用于暴击)/速度(Spd用于追击)/幸运/魅力"维度——更加精简
- 物理攻击力同时作用于攻击和防御（STR一体两面）
- AGI在重生中被大幅削弱——不再影响WT
- 没有"追击"概念——攻击次数由武器/技能固定

## 二、命中与伤害公式

### 2.1 命中公式（社区估算）
```
物理命中率 ≈ 基础命中 + (DEX + AGI修正) − 目标AVD − 地形回避
魔法命中率 ≈ 基础命中 + (MND修正) − 目标RES
```
因重生命中率极高（几乎100%），DEX和AGI实战意义大幅降低。

### 2.2 伤害公式
```
物理伤害 = (STR + 武器STR) × 攻击类型修正 − (目标VIT + 防具VIT) − 目标STR

魔法伤害 = (INT + 魔法INT) × 元素修正 × 卡片修正 − 目标MND − 目标RES
```
关键点：STR同时影响攻防——高STR不仅是高输出，也是高物防。

### 2.3 没有概率系统
皇骑的重生版本几乎**没有命中概率**——大部分攻击在正常条件下必然命中。暴击由技能/武器词条触发而非概率计算。与火纹的2-RN概率系统形成极端对比。

## 三、八元素系统

皇骑的元素系统是品类中最复杂的：

### 3.1 元素相克链
```
风(Wind) → 土(Earth) → 雷(Thunder) → 水(Water) → 火(Fire) → 冰(Ice) → 风(Wind)
光(Light) ↔ 暗(Dark)（互相克制）
```

### 3.2 角色元素
每个角色出生时带有固定元素（不可改变）：
- 使用与自身同元素的武器/魔法 → **伤害+10~20%**
- 攻击被自身元素克制的目标 → 额外伤害加成
- 被克制元素攻击 → 额外受伤

### 3.3 武器/防具元素
- 武器可附有元素属性（如火之剑）
- 防具可提供元素抗性
- 后期锻造可将元素附到武器上

### 3.4 元素与职业
某些职业的元素倾向明确：
- 巫师/巫女：全元素魔法但各有专长
- 龙骑士：龙系（特殊）+
- 忍者：暗系倾向

## 四、MP vs TP系统变化（重生关键）

| 系统 | PSP版 | 重生版 |
|------|------|------|
| 特殊技能 | TP(技能点)单独积累 | **统一使用MP** |
| MP来源 | 每回合恢复MP | 每回合恢复MP+使用物品 |
| 设计意图 | TP和MP两套资源管理系统 | **简化**——降低系统复杂度 |
| 影响 | 技能使用受"需要等待TP积累"限制 | 开局MP满→可直接使用技能 |
