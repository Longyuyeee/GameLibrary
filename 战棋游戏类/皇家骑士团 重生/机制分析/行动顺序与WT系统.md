# 行动顺序与WT系统 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (2022) | 数据来源: [Gematsu系统详解](https://www.gematsu.com/2022/10/tactics-ogre-reborn-details-skills-battlefield), [游侠网WT/AT指南](https://gamemad.com/guide/212413), [A9VG攻略](https://bbs.a9vg.com/thread-8877464-1-1.html)

## 一、WT（Wait Time）系统概述

WT系统是皇家骑士团最核心的战斗机制——不同于火纹的PPEP（我方全动→敌方全动），皇骑使用**动态行动顺序**。这是品类中最早的CTB（Conditional Turn-Based）实现之一。

### 1.1 WT公式
```
WT = 角色固有WT + 职业WT + 装备重量 − 装备减重 + 上次行动WT增加值

上次行动WT增加值 = 基础行动消耗 + 移动消耗 + 技能/魔法消耗
```

屏幕底部从左到右排列的图标显示行动顺序——WT越小的单位越先行动。当最左侧单位进入AT（Attack Turn）时，该单位可行行动。

### 1.2 WT与装备重量的关系
这是皇骑系统最深的设计——**装备重量直接加入WT**，意味着重甲/重武器让你更耐打但行动更慢：

| 装备 | 重量影响 | WT惩罚 |
|------|:--:|------|
| 布衣/轻甲 | 轻(1-5) | 小——法师/忍者行动快 |
| 锁甲 | 中(6-10) | 中——战士/骑士标准 |
| 重甲/板甲 | 重(11-20) | 大——恐怖骑士行动极慢 |
| 匕首/单手剑 | 轻 | +18WT每次攻击 |
| 双手剑/斧 | 重 | +28~36WT每次攻击 |
| 魔法 | 因魔法而异 | +20~50WT每次施法 |

### 1.3 WT的战术深度
- **调隙（Turn Manipulation）**：通过让短WT单位多做动作、长WT单位少做动作来调整不同单位的行动间隙
- **集火策略**：让我方3-4个单位在连续WT位中行动→可以集火消灭一个敌人而不给其反击/治疗的机会
- **压制策略**：使用高WT消耗技能（如大魔法）延迟敌方行动→后发先至

## 二、AGI的设计变化

在重生中，AGI（敏捷）**不影响行动顺序**——这是一个重大改变：

| 版本 | AGI作用 |
|------|------|
| SFC原版 | 影响行动顺序+命中 |
| PSP版 | 影响行动顺序+命中 |
| **重生** | **仅影响命中率——不影响WT** |

**设计意图**：让"装备选择"取代"敏捷属性"成为决定WT的唯一变量——玩家通过装备管理而非凹属性来控制行动顺序。

## 三、与火纹PPEP的对比

| 维度 | 皇骑WT系统 | 火纹PPEP |
|------|------|------|
| 行动顺序 | 动态——按WT排队 | 静态——我方全员→敌方全员 |
| 速度快的优势 | 行动更频繁 | 可以追击 |
| 装备对顺序的影响 | **重大**——重量直接加入WT | 仅影响AS(攻速) |
| 战术规划方式 | "谁将在何时行动" | "我这一轮全体如何配合" |
| 集火可能性 | 高——可排列连续行动 | 限于回合内配合 |
| 模拟真实感 | 高——"重装后动"符合直觉 | 低——我方全员可先动 |

**设计哲学差异**：WT追求"模拟真实战场的时间流"，PPEP追求"清晰的战术规划窗口"。

## 四、战车塔罗（Chariot Tarot）——时间回溯

重生新增的战车塔罗是风花雪月"天刻之脉动"的直接竞争者：

| 参数 | 战车塔罗 | 天刻之脉动 |
|------|:--:|:--:|
| 初始次数 | 10次/战斗 | 3次 |
| 最大次数 | 随剧情增加到50+ | 13 |
| 回溯范围 | 1-50回合 | 任意前一状态 |
| RNG机制 | **固定种子**——必须改变操作才能改变结果 | 固定乱数表——同操作同样结果 |
| 设计目的 | 学习工具——"试试不同走位" | 安全网——"这次我走错了，退回去" |

**关键差异**：皇骑的RNG是固定种子的——如果从同一位置做同一动作，结果永远相同。玩家必须通过"移动到不同位置再攻击"来改变随机结果。

## 五、BUFF卡片系统（重生新增）

战斗场上随机刷新4种蓝色卡片+红色卡片+绿色卡片：

| 卡片 | 效果 |
|------|------|
| **蓝卡·物理** | 物理攻击力+25%（可叠加4层→+100%） |
| **蓝卡·暴击** | 暴击率+25%（可叠加） |
| **蓝卡·技能** | 自动技能触发率+25% |
| **蓝卡·魔法** | 魔法攻击力+25% |
| **红卡** | 清除目标所有BUFF（敌我通用） |
| **绿卡** | 击杀敌人掉落——永久微量提升角色数值 |

**设计冲击**：BOSS出场自带4层BUFF卡片——输出爆炸。这从根本上改变了战斗节奏——玩家必须主动抢夺/清除卡片。
