# 网格与地形系统 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (PC/PS5/PS4/Switch, 2022年11月11日)
> 数据来源: [Gematsu系统详解](https://www.gematsu.com/2022/10/tactics-ogre-reborn-details-skills-battlefield), [游侠网攻略](https://gl.ali213.net/html/2022-11/955247_2.html), [A9VG攻略](https://bbs.a9vg.com/thread-8877464-1-1.html)

## 一、网格基础

### 1.1 等角3D网格
皇家骑士团使用**等角正方形网格**——与火纹的俯视正方形不同，皇骑的等角视角让高度差在视觉上更显著：

| 网格属性 | 数值 |
|------|------|
| 网格类型 | 正方形（等角3D视角） |
| 移动方向 | 4向（上下左右——但在等角视角下看起来是斜向） |
| 高度维度 | **多层高度系统**（3-5层高度差） |
| 视角 | 等角固定视角——不可旋转 |

**与火纹的核心差异**：皇骑的等角3D让高度差成为一个完整的战术维度——可以从高台射下低处的敌人，也可以在低处被高处的弓手压制。火纹的高度差是二元（高/低）+2Mt，皇骑是多层+弹道+命中修正。

### 1.2 网格规模
- 标准战场：约15×20格
- 大型战场：约20×30格
- 与风花雪月（最大30×35）相当，但因等角视角感知更紧凑

### 2.2 高度差与弹道
皇骑的高度差系统是品类中最完善的之一：

| 高度差层数 | 攻击方 | 防御方 | 效果 |
|:--:|------|------|------|
| 1层 | 高处 | 低处 | 命中+10%、伤害+10% |
| 2层+ | 高处 | 低处 | 命中+20%、伤害+20% |
| 1层 | 低处 | 高处 | 命中-10%、伤害-10% |
| 2层+ | 低处 | 高处 | 命中-20%、伤害-20% |
| — | 弓箭/魔法 | — | 弹道需要无阻挡视线——中间有障碍则无法攻击 |
| — | 投掷武器 | — | 抛物线弹道——可越过障碍但命中降低 |

**与陷阵之志/风花雪月的区别**：皇骑是多层高度"弓兵在高台=王者"，FFT继承了这个设计。火纹风花雪月简化了高度差，是因为战斗间运营占用了太多的设计注意力。

## 三、元素与天气

### 3.1 八元素系统
皇骑独有的元素系统贯穿地形/装备/角色：

| 元素 | 克制 | 被克制 | 关联地形 |
|------|:--:|:--:|------|
| 风 | 土 | 冰 | 高地/山峰 |
| 土 | 雷 | 风 | 平原/洞穴 |
| 雷 | 水 | 土 | 暴风雨/高塔 |
| 水 | 火 | 雷 | 水域/雨 |
| 火 | 冰 | 水 | 火山/熔岩 |
| 冰 | 风 | 火 | 雪地/冰原 |
| 光 | 暗 | — | 神殿/圣地 |
| 暗 | 光（互克） | — | 墓地/地底 |

角色出生时带有固定元素属性——影响使用同元素魔法/武器的伤害加成，以及被克元素攻击时额外受伤。

### 3.2 天气系统
皇骑有**天气系统**（品类少数之一）：
- 雨：增强水/雷魔法，减弱火魔法
- 暴风雨：大幅增强雷魔法，飞行单位移动减少
- 雪：增强冰魔法，减少移动力
- 晴天/多云：中性
- 天气在战斗中可能变化
