# 故事分支与LNC路线设计 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (2022) | 数据来源: [DualShockers路线指南](https://www.dualshockers.com/tactics-ogre-reborn-law-chaos-neutral-route-guide/), [Gematsu系统详解](https://www.gematsu.com/2022/10/tactics-ogre-reborn-details-skills-battlefield), [游戏狂攻略](https://gamemad.com/guide/211545)

## 一、LNC——日式RPG道德选择的奠基之作

皇家骑士团（1995年SFC版）的**Law-Neutral-Chaos（秩序-中立-混沌）**系统是日式RPG/战棋中最早将道德选择作为核心机制的尝试之一。风花雪月的三条路线、苏丹的游戏的欲望系统——都可以追溯到皇骑的LNC。

### 1.1 三路线概述

| 路线 | 核心问题 | 主角身份 | 叙事主题 |
|------|------|------|------|
| **L (秩序/Law)** | "服从不对等的命令，哪怕它们是不道德的？" | 遵命行事——即使这意味着屠杀平民 | 体制内的正义——用合法手段从内部改变 |
| **N (中立/Neutral)** | "两边都不选——能否找到自己的路？" | 拒绝服从——成为两方的敌人 | 个人良知胜过集体效忠 |
| **C (混沌/Chaos)** | "为了更大的善，需要多大的破坏？" | 反抗——与原本的敌人联手 | 革命——不完美但必要的手段 |

### 1.2 关键选择分布
不同于风花雪月的单点选择（第11章一次决定），皇骑的LNC是**累积选择**：

| 章节 | 关键选择 | L/C/N导向 |
|------|------|:--:|
| 第1章末 | **巴拉姆斯大屠杀**——执行(参与) vs 拒绝 | 执行→L / 拒绝→C |
| 第2章 | 对待囚犯的态度 | 宽容→N / 严厉→L / 释放→C |
| 第3章 | 是否与原敌人合作 | 合作→C / 拒绝→L |
| 第4章 | 结局选择 | 取决于之前的累积选择+特殊条件 |

## 二、混沌框架（Chaos Frame）——隐藏数值

皇骑有一个**隐藏的道德计量系统**——Chaos Frame。玩家看不到具体的数字，但你的每个选择都在累积影响它：

| 影响因子 | 效果 |
|------|------|
| 关键剧情选择 | ±10-20 L/C偏向 |
| 战斗中杀敌 | 过量杀敌→C偏，克制→L偏向 |
| 特定角色存活/死亡 | 显著影响——如姐姐卡秋娅的存活是公主职业的解锁条件 |
| 民族好感度 | 游戏中有多个民族(瓦尔斯塔/加尔加斯坦/巴库拉姆等)——L/C选择影响各民族的信任值 |

**设计意图**：隐藏数值让玩家无法"游戏化"道德选择——你不能通过查看一个数字就知道"我偏C偏了多少"。你只能通过故事的走向来感受自己是什么样的人。

## 三、姐姐卡秋娅——路线选择的情感锚

卡秋娅（Catiua/Kachua）的存在是皇骑LNC系统最成功的叙事设计：

- 她是主角德尼姆（Denam）的姐姐——也是你的选择最直接的受害者/受益者
- **L路线**：她离开你——因为她无法接受你执行屠杀命令的行为
- **C路线**：她留在你身边——但你们一起被世界视为叛徒
- **只有特定路线她才能存活并解锁公主职业**——这是有意识地用"你在乎的人"来加重道德选择的重量

**跨游戏对比**：风花雪月的艾黛尔贾特与此有异曲同工之妙——你在路线选择中失去的那个级长，就是你在乎的那个人。但皇骑比风花雪月早24年。

## 四、命运之轮（WORLD Tarot）——路线跳跃系统

重生最大的创新是**WORLD系统**——允许玩家在通关后跳跃到任何"锚点(Anchor Point)"：

### 4.1 WORLD机制

| 功能 | 说明 |
|------|------|
| 锚点 | 游戏自动记录每个关键选择点 |
| 跳跃 | 玩家可跳回任意锚点——保留当前军队/装备/等级 |
| 目的 | 体验不同路线——不需要从头开始新游戏 |
| 限制 | 跳跃后该锚点之后的剧情进度被覆盖 |

### 4.2 与风花雪月NG+的对比

| 维度 | 皇骑 WORLD | 风花雪月 NG+ |
|------|------|------|
| 跳跃机制 | 到任意锚点（细粒度） | 完全重新开始（仅继承名声） |
| 保留内容 | 全部军队+装备+等级 | 圣人像+名声+可购买回等级 |
| 多周目效率 | 极高——跳过共通章节 | 中——需要重新玩共通12章 |
| 设计哲学 | "你不需要重复劳动来体验不同选择" | "每条路线都值得重新体验" |

WORLD系统让皇骑的LNC设计从"三选一"变成了"三个全都看"——与风花雪月的四条完整路线设计走向了同一目的地，但路径不同。

## 五、三路线的角色差异

| 路线 | 可加入独有角色 | 失去的角色 |
|------|------|------|
| **L (秩序)** | 兰斯洛特(白骑士)、奥兹玛(白骑士)、等共4名白骑士 | 姐姐(离开→可说服回归) |
| **C (混沌)** | 包括一些L线无法获得的角色 | 部分L线的角色无法获得 |
| **N (中立)** | 较少独有角色 | 两边都失去一些 |

**设计意图**：不同路线不仅影响故事——还影响你军队的构成。这在1995年是革命性的："你的道德选择决定了你能指挥哪些人"。

## 六、CODA——通关后内容

通关后解锁CODA（Chapter of the Dead Apocrypha），4个追加章节：
- 允许在通关状态下继续探索
- 需要特定路线条件才能解锁全部内容
- 利用WORLD系统在不通关之间切换以达成所有CODA
- 含最强装备和隐藏BOSS
