# 装备与道具经济 — 皇家骑士团：重生

> 游戏版本: Tactics Ogre: Reborn v1.0 (2022) | 数据来源: [A9VG攻略](https://bbs.a9vg.com/thread-8877464-1-1.html), [游侠网](https://gl.ali213.net/html/2022-11/955247_2.html), [NGA心得](https://ngabbs.com/read.php?tid=34425790)

## 一、装备槽与重量

### 1.1 装备界面

| 装备槽 | 内容 | 对WT影响 |
|------|------|:--:|
| 右手武器 | 剑/枪/斧/锤/弓/杖/乐器/火枪 | 重量加入WT |
| 左手武器/盾 | 盾牌/副手武器(二刀流) | 重量加入WT |
| 头盔 | 头防具 | 重量加入WT |
| 铠甲 | 身防具 | 重量加入WT |
| 手套/臂甲 | 手防具 | 重量加入WT |
| 鞋子/腿甲 | 脚防具 | 重量加入WT |
| 饰品 | 戒指/项链/特殊 | 部分有重量 |

**7个装备槽**——远多于风花雪月的3槽，装备策略深度更高。

### 1.2 重量与WT的经济学
每件装备的重量直接加入WT计算——这意味着：
- 穿戴全套重甲=最高防御但行动最慢
- 穿布衣=最快行动但容错低
- 寻找装备的最优组合=皇骑的核心养成乐趣

### 2.3 元素武器
武器可通过锻造附上元素属性——这是中期之后的核心追求：
- 火之剑+对冰系敌人伤害加成
- 元素附魔需要对应素材（精灵石/龙鳞等）
- 角色自身元素+武器元素=双加成（同元素暗加20%伤害）

## 三、锻造系统

皇骑的锻造系统是另类的装备升级机制：

| 锻造等级 | 可执行 |
|:--:|------|
| +1 | 提升基础属性(+10%) |
| +2~3 | 大幅提升(+20~30%额外攻击/防御) |
| 元素附魔 | 将元素属性附加到武器/防具 |
| 特殊锻造 | 部分装备有独特的锻造路线 |

锻造需要消耗素材和金币——素材来源包括战斗掉落、分解装备、商店购买。
