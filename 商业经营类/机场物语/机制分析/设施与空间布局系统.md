## 一、设施分类

### 1.1 运营设施

| 设施 | 建议数量 | 功能 |
|------|:--:|------|
| 控制塔 | 1 | 核心(多余的无效) |
| 值机柜台 | 5 | 旅客登机手续 |
| 安检口 | 3 | 安全筛查 |
| 入境检查 | 3 | 国际航班入境 |
| 登机口 | 5 | 匹配值机容量 |
| 行李提取 | 2 | 行李流 |
| 停机坪 | ~25 | 飞机停放 |
| 跑道 | 4-6 | 最少4条保证流畅 |

### 1.2 商业设施

| 类型 | 示例 | 功能 |
|------|------|------|
| 餐饮 | 小酒馆/咖啡厅/食品摊 | 旅客消费(主要收入) |
| 零售 | 书店/纪念品店 | 旅客消费 |
| 服务 | 美容院/SPA | 高附加值消费 |

### 1.3 舒适设施

| 设施 | 功能 |
|------|------|
| 长椅/沙发 | 旅客休息(机场大了走得累) |
| 绿植 | 安抚旅客情绪(机场本身是"无菌"环境) |
| 装饰 | 提升美观评分 |

## 二、设施兼容性系统（开罗特色）

| 加成组合 | 效果 |
|------|------|
| 美容院+美容SPA | 兼容——评分加成 |
| 厕所+神社 | 冲突——评分惩罚 |
| 其他组合 | 多种兼容/冲突关系(需摸索) |

兼容性是开罗系列的核心空间设计维度——不是简单的"覆盖范围"，而是**相邻设施的化学效应**。

## 三、布局策略

### 3.1 动线原则

| 原则 | 说明 |
|------|------|
| 商店放登机口路径上 | 旅客走必经之路→最大化消费 |
| 座椅分散在商店附近 | 旅客逛累了坐下→恢复体力继续逛 |
| 绿植均匀分布 | 覆盖全机场→持续安抚 |

### 3.2 "双排滑行道"技巧

在拥堵区域使用平行双排滑行道→防止飞机互相等待→提升跑道利用率。

### 3.3 限制

- **仅两个旋转方向**——社区普遍抱怨缺乏四向旋转
- **无第二层**——后期机场可能拥挤
- **可免费重新布置**——降低布局试错成本

## 四、设计特点分析

开罗的机场布局本质上是"购物中心设计"——机场本身的航空功能(跑道/登机口)是背景，核心玩法是**"如何让旅客经过尽可能多的商店"**。这与**机场物语**的核心定位一致：它是"以机场为场景的商业经营"，而非"航空模拟"。兼容性系统是开罗系列最具策略深度的空间设计——它要求玩家发现并记住哪些设施搭配最好(这部分知识跨周目继承)。
