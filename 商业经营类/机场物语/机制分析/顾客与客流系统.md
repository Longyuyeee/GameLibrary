## 一、旅客类型

| 旅客类型 | 来源 | 行为 | 重要性 |
|------|------|------|:--:|
| 普通旅客 | 日常客流 | 候机→逛商店→登机 | ★★★★★ (消费主力) |
| 航空公司访客 | 签约航司 | 前4位普通→第5位=市长 | ★★★★ (解锁合约) |
| 市长(Mayor) | 航空公司第5位访客 | 检查机场品质→满意=签约 | ★★★★★ (关键) |
| VIP/特殊角色 | 开罗经典彩蛋角色 | Kairobot等→特殊奖励 | ★★★ (NG+传承) |
| 小偷(Thief) | 随机出现 | 红色背包→需手动抓捕 | ★★ (安保解锁条件) |

## 二、满意度与粉丝等级

| 满意度要素 | 影响 |
|------|------|
| 商店多样性 | 旅客有地方花钱→满意度↑ |
| 候机舒适度 | 座椅/绿植/装饰→满意度↑ |
| 等待时间 | 安检/入境/值机瓶颈→不满 |
| 设施兼容性 | 美容院+美容SPA=加成；厕所+神社=冲突 |

粉丝等级(Fan Level)0→100——满100获勋章(跨周目继承)。

## 三、客流来源

| 来源 | 说明 |
|------|------|
| 日常自然客流 | 随机场声誉增长 |
| 航空公司合约 | 签约后定期航班带来稳定客流 |
| 自有航班 | 购买飞机→自定航线→额外客流 |
| 国际展会 | 短期大量外国游客涌入 |

## 四、小偷机制

| 要素 | 说明 |
|------|------|
| 识别 | 红色背包+单人+无行李+无航班 |
| 抓捕 | 手动点击→抓住3-4个后解锁安保室 |
| 安保室 | 全机场仅需1间——自动处理后续小偷 |

## 五、设计特点分析

市长访问机制是开罗独创的"合约解锁"方式——不是"点击签约"，而是"让市长作为旅客体验你的机场→满意了才签约"。这让"提升机场品质"有了具体的叙事目标。小偷系统是开罗游戏中罕见的手动互动元素——为纯经营增添了动作游戏式的趣味。与**双点医院**(病人=收入)和**过山车之星**(游客满意度多维模型)相比，开罗的旅客系统更简单但清晰——满意度→消费→收入，无复杂需求维度。
