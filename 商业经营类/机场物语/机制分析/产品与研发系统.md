## 一、"产品"=航班服务+商业体验

| 层次 | 内容 |
|------|------|
| 核心 | 航空运输服务(航班) |
| 附加 | 候机消费体验(商店+餐饮+服务) |
| 整体 | 机场品牌(全球排名) |

---

## 二、研究系统——灵感(Inspiration)

| 要素 | 说明 |
|------|------|
| 获取方式 | 建造"灵感设施"(研究型建筑) |
| 用途 | 解锁新飞机、提升载客量、改善舒适度 |
| 无金钱成本 | 灵感独立于金币——是第二资源 |
| 研究项目 | 更大飞机、更多座位、更高舒适度、新食物菜单 |

---

## 三、飞机系统

| 要素 | 说明 |
|------|------|
| 自有飞机 | 购买→建造机库→设定航班计划 |
| 航空公司合约 | 市长满意→签约→外国航司定期飞来 |
| 飞机升级 | 研究解锁更大/更舒适的机型 |
| 特殊飞机 | 气球(Balloon)——纯研究型飞机(12座/71舒适满级) |

---

## 四、航线扩展

| 阶段 | 内容 |
|:--:|------|
| 国内 | 初始——基础客流 |
| 国际 | 市长签约→解锁新航司和航线 |
| 全球 | 举办国际展会→提升全球排名→更多外国游客 |

---

## 五、设计特点分析

灵感系统是开罗对"研发"的独特诠释——不是花钱研究，而是**建造特定设施来产出研究点数**。这让空间规划("研究设施放哪里？")与技术进步绑定。飞机系统的核心是"从租借到自有"——初期依赖外部航司，后期自购飞机掌握时刻表主权。

与**Game Dev Tycoon**(技术点分配)和**双点医院**(研究部)相比，开罗的灵感系统更简单——但有"设施位置影响产出效率"的空间策略层。
