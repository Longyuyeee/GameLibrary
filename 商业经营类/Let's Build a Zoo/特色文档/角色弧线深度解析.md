# 角色弧线深度解析 — Let's Build a Zoo

> 游戏版本: Let's Build a Zoo v1.0+ | 2021
> 数据来源: [Escapist Magazine](https://www.escapistmagazine.com/lets-build-a-zoo-interview-james-barnard-springloaded/), [Game Rant](https://gamerant.com/lets-build-a-zoo-interview-james-barnard-zoo-ethics-inspirations/), [Fandom Wiki](https://letsbuildazoo.fandom.com)

## 一、"无主角"的设计分析

### 1.1 主角类型：空白主角 (Blank Avatar)

Let's Build a Zoo 属于**无定义主角**的游戏。玩家不扮演一个有名有姓、有背景故事、有性格的角色——你是一个**抽象的"动物园经营者"**。

这是商业经营品类的标准做法（开罗系列、双点医院、过山车之星均无定义主角），但在 Let's Build a Zoo 中，这个"空白"有一个特别的维度：**玩家的人格通过道德系统被"填入"空白之中**。

### 1.2 "空白"的设计意图

为什么设计师选择不定义主角？

1. **主角=玩家的道德镜像**：动物园经营者的"人格"不是预设的——它通过玩家每一次善良/邪恶选择被逐步定义。第一天你是一个空白经营者，第100天你"成为"了保育英雄或工业大亨——这个过程就是角色的"弧线"，只不过弧线的作者是玩家自己。
2. **道德系统需要"空白人格"才能运作**：如果主角有预设性格（如"热爱动物的善良女孩"），邪恶路线的选择就会与角色设定冲突。空白主角让道德选择成为"定义我是谁"而非"违背我是谁"。
3. **经营游戏的传统——但加了道德维度**：大多数经营游戏的空白主角是纯粹的功能性选择（降低叙事成本），Let's Build a Zoo 则在空白中加入了"可被道德选择定义"的维度——这让空白主角从"无角色"变成"待定义的角色"。

### 1.3 弧线阶段（由玩家行为决定）

| 路线 | 起点状态 | 转变节点 | 终点状态 |
|------|------|------|------|
| 善良路线 | 中立经营者 | 第一次选择捐赠/释放/高薪→认识到道德选择的"可见后果" | 保育英雄：风能+农场+实验室培养肉 |
| 邪恶路线 | 中立经营者 | 第一次选择黑市/压榨/污染→发现邪恶路线的"利润诱惑" | 工业大亨：偷电+工厂+皮草+手提包 |
| 混合/摇摆 | 中立经营者 | 在不同选择间反复→体验两种路线的建筑→最终倾向于一侧 | 有道德瑕疵的实用主义者 |

## 二、角色"属性"与能力设计

### 2.1 "无属性系统"的设计

Let's Build a Zoo **没有角色属性面板**——没有玩家角色的等级、技能、特质或能力值。这与培养模拟类（如火山的女儿有智力/魅力/体力等属性）或人生沙盒类（如CK3的角色属性面板）完全不同。

### 2.2 "无属性"的替代设计

虽然没有角色属性，但游戏通过**动物园的状态**间接定义了"经营者"的能力：

| "经营者能力" | 由什么衡量 | 如何提升 |
|------|------|------|
| 经营能力 | 动物园评分+日均收入 | 更好的围栏/动物/商店布局 |
| 动物学知识 | 已收集的物种数×变体数 | 育种+交易+CRISPR拼接 |
| 科技水平 | 科技树解锁进度 | 研究员+研究点数积累 |
| 道德立场 | 善良值/邪恶值 | 日常选择积累 |
| 审美能力 | 装饰评分 | 装饰物布局 |

这种设计让"角色成长"被**外化为动物园的成长**——玩家的成就感不来自"我的角色变强了"，而来自"我的动物园变得更繁荣/更美丽/更独特了"。

### 2.3 设计意图

将角色属性外化为动物园状态的设计有双重目的：
1. **经营游戏的核心是"场所"而非"人"**——玩家来玩动物园游戏是想建造动物园，不是想"养成一个动物园管理员角色"。将注意力集中在动物园而非角色上是对品类核心体验的尊重。
2. **道德值作为唯一的"角色属性"**：在所有这些"无属性"之中，道德值是一个独特的存在——它是唯一直接附着在"经营者"（而非动物园）上的属性。这说明设计师认为"道德立场"是经营者唯一值得被量化的内在特质。

## 三、角色"魅力"分析——无角色如何产生魅力？

### 3.1 "无角色游戏"的魅力来源

当游戏没有人类主角时，魅力从哪里来？

| 魅力来源 | 在 Let's Build a Zoo 中如何体现 |
|------|------|
| **动物的可爱** | 像素精灵的可爱画风——熊猫、企鹅、兔子等用简单像素传达萌感 |
| **创造的满足感** | 从一片空地到繁荣动物园——"这是我建的"的拥有感 |
| **收集的惊喜** | 发现新变异品种→创造独特杂交种→"开盲盒"式的期待与惊喜 |
| **道德叙事** | "我选择成为什么样的人"——道德选择让玩家的自我叙事成为魅力来源 |
| **幽默反差** | 像素可爱的画风×黑暗工厂（屠宰场/皮草厂）——巨大的视觉/主题反差制造幽默 |

### 3.2 记忆点设计

| # | 记忆点 | 为什么让人记住 |
|:--:|------|------|
| 1 | **第一次CRISPR惊喜** | 等待杂交后代的外观揭晓——不知道会长什么样→"开盲盒"的快感 |
| 2 | **从可爱到黑暗的切换** | 像素风动物园里建起屠宰场——这种"可爱外壳×黑暗内核"的反差是社交分享的热门内容 |
| 3 | **"我的独特杂交种"** | 30万+组合中属于自己的那只独特动物——它是由"我"的育种选择创造的，有情感所有权 |

### 3.3 跨游戏对比

| 维度 | Let's Build a Zoo | 动物园之星 | 双点医院 |
|------|:--:|:--:|:--:|
| 魅力来源 | 动物可爱+创造+收集+道德 | 动物真实+个体模拟+保育 | 幽默+广播+疾病设计 |
| 情感核心 | "我创造了这些生命" | "我照顾着这些真实的动物" | "我治好了这些搞笑的病人" |
| 社交传播点 | CRISPR杂交种 | 精美栖息地 | 搞笑疾病名称 |
| 无主角魅力策略 | 道德选择定义"我" | 动物个体成为"主角" | 广播员成为"主角" |

Let's Build a Zoo 的独特之处在于：**空白主角通过道德选择成为"有立场的经营者"**——这种"自己定义自己"的魅力策略在商业经营品类中极少见。

## 四、"关键角色"——无人类角色，动物是"角色"

### 4.1 动物作为"角色"的设计

游戏没有人类NPC角色（无员工个性、无访客姓名），但**动物就是游戏中的"角色"**：

| 动物角色的戏剧功能 | 如何体现 |
|------|------|
| 收集目标 | 每个变异品种都是"待邂逅的角色" |
| 情感依恋 | 玩家对自己育出的第一只稀有变体有情感所有权 |
| 故事载体 | CRISPR拼接——"两个物种的结合创造了一个新生命"——这就是故事 |
| 道德行动的承受者 | 动物被善待（释放/高品质食物）或被剥削（屠宰/皮草）——它们是玩家道德选择的承受者 |

### 4.2 动物的"戏剧功能"分类

| 动物类别 | 在"游戏叙事"中的角色 |
|------|------|
| 基础物种 | "入门角色"——常见、易获取 |
| 稀有变异品种 | "隐藏角色"——育种中的惊喜发现 |
| CRISPR杂交种 | "玩家创造的角色"——不存在于自然，由你的选择诞生 |
| 被释放的动物 | 善良路线的"被拯救者" |
| 被加工的动物 | 邪恶路线的"牺牲品" |

## 五、反派/对手设计——"反派"是你的另一个自己

### 5.1 无传统反派

游戏**没有外部反派**——没有竞争对手、没有敌对动物园、没有邪恶大亨。但这并不意味着没有对抗力量。

### 5.2 "内部的对抗"

游戏的"反派"是**内在的**——是道德路线选择中的"另一个自己"：

| 路线 | "反派"是谁 | 对抗方式 |
|------|------|------|
| 善良 → 邪恶 | 利润的诱惑、效率的便利（偷电比风电便宜、屠宰比释放赚钱） | 抵抗低成本高效率的诱惑 |
| 邪恶 → 善良 | 道德的谴责（抗议者、负面新闻） | 花钱摆平或无视 |

### 5.3 镜像关系

善良路线和邪恶路线互为镜像：
- 善良的风力发电机 ↔ 邪恶的偷电器
- 善良的农场+谷仓 ↔ 邪恶的工厂+屠宰场
- 善良的释放中心 ↔ 邪恶的处理厂
- 善良的不可思议实验室（培植肉）↔ 邪恶的屠宰场（真肉）

两组建筑的平行对应设计在说：**同样的资源（动物、土地、金钱）在不同道德选择下走向截然不同的用途**——"你"是唯一的变量。

## 六、角色关系网络——"经营者–动物–游客"三角

### 6.1 无人类关系网络

游戏没有人物之间的好感度/关系系统（这与其他经营游戏一致）。

### 6.2 "经营者–动物–游客"的三角关系

虽然无人类社交网络，但有一个隐性的三角关系：

```
       经营者
       ╱    ╲
      ╱      ╲
   动物 ←——→ 游客
```

| 关系边 | 动态 |
|------|------|
| 经营者→动物 | 引进、育种、拼接、喂食、医疗、释放（善）或 屠宰、剥削（恶） |
| 动物→游客 | 观赏→满意度↑、稀有度→吸引力↑ |
| 游客→经营者 | 购票→收入、满意度→口碑→更多客流 |
| 经营者→游客 | 定价、提供服务、满足需求 |

### 6.3 进程变化

- **初期**：经营者主导——主动引进动物、建设施、吸引游客
- **中期**：三角平衡——动物繁殖（自然增长）、游客口碑（自然传播）、经营者优化
- **后期**：CRISPR创造——经营者从"管理者"变为"创造者"，动物从"被引进"变为"被创造"

## 七、设计启示

### 7.1 对本品的参考价值

1. **"空白主角+道德选择=玩家定义的角色弧线"**：这是经营游戏中"无主角"的最高形式——不是懒于设计主角，而是**将主角的设计权交给玩家**。适用于想做"有意义的选择"但不想写线性剧情的经营游戏。
2. **动物=角色是动物园经营游戏的核心情感策略**：不需要为动物写对话或背景故事——变异品种的"稀有性"和杂交种的"独特性"本身就是角色的"个性"。
3. **内在对抗替代外部反派**：不需要设计一个"竞争对手动物园"——道德系统本身就是足够的对抗力量。"利润vs良知"的内部冲突比外部竞争更持久、更普遍。

### 7.2 跨游戏角色设计对比

| 游戏 | 角色设计策略 | 情感驱动力 |
|------|------|------|
| **Let's Build a Zoo** | 空白主角—由道德选择定义 | 道德自我实现+创造独特动物 |
| **动物园之星** | 无主角—但每个动物有名字/基因/个性 | 动物个体关怀 |
| **双点医院** | 无主角—广播员/病人承担"角色"功能 | 幽默+成就感 |
| **星露谷物语** | 有主角（自定义）+ NPC社交网络 | 社交关系+田园生活 |
| **开罗温泉物语** | 空白主角—纯功能性 | 经营效率最大化 |

Let's Build a Zoo 在角色设计上的独特地位是：**"空白主角"的极简形式下，通过道德系统给了玩家最大的角色定义空间**——这是在"无角色"和"强角色"（如星露谷）之间的独到中间路线。
