## 一、扩张阶段划分

### 1.1 阶段总览

| 阶段 | 动物园规模 | 核心活动 | 科技树进度 |
|------|------|------|:--:|
| **初期（起家）** | 1-3个围栏 | 基础动物+沙漠围栏+棉花糖店 | 1-20点 |
| **中期（发展）** | 4-8个围栏 | 多生物群落+育种+商店网络+农场/工厂 | 20-100点 |
| **后期（繁荣）** | 8-15个围栏 | CRISPR拼接+道德路线顶点+完整科技树 | 100-200点 |
| **末期（无限）** | 自有规划 | 全变体收集+全杂交组合+纯沙盒创造 | 科技树完成 |

### 1.2 各阶段关键解锁

| 阶段 | 关键解锁 | 经济影响 |
|------|------|------|
| 初期 | 沙漠围栏(1)、托儿所(5)、热带草原围栏(5) | 基础门票+首次育种收入 |
| 初期→中期 | 研究员+1(20)、减孕时间(8)、农场基础(10) | 研究加速+育种效率+农场新收入 |
| 中期 | 北极围栏(10)、山地围栏(10)、热带围栏(12)、森林围栏(12) | 6种围栏全覆盖→物种多样性最大化 |
| 中期→后期 | 回收中心(18/善良)、焚烧炉(18/邪恶)、CRISPR | 废物管理自动化+基因拼接开启 |
| 后期 | 无限CRISPR(35)、全道德建筑解锁 | 无限杂交组合+道德路线完全体 |
| 末期 | 广告牌(32)、双层巴士(30)、招聘中介(19) | 客流最大化+便利性补完 |

## 二、土地与空间扩张

### 2.1 土地购买

| 扩张方式 | 说明 |
|------|------|
| 相邻地块购买 | 逐步购买动物园周边地块 |
| 价格递增 | 后期地块价格显著高于前期 |
| 多岛扩展（DLC） | Dinosaur Island / Aquarium Odyssey 各自为独立可玩岛屿 |

### 2.2 空间利用率优化

| 优化策略 | 说明 |
|------|------|
| 地铁网络连接远区 | 减少游客/员工移动时间 |
| 员工工作区域划分 | 提高清洁和管理效率 |
| 围栏面积vs动物数量平衡 | 避免拥挤导致动物福利下降 |

## 三、科技树驱动的扩张节奏

### 3.1 科技树的扩张功能

科技树不仅解锁内容，更定义了扩张的节奏和方向：

| 科技树类别 | 扩张方向 | 节点示例 |
|------|------|------|
| 围栏解锁 | 横向扩张（新物种可能） | 沙漠→热带草原→北极→山地→热带→森林 |
| 育种升级 | 纵向扩张（变体深度） | 托儿所→超声波→减孕→扩容→CRISPR |
| 商店网络 | 横向扩张（收入来源） | 棉花糖→披萨→塔可→汉堡→礼品店 |
| 基础设施 | 效率扩张 | 仓库→地铁→巴士升级→招聘中介 |
| 道德路线 | 策略扩张 | 农场线（善良）/ 工厂线（邪恶） |

### 3.2 研究点数的最优分配

社区攻略推荐的早期分配优先级：

```
第一优先级：围栏解锁（新增物种→提升评分+新收入）
第二优先级：托儿所+育种（开启变体收集）
第三优先级：研究员+1（加速后续研究）
第四优先级：基础设施（风力/水塔/回收→能源自给）
第五优先级：商店网络（新增收入渠道）
```

## 四、道德路线扩张

### 4.1 双路线建筑解锁链

善良和邪恶路线的建筑都有**渐进式解锁**——不是一次全部可用：

**善良路线扩张链**（所需道德值递增）：
```
风力发电机(10善) → 农场基础(10善) → 水塔(20善) → 水泵升级(25善)
→ 回收中心(30善) → 释放中心(40善) → 谷仓(50善) → 鸡舍(55善)
→ 农场加工(75善) → 风车(80善) → 啤酒酿造(85善) → 不可思议实验室(100善)
```

**邪恶路线扩张链**（所需邪恶值递增）：
```
偷电器(5恶) → 处理厂(5恶) → 培根工厂(10恶) → 污水循环(20恶)
→ 胶水厂(25恶) → 焚烧炉(30恶) → 皮带厂(35恶) → 屠宰场(40恶)
→ 牛奶电池(50恶) → 蛋电池(60恶) → 翅膀厂(75恶) → 皮草厂(95恶) → 手提包厂(100恶)
```

### 4.2 路线切换的代价

- 积累对立道德值→抵消当前道德值（如5恶+6善=1善净剩余）
- 对立道德建筑无法同时运转
- 切换路线需要拆除所有对立建筑→重建周期和投资成本

## 六、设计特点分析

### 6.1 "科技树=扩张节奏"的设计

游戏将几乎所有扩张内容（围栏/商店/设施/育种）统一整合到同一棵科技树中——这简化了多维度决策（不需要同时管理"科技/土地/建筑"三个独立维度），但也让科技树成为"唯一瓶颈"（如果研究点数不够→所有扩张方向同时停滞）。

### 6.2 道德路线的"平行扩张"设计

善良和邪恶路线的建筑解锁链是平行的——都是10+座建筑、从初期到末期的渐进解锁。这种对称设计让两条路线都有"从起点到终点"的完整体验，而非一条主线+一条支线。

### 6.3 与同品类对比

| 维度 | Let's Build a Zoo | 过山车之星 | 双点医院 | Game Dev Tycoon |
|------|:--:|:--:|:--:|:--:|
| 扩张机制 | 科技树+土地购买 | 自由建造+研究 | 关卡制+星级解锁 | 时间阶段+研发 |
| 阶段划分 | 模糊（连续扩张） | 模糊（沙盒） | 清晰（每关结束） | 清晰（办公室规模） |
| 科技树形式 | 隐藏迷雾网格 | 研究列表 | 研究部 | 研发项目 |
| 道德平行扩张 | ✅（独有） | ❌ | ❌ | ❌ |

## 七、设计启示

1. **隐藏科技树的探索驱动**：迷雾覆盖未解锁节点→每次研究都像"翻牌"→维持科技树的惊喜感直至末期。适合需要持续新鲜感的经营游戏。
2. **道德平行扩张保证两条路线的完整体验**：不走"善良=减少内容量"的陷阱——两条路线各自有从初期到末期的完整建筑链和策略深度。
3. **科技树作为"唯一瓶颈"的利弊**：统一在一棵树中=简洁（利）；所有方向共享同一资源=缺乏多元策略节奏（弊，后期可能出现研究点过剩）。
