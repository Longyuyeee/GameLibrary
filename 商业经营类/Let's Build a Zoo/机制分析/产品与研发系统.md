# 产品与研发系统 — Let's Build a Zoo

## 一、"产品"的重新定义

在传统商业经营游戏中，"产品"是制作或采购的商品。在 Let's Build a Zoo 中，**"产品"是动物本身**——更准确地说，是"游客可以看到的动物品种及其变体"。

| 传统商业经营产品 | Let's Build a Zoo 的对应概念 |
|------|------|
| 产品种类 | 动物物种 |
| 产品品质等级 | 动物变异品种（10种/物种） |
| 产品研发 | 育种+CRISPR基因拼接 |
| 产品组合 | 围栏内动物搭配 |
| 产品生命周期 | 动物繁殖→成长→衰老→死亡 |
| 加工升级 | DNA拼接创造杂交物种（30万+组合） |

## 二、动物获取途径

### 2.1 引进（Import）

| 途径 | 说明 | 费用 |
|------|------|:--:|
| **全球动物园交易** | 与其他动物园进行动物交换/购买 | 中 |
| **动物保护站** | 收养被救助动物，变体标注"NEW" | 低 |
| **黑市交易** | 购买稀有/非法动物 | 高（-道德值） |

### 2.2 育种（Breeding）

| 育种方式 | 说明 |
|------|------|
| **托儿所育种 (Nursery)** | 人工配对一公一母，有几率发现新变种 |
| **自然繁殖** | 围栏内放置10+同种动物，自然产生后代 |

---

## 三、育种系统详解

### 3.1 托儿所机制

| 参数 | 说明 |
|------|------|
| **配对条件** | 一公一母，需有生育能力（不能太老或太小） |
| **发现几率** | 每次育种有一定几率发现新变种（初始约50%） |
| **育种经验** | 反复育种积累经验值，提升发现新变种的概率 |
| **怀孕时间** | 可研究缩短至1天（前提：10善良道德值） |
| **超声波预测** | 研究解锁后可在出生前预览后代外观，不满意可终止（无道德惩罚） |
| **托儿所扩容** | 研究后可增加育种室数量 |

### 3.2 变异品种

每种动物有**10种颜色/图案变体**（Variant）。收集全部10种变体即完成该物种的"基因组图谱"。

| 变体解锁方式 | 说明 |
|------|------|
| 育种发现 | 通过托儿所/自然繁殖随机发现 |
| 动物保护站 | 救助的动物可能携带新变体 |
| 动物园交易 | 从其他动物园获取已有变体 |

### 3.3 育种策略

| 策略 | 适合阶段 | 说明 |
|------|:--:|------|
| 集中育种 | 初期 | 少量物种×多对配对→快速解锁变体 |
| 自然繁殖 | 中期 | 围栏内放置10+只同种→被动收集变体 |
| 批量托儿所 | 后期 | 建造多个托儿所（社区推荐约30个）→大规模育种 |

## 四、DNA拼接系统（CRISPR Splicing）

### 4.1 核心机制——品类独有创新

CRISPR拼接是 Let's Build a Zoo **最具差异化的特色系统**——允许玩家将任意两种已"完全图谱"的动物物种融合创造杂交品种。

| 参数 | 数值 |
|------|:--:|
| 拼接条件 | 两种动物均完成10/10变体收集（基因组图谱完整） |
| 基础游戏组合数 | **300,000+** 种杂交可能 |
| 含DLC组合数 | **10,000,000+** 种杂交可能（含水生/恐龙） |
| 拼接结果 | 随机生成——外观融合+属性继承自父代双方 |
| CRISPR储存 | 储存所有已发现物种的DNA，无需动物当前在动物园中 |

### 4.2 拼接流程

```
1. 完成物种A的全部10种变体收集
2. 完成物种B的全部10种变体收集
3. 在CRISPR建筑中选择"A + B"
4. 游戏随机生成杂交后代（外观/属性为双方融合）
5. 杂交品种可继续与其他物种拼接（递归拼接）
```

### 4.3 杂交示例

| 杂交组合 | 产物名 | 视觉效果 |
|------|------|------|
| 长颈鹿 + 大象 | Giraffephant | 长颈鹿脖子+大象身体 |
| 熊猫 + 猫头鹰 | PandOwl | 熊猫脸+猫头鹰翅膀 |
| 猪 + 鸭子 | Piguck | 猪身+鸭嘴 |
| 鸡 + 鲸鱼 | Chickale (Aquarium DLC) | 鸡+鲸鱼特征 |
| 鳗鱼 + 鹅 | Eeloose (Aquarium DLC) | 鳗鱼+鹅 |
| 水豚 + 恐龙 | Capysaurus (Dino DLC) | 可爱+史前 |

### 4.4 克隆功能

CRISPR建筑还提供**克隆功能**——复制任何曾经拥有过的变体：
- 用途：当稀有变体动物衰老/绝育时保留其基因
- 成本：需要研究点数解锁

## 五、研究系统（Research / Tech Tree）

### 5.1 研究点数获取

| 来源 | 产出效率 |
|------|------|
| **研究员 (Researchers)** | 被动产出研究点数 |
| 额外研究员 | 研究解锁"+1 研究员"节点（费用20点） |
| **建议**：尽早雇佣第二名研究员以加速科技树推进 |

### 5.2 科技树结构

研究采用**隐藏网格**布局——玩家从中心（棉花糖店位置）出发，解锁相邻节点后逐步揭示周围可选节点。

| 类别 | 节点数（约） | 核心节点示例 |
|------|:--:|------|
| **围栏** | 6 | 沙漠(1)→热带草原(5)→北极(10)→山地(10)→热带(12)→森林(12) |
| **动物丰富化** | 18 | 小球(1)→木桩(7)→喷水器(7)→悬崖(9)→嗅味标记(19) |
| **动物庇护所** | 4 | 木质庇护所(5)→洞穴(9)→苔藓庇护所(9)→北极(11) |
| **商店** | 17 | 棉花糖(5)→披萨(10)→塔可(14)→汉堡(18)→礼品店(20) |
| **员工** | 5 | 吉祥物(15)→研究员+1(20)→招聘中介(19) |
| **育种** | 5 | 托儿所(5)→超声波(7)→减孕(8)→扩容(21)→无限CRISPR(35) |
| **善良能源** | 5 | 风力发电机(10)→水塔(12)→回收中心(18)→全桶回收(32) |
| **邪恶能源** | 4 | 偷电器(10)→污水循环(12)→焚烧炉(18)→焚烧效率(23) |
| **善良农场** | 8 | 农场基础(10)→谷仓(17)→鸡舍(20)→农场加工(20)→风车(21)→啤酒酿造(21) |
| **邪恶工厂** | 10 | 培根厂(17)→胶水厂(18)→屠宰场(18)→牛奶电池(20)→蛋电池(20)→翅膀厂(21)→皮草厂(23)→手提包厂(20) |
| **装饰/长椅/灯具/植物/厕所/地铁等** | 60+ | 各类美化节点 |

### 5.3 研究策略优先级

早期推荐研究顺序（社区攻略共识）：
```
沙漠围栏(1) → 爆米花摊(12) → 研究员+1(20) → 托儿所(5) → 减孕时间(8) → 水塔/风力(10-12)
```

## 六、设计特点分析

### 6.1 "动物=产品"的品类范式转移

传统商业经营游戏"研发=制作新商品"，Let's Build a Zoo 将研发重新定义为**"生命创造"**——育种和基因拼接。这让"产品研发"获得了情感维度（等待新生命诞生、收集稀有变体的成就感、创造出独特杂交种的惊喜），而不仅仅是"点击按钮→等待进度条"。

### 6.2 30万组合的"无限内容"设计

CRISPR拼接产生的30万+组合不是纯噱头——它是让游戏的"末期内容"无限延伸的机制。在完成所有科技树节点后，收集基因图谱和创造杂交品种成为驱动玩家继续游戏的长期目标。这是**"程序生成式"后期内容**的优秀案例（虽然组合本身是手动定义的，但数量级实现了类程序生成的体验）。

### 6.3 与同品类对比

| 维度 | Let's Build a Zoo | 动物园之星 | Game Dev Tycoon |
|------|:--:|:--:|:--:|
| "产品"是什么 | 动物（物种×变体×杂交） | 动物+栖息地 | 游戏项目 |
| 研发方式 | 育种+基因拼接+科技树 | 研究+保育项目 | 研发点数+员工组合 |
| 组合/变体深度 | 极深（30万+杂交组合） | 深（基因遗传4代） | 中（类型×平台×方向组合） |
| 情感维度 | 高（生命→惊喜→依恋） | 高（动物个体模拟） | 低（抽象项目） |

Let's Build a Zoo 在"产品变体数量"维度远超同品类——这是像素风低成本制作大量变体的优势（每个变体=调色板+局部sprite修改），3D游戏（如动物园之星）因建模成本不可能做到同等的变体数量级。

## 七、设计启示

1. **"生命创造=产品研发"是经营游戏中极其稀缺的设计模式**——将冰冷的"研发进度条"替换为有生命的"等待新生命→惊喜/失望→收集成就感"，值得同品类借鉴。
2. **程序生成式后期内容**：30万+的组合不是为了被穷尽，而是为了让"永远有新东西可以创造"的体验取代传统经营游戏的"科技树点完就无聊了"。
3. **隐藏科技树（迷雾网格）增加了探索感**：不知道下一个节点是什么→每次研究都是一次小惊喜。对比传统线性科技树（所有节点从一开始就可见），迷雾网格有天然的"再来一回合"驱动力。
