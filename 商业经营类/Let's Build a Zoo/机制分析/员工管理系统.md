## 一、员工类型与角色

### 1.1 员工种类

| 员工类型 | 职能 | 工作区域 | 关键属性 |
|------|------|------|------|
| **动物管理员 (Zoo Keeper)** | 喂养动物、清理围栏 | 分配到特定围栏/区域 | 效率（清理速度）、可靠性 |
| **清洁工 (Janitor)** | 清扫道路垃圾、清理垃圾桶 | 分配到特定区域 | 效率、覆盖范围 |
| **研究员 (Researcher)** | 产生研究点数推进科技树 | 研究室（被动工作） | 产出效率 |
| **店员 (Stall Employee)** | 运营商店/食品摊 | 分配到特定商店 | 服务速度、礼貌度 |
| **吉祥物 (Mascot)** | 提升游客满意度/娱乐效果 | 园区内巡游 | 娱乐效果、礼貌度 |
| **仓库管理员 (Storeman)** | 管理仓库物流 | 仓库 | 物流效率 |
| **农夫 (Farmer)** | 种植/收获作物 | 善良路线农场 | 耕作效率、最多10名初级农夫 |
| **动物处理员 (Undertaker)** | 处理死亡动物（邪恶路线） | 处理厂 | 处理效率 |

### 1.2 员工解锁条件

| 员工类型 | 解锁方式 |
|------|------|
| 动物管理员 / 清洁工 / 店员 | 初始可用 |
| 研究员 | 初始1名，科技树"研究员+1"解锁第2名（费用20） |
| 吉祥物 | 科技树"员工解锁-吉祥物"（费用15） |
| 农夫 | 科技树"农场"系列节点解锁 |
| 仓库管理员 | 科技树"仓库"节点解锁 |
| 动物处理员 | 科技树"处理厂-额外动物处理员" |

## 二、招聘与培养

### 2.1 招聘机制

| 招聘方式 | 说明 |
|------|------|
| **每日随机候选人** | 每天开始时有随机员工候选池 |
| **招聘中介** | 科技树8级解锁，付费即时招聘任意类型员工 |

### 2.2 员工属性

每个员工拥有多项"绿条"属性：

| 属性 | 影响 |
|------|------|
| **满意度 (Satisfaction)** | 影响工作表现和离职概率 |
| **礼貌度 (Politeness)** | 影响游客满意度（尤其店员/吉祥物） |
| **职业操守 (Work Ethics)** | 影响工作效率和怠工概率 |
| **效率 (Efficiency)** | 完成任务的速率 |

### 2.3 培养与成长

| 成长机制 | 说明 |
|------|------|
| **时间升级** | 员工随工作时间积累经验→自动升级 |
| **满意度驱动** | 高满意度加速升级，低满意度暂停成长 |
| **速度升级** | 升级后工作效率自动提升 |
| **无主动培训** | 游戏无培训系统，员工成长完全由时间和满意度驱动 |

## 三、薪资与福利

### 3.1 薪资系统

| 动作 | 效果 |
|------|------|
| **提高薪资** | 减缓满意度/礼貌度等绿条下降速度 |
| **发放奖金** | 直接提升满意度和礼貌度数值 |
| **提供遣散费** | 解雇时给遣散费→+道德值；不给→-道德值 |
| **市场薪资以上支付** | +道德值（善良路线受益） |
| **最低薪资支付** | -道德值（邪恶路线策略） |

### 3.2 薪资策略对比

| 策略 | 月成本 | 员工稳定性 | 道德值影响 | 适合路线 |
|------|:--:|:--:|:--:|------|
| 高薪+奖金 | 高 | 极高 | +善 | 善良路线/追求稳定 |
| 市场价 | 中 | 正常 | 无 | 平衡路线 |
| 最低薪资 | 低 | 低（易离职） | +恶 | 邪恶路线/初期省钱 |

## 四、排班与工作分配

### 4.1 分区管理 (Zoning)

| 管理工具 | 功能 |
|------|------|
| **工作区域** | 限定管理员/清洁工的服务范围 |
| **利用率检查** | 动物园入口→员工→查看利用率（目标：接近100%） |
| **员工门** | 控制员工可通行的路径 |

### 4.2 工作比例建议（社区共识）

| 比例 | 说明 |
|------|------|
| 1管理员 : 1-2小型围栏 | 小型围栏一个管理员可覆盖2个 |
| 1管理员 : 1大型围栏 | 大型围栏/多排泄物动物需单独分配 |
| 1清洁工 : 1个区域 | 根据区域内垃圾桶密度调整 |
| 2+研究员 | 尽早解锁第二名研究员以加速科技 |

### 4.3 效率优化技巧

| 技巧 | 效果 |
|------|------|
| 围栏内放满丰富化道具 | 动物排泄物集中在围栏门口，方便管理员清理 |
| 在围栏门附近设地铁站 | 管理员从仓库运输食物的时间大幅缩短 |
| 使用碰撞热力图 | 检查排泄物是否被装饰品阻挡 |

## 五、设计特点分析

### 5.1 "无主动培训"的极简成长模型

游戏有意省略了培训系统——员工的成长完全是被动的（时间×满意度）。这大幅降低了管理的微观操作（不需要决定"送谁去培训什么"），但也在后期缺少了员工培养的策略深度。对比**双点医院**的员工技能树（学习→晋升→转职），Let's Build a Zoo 的员工系统更接近**开罗系列**的"使用即升级"理念。

### 5.2 道德体系在员工管理中的渗透

员工管理是道德体系的重要载体——发高薪/遣散费=善良，压低薪资/零遣散=邪恶。与其他经营游戏将HR视为"成本最小化问题"不同，Let's Build a Zoo 将HR设计为**道德立场表达**：你怎么对待员工反映你想成为什么样的动物园经营者。

### 5.3 与同品类对比

| 维度 | Let's Build a Zoo | 双点医院 | 过山车之星 | 开罗温泉物语 |
|------|:--:|:--:|:--:|:--:|
| 员工类型数 | 8 | 5（医生/护士/助理/勤杂/研究） | 5+ | 4 |
| 培训系统 | 无（被动成长） | 有（技能树+培训室） | 有（培训升级） | 有（道具/等级） |
| 薪资策略深度 | 中（薪资+奖金+遣散+道德） | 低（固定薪资） | 中（薪资+培训费） | 低 |
| 分区管理 | 有（工作区域） | 有（房间分配） | 有（工作排班） | 无 |
| 道德嵌入HR | ★★★★★ | ★ | ★ | ★ |

Let's Build a Zoo 的员工系统在"道德嵌入HR"维度独树一帜——将薪资决策从单纯的数字优化转变为经营者立场的表达。

## 六、设计启示

1. **道德×HR的耦合设计**：将员工待遇与道德体系绑定，让"对待员工的方式"成为游戏叙事的一部分——适合任何想做"有意义的选择"的经营游戏参考。
2. **被动成长降低微观管理负担**：在像素风轻量经营游戏中，省略培训系统是合理的取舍——不让员工管理"抢走"育种/拼接/扩张的核心注意。
3. **分区系统的利用率是简洁的效能指标**：用百分比而非复杂的KPI面板来呈现员工效率——简洁但有效的设计。
