# 跨界与特色机制 — Let's Build a Zoo

## 一、纯经营定位

Let's Build a Zoo 是**纯商业经营游戏**——无战斗/冒险/探索等跨界元素。所有系统（育种、拼接、研究、建造）都在经营框架内运作。

但这并不意味着它缺乏独有机制创新——恰恰相反，游戏有四个维度的特色机制使其在商业经营品类中独树一帜。

---

## 二、核心特色机制

### 2.1 CRISPR 基因拼接系统

**品类内独有——30万+组合的"生命创造"系统。**

这是整个商业经营品类中**最独特的"产品研发"机制**：不制造物品，而是创造生命。CRISPR拼接将"研发新产品"从抽象按钮转变为有情感价值的行为——等待杂交后代的外观揭晓是一种"开盲盒"式的惊喜体验。

| 对比维度 | 传统经营游戏"研发" | Let's Build a Zoo "拼接" |
|------|------|------|
| 结果可预测性 | 完全确定 | 部分随机 |
| 情感参与 | 低（等待进度条） | 高（期待后代外观） |
| 组合规模 | 几十到几百 | 30万+ |
| 视觉反馈 | 图标/菜单 | 像素精灵实时展示 |
| 社交价值 | 低 | 高（分享独特杂交种） |

**设计起源**（开发者访谈）：James Barnard 表示灵感来自于"想让动物园有无限的内容"——CRISPR解决了经营游戏"科技树研究完就没新内容了"的经典问题。

### 2.2 "道德-利润"内生耦合系统

**品类内独有——道德不是附加分，而是完整的第二条发展轴。**

大多数经营游戏的道德系统是"加分项"（多几个成就/好评），Let's Build a Zoo 的道德系统是**完整的经济循环**：

```
善良经济循环：风力发电→农场种植→农场加工→高质量产品→环保声誉
邪恶经济循环：偷电→处理厂→工厂加工→廉价产品→工业声誉
```

每条路线都有自己完整的收入来源、成本结构和建筑解锁链。这确保了"善良路线不会因为收入低而不可玩"或"邪恶路线不会因为惩罚太重而不值得"。

**设计意图**（开发者访谈）：Barnard 认为真实的动物园本身就存在伦理张力——"动物园是保育机构还是娱乐场所？"——他将这个没有答案的问题转化为游戏中的两条路线，让玩家自己选择并承受后果。

### 2.3 "变异品种收集"作为收集驱动力

**品类内横向对比——在经营游戏中引入"宝可梦式"收集。**

每种动物10种变体×63种基础物种=630个收集目标。这与培育品类的收集驱动力同构（如**美少女梦工厂**的多结局收集、**星露谷物语**的博物馆全捐献），但在商业经营品类中是罕见的。

收集驱动的设计让 Let's Build a Zoo 与**动物园之星**（强调动物个体而非变体收集）形成了鲜明差异——动物园之星关心"每一只动物的基因细节"，Let's Build a Zoo 关心"你有多少种颜色变体"。

### 2.4 隐藏科技树的"探索"体验

**品类内少见——科技树不是可见列表，而是需要"揭开迷雾"的隐藏网格。**

玩家只能看到与已解锁节点相邻的未解锁节点——看不到整个科技树的布局。这让每次研究都带有"翻牌"的惊喜感：

- 不是"我需要解锁A节点→点击研究→完成"的工具性操作
- 而是"这个方向是什么？→研究→原来是个新商店/新装饰"的探索性发现

这借鉴了策略游戏（如文明系列）的科技树可视化，但加入了"隐藏迷雾"的Roguelite式发现机制。

## 三、特色机制协同效应

四大特色机制彼此之间有协同强化：

| 协同关系 | 说明 |
|------|------|
| CRISPR × 变异收集 | 完成10/10变体收集→解锁该物种CRISPR拼接→创造更多杂交种 |
| 道德 × 收集 | 善良路线（释放中心）vs 邪恶路线（黑市）→不同路线的收集策略 |
| 隐藏科技树 × CRISPR | 科技树中后才解锁CRISPR节点→拼接成为中后期新驱动力 |
| 道德 × 隐藏科技树 | 善良/邪恶专属建筑分散在科技树不同位置→路线选择影响研究方向 |

## 四、独有机制创新总结

| 机制 | 独有程度 | 参考价值 |
|------|:--:|------|
| CRISPR生命创造 | ★★★★★ 品类独一无二 | "无限变体"替代"内容耗尽"的终局设计 |
| 道德-利润内生循环 | ★★★★★ 品类独一无二 | 道德=第二条完整经济轴（非附加分） |
| 变体收集驱动 | ★★★★ 品类罕见 | "宝可梦式"收集×经营游戏 |
| 隐藏科技树 | ★★★ 品类少见 | 迷雾网格×经营研究的探索化 |

## 五、设计启示

1. **将"产品"从物品升维为"生命"**——让研发不再是无情的进度条，而是有情感价值的行为。这对任何以"创造"为核心的经营游戏都有启发。
2. **道德不应是装饰**——要么不做道德系统，要做就做成与核心经济循环深度耦合的第二条发展轴。半吊子的道德系统（只影响成就/评分）不如不做。
3. **收集驱动是经营游戏中最被低估的终局设计**——大多数经营游戏终局空洞（"变大变强"），而一个明确的收集清单为"继续玩下去"提供了可见的目标锚点。
4. **隐藏科技树=将"研究按钮"从工具变成内容**——每次研究不是因为"我需要这个"而是因为"我想知道这个方向有什么"——这种探索驱动的内在动机远比效率驱动的外在动机持久。
