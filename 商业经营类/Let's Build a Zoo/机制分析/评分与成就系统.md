## 一、动物园评分系统

### 1.1 评分维度与权重

| 维度 | 权重估算 | 提升方式 |
|------|:--:|------|
| **动物多样性** | ★★★★★ 最高 | 物种数量↑、变体收集率↑、杂交品种数量↑ |
| **动物福利** | ★★★★ 高 | 充足空间、食物、水源、丰富化道具、医疗保障 |
| **装饰与环境** | ★★★ 中 | 每个地块的装饰评分、照明覆盖率、清洁度 |
| **游客满意度** | ★★★ 中 | 需求满足率、商店/厕所/长椅覆盖率 |
| **设施完备度** | ★★ 低 | 商店种类、交通便利性 |

### 1.2 评分→效果映射

| 评分等级 | 效果 |
|:--:|------|
| ★☆☆☆☆ 低 | 基础客流量，门票不可涨价 |
| ★★☆☆☆ 中低 | 少量客流增长 |
| ★★★☆☆ 中等 | 显著客流增长，可适度提价 |
| ★★★★☆ 高 | 大量客流，富裕游客占比提升 |
| ★★★★★ 极高 | 客流最大化，门票可大幅提价 |

## 三、终局目标与"通关"

### 3.1 无官方通关定义

Let's Build a Zoo **无官方定义的"通关"条件**——游戏是开放式沙盒。以下是社区认知的"终局里程碑"：

| 里程碑 | 类型 | 说明 |
|------|:--:|------|
| 科技树100% | 内容完成 | 研究完所有约150+节点 |
| 全物种全变体 | 收集完成 | 63×10=630种变体（基础游戏） |
| 道德路线顶点 | 路线完成 | 善良100（不可思议实验室）/ 邪恶200 |
| 评分MAX | 数值极限 | 动物园评分达到最高 |
| 全杂交组合（理论） | 无限目标 | 30万+组合不可能穷尽——属于"永恒目标" |

### 3.2 沙盒模式

游戏提供专门的**沙盒模式**——无资金限制、所有内容解锁，纯粹用于创意建造和CRISPR拼接实验。

## 五、设计特点分析

### 5.1 模糊评分→清晰策略

游戏不显示精确的评分计算公式——而是通过热力图和游客行为反馈来间接传达评分逻辑。这避免了"玩家对着数字面板优化评分公式化"的Meta玩法，保持了建造的直觉性和趣味性。

### 5.2 "无通关"的开放式终局

开放式终局（open-ended）是商业经营品类的常见选择（过山车之星、开罗系列同样无硬通关），但 Let's Build a Zoo 的终局驱动力（收集全变体+全杂交组合探索）比同行更具体和可感知。大多数经营游戏的终局是"做大做强"的模糊感，而这里有明确的收集清单。

### 5.3 与同品类对比

| 维度 | Let's Build a Zoo | 开罗游戏开发物语 | 双点医院 | 过山车之星 |
|------|:--:|:--:|:--:|:--:|
| 评分系统 | 多维度综合评分 | 游戏评分公式 | 声誉+关卡星级 | Prestige评分 |
| 通关定义 | 无 | 20年结束 | 关卡3星 | 无 |
| 收集驱动 | ★★★★★（最强） | ★★★ | ★★ | ★★ |
| 成就量 | 中等（含DLC） | 少 | 多 | 多 |
| 终局可玩性 | 极高（CRISPR无限） | 中（20年限制） | 低（关卡完成） | 高（纯创意） |

## 六、设计启示

1. **"收集驱动终局"比"评分驱动终局"更具可持续性**：收集63×10个变体是可见的进度条，而"让评分更高"是无限的模糊感。前者给玩家清晰的目标感和完成感。
2. **热力图是评分系统最好的UX**：不用数字面板解释评分逻辑，而是用颜色直观展示——玩家看到"那个区域绿了=好"比看数字更容易形成直觉判断。
3. **无限组合的"无法穷尽"既是特色也是遗憾**：30万+组合太庞大以至于无法做"全部收集完成就跳成就"的设计——这在成就系统和收集驱动之间形成了张力。
