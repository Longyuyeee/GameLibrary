# 营销与竞争系统 — Let's Build a Zoo

> 游戏版本: Let's Build a Zoo v1.0+ (含 DLC) | Steam, 2021
> 数据来源: [Fandom Wiki](https://letsbuildazoo.fandom.com/wiki), [GamePretty Tech Tree](https://gamepretty.com/lets-build-a-zoo-technology-guide-all-tech-tree/)

## 一、营销手段

### 1.1 广告系统

游戏通过科技树解锁广告功能，属于后期营销手段：

| 广告类型 | 研究费用 | 效果 | 位置 |
|------|:--:|------|------|
| **富裕游客广告** | 23 | +25% 游客财富水平（更高消费力） | 8级左区域 |
| **广告牌 (Billboards)** | 32 | +5% 总客流量 | 8级右区域 |

### 1.2 隐性营销/口碑

| 机制 | 说明 |
|------|------|
| **口碑传播** | 满意游客→正面口碑→自然客流增长 |
| **道德新闻事件** | 善良/邪恶选择可能触发新闻→影响公众认知→客流变化 |
| **动物交换声誉** | 参与全球动物园交易网络→同行认可→更多交易机会 |

## 二、品牌与声誉

### 2.1 动物园评分 (Zoo Rating)

动物园评分是核心声誉指标：

| 影响维度 | 权重 | 说明 |
|------|:--:|------|
| 动物多样性 | ★★★★★ | 物种数量、变体丰富度、杂交品种 |
| 动物福利 | ★★★★ | 食物/水源/空间/丰富化/医疗 |
| 装饰与环境 | ★★★ | 装饰评分、照明、清洁度 |
| 游客服务 | ★★★ | 商店/厕所/长椅/交通便利性 |
| 道德声誉 | ★★ | 善良或邪恶方向的"知名度" |

### 2.2 评分→客流映射

| 动物园评分 | 客流效果 |
|:--:|------|
| 低评分 | 基础客流+缓慢增长 |
| 中等评分 | 显著客流增长 |
| 高评分 | 大量客流，可大幅提高门票价格 |
| 极高评分 | 高客流+富裕游客占比提升 |

## 三、竞争系统

### 3.1 竞争模型

Let's Build a Zoo **无直接的AI竞争对手**——这是与Game Dev Tycoon（有AI公司竞争评分）或开罗游戏开发物语（有行业排名）的显著差异。游戏选择的是纯PvE/自我挑战模式：

| 竞争维度 | 有无 | 说明 |
|------|:--:|------|
| AI竞争对手 | ❌ 无 | 无其他动物园与你竞争 |
| 行业排名 | ❌ 无 | 无排行榜系统 |
| 动物园交易网络 | ✅ 有 | 可与其他动物园交换/购买动物（非竞争性合作） |
| 自我挑战 | ✅ 有 | 收集全部变体/完成基因组图谱/达成高评分 |

### 3.2 无竞争的设计意图

游戏故意省略竞争系统有以下原因：
- **像素风轻松定位**：竞争会引入压力→违背"轻松建造可爱动物园"的核心体验
- **内在动机驱动**：收集全部变异品种/创造独特杂交种本身就是驱动力，不需要外部排名
- **道德体系已提供"张力"**：善良vs邪恶的选择已经提供了足够的决策紧张感

**跨游戏对比**：
- **Game Dev Tycoon**：有AI竞争+行业排名→驱动玩家优化
- **过山车之星**：无直接竞争，但Workshop展示他人作品形成间接竞争
- **开罗游戏开发物语**：有明确的行业排名和评分竞争
- **Let's Build a Zoo**：完全无竞争——这在商业经营品类中是少数派选择

## 四、媒体/评价系统

### 4.1 社会事件

游戏通过**道德选择触发新闻事件**而非传统的媒体评价：

| 事件类型 | 触发方式 | 影响 |
|------|------|------|
| 动物救助新闻 | 善良路线—捐赠/释放动物 | 正面声誉 |
| 黑市交易曝光 | 邪恶路线—频繁黑市交易 | 负面声誉/罚款风险 |
| 环保贡献报道 | 使用清洁能源/回收 | 正面声誉 |
| 工厂污染丑闻 | 焚烧垃圾/排污 | 负面声誉 |

### 4.2 抗议者系统

| 触发条件 | 应对方式 | 道德影响 |
|------|------|------|
| 动物福利极低 | 安抚诉求（善良） | +道德值 |
| 动物福利极低 | 贿赂驱散（邪恶） | -道德值 |

## 五、设计特点分析

### 5.1 "无竞争"的独特设计选择

在商业经营品类中，省略竞争系统是冒险但自洽的选择。Let's Build a Zoo 用"内在动机系统"（收集/创造/发现）替代了"外部竞争驱动"（打败对手/排名上升）——这与游戏的像素风轻松定位和"生命创造"核心体验一致。玩家不是在"比谁的动物园更好"，而是在"创造属于自己的独特动物王国"。

### 5.2 广告系统的极简处理

整个游戏只有2个广告节点（+25%富裕游客 / +5%客流量），且都在研究树后期。这是刻意的——游戏不想让"营销优化"成为玩家的关注点。核心循环是"建好动物园→自然吸引游客"，而非"打广告→吸引游客→用利润打更多广告"。

### 5.3 与同品类对比

| 维度 | Let's Build a Zoo | 开罗温泉物语 | 双点医院 | 过山车之星 |
|------|:--:|:--:|:--:|:--:|
| 竞争系统 | 无 | 无 | 无 | 无（有Workshop展示） |
| 广告系统 | 极简（2节点） | 有（杂志/电视等） | 有（营销部+活动） | 有（广告活动） |
| 声誉驱动 | 评分+道德 | 评分+客层 | 声誉+治愈率 | Prestige评分 |
| 评价来源 | 隐性的（客流变化） | 客人反馈 | 病人评价+奖项 | 游客满意度面板 |

## 六、设计启示

1. **"无竞争"对轻松经营游戏是有效策略**：不是所有经营游戏都需要"打败对手"。当核心体验是"创造"和"收集"时，竞争反而会干扰沉浸感。
2. **道德新闻替代了营销**：游戏用道德选择触发的社会事件来塑造公众认知——这是一种"叙事式口碑"替代"数值式营销"的有趣尝试。
3. **广告可作为后期"锦上添花"而非核心系统**：2个广告节点的极简设计说明——游戏相信"好产品自己会说话"，营销是放大镜而非发动机。
