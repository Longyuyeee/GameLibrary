## 一、游客行为模型

### 1.1 游客需求维度（5维）

| 需求维度 | 衰减方式 | 补充方式 | 耗尽后果 |
|------|------|------|------|
| **体力 (Energy)** | 行走持续消耗 | 坐在长椅上恢复 | 无法继续游览 |
| **饱腹度 (Satiation)** | 随时间缓慢下降 | 食品店/自动售货机购买食物 | 游客提前离园 |
| **口渴度 (Hydration)** | 随时间缓慢下降 | 饮品店/自动售货机购买饮料 | 游客提前离园 |
| **如厕需求 (Bathroom)** | 消费食物/饮料后加速下降 | 使用厕所 | 游客提前离园 |
| **满意度 (Happiness)** | 受环境/服务/动物影响 | 精美装饰+丰富动物+良好服务 | 差评/提前离园 |

### 1.2 游客完整行为链

```
巴士抵达 → 购票入园 → 沿路行走（消耗体力）
  → 观赏动物（提升满意度）→ 体力低→寻找长椅休息
  → 饥饿/口渴→寻找商店消费 → 如厕需求→寻找厕所
  → 满意/体力耗尽/需求未满足 → 离园
```

### 1.3 游客AI特点

- **自主寻路**：游客会主动寻找商店/厕所/长椅，无论它们位于园区的什么位置
- **信息感知**：游客"知道"已解锁设施的位置（不需要视线内可见）
- **体力=游览范围**：体力决定了游客能走多远→动物园的实际"可到达半径"由长椅密度决定

## 二、客流来源与增长

### 2.1 客流来源

| 来源 | 机制 | 说明 |
|------|------|------|
| **巴士 (Buses)** | 必须建造巴士站 | **无巴士=无游客**，这是游戏明确的硬性要求 |
| **巴士数量** | 建造更多巴士 | 直接提升每日客流量上限 |
| **巴士升级** | 研究解锁更大巴士 | 红巴士→白色加大巴士→双层巴士，容量递增 |

### 2.2 客流增长因素

| 因素 | 影响机制 | 幅度 |
|------|------|:--:|
| 动物园评分提升 | 高分→更多游客慕名而来 | 核心驱动力 |
| 广告/营销 | 研究解锁"广告牌"节点 | +5% 客流量 |
| 广告-富裕游客 | 研究解锁"更富裕游客"节点 | +25% 游客消费力 |
| 口碑传播 | 满意游客→自然增长 | 隐性的基础增长 |
| 新围栏/动物 | 每次新增吸引关注 | 短时爆发→回落稳定 |

### 2.3 游客分层

游戏未明确定义游客收入分层（不同于温泉物语的客层系统），但有隐含的消费力差异：

| 游客类型 | 消费行为 | 来源 |
|------|------|------|
| 普通游客 | 标准消费 | 基础客流 |
| 富裕游客 | 更高消费意愿和预算 | "广告-富裕游客"研究解锁后出现 |

## 三、游客满意度系统

### 3.1 满意度影响因素

| 因素 | 正面影响 | 负面影响 |
|------|------|------|
| **动物多样性** | 物种数量多、变异品种丰富 | 动物少、无新物种 |
| **动物福利** | 充足空间/食物/水源/丰富化 | 拥挤/饥饿/口渴/无聊 |
| **装饰评分** | 每个地块装饰值高 | 光秃秃的园区 |
| **照明** | 10盏路灯=100%照明 | 黑暗区域 |
| **清洁度** | 垃圾桶充足+清洁工高效 | 垃圾遍地、动物粪便未清理 |
| **便利设施** | 长椅/厕所/商店充足且分布合理 | 找不到厕所、无处休息 |
| **商店品质** | 高品质食材 | 低劣食物（邪恶路线可毒害游客） |

### 3.2 满意度的经济影响

| 满意度等级 | 游客行为 | 经济影响 |
|------|------|------|
| **高满意度** | 长时间停留、多次消费、正面口碑 | 门票+商店收入最大化 |
| **中等满意度** | 正常游览后离园 | 标准收入 |
| **低满意度** | 提前离园、减少消费 | 收入下降 |
| **极低满意度** | 抗议者出现（动物福利极差时） | 需花钱安抚或贿赂 |

## 四、客流规律

### 4.1 日循环

游戏以"天"为基本单位，每天经历完整的营业周期：
- **开园**：巴士运送游客到达
- **高峰时段**：游客集中到达期
- **运营期**：游客在园区内活动
- **闭园**：游客离开，进入结算

### 4.2 客流波动因素

| 因素 | 波动类型 |
|------|------|
| 新增围栏/动物 | 短期客流高峰 |
| 道德事件新闻 | 可能影响客流（正面或负面） |
| 季节/节日 | 游戏未设计明显的季节性波动 |
| 动物园评分变化 | 持续的长期影响 |

## 五、设计特点分析

### 5.1 "体力=游览半径"的空间经济设计

游客体力系统本质上是**空间经济的限制器**——体力不是为了让玩家关心"游客累不累"，而是为了限制游客的消费范围。这意味着：
- **长椅不是装饰**——是"解锁更多消费区域"的门槛
- **长椅位置=游客的折返点**——决定了他们能走到动物园第几区
- **更高效的长椅=更远的可到达距离=更多商店可以触达**

### 5.2 "无巴士=无游客"的硬性约束

将客流完全绑定到交通设施上是简洁但有力的设计——它给新手一个明确的第一步（建巴士站），同时给玩家完全可控的客流量上限。这比**过山车之星**（由公园声誉自然吸引游客）或**双点医院**（病人由声誉+可见疾病决定）更简单直接。

### 5.3 与同品类对比

| 维度 | Let's Build a Zoo | 双点医院 | 过山车之星 |
|------|:--:|:--:|:--:|
| 客流来源 | 巴士（硬性要求） | 声誉+疾病类型 | 声誉+价格+位置 |
| 游客需求 | 5维明确需求条 | 健康/幸福/舒适等 | 饥饿/口渴/恶心/如厕 |
| 游客AI复杂度 | 中（自主寻路但简单） | 中高（诊断→治疗2阶段） | 高（复杂情感模型） |
| 逛园时间 | 由体力决定 | 由治愈时间决定 | 由满意度动态决定 |

Let's Build a Zoo 的游客系统选择了一条"需求清晰、逻辑简单、但每个需求都有明确经营应对"的路线——适合像素轻量定位，不过度模拟。

## 六、设计启示

1. **"体力=游览范围"的设计范式**：将游客的物理移动能力量化为体力条，让基础设施（长椅）的布局成为空间经济的关键决策——这是将"现实约束→游戏机制"的优雅简化。
2. **硬性客流控制的简洁性**：通过"巴士=客流"的直接映射，避免了复杂声誉模型的UI负担。适合中小体量经营游戏参考。
3. **需求维度恰好5个**：不多不少——体力/饱腹/口渴/如厕/满意——每个都对应明确的经营应对（长椅/食品店/饮品店/厕所/环境优化），形成了完整而不过载的策略闭环。
