# 经济与定价系统 — Let's Build a Zoo

> 游戏版本: Let's Build a Zoo v1.0+ (含 Dinosaur Island DLC / Aquarium Odyssey DLC) | Steam, 2021

## 一、货币与收入体系

### 1.1 货币类型

游戏使用**单一货币（金钱/$）**，无代币或多货币体系。这简化了经营决策——所有经济行为统一由金钱计量。

### 1.2 收入来源及权重

| 收入来源 | 权重 | 说明 |
|------|:--:|------|
| **门票收入** | ★★★★★ 主力 | 最主要的稳定收入来源，价格由玩家自主设定 |
| **商店收入** | ★★★★ 重要 | 食品/饮料/礼品店，受客流量和商品品质影响 |
| **加工品销售收入** | ★★★ 中期补充 | 农场种植→加工→售卖（咖啡豆、啤酒等），需要研发投入 |
| **动物交易收入** | ★★ 辅助 | 向其他动物园出售/交换动物，非主要收入 |
| **邪恶路线工厂收入** | ★★★★ 邪恶路线主力 | 屠宰场/培根工厂/皮革厂等提供大量收入，但降低道德值 |
| **捐赠/任务奖励** | ★ 微量 | 特定事件中的一次性收入 |

### 1.3 门票定价机制

门票价格是核心经济杠杆：

| 定价策略 | 推荐区间 | 说明 |
|------|:--:|------|
| 最优区间 | 75%-90% 购买率 | 价格过高→大量游客拒买→实际收入下降 |
| 调整时机 | 每次新增围栏/动物后 | 动物园价值提升→可小幅涨价 |
| 查看工具 | 售票处→销售历史图表 | 实时显示拒买游客数量 |

**设计特点分析**：门票定价本质上是一个"价格弹性发现"的迷你游戏。游戏不直接告诉玩家最优价格，而是通过图表反馈让玩家自行摸索——这种"间接信息→自主决策"的设计比直接给最优解更有经营代入感。与**双点医院**（固定诊疗费+声誉修正）和**过山车之星**（可对单个设施单独定价）不同，Let's Build a Zoo 的门票是园区统一门票，简化了定价维度但强化了"整体园区价值决定票价"的逻辑。

### 1.4 免费入园模式

游戏提供"免费入园"复选框——取消门票收入，完全依赖园内消费。这是一种高风险高回报的策略变体，适用于商店网络极度发达的后期动物园。

## 二、成本结构

### 2.1 固定成本

| 成本类型 | 说明 |
|------|------|
| **员工薪资** | 所有员工的持续性工资支出，可调节薪资水平影响满意度 |
| **围栏维护费** | 每种围栏类型的日常维护成本 |
| **设施维护** | 商店、厕所、长椅等公共设施的维护 |
| **动物饲养费** | 食物成本，取决于动物数量/类型和饲料品质选择 |

### 2.2 可变成本

| 成本类型 | 说明 |
|------|------|
| **新建/扩张费用** | 购买土地、建造新围栏、铺设道路 |
| **研究投入** | 每个科技树节点需要研究点数（由研究员产出） |
| **动物采购费** | 从全球动物园引进新动物或从黑市购买 |
| **商店原材料** | 食品店食材、礼品店商品补货 |
| **突发事件支出** | 罚款、贿赂、捐赠等道德选择相关费用 |

### 2.3 成本控制策略

- **饲料品质选择**：高品质饲料（+道德值、+动物健康）vs 廉价饲料（+利润、-道德值）
- **薪资调节**：高薪提升员工效率/满意度，低薪引发离职/怠工
- **能源选择**：风力发电（前期投入高/长期无燃料费）vs 偷电（0成本但-道德值）

## 三、利润模型

### 3.1 利润率分析

| 收入类型 | 毛利率估算 | 说明 |
|------|:--:|------|
| 门票 | ~95% | 几乎零边际成本，固定维护费分摊后利润极高 |
| 商店（普通品质） | ~40-60% | 食材成本+员工工资 |
| 商店（低品质/邪恶） | ~70-85% | 廉价食材→高利润，但可能毒害游客 |
| 农场加工品 | ~60-80% | 种子成本低，加工后价值翻倍（如咖啡豆→咖啡） |
| 邪恶工厂产品 | ~80-90% | 原材料来自动物园自身动物，边际成本极低 |

### 3.2 投资回报周期

| 投资类型 | 预计回收周期 | 说明 |
|------|:--:|------|
| 新围栏+动物 | 5-10天 | 提升门票价值→吸引更多游客→门票+商店双收入 |
| 商店 | 3-7天 | 直接销售收入 |
| 研究投入 | 间接回报 | 解锁高利润建筑/作物/效率提升 |
| 装饰/美化 | 间接回报 | 提升游客满意度和停留时间 |

### 3.3 金钱Sinks（防止资金过度积累的设计）

| Sink类型 | 说明 |
|------|------|
| **土地扩张** | 后期地块价格递增 |
| **高级研究** | 顶级科技节点研究点需求高（如无限CRISPR拼接 35点） |
| **快速招聘** | 招聘中介（8级研究解锁）—即时招聘但费用高 |
| **动物引进** | 稀有动物/变异品种的引进费用 |
| **捐赠选项** | 道德事件中捐款（如森林火灾动物救助 $1000） |

## 四、道德体系的经济耦合

游戏最独特的经济设计是**道德体系与利润的直接关联**：

| 道德路径 | 收入特点 | 成本特点 |
|------|------|------|
| **善良路线** | 稳定但增长慢（释放动物无收入、高品质饲料成本高） | 能源环保（风电零燃料）、废物回收（变废为宝） |
| **邪恶路线** | 爆发性强（工厂加工动物→高利润产品） | 排污需付费、偷电有风险、可能被罚款 |

**设计意图分析**：这是对现实动物园伦理问题的游戏化映射。善良路线模拟"保育导向动物园"的经济模型（门票+捐赠+教育），邪恶路线模拟"商业化/工业化动物利用"的经济模型（加工品+成本压缩）。两条路线都"可行"且都有完整的经济循环设计——这避免了"善良=难/邪恶=简单"的二元简化，让道德选择成为经营策略的一部分而非道德说教。

**跨游戏对比**：与**双点医院**（无道德维度）和**动物园之星**（保育点数作为独立货币）不同，Let's Build a Zoo 将道德直接嵌入经营系统的每个环节（饲料/能源/废物/产品），形成"道德=经营策略选择"而非"道德=额外加分项"的设计。这在商业经营品类中极为罕见——大多数经营游戏将道德边缘化为锦上添花的事件选项，而这里将道德设为与科技树平行的第二发展轴。

---

## 五、设计启示

1. **简化货币体系降低认知负荷**：单一货币+门票统一定价，让玩家专注于"园区整体价值提升→门票涨价"的正循环，而非纠结于每项服务的个别定价。这适合像素风轻量经营游戏的定位。
2. **道德与经济的内生耦合**：道德不仅是"好人/坏人"标签，而是两条平行的经济循环——各自有完整的收入来源和成本结构。这种设计值得任何想做"选择有意义"的经营游戏参考。
3. **"价格弹性发现"是隐形的可玩性**：不直接告诉玩家最优价格，而是通过数据反馈让玩家自己摸索——让定价本身成为一个待解决的经营谜题。
