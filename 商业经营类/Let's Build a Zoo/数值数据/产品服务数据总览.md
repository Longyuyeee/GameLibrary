## 二、育种系统数据

### 2.1 育种参数

| 参数 | 数值/说明 |
|------|------|
| 托儿所配对容量 | 初始2对 |
| 育种发现新变体概率 | 初始约50%，随育种经验提升 |
| 怀孕周期（初始） | 多天（具体天数待补充） |
| 怀孕周期（研究后） | 1天（研究"减少怀孕时间"+10善） |
| 托儿所扩容上限 | 可研究增加额外育种室 |
| 自然繁殖条件 | 围栏内≥1雄性+≥1雌性同物种 |

### 2.2 变体收集里程碑

| 收集进度 | CRISPR解锁状态 |
|:--:|------|
| 0-9/10 变体 | 该物种不可用于拼接 |
| 10/10（基因组完整） | 该物种可用于CRISPR拼接 |

## 三、CRISPR拼接数据

### 3.1 拼接条件与限制

| 参数 | 数值/说明 |
|------|------|
| 前提条件 | 需建造CRISPR建筑（剧情触发） |
| 拼接条件 | 两种基础物种均完成10/10变体收集 |
| 每次拼接DNA消耗 | 消耗父代双方的DNA样本 |
| 结果随机性 | 外观融合+属性继承为随机组合 |
| 无限拼接解锁 | 研究节点35点（后期） |
| 克隆功能 | 复制任何曾经拥有的变体 |
