## 四、经营节奏数据

### 4.1 日常节奏

| 时段 | 活动 | 玩家操作 |
|------|------|------|
| 开园前 | 查看报表、调整价格 | 策略规划 |
| 早高峰 | 游客集中到达 | 观察客流 |
| 运营中 | 游客活动 | 建造/育种/扩张 |
| 闭园 | 游客离开 | 查看收入统计 |
| 结算 | 日报生成 | 评估表现→规划次日 |

### 4.2 建设→反馈周期

| 行动 | 反馈延迟 | 说明 |
|------|:--:|------|
| 新建商店 | 次日 | 次日即可看到收入贡献 |
| 新建围栏+动物 | 次日 | 次日即可吸引更多游客 |
| 门票调价 | 即时生效+次日反馈 | 当天影响购买率，次日统计收入 |
| 育种（怀孕） | 1天（研究后） | 从配对到后代出生 |
| 研究完成 | 积累点数当天完成 | 点数达标即时解锁 |
| 道德事件 | 即时选择→延迟后果 | 后果可能在数天后显现 |

### 4.3 节奏曲线（定性）

```
紧张度
  │
3 │               ╭──道德事件（随机打断）
  │              ╱
2 │  ╭─扩建──╮  ╱  ╭─CRISPR惊喜─╮
  │ ╱        ╲╱  ╱              ╲
1 │╱  日常运营   ╲╱   日常运营     ╲___
  │
0 └──────────────────────────────→ 游戏天数
   初期      中期      后期      末期
```

游戏整体是**低紧张度的缓慢上升曲线**——没有Hard deadline或危机驱动，压力来自玩家自设的收集/扩张目标。
