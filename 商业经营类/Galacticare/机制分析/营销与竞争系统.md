## 一、声誉系统

### 1.1 医院评分 (Hospital Rating)

医院评分采用**5星制(1-5★)**，是核心声誉指标：

| 评分维度 | 影响因子 |
|------|------|
| **治愈率** | 成功治疗的患者比例 |
| **患者满意度** | 等待时间+环境+治疗效果+物种需求满足 |
| **死亡数** | 死亡患者降低评分（挑战模式下过多死亡→失败） |
| **设施品质** | 房间升级等级+设备质量+装饰美观度 |
| **服务效率** | 从到达到出院的平均流程时间 |

### 1.2 评分→解锁关联

| 评分等级 | 效果 |
|:--:|------|
| ★★ | 基础患者流 |
| ★★★ | 新物种患者解锁、Baz商人更多商品 |
| ★★★★ | 高流量、高级顾问可能加入 |
| ★★★★★ | 最高流量、全部功能解锁、章节高评价 |

## 二、竞争系统

### 2.1 无AI竞争

Galacticare **无直接的AI竞争对手医院**——这与双点医院（无竞争）一致。挑战来自**内在的经营目标**（关卡目标+评分追求）而非外部竞争。

### 2.2 挑战模式的"竞争感"

挑战模式(Challenge Mode)通过环境压力替代竞争：
- 突变疾病→需要快速适应新治疗方案（"技术竞争"）
- 更频繁灾害→更高运营压力（"生存竞争"）
- 更严苛经济→资源管理压力（"效率竞争"）

## 三、Baz商人——特殊的"市场"机制

### 3.1 Baz商人简介

Baz是一只**巨大的宇宙"鲸鱼"商人**，在太空中游荡，是医院的特殊资源来源。

| Baz特性 | 说明 |
|------|------|
| 外表 | 巨大的宇宙生物（像鲸鱼/利维坦） |
| 功能 | 出售稀有设备、道具、装饰 |
| 出现频率 | 定期造访（具体间隔待补充） |
| 商品轮换 | 每次造访可能带来不同商品 |
| 免费赠品 | 偶尔提供免费样品 |

### 3.2 Baz的经济角色

Baz是经济系统中的一个特殊"供应商"而非"竞争者"——他提供市场上买不到的商品，是Craftech制造的补充。这类似于**动物森友会**的随机商人角色，而非**Game Dev Tycoon**中的竞争AI。

## 四、章节/关卡目标系统

### 4.1 11章战役结构

| 章节 | 场景设定 | 核心挑战 |
|------|------|------|
| 各章 | 太空站/音乐节/监狱船/农场殖民地/异次元等 | 不同场景有不同患者类型+空间约束 |

### 4.2 关卡目标类型

| 目标类型 | 示例 |
|------|------|
| 治愈数量 | 在X天内治愈Y名患者 |
| 评分门槛 | 达成N★医院评分 |
| 财务目标 | 累计收入达到X信用点 |
| 特殊事件 | 应对特定灾害/突发事件 |
| 研究解锁 | 研究完成X个项目 |

## 五、设计特点分析

### 5.1 "无竞争=专注内在优化"

省略竞争系统是医院模拟品类的共识——双点医院、双点校园均无AI竞争。这是因为"治愈疾病"本身就是足够有张力的目标——你不需要"比另一家医院更好"，只需要"把这家医院运营好"。

### 5.2 "Baz=温馨的经营-探索交织点"

Baz作为友好的太空商人，在设计上起到了打破"医院围墙"的作用——他让玩家意识到"外面还有更大的宇宙"，同时提供了随机性的商品惊喜。这比纯粹的菜单式商店更有世界构建价值。

### 5.3 与同品类对比

| 维度 | Galacticare | 双点医院 | 双点博物馆 | 开罗温泉物语 |
|------|:--:|:--:|:--:|:--:|
| 竞争系统 | 无 | 无 | 无 | 无 |
| 商人/市场 | ✅ Baz太空鲸鱼 | ❌ | ✅ 探险市场 | ❌ |
| 评分制 | 5★ | 3★/关 | Buzz+Knowledge | 评分+排名 |
| 关卡制 | 11章战役 | 多关 | 多关 | 无限+年度评分 |

## 六、设计启示

1. **太空商人(Baz)是打破封闭经营循环的有效设计**——让玩家感知到"外部世界"的存在，而不仅是封闭的医院围墙。这对任何"室内经营"型游戏都有参考价值。
2. **关卡目标系统提供清晰的成就感路径**——11章战役让玩家有"完成度"的可见进度。纯沙盒经营游戏可以借鉴"目标可选"模式。
3. **无竞争=品类共识而非缺陷**——医院经营中的"治愈"本身就有足够的叙事张力，不需要外加竞争。
