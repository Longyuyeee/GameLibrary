## 一、时间结构

### 1.1 基本时间单位

| 时间维度 | 说明 |
|------|------|
| 基本节奏 | 实时进行——非回合制 |
| 关卡时间 | 每章有独立的时间框架（非无限） |
| 游戏速度 | 可暂停、可加速 |
| 患者流 | 持续涌入——无昼夜差别 |

### 1.2 章节制的时间框架

Galacticare是**关卡制**游戏——11章战役，每章有独立的时间预算和目标期限：

| 时间约束 | 说明 |
|------|------|
| 关卡时间 | 多数关卡有时间期限（天/月数） |
| 目标DDL | 达到X治愈数/评分/收入必须在截止前完成 |
| 沙盒模式 | 无时间限制——自由建造 |

## 二、经营节奏

### 2.1 关卡内节奏曲线

```
每章节奏：
  开局(压力低) ──→ 患者涌入(压力↑) ──→ 建造应对(压力↓)
  ──→ 新疾病出现(压力↑) ──→ 研究解锁(压力↓)
  ──→ 灾害打断(压力↑↑) ──→ 恢复重建(压力↓)
  ──→ 终局冲刺(压力最高) ──→ 关卡完成(压力释放)
```

### 2.2 高峰期设计

| 高峰类型 | 原因 | 应对策略 |
|------|------|------|
| 新疾病爆发 | 关卡触发新型疾病批量出现 | 快速建造对应治疗室 |
| 灾害连锁 | 虫群→设备损坏→患者堆积→死亡风险 | Medibot预先部署 |
| 终局冲刺 | 关卡目标DDL逼近 | 暂停→大规模扩建→恢复 |
| 急诊波次 | 特定事件触发大量患者集中到达 | 预留浮动医生+全息医生补位 |

## 三、压力系统

### 3.1 压力来源

| 压力源 | 强度 | 频率 | 说明 |
|------|:--:|:--:|------|
| 患者堆积 | ★★★★ | 持续 | 诊断/治疗瓶颈→等待队列增长→健康下降→死亡风险 |
| 疾病突变 | ★★★ (挑战模式) | 条件触发 | 已知疾病变异→需要新治疗方案 |
| 虫群入侵 | ★★★ | 间歇 | 破坏设备→手动消灭→需维修 |
| 陨石撞击 | ★★★★ | 罕见 | 严重破坏+可能的伤亡 |
| 财务压力 | ★★☆ | 持续 | 初期紧张、中后期财务自由 |
| 时间DDL | ★★★ | 关卡末期 | 目标未达成→关卡失败 |
| 死亡风险 | ★★★★ | 持续 | 过多死亡→评分下降→挑战模式失败 |

### 3.2 失败条件

| 模式 | 失败条件 |
|------|------|
| 战役模式 | 关卡目标未在期限内完成 |
| 挑战模式 | "过多死亡"——累计死亡超阈值 |
| 沙盒模式 | 无失败条件 |

## 四、灾害系统与时间

### 4.1 灾害频率

| 灾害 | 频率(估算) | 破坏程度 |
|------|:--:|:--:|
| 虫群入侵 | 中（每关数次） | 轻-中 |
| 陨石撞击 | 低（每关0-2次） | 重 |
| 外星病毒泄漏 | 低（特定关卡/条件触发） | 中-重 |

### 4.2 灾害的时间策略意义

灾害的设计目的不是"惩罚玩家"而是**打破单纯的扩张节奏**——在建造→收入→建造的无脑循环中插入"需要立即响应"的事件，迫使玩家在"继续扩建"和"紧急修复"之间做即时决策。

## 五、设计特点分析

### 5.1 "关卡制=受控的节奏曲线"

11章战役的结构让设计师可以精确控制每一章的节奏——什么时候引入新疾病、什么时候触发灾害、什么时候给玩家喘息空间。这与沙盒经营游戏（过山车之星）的"完全由玩家决定节奏"形成了鲜明对比。

关卡制的优势：**有设计好的高潮**——每个章节末期都是自然的紧张峰值（DDL逼近+患者涌入）。
关卡制的代价：**重玩时节奏完全可预测**——第二次打同一关就没有了"惊喜"。

### 5.2 灾害是"反自动化"设计

在自动化程度越来越高的经营游戏中，灾害系统是一种**反自动化**设计——它迫使玩家从"宏观规划"切换到"微观应急响应"，打破经营的惯性。虫群入侵需要手动点击消灭——这不是技术限制，而是设计上刻意保留了"手动"操作以维持玩家的即时参与感。

### 5.3 与同品类对比

| 维度 | Galacticare | 双点医院 | 冰汽时代 |
|------|:--:|:--:|:--:|
| 时间制 | 关卡制+实时 | 关卡制+实时 | 实时+DDL |
| 压力类型 | 患者+灾害+DDL | 患者+流行病 | 温度+资源+希望 |
| 灾害系统 | 虫群+陨石+病毒 | 地震+流行病 | 暴风雪+降温 |
| 失败条件 | 目标未完成/过多死亡 | 评分过低 | 城市被冰冻 |
| 压力曲线 | 中高（关卡末期高） | 中 | 极高（全程） |

## 六、设计启示

1. **关卡制经营游戏的节奏控制权在设计师手中**——可以通过关卡设计精确调控压力曲线，适合想做"有故事/有章节"的经营游戏。
2. **灾害=反自动化设计**：在运营自动化程度高的游戏中，保留一些"必须手动响应"的事件来维持玩家的实时参与感。
3. **挑战模式=经营游戏的"硬核出口"**：战役模式服务休闲玩家，挑战模式服务硬核玩家——双模式覆盖不同受众。
