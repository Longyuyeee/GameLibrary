## 一、员工类型总览

### 1.1 员工角色

| 员工类型 | 职能 | 关键属性 | 工作区域 |
|------|------|------|------|
| **医生 (Doctor)** | 诊断+治疗 | 技能等级(1-3)、物种特质、个人怪癖 | 分配到特定房间 |
| **顾问 (Consultant)** | 特殊高级角色 | 完整技能树、独特外观和性格 | 可跨多个房间发挥作用 |
| **研究员 (Researcher)** | 推进研究项目 | 研究效率 | 研究室 |
| **医疗机器人 (Medibot)** | 维护、清洁、尸体处理 | 效率、可靠性 | 全院自动巡逻 |
| **勤杂工 (Janitor)** | 清洁地面、处理垃圾 | 清洁效率 | 全院/分配区域 |
| **接待员 (Receptionist)** | 接待台登记分配 | 服务速度 | 接待台 |

### 1.2 顾问系统（Consultant System）— 核心特色

顾问是Galacticare最独特的员工系统设计：

| 顾问特性 | 说明 |
|------|------|
| **独特性** | 每个顾问有独特的姓名、外观、个性、配音 |
| **技能树** | 完整的技能树——随游戏进程解锁新能力 |
| **跨关卡持续** | 顾问在整个战役中跟随玩家（不随关卡重置） |
| **情感投资** | 有性格、有台词——是"角色"而非"工具" |

**已知顾问示例**：

| 顾问 | 定位 | 特点 |
|------|------|------|
| DJ顾问 | 士气/娱乐型 | 通过音乐提升医院氛围 |
| 僧侣顾问 | 精神/安抚型 | 帮助患者和员工保持冷静 |
| 蔬菜农夫顾问 | 后勤/补给型 | 提供医院食材和资源 |
| 其他 | 多种类型 | 待补充 |

## 二、医生系统

### 2.1 招聘与雇佣

| 维度 | 说明 |
|------|------|
| 招聘方式 | 从候选人名单中挑选雇佣 |
| 技能等级 | Level 1 → Level 2 → Level 3 |
| 物种身份 | 雇佣的医生属于7物种之一→继承该物种的特质 |
| 个人怪癖 | 每个医生有随机怪癖——可能是正面或负面 |

### 2.2 医生怪癖(Quirks)

| 怪癖类型 | 示例 | 影响 |
|------|------|------|
| 负面 | Litterbug（随手扔垃圾） | 增加清洁工作量 |
| 负面 | Sadist（施虐倾向） | 治疗时患者满意度下降 |
| 负面 | 频繁如厕 | 离岗时间长 |
| 中性 | 特定食物偏好 | 影响休息室满意度 |
| 正面 | 工作狂 | 加班效率提升 |

### 2.3 技能培训

| 培训方式 | 说明 |
|------|------|
| 培训室 (Training Room) | 建造培训室→医生在室内学习→提升技能等级 |
| 挑战模式限制 | Lv3医生不可直接雇佣——必须通过培训晋升 |
| 顾问技能树 | 顾问通过使用经验解锁技能节点 |

## 三、员工分配与效率

### 3.1 房间分配

| 策略 | 效果 |
|------|------|
| 专职医生 | 分配特定医生到特定房间→减少响应延迟 |
| 浮动医生 | 未分配医生自动填补空缺 |
| 顾问部署 | 根据顾问技能决定放置位置 |

### 3.2 全息医生(Holographic Doctor)

游戏提供全息医生作为补充劳动力：

| 特点 | 说明 |
|------|------|
| 无需休息 | 24/7在岗 |
| 无需薪资 | 但需要设备和能源 |
| 有限技能 | 不如高级人类/外星医生 |
| 策略用途 | 填补夜班空缺/急诊高峰 |

### 3.3 员工休息与恢复

| 设施 | 功能 |
|------|------|
| **Staff Lounge（员工休息室）** | 医生休息、恢复体力、社交 |
| 休息室配置 | 家具、装饰、娱乐设施 |
| 未休息惩罚 | 过度疲劳→效率下降→医疗事故增加 |

## 四、薪资与满意度

| 维度 | 说明 |
|------|------|
| 基础薪资 | 按技能等级定价 |
| 顾问薪资 | 高于普通医生（有完整技能树的代价） |
| 满意度因素 | 薪资水平+休息质量+医院环境+工作量 |
| 低满意度后果 | 效率下降、离职概率上升 |
| 高满意度效果 | 工作效率↑、可能解锁隐藏能力 |

## 五、设计特点分析

### 5.1 "顾问系统=经营游戏中的角色RPG"

顾问系统是将RPG角色的"技能树成长"与经营模拟的"员工系统"融合。每个顾问是一个**有名字、有性格、会成长的个体**——而非普通的可替换劳动力。这让员工管理从"成本控制问题"变为"角色养成体验"，增加了情感投资维度。

这在商业经营品类中是罕见的设计——大多数游戏的员工是无面目的可替换单位（双点医院、过山车之星、开罗系列均是如此）。

### 5.2 "物种=员工属性"的世界一致性

如前所述，医生的物种身份决定其特质——Kouber Baly医生耐心更好、Dyonai医生需要更高的天花板——这让员工招聘不仅是技能匹配，也是种族多样性管理。

### 5.3 "怪癖系统=人格化的随机性"

随机怪癖让每个医生都不同——你需要决定"这个Sadist医生虽然技术好但会让患者受苦，值不值得留下？"这种随机人格化设计在RPG中常见（如RimWorld的特质系统），但在医院经营游戏中是创新。

### 5.4 与同品类对比

| 维度 | Galacticare | 双点医院 | RimWorld |
|------|:--:|:--:|:--:|
| 核心角色 | 顾问（有性格+技能树） | 所有员工（无性格） | 所有殖民者（极深模拟） |
| 技能成长 | 培训室+顾问树 | 培训室→晋升 | 使用→升级 |
| 人格/特质 | ✅ 物种+怪癖 | ✅ 少量特质 | ✅ 深度特质 |
| 情感维度 | ★★★★ (顾问) | ★★ | ★★★★★ |
| 物种影响 | ✅ 7种 | ❌ | ❌ |

Galacticare的员工系统在医院经营品类中处于"情感投入最高"的位置——顾问系统让至少部分员工从"可替换资源"升级为"有名字的伙伴"。

## 六、设计启示

1. **顾问系统是经营游戏中"员工人格化"的最优解**——并非每个员工都需要有性格(管理成本太高)，但少量"主角级"员工可以承载情感投入。这在RimWorld（全人格化→管理压力大）和双点医院（全匿名→无情感）之间找到了一条中间路。
2. **物种特质→员工属性的设计协议**：任何有多类型的种族/物种/派系的游戏都可以参考——让员工的"出身"直接影响其工作表现和需求。
3. **怪癖=零成本的人格多样**：几行随机怪癖代码就能让每个员工"感觉不同"——这是低成本增加经营游戏角色深度的有效方法。
