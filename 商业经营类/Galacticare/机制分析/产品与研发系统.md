## 一、"产品"的重新定义

在Galacticare中，"产品"是**医疗服务本身**——具体来说，是"诊断+治疗方案"的组合。这与双点医院一致。

| 传统商业经营产品 | Galacticare的对应概念 |
|------|------|
| 产品种类 | 49种外星疾病及其治疗方案 |
| 产品研发 | 研究室解锁新诊断/治疗设备 |
| 产品质量 | 设备等级+医生技能→治愈率 |
| 产品组合 | 诊断室配置×治疗室配置 |
| 新产品解锁 | 研究完成→新房间类型→可治疗新疾病 |

## 二、疾病系统

### 2.1 疾病概览

游戏有**49种外星疾病**，每种有独特的症状、诊断需求和治疗方案：

| 疾病分类 | 示例 | 症状表现 |
|------|------|------|
| 体表异常 | Star Warts（星疣）、Metalhead（皮肤金属化） | 俯视视角可见的体表变化 |
| 体液/变形 | Jellification（果冻化）、Festicrosis | 颜色/形态变化 |
| 心理疾病 | Space Fright（太空恐惧） | 行为异常 |
| 寄生虫/侵入 | Cranial Leech（颅骨水蛭）、Unidentified Internal Object | 附着物/异物 |
| 休眠/衰退 | Hypersleep Crust（休眠结壳）、Galaxy Brain | 生理功能退化 |
| 异变 | 多种突变疾病（挑战模式） | 随机组合症状 |

### 2.2 视觉化诊断

游戏的一个特色设计是：**疾病在俯视视角下可见**——患者的身体上会显示疾病对应的视觉特征：
- Star Warts = 身体上的星形斑点
- Metalhead = 金属光泽覆盖皮肤
- Jellification = 身体变得半透明颤巍巍
- Cranial Leech = 头部附着可识别的水蛭状生物

这让"诊断"不仅是点击按钮——玩家可以肉眼判断患者可能患了什么病。

## 三、研究与解锁系统

### 3.1 研究室(Research Lab)

| 参数 | 说明 |
|------|------|
| 建造条件 | 建造研究室+分配研究员 |
| 研究项目 | 新房间类型、新设备、新升级、新治疗选项 |
| 研究时间 | 项目不同耗时不同（具体数值待补充） |
| 研究加速 | 多研究室+多研究员并行 |

### 3.2 研究解锁链

```
研究室建造 → 基础研究项目 → 解锁新诊断设备
  → 更准确的诊断 → 发现新疾病类型
  → 解锁对应治疗室 → 可治疗新疾病
  → 更深层研究 → 设备升级 → 更高治愈率
```

### 3.3 设备升级

| 升级维度 | 效果 |
|------|------|
| 诊断设备升级 | 提高诊断准确率、减少复诊次数 |
| 治疗设备升级 | 提高治愈率、缩短治疗时间 |
| 房间整体升级 | 提升患者满意度、解锁新功能 |

升级通过**Craftech工坊**进行——这是一个专门的设备制造和升级空间。

## 四、Craftech工坊系统

### 4.1 工坊功能

Craftech是Galacticare的独有系统之一：

| 功能 | 说明 |
|------|------|
| 设备制造 | 制作特殊的诊断/治疗设备 |
| 设备升级 | 提升现有设备的性能和外观 |
| 物品合成 | 组合材料制造高级设备 |

### 4.2 与Baz商人的协同

| 获取方式 | 说明 |
|------|------|
| Craftech制造 | 自给自足——需要研究解锁配方 |
| Baz商人购买 | 可购买稀有/无法制造的设备和道具 |

## 五、设计特点分析

### 5.1 "视觉化诊断"的品类创新

Galacticare将疾病症状做成**俯视视角可见的视觉特征**——这在医院模拟品类中是独特的。传统医院游戏（如双点医院）的疾病主要通过文字描述和UI面板传达，而Galacticare让"看到患者就知道大概是什么病"成为可能。这降低了诊断的UI依赖，增加了"观察力"的游戏性。

### 5.2 Craftech作为"装备制造"系统

Craftech将医院经营与RPG/策略游戏中的"装备制造"概念融合——自研设备配件、升级现有设备、合成高级工具。这比双点医院的"点击升级按钮"更具体验深度，也让研究室和工坊之间的"研究→制造"形成完整的研发链条。

### 5.3 与同品类对比

| 维度 | Galacticare | 双点医院 | Game Dev Tycoon |
|------|:--:|:--:|:--:|
| "产品"种类数 | 49疾病×多种治疗方案 | 100+疾病 | 多种游戏类型组合 |
| 研发机制 | 研究室+Craftech制造 | 研究部 | 研发点数分配 |
| 视觉化"产品" | ✅ 俯视可见症状 | ❌ (UI面板) | ❌ (抽象项目) |
| 设备升级路径 | Craftech多级升级 | 设备I→II→III | N/A |
| 研发→治疗闭环 | 研究→新设备→新治疗→更高收入 | 研究→新房间→新治疗 | 研发→新游戏→收入 |

## 六、设计启示

1. **"视觉化诊断"让医疗游戏从"看面板"变成"看病人"**：将信息从UI移到游戏世界中——这是沉浸感设计的核心技巧。
2. **Craftech=将"装备系统"引入医院经营**：自制设备+升级+合成→让"技术投资"有一个可见的制造过程，而非简单的数值提升。
3. **49种疾病是合理的数量**：足够多到维持新鲜感（覆盖11章战役），但不过多到难以管理。对比双点医院的100+疾病，Galacticare选择了更精确的疾病-治疗映射。
