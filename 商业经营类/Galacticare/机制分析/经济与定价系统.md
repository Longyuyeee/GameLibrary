## 一、货币与收入体系

### 1.1 货币类型

游戏使用**单一货币——信用点(Credits)**，无多货币或代币体系。信用点是通用的经营货币，用于建造、雇佣、研究、装修和采购。

### 1.2 收入来源及权重

| 收入来源 | 权重 | 说明 |
|------|:--:|------|
| **诊疗收入** | ★★★★★ 主力 | 诊断+治疗流程完成后患者支付的费用 |
| **关卡目标奖励** | ★★★★ 重要 | 完成章节/关卡目标的一次性奖励金 |
| **研究变现** | ★★★ 中期补充 | 研究完成后可能解锁新的收入来源或效率提升 |
| **Baz商人交易** | ★★ 辅助 | 向Baz出售/交换物品获得额外信用点 |
| **入侵虫群清理** | ★ 微量 | 手动消灭侵入医院的虫群获得少量信用点奖励 |

### 1.3 诊疗定价机制

与双点医院的自由定价不同，Galacticare的诊疗费用由**治疗室类型+设备等级**决定：

| 定价因素 | 说明 |
|------|------|
| 治疗室类型 | 不同疾病的治疗方案有各自的基准收费 |
| 设备等级 | 升级治疗室设备→提高诊疗费用上限 |
| 诊断效率 | 快速诊断→患者满意度高→可能复诊→长期收入 |

> 注：精确定价公式游戏未公开，标注"待补充"。

### 1.4 挑战模式的经济约束

挑战模式(Challenge Mode)增加了更严苛的经济条件：
- 更频繁的灾害→更高的维修成本
- 突变疾病→需要更高级设备→更高投资门槛
- "过多死亡"失败条件→医疗事故有直接经济惩罚

## 二、成本结构

### 2.1 固定成本

| 成本类型 | 说明 |
|------|------|
| **医生薪资** | 持续性的工资支出，不同技能等级的医生薪资不同 |
| **顾问薪资** | 顾问(Consultant)是特殊的高级角色，薪资高于普通医生 |
| **医疗机器人维护** | Medibot的维护和充电成本 |
| **房间维护费** | 每个功能房间的日常维护开销 |

### 2.2 可变成本

| 成本类型 | 说明 |
|------|------|
| **新建/扩建房间** | 建造诊断室、治疗室、研究室等 |
| **设备采购** | 房间内设备的购买和升级 |
| **研究投资** | 研究室的研究项目消耗信用点 |
| **装修/装饰** | 提升房间美观度和患者满意度 |
| **灾害修复** | 虫群入侵/陨石撞击后的房间修复费用 |
| **Baz商人采购** | 从Baz处购买稀有道具和设备 |

## 三、利润模型

### 3.1 利润优化策略

| 策略 | 效果 | 风险 |
|------|------|------|
| **集中升级高需求治疗室** | 提升该室诊疗效率→更多患者/单位时间 | 若诊断设备不足→前面环节成为瓶颈 |
| **优化患者动线** | 诊断→治疗→康复的路径最短化→减少等待时间 | 空间成本 |
| **雇佣高效率顾问** | 顾问技能树解锁效率Buff | 高薪资 |
| **满足物种需求** | 各物种有独特渴望(宽敞/装饰/窗户)→满足后满意度↑→复诊率↑ | 装修成本 |

### 3.2 金钱Sinks

| Sink类型 | 说明 |
|------|------|
| **后期房间全升级** | 5星评级的诊断/治疗室需要大量信用点 |
| **顾问技能树全解锁** | 顾问的技能树点亮需要信用点+时间 |
| **全物种需求满足** | 为7种物种分别定制空间/装饰→高昂的装修成本 |
| **挑战模式额外困难** | 灾害修复+突变疾病设备+死亡罚款 |

## 四、设计特点分析

### 4.1 "中等定价自由"的经济设计

Galacticare选择了一条介于双点医院（完全自由定价）和双点博物馆（固定收入/探险成本）之间的路线。诊疗收入由设备和诊断链决定，玩家无法逐项调整价格，简化了经济微操作——这与游戏的"轻松科幻氛围"一致。

### 4.2 经营压力与叙事节奏

章节制(Single-player campaign 11章)使经济节奏与叙事节奏绑定——每章的经济启动条件、目标奖励、难度递增都由关卡设计控制。这与沙盒式经营游戏（过山车之星的自由建造）形成了不同的经济节奏：**关卡制的经济是"脉冲式"的**（开局紧张→中期扩张→关卡完成→下关重置部分进度）。

### 4.3 与同品类对比

| 维度 | Galacticare | 双点医院 | 过山车之星 |
|------|:--:|:--:|:--:|
| 定价自由度 | 中（设备驱动） | 高（逐项自由定价） | 高（逐设施定价） |
| 经济节奏 | 脉冲式（关卡制） | 脉冲式（关卡制） | 连续式（沙盒） |
| 成本压力来源 | 灾害+设备升级 | 员工薪资+房间维护 | 建造+维护+薪资 |
| 金钱Sinks深度 | 中 | 中 | 深（创意建造） |

## 五、设计启示

1. **关卡制经营游戏的经济设计需要"脉冲式"节奏**：每关重置部分进度→保留核心解锁→让玩家在熟悉的经济循环中面对递增的挑战。
2. **设备驱动定价=降低经济微操作**：将价格与设备等级绑定而非手动调整，简化了UI但降低了策略深度——适合轻松向经营游戏。
