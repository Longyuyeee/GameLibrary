## 一、患者（顾客）——7种外星物种

### 1.1 物种总览

Galacticare的"顾客"是患上各种外星疾病的**患者(Patients)**。游戏设计了**7种独特的智慧物种**，每种有自己的生理特征、行为偏好和医院期望：

| 物种 | 体型 | 特质 (Trait) | 欲望 (Desire) |
|------|:--:|------|------|
| **Kouber Baly** | 中 | Saurian Serenity — 等待时健康/需求衰减-75%，不因排队产生负面情绪 | 渴望宽敞的治疗室空间 |
| **Tenki** | 小 | 小巧可爱，尾巴偶尔"打结" | 渴望维护良好、已升级的房间 |
| **Humans（人类）** | 中 | 怀旧 | 渴望简单装饰——来自"家乡"的熟悉物品 |
| **Xil** | 中 | 爱吃零食 | 渴望方便获取垃圾桶来"觅食" |
| **Dyonai** | 高（最高物种之一） | 高大身材 | 渴望高天花板、宽阔走廊 |
| **Ohde** | 中 | 前征服者，现已退休 | 待补充 |
| **Vizarj** | 中 | 触手生物 | 待补充 |

### 1.2 物种特质的设计意义

每个物种的特质(Trait)同时适用于**患者和医生**——这意味着：
- 雇佣一个Kouber Baly医生→她也会享受"等待不受惩罚"的特质
- 雇佣一个人类医生→她会渴望看到"家乡风格"的装饰

这创造了一个策略层：**员工的物种身份不仅影响美观，也影响效率**。

### 1.3 欲望(Desire)机制

| 欲望特性 | 说明 |
|------|------|
| **Opt-in设计** | 忽略欲望不会惩罚玩家——不满足Tenki的升级需求不会扣分 |
| **满足=奖励** | 满足欲望→患者心情↑→满意度↑→医院评分↑ |
| **渐进引导** | 欲望设计为"微妙的引导"——Kouber Baly想要大房间→自然引导玩家建造更宽敞的医院 |

## 二、患者流程

### 2.1 完整就诊链

```
患者到达(飞船/接驳舱) → 接待台登记 → 诊断室检查
  → (可能需要多次诊断) → 治疗室治疗
  → 康复/观察 → 出院(治愈) 或 死亡
```

### 2.2 诊断系统

| 诊断阶段 | 说明 |
|------|------|
| 初诊 | 接待台分配→第一个诊断室 |
| 复诊 | 部分疾病需要多次诊断才能确定治疗方案 |
| 诊断设备 | 不同诊断室提供不同诊断能力 |
| 诊断效率 | 受医生技能+设备等级+房间等级影响 |

### 2.3 巨型患者特殊处理

部分患者**体型过大**无法进入医院建筑内部：
- 通过**接驳舱(Shuttle)**进行远程诊疗
- 可进行活检(Biopsy)和远程治疗
- 这在空间布局上创造了独特的"外部诊疗区"需求

## 三、患者健康与满意度

### 3.1 健康衰减机制

| 状态 | 说明 |
|------|------|
| 等待中健康衰减 | 排队过程中患者健康持续下降 |
| 物种缓冲 | Kouber Baly等待衰减-75%——显著降低排队风险 |
| 稳定手段 | 药水(Potions)、生物静滞信标(Bio-stasis Beacon)可减缓健康衰减 |

### 3.2 满意度因素

| 因素 | 正面影响 | 负面影响 |
|------|------|------|
| 等待时间 | 快速就诊 | 排队过长 |
| 房间品质 | 升级+装饰精美 | 简陋破旧 |
| 物种需求满足 | 满足欲望 | 忽略（无惩罚） |
| 装饰/美观 | 高美观度房间 | 单调无聊的环境 |
| 治疗效果 | 成功治愈 | 治疗失败/死亡 |

## 四、患者行为AI

| 行为 | 说明 |
|------|------|
| 自主导航 | 从接待台→诊断室→治疗室→出口自动寻路 |
| 排队容忍 | 各物种对排队的态度不同（Kouber Baly最宽容） |
| 零食/垃圾桶互动 | Xil物种会主动寻找垃圾桶获取零食 |
| 视觉疾病 | 疾病症状在俯视视角下可见——医生和玩家可通过视觉判断病症 |

## 五、设计特点分析

### 5.1 "Opt-in欲望系统"的智能设计

Galacticare不惩罚忽略物种需求的玩家——这是一个富有洞察力的设计选择。强制性的多物种需求管理会让游戏变得繁琐（必须同时满足7种物种的不同偏好），而Opt-in设计将需求变成**锦上添花的引导**：做了有奖励，不做不受罚。

### 5.2 物种特质对员工的适用性

将物种特质同时应用于患者和员工是一个精巧的对称设计——它让雇佣决策多了一层考量（"我需要一个等待不受罚的医生来应对急诊高峰→雇佣Kouber Baly"），同时增加了世界构建的一致性（"Kouber Baly就是有耐心的种族，无论他们在医院里扮演什么角色"）。

### 5.3 与同品类对比

| 维度 | Galacticare | 双点医院 | 动物园之星 |
|------|:--:|:--:|:--:|
| 顾客类型 | 7种外星物种（含特质+欲望） | 多种疾病病人（无个性差异） | 多种动物物种（个体差异极深） |
| 需求系统 | Opt-in欲望（满足=奖励） | 幸福/健康/舒适等硬需求 | 五项福利（必须满足） |
| 行为复杂度 | 中（特质驱动+视觉诊断） | 中（诊断→治疗2阶段） | 高（个体行为模拟） |
| 巨型单位 | 有（接驳舱远程治疗） | 无 | 无 |

## 六、设计启示

1. **Opt-in需求系统适合多物种/多类型的经营游戏**：强制性的多种类需求管理容易变成繁琐的微操作——"做了有奖励"比"不做被惩罚"更符合轻松定位。
2. **物种特质→员工的双向适用**：让"种族/物种"不仅是顾客属性也是员工属性，增加了世界构建的一致性，值得任何有"多类型角色"的游戏参考。
3. **巨型患者的远程诊疗**打破了"所有人必须进建筑"的空间约束——这创造了独特的"院外服务区"空间设计维度。
