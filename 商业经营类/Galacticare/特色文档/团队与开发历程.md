# 团队与开发历程 — Galacticare

> 开发商/工作室: Brightrock Games (英国Brighton)
> 发行商: CULT Games
> 发行年份: 2024年5月23日
> 平台: Steam / PS5 / Xbox Series X|S / Xbox One / Game Pass
> 团队规模: 约15人核心团队

### 1.2 工作室历史

Brightrock Games的故事是一个经典的独立游戏传奇：

- **前身**：Subterranean Games，一群在Keeper Klan论坛上认识的Dungeon Keeper超级粉丝
- **2012年**：Kickstarter众筹£200,000+制作**War for the Overworld**（地下城守护者精神续作），获得原版配音演员Richard Ridings和Peter Molyneux的支持
- **2013-2015年**：War for the Overworld开发艰难——团队仅2.5个程序员、3个全职美术，分布在英国/德国/法国/澳大利亚的完全远程团队。资金耗尽迫使2014年提前Steam Early Access。
- **2015年4月**：WFTO正式发售——因资金压力仓促发布，初期Bug多、评价不佳（包括知名YouTuber TotalBiscuit的批评），但团队持续修复，最终挽回了声誉
- **2015年9月**：更名为Brightrock Games，入驻Brighton办公室。WFTO最终销量超过**150,000份**。
- **2018年**：WFTO Patch 2.0完成后，大部分人力转向新项目（代号"Project Aftercare"→Galacticare）
- **2020-2021年**：COVID期间转为**永久远程办公**，将办公室租约捐赠给慈善机构，扩展欧洲招聘
- **2024年5月23日**：Galacticare正式发售

### 1.3 发行商合作

从WFTO的自发行到Galacticare的CULT Games合作——这是一个重要的战略转变。WFTO的自发行让团队深刻体会到"缺乏发行经验=营销和平台关系的巨大短板"。CULT Games由前Mediatonic副总裁Helen Burnill创立，为Galacticare提供了专业的发行支持。

## 2. 开发历程

### 2.1 从"地下城"到"医院"

团队从WFTO的续作转向医院经营游戏的决策来自：
- 粉丝持续要求Brightrock"像对Dungeon Keeper一样对待Theme Hospital"
- 团队内部对Bullfrog/Lionhead经典的热爱
- 认为医院经营品类在双点医院之后还有创新空间（科幻主题+角色深度）

### 2.2 开发周期

| 阶段 | 时间 | 说明 |
|------|------|------|
| 概念/原型 | ~2018-2019 | 代号"Project Aftercare" |
| 主要开发 | ~2020-2023 | 约3-4年核心开发期 |
| COVID影响 | 2020-2022 | 永久远程化→改变团队协作模式 |
| 宣发 | 2023-2024 | CULT Games加入 |
| 发售 | 2024年5月23日 | Steam+PS5+Xbox+Game Pass |

### 2.3 从WFTO学到的教训

WFTO的"混乱开发"经验深刻影响了Galacticare的开发方式：

| WFTO教训 | Galacticare应用 |
|------|------|
| 别在资金耗尽时发布 | 确保充足的开发和营销预算 |
| 别自发行(如果没有经验) | 与CULT Games合作 |
| 别让远程协作变混乱 | 永久远程但用Discord+正式流程 |
| Bug毁掉首印象 | 更长的QA周期、更稳定的首发 |
| 小团队应聚焦核心 | 顾问系统+视觉诊断作为核心创新(不贪多) |

## 3. 创意来源与设计哲学

### 3.1 灵感来源

| 来源 | 借鉴 |
|------|------|
| **Theme Hospital** | 医院经营核心循环——诊断→治疗→康复 |
| **Startopia** | 太空站管理+多物种社交 |
| **Futurama** | 科幻幽默+外星日常 |
| **Red Dwarf** | 英国科幻喜剧传统 |
| **双点医院** | "奇幻疾病+幽默治疗"的现代标杆 |

### 3.2 设计哲学

1. **"不只是双点医院的太空换皮"**：通过顾问系统、视觉化诊断、物种特质对称设计，在经典医院经营框架上创造了独特的创新
2. **"15人团队要做精准的创新点"**：顾问系统和Craftech是核心差异化，不追求在所有维度超越双点
3. **"幽默感不能掩盖硬核"**：虽然设定搞笑，但经营逻辑是严肃的——挑战模式的难度不输任何同类游戏

## 5. 设计启示

### 5.1 对独立游戏开发者的启示

1. **WFTO→Galacticare的演进是独立团队"从混乱到成熟"的范本**：第一次做大型游戏吃尽苦头→第二次在流程/预算/发行上更专业。
2. **15人团队用科幻主题+核心创新（顾问/视觉诊断）在成熟品类中找到了空间**：不需要在所有维度超越品类霸主（双点医院），只需要在1-2个核心维度做出差异化。
3. **永久远程不是问题——流程混乱才是**：WFTO的远程开发混乱→Galacticare的远程开发顺利，说明关键在于流程而非物理位置。

### 5.2 对商业经营品类的参考价值

1. **顾问系统是"经营游戏角色化"的最优实践**——不是把所有员工变成角色（RimWorld式的管理压力），而是让少数核心角色承载情感投资。
2. **视觉化诊断证明"将UI信息迁移到游戏世界"是提升沉浸感的高效技巧**。
3. **关卡制+顾问继承的混合模式**在结构性和连续性之间找到了比纯关卡制（双点医院）更好的平衡。

### 5.3 团队规模与游戏品质的关系

15人团队用约4年时间做出了一个Steam好评率87%+的科幻医院经营游戏。对比**双点医院**（Two Point Studios, 约30-50人团队, 2018年），Galacticare用一半的人力在6年后做出了有独特创新的同品类竞争品——这证明了**精准的差异化创新点比团队规模更能决定市场定位**。
