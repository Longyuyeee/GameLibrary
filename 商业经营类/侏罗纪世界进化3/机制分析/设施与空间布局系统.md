## 一、模块化建造系统（系列首次）

### 1.1 Custom Design系统

JWE3引入了从Planet系列借鉴的**模块化建造系统**：

| 建造模式 | 说明 |
|------|------|
| **蓝图(Blueprint)** | 预设建筑——一键放置（适合新手） |
| **自定义设计(Custom Design)** | 放置空白核心模块→连接功能细节→完全自由设计 |
| **Frontier Workshop** | 社区蓝图分享——跨平台下载使用 |

### 1.2 核心模块→功能附加

```
空白核心模块 → 加上门窗/设备/装饰 → 功能性建筑
     ↓
  自动平整地形
     ↓
  可与其他模块拼接 → 大型建筑群
```

## 二、围栏系统——三大类型

### 2.1 陆地围栏

| 围栏类型 | 安全等级 | 适用恐龙 | 电力需求 |
|------|:--:|------|:--:|
| 轻型围栏 | 低 | 小型温和草食龙 | 无/低 |
| 中型围栏 | 中 | 中型恐龙 | 中 |
| 重型围栏 | 高 | 大型肉食龙 | 高 |
| 电围栏 | 最高 | 霸王龙/暴虐霸王龙 | 极高 |
| **自然屏障** | — | 任何(如果设计得当) | 无 |

### 2.2 自然主义围栏（新系统）

JWE3允许用**地形工具+岩石+水体+悬崖**替代传统围栏：
- 降低电力成本（无电围栏）
- 更美观（自然栖息地外观）
- 但需要**障碍物热力图**检查是否有逃脱漏洞
- 恐龙舒适度更高=更少逃脱尝试

### 2.3 泻湖(Lagoon)与鸟笼(Aviary)

| 栖息地类型 | 适配物种 | 建造方式 | 专属设施 |
|------|------|------|------|
| 泻湖(Lagoon) | 沧龙、巨齿鲨、克柔龙等海洋爬行动物 | 拼接泻湖模块 | 泻湖孵化场+泻湖观光廊 |
| 鸟笼(Aviary) | 无齿翼龙、风神翼龙等飞行爬行动物 | 拼接穹顶模块 | 鸟笼孵化场+鸟笼观光廊 |

## 三、核心建筑系统

### 3.1 运营建筑

| 建筑 | 功能 | 建议数量 |
|------|------|:--:|
| Science Centre（科学中心） | 研究+化石检查+基因组提取 | 1-2 |
| Expedition Centre（远征中心） | 派遣团队全球挖掘化石 | 1-2 |
| Staff Centre（员工中心） | 雇佣科学家+休息恢复 | 1-3 |
| Control Room（控制室） | 管理中枢(远征/化石/研究/市场) | 1 |

### 3.2 安保建筑

| 建筑 | 功能 |
|------|------|
| Response Facility（应急中心） | 驻扎捕捉队→麻醉逃脱恐龙 |
| Ranger Post（巡逻站） | 自动检查围栏/补给喂食器/监控疾病 |
| Maintenance Post（维修站） | ATV巡逻队→维修设施 |
| Backup Generator（备用发电机） | 电力覆盖范围内的建筑 |
| Security Camera（安保摄像头） | 自动检测恐龙逃脱 |
| Emergency Shelter（紧急避难所） | 逃脱时保护游客 |

### 3.3 游客建筑

| 建筑 | 功能 |
|------|------|
| Viewing Gallery（观光廊） | 多种：普通/穹顶/鸟笼/泻湖观光廊 |
| Tour（游览项目） | 吉普车游览路线 |
| Hotel（酒店） | 游客过夜→延长停留 |
| 商店/餐厅/厕所/长椅 | 基础游客服务 |

## 四、空间布局策略

### 4.1 围栏布局原则

| 原则 | 说明 |
|------|------|
| 高危恐龙→公园深处 | 霸王龙围栏远离入口→逃脱时更多反应时间 |
| 温和草食龙→外围 | 靠近入口→家庭游客首选 |
| 泻湖→中央 | 高视觉冲击→最大化观赏效果 |
| 观光廊沿围栏边界 | 最大化恐龙可见性 |
| 避难所均匀覆盖 | 逃脱时任何位置30秒内可到达 |

### 4.2 功能分区

```
[入口区]  — 售票→商店→信息中心
[草食龙区] — 低风险+家庭友好
[游览路径] — 吉普车路线连接各区域
[肉食龙区] — 高风险+高吸引力(公园深处)
[泻湖区]   — 海洋爬行动物表演
[鸟笼区]   — 飞行爬行动物
[后勤区]   — 远征中心+科学中心+员工中心
```

## 五、设计特点分析

### 5.1 "自然屏障围栏"模糊了经营和创造

传统经营游戏有明确的"建筑/围栏"边界——JWE3的自然屏障系统让"地形设计=安保设计"，模糊了美学和功能的边界。这是从过山车之星继承的自由建造精神。

### 5.2 "安保是空间布局的核心约束"

与其他经营游戏不同（"服务覆盖"是主要布局约束），JWE3的布局由"安全"主导——高危恐龙需要放在公园深处、避难所需要均匀覆盖、巡逻路线需要高效。

### 5.3 与同品类对比

| 维度 | JWE3 | 动物园之星 | 过山车之星 |
|------|:--:|:--:|:--:|
| 围栏类型 | 4级+自然屏障 | 围栏+栖息地 | 无(游乐设施) |
| 安保核心性 | ★★★★★ | ★★★ | ★ |
| 水域/空中区域 | ✅ 泻湖+鸟笼 | ❌ | ❌ |
| 模块化建造 | ✅ (系列首次) | ❌ (独立建筑) | ✅ (模块化) |

## 六、设计启示

1. **自然屏障=""

去围墙化"的经营游戏趋势**：让"关卡设计"（地形/水体）替代"人工围栏"——这是自由建造感的重要来源。
2. **安保作为布局核心约束**在经营游戏中极其罕见——为"空间规划"提供了独特的"防御纵深"策略维度。
3. **Workshop社区蓝图=无限的内容杠杆**——让玩家为玩家创建内容，Frontier通过审核机制保证质量。
