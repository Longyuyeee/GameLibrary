## 一、"产品"定义

在JWE3中，"产品"是**恐龙本身**——准确的说是"可展示的活恐龙及其观赏体验"。

| 层次 | 对应"产品" |
|------|------|
| 核心产品 | 恐龙(91种：陆地+海洋+飞行+杂交) |
| 产品变体 | 雌/雄/幼+基因改造属性+皮肤颜色 |
| 附加产品 | 观光体验(游览项目/画廊/表演) |
| 整体产品 | 侏罗纪公园品牌(公园评分) |

## 二、恐龙创造流程

### 2.1 从化石到恐龙

```
远征中心派队 → 全球挖掘化石 → 科学中心提取DNA
  → 基因组完整度达标 → 合成恐龙蛋 → 孵化场孵化
```

| 步骤 | 设施 | 时间 | 科学家需求 |
|------|------|:--:|------|
| 远征 | Expedition Centre | 实时 | 后勤(Logistics)属性 |
| 化石检查 | Science Centre | 实时 | 遗传(Genetics)属性 |
| DNA提取 | Science Centre | 实时 | 遗传属性 |
| 恐龙合成 | Hatchery | 即时(费用) | 足够基因组完整度 |
| 孵化 | Hatchery | 实时 | — |

### 2.2 基因组完整度

每种恐龙的基因组需要从多个化石中提取→达到一定完整度才能合成。完整度越高→恐龙越健康/属性越好。

## 三、研究系统（8领域×113节点）

### 3.1 研究领域

| 领域 | 节点数(估) | 解锁内容 |
|------|:--:|------|
| Attractions（景点） | ~15 | 游览项目、观光体验 |
| Guests（游客） | ~15 | 商店、道路、游客建筑 |
| Operations（运营） | ~15 | 基础设施、员工升级、维护工具 |
| Dig Sites（挖掘点） | ~20 | 新化石地点→新恐龙物种 |
| Enclosures（围栏） | ~15 | 孵化场、围栏类型、栖息地升级 |
| Medicine（医疗） | ~10 | 疾病治疗和预防 |
| Gene Modification（基因改造） | ~15 | 增强属性(健康/力量/生育) |
| Hybrids（杂交） | ~8 | 杂交恐龙(如暴虐霸王龙) |

### 3.2 推荐解锁顺序

```
Operations → Enclosures → Medicine → Guests → Attractions → Gene Mod → Hybrids
```

## 六、设计特点分析

### 6.1 "从化石到恐龙"的完整科学叙事

JWE3不只是"点击购买恐龙"——它有一个完整的"远征→挖掘→提取→合成→孵化"的伪科学流程。这让"获得一只新恐龙"成为数小时的期待和努力的结果，而非几秒钟的菜单操作。

### 6.2 113研究节点的适度规模

对比过山车之星的自由建造（无科技树）和双点医院的研究（较少节点），JWE3的113节点提供了约15-20小时的完整解锁曲线——不长不短，恰好覆盖战役的中后期。

### 6.3 与同品类对比

| 维度 | JWE3 | 动物园之星 | Let's Build a Zoo |
|------|:--:|:--:|:--:|
| "产品"创造流程 | 远征→提取→合成→孵化 | 市场购买+基因育种 | 引进→育种→CRISPR拼接 |
| 研究规模 | 8领域×113节点 | 研究项目(逐项解锁) | 隐藏科技树~150节点 |
| 基因改造深度 | ★★★★ | ★★★★★ (4代遗传) | ★★★ (CRISPR杂交) |
| 杂交/拼接 | ✅ (6种杂交恐龙) | ❌ | ✅ (30万+组合) |

## 七、设计启示

1. **"远征→化石→DNA→合成"的伪科学叙事是JWE3最独特的"产品创造"流程**——比"在菜单里点购买"有万倍的沉浸感。
2. **8领域113节点的研究规模是AAA经营游戏的"黄金分割"**——足够大但不臃肿。
3. **基因改造=后期的"产品微调"出口**——当所有恐龙都解锁后，优化每只恐龙的基因成为持续游戏的动力。
