## 一、货币与收入体系

### 1.1 货币类型

游戏使用**单一货币(现金/$)**，无多货币体系。这与前作一致。

### 1.2 收入来源及权重

| 收入来源 | 权重 | 说明 |
|------|:--:|------|
| **门票收入** | ★★★★★ | 核心收入——受恐龙吸引力(Appeal)和公园评分驱动 |
| **商店/设施收入** | ★★★★ | 食品/饮品/纪念品——游客越多消费越多 |
| **游览项目(Tours)** | ★★★★ | 吉普车游览/观光画廊——高附加值 |
| **酒店住宿** | ★★★ 中后期 | 游客过夜→延长停留→增加总消费 |
| **海洋表演** | ★★★★ | 沧龙表演日收入$20,000+ |
| **任务/合约奖励** | ★★ 补充 | 完成部门(科学/安保/娱乐)合约的一次性奖励 |

### 1.3 恐龙吸引力→收入映射

| 吸引力等级 | 代表恐龙 | 日收入(估) | 占公园收入比 |
|:--:|------|:--:|:--:|
| 极高 | 霸王龙、沧龙、暴虐霸王龙 | $15,000-20,000+/天 | 核心收入引擎 |
| 高 | 棘龙、腕龙、三角龙 | $8,000-15,000/天 | 主要贡献 |
| 中 | 迅猛龙、剑龙、副栉龙 | $3,000-8,000/天 | 补充 |
| 低 | 秀颌龙、橡树龙 | <$3,000/天 | 生态多样性价值 |

## 三、利润模型

### 3.1 "星恐龙"经济

JWE3的核心经济逻辑是：**高吸引力恐龙=客流引擎=收入基石**。一只霸王龙可以支撑整个中型公园的门票收入。

### 3.2 恐龙→客流→消费的转化链

```
高吸引力恐龙 → 游客涌入 → 门票收入↑
  → 游客停留 → 商店/餐厅消费↑
  → 游客过夜 → 酒店收入↑
  → 高满意度 → 公园评分↑ → 更多游客 → 正循环
```

### 3.3 金钱Sinks

| Sink | 费用等级 |
|------|:--:|
| 合成新恐龙(特别是大型肉食龙) | 极高 |
| 研究全113节点 | 高 |
| 基因改造(满属性) | 高 |
| 大型泻湖/鸟笼建造 | 中-高 |
| 自然灾害恢复 | 不定 |

## 四、设计特点分析

### 4.1 "霸王龙经济学"

JWE3的经济模型核心是一个简单但有效的原则：**最酷的恐龙赚最多的钱**。这与现实主题公园的"明星设施"经济完全一致——迪士尼有灰姑娘城堡，你的侏罗纪公园有霸王龙。这种设计让"获得一只霸王龙"成为每个玩家的中期经济转折点。

### 4.2 "部门合约=有方向的收入"

科学/安保/娱乐三个部门发出的合约提供了有方向性的额外收入——让玩家在"自由沙盒"之外有具体的短期经济目标。这与双点医院的关卡目标异曲同工。

### 4.3 与同品类对比

| 维度 | JWE3 | 动物园之星 | 过山车之星 |
|------|:--:|:--:|:--:|
| 收入核心 | "星恐龙"门票 | 门票+保育+捐赠 | 门票+设施+商店 |
| 成本核心 | 科学家+恐龙维护 | 动物福利+员工 | 建造+维护+薪资 |
| 基因改造 | ✅ (属性+外观) | ✅ (基因育种) | ❌ |
| 部门合约 | ✅ (三方) | ❌ | ❌ |

## 五、设计启示

1. **"明星产品"经济模型**：不是所有产品平均贡献——一个霸王龙可以支撑整个公园。这对任何想做"有爆款逻辑"的经营游戏都是核心参考。
2. **部门合约=内置的任务系统**：给自由沙盒提供方向性收入目标——平衡了"自由"和"引导"。
3. **基因改造=后期金钱Sink**：当公园基本建成后，基因改造为"追求完美恐龙"提供了持续的资金出口。
