## 一、公园评分系统（Park Rating）

### 1.1 四大评分指标（Park Metrics）

每个关卡/地图有可变的评分指标（随关卡目标变化）：

| 常见指标 | 说明 |
|------|------|
| 恐龙数量 | 公园中的恐龙总数 |
| 恐龙多样性 | 不同物种的数量 |
| 每分钟收入 | 门票+商店+游览的持续收入 |
| 游客满意度 | 综合满意指标 |
| 总资金 | 累计收入 |
| 游览项目数 | 观光廊+游览路线 |
| 安保覆盖率 | 围栏等级+摄像头+避难所 |

### 1.2 评分→星级

| 评分达标 | 星级 |
|:--:|:--:|
| 1-2指标达标 | ★★ |
| 3指标达标 | ★★★ |
| 4指标达标 | ★★★★ |
| 5+指标全达标 | ★★★★★ |

**社区反馈**：JWE3比前作更容易达到5★——这是刻意设计，让更多玩家能体验完整内容。

## 五、设计特点分析

### 5.1 "可变评分指标"让每张地图有独特挑战

不是固定看"恐龙数+收入+满意度"三件套——每张地图的Park Metrics可能不同。这避免了"用同一套模板攻略所有关卡"的单调。

### 5.2 "更容易5★"是包容性设计

社区反馈JWE3比前作更容易达到5★——这不是"降低难度"，而是让更多玩家能解锁全部内容。挑战模式提供了硬核玩家的难度出口。

---

## 六、设计启示

1. **可变评分指标=每张地图的独特"考试科目"**：让玩家在不同地图面对不同的优化挑战。
2. **"容易5★"不代表"没有挑战"**：挑战模式+全成就+全物种收集提供了多层级的难度出口。
