## 一、游客系统

### 1.1 游客需求维度

| 需求 | 满足方式 | 不满后果 |
|------|------|------|
| 恐龙观赏 | 观光画廊/游览项目/围栏视野 | 不满→提前离园 |
| 饮食 | 餐厅/食品摊/饮品店 | 饥饿→不满 |
| 购物 | 礼品店/纪念品 | 消费减少 |
| 休息 | 长椅/休息区 | 疲劳→缩短停留 |
| 厕所 | 卫生间覆盖 | 不满 |
| 住宿 | 酒店(中后期) | 无法过夜→停留时间短 |
| 安全 | 紧急避难所+围栏安保 | 恐龙逃脱→恐慌→死亡/诉讼 |

### 1.2 游客类型与消费

| 游客类型 | 消费力 | 偏好 | 吸引方式 |
|------|:--:|------|------|
| 普通游客 | 中 | 各种恐龙 | 基础门票 |
| 恐龙爱好者 | 中高 | 稀有/大型恐龙 | 高吸引力物种 |
| 家庭游客 | 中高 | 温和草食龙+幼龙 | 幼年恐龙展示 |
| VIP/富裕游客 | 高 | 专属观光+豪华酒店 | 高级游览项目 |

## 二、客流来源与增长

### 2.1 客流驱动因素

| 因素 | 影响 | 幅度 |
|------|:--:|:--:|
| 恐龙吸引力(Appeal) | 核心驱动 | ★★★★★ |
| 公园评分(Park Rating) | 评价→客流 | ★★★★ |
| 恐龙多样性 | 物种数×独特性 | ★★★★ |
| 营销/声誉 | 部门声誉+口碑 | ★★★ |
| 酒店容量 | 影响过夜游客数 | ★★ |

### 2.2 管理热力图

游戏提供多种热力图辅助决策：
- **客流分布热力图** — 显示游客集中的区域
- **恐龙可见性热力图** — 显示哪些恐龙被最多游客看到
- **满意度热力图** — 识别不满区域

## 三、游客安全系统

### 3.1 恐龙逃脱应对

| 安全设施 | 功能 |
|------|------|
| 紧急避难所(Emergency Shelters) | 保护游客——逃脱时游客自动躲入 |
| 捕捉队(Response Facility) | 麻醉→运回围栏 |
| 安保摄像头 | 自动检测逃脱（新功能） |
| 围栏等级 | 轻型→中型→重型→电围栏 |

### 3.2 逃脱的经济后果

- 游客伤亡→诉讼→巨额赔偿
- 游客恐慌→满意度暴跌→客流下降
- 恐龙可能被捕杀→失去"明星产品"

## 四、"常驻角色"——伊恩·马尔科姆博士

Jeff Goldblum配音的Ian Malcolm是游戏中反复出现的"评论家角色"——他对公园的安全/伦理决策发表评价。这在经营游戏中是一种独特的人格化反馈系统。

## 五、设计特点分析

### 5.1 "恐龙=客流引擎"的直白经济学

比动物园之星更直白——JWE3不隐藏"霸王龙=钱"的逻辑。恐龙吸引力与收入的关联清晰可见，让"获取下一只更大的恐龙"成为天然的经营驱动力。

### 5.2 "逃脱=终极惩罚"的安全维度

恐龙逃脱是JWE3独有的"服务质量失败"——不是客人不满离开，而是客人可能被吃掉。这为经营游戏创造了独特的"安全-利润"张力：为了利润需要高危高吸引力恐龙，但高危恐龙可能逃脱导致灾难。

### 5.3 与同品类对比

| 维度 | JWE3 | 动物园之星 | 过山车之星 |
|------|:--:|:--:|:--:|
| 核心吸引力 | 恐龙(91种) | 动物(100+种) | 过山车/设施 |
| 安全系统 | ★★★★★ (逃脱/捕捉) | ★★★ (动物逃逸) | ★ (设施故障) |
| 游客伤害风险 | 致命 | 低 | 极低 |
| 客流驱动 | 恐龙吸引力 | 动物多样性 | 游乐设施 |

## 六、设计启示

1. **"危险=利润"的张力是JWE3的核心设计DNA**：高吸引力恐龙=高危险=需要更多安保投入——这个三角权衡是JWE3与所有其他经营游戏最大的差异。
2. **热力图系统是大型公园管理的必要工具**：当公园扩展到15+围栏时，热力图是不可或缺的信息层。
3. **名人配音(Malcolm)将反馈系统人格化**：比UI面板更有记忆点。
