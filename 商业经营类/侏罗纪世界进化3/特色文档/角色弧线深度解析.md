## 一、"无主角"的设计分析

### 1.1 主角类型：空白主角

JWE3属于**无定义主角**的经营游戏——玩家是抽象的"公园管理者/总监"。

### 1.2 "空白"的设计意图

与一般经营游戏不同，JWE3的空白主角有一个独特的叙事框架：**你是侏罗纪世界的正统时间线中的一份子**。你的选择（偏向科学/安保/娱乐）决定了"你是哪种公园管理者"。

### 1.3 弧线阶段

| 阶段 | 体现 |
|:--:|------|
| 初期 | 学徒管理者——学习基础恐龙合成和管理 |
| 中期 | 专业经营者——处理部门冲突+大型危机(逃脱/风暴) |
| 后期 | 大师——5★公园+全物种+基因改造完美恐龙 |
| 终极 | 传奇——对抗反派+保护恐龙家族+沙盒无限创造 |

## 二、角色"属性"——管理者的能力具象化

### 2.1 无属性面板

JWE3 **没有玩家角色属性面板**。但"管理能力"通过以下指标体现：

| 能力 | 由什么衡量 |
|------|------|
| 科学能力 | 科学部门声誉+解锁物种数 |
| 安保能力 | 逃脱次数(超低=好)+围栏等级 |
| 经营能力 | 公园评分+收入 |
| 道德选择 | 部门偏向(科学/安保/娱乐) |
| 创造力 | 公园设计美观度+Workshop蓝图质量 |

## 三、角色魅力——恐龙+Malcolm+反派

### 3.1 "无主角游戏"的魅力来源

## 四、关键角色

### 4.1 恐龙=真正的"主角"

在JWE3中，恐龙不是"产品"——它们是"角色"。每只恐龙有性别、年龄、个性特质、家庭关系。玩家和恐龙之间的关系是"守护者-被守护者"而非"制造商-产品"。

### 4.2 Ian Malcolm=人格化的游戏评论

他评价你的选择、警告你的风险、庆祝你的成功——本质上就是月度评论家(Hotel Architect)的AAA版本。

### 4.3 反派=有叙事动机的对抗力

系列首次引入的明确反派为"破坏"事件提供了叙事之"为什么"——不是随机事件，而是有人在针对你。

---

## 五、反派/对手设计

| 反派层次 | 说明 |
|------|------|
| 剧情反派 | 有动机——"你不应该扮演上帝"的信念冲突 |
| 恐龙自身 | 霸王龙不是"坏"——它是自然界的力量 |
| 自然灾害 | 风暴/疾病——非道德性对抗 |
| 部门冲突 | 科学vs安保vs娱乐——内在的"对手" |

## 七、设计启示

1. **"从展示品到家庭"的情感升级**是JWE3最大的角色设计创新——恐龙不是"产品"，而是"你照顾的生命"。
2. **名人配音(Malcolm)将反馈系统从UI升级为"角色互动"**。
3. **剧情反派=经营游戏可以有的叙事维度**——不是所有经营游戏都必须是"无故事的功能沙盒"。
