## 2. 开发历程

| 时间 | 事件 |
|------|------|
| 2024年5月 | 与Universal续签授权协议，宣布JWE3开发中 |
| 2024-2025 | "从头重建"——模块化建造系统+恐龙家族系统 |
| 2025年10月21日 | 正式发售 |
| 2025年12月 | Wetlands DLC |
| 2026年1月起 | 每月免费新恐龙(家庭完整单位：雄/雌/幼) |
| 2026年6月16日 | Rebirth Expansion DLC ($24.99) |

### 2.3 "从头重建"

Game Director描述为"ground-up overhaul"——将前作拆解后用新工具重建，包括:模块化建造(来自Planet系列)、恐龙家族(雄/雌/幼)、自然主义围栏、岛屿生成器。这是一个"在成功的肩膀上重建"而非"修修补补"的策略。

## 5. 设计启示

1. **"在成功的肩膀上重建"**：JWE3不是从零开始——它继承了JWE1/2的核心受众，同时通过模块化建造和恐龙家族实现了质的飞跃。
2. **"每月免费恐龙"的持续运营模型**：每月新增一个完整恐龙家族(雄/雌/幼)——维持社区活跃度和持续关注。
3. **科学顾问+IP授权**：与Dr. Brusatte合作确保科学可信度，同时保持侏罗纪宇宙的电影感——"可信度与电影魔法的平衡"。
