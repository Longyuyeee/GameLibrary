# 员工数据总览 — Jurassic World Evolution 3

> 游戏版本: JWE3 v1.0+ | Steam/PS5/Xbox, 2025
> 数据来源: [Frontier](https://www.jurassicworldevolution.com/en-US/3/), [TheGamer](https://www.thegamer.com/jurassic-world-evolution-3-research-unlock-guide/)

---

## 一、科学家三维属性

| 属性 | 图标 | 影响效率 |
|------|:--:|------|
| 后勤(Logistics) | ⚙ | 远征速度→挖掘化石 |
| 遗传(Genetics) | 🧪 | DNA提取→基因组完整度 |
| 科学(Science) | 🔬 | 研究速度→解锁节点 |

## 二、运营团队

| 类型 | 驻扎 | 功能 |
|------|------|------|
| Ranger Team | Ranger Post | 自动巡逻检查围栏/补给喂食器 |
| MVU | Paleo-Medical | 治疗伤病恐龙 |
| Capture Team | Response Facility | 麻醉+运回逃脱恐龙 |
| Maintenance ATV | Maintenance Post | 自动维修设施 |

## 三、自动化设置

| 系统 | 方式 |
|------|------|
| 巡逻站周期检查 | 分配Ranger到Ranger Post |
| ATV自动维护 | 分配ATV到Maintenance Post |
| 摄像头自动检测逃脱 | 放置Security Camera |

## 四、科学家疲劳

| 状态 | 影响 |
|------|------|
| 正常 | 满效率 |
| 疲劳 | 效率↓ |
| 过度疲劳 | 效率↓↓+可能出错 |

休息：Staff Centre恢复。

---

## 五、科学家管理策略

| 策略 | 说明 |
|------|------|
| 早期优先雇佣高后勤 | 加速远征→更快解锁新恐龙物种 |
| 中期补强高遗传 | 提升DNA提取效率→更快完成基因组 |
| 后期补强高科学 | 加速113节点科技树完成 |
| 关注疲劳度 | 疲劳科学家远征/研究时间大幅延长 |
| 控制科学家数量 | 薪资是社区公认的最大成本压力 |

## 六、自动化效率

JWE3相比前作最大的QoL改进是自动化系统——设置好巡逻站和维修站后，日常维护几乎不需要手动干预。这让玩家可以专注于"经营决策"而非"点击每一个围栏检查状态"。
