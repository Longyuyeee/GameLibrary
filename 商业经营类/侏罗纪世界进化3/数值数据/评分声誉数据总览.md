## 一、公园评分指标(Park Metrics)

可变——每张地图有不同指标组合：

| 常见指标 | 说明 |
|------|------|
| 恐龙数量 | 总恐龙数 |
| 恐龙多样性 | 不同物种数 |
| 每分钟收入 | 持续现金流 |
| 游客满意度 | 综合指标 |
| 游览项目数 | 观光+游览路线 |
| 安保覆盖率 | 围栏+摄像头+避难所 |

---

## 五、评分策略要点

| 星级 | 最关键指标(通常) | 优先行动 |
|:--:|------|------|
| ★→★★ | 恐龙数量 | 合成2-3只新恐龙 |
| ★★→★★★ | 收入+多样性 | 增加物种+优化商店布局 |
| ★★★→★★★★ | 游客满意度 | 补齐商店/厕所/酒店 |
| ★★★★→★★★★★ | 全指标 | 全面优化+高吸引力恐龙 |

## 六、部门声誉策略

三大部门各自提供不同的内容解锁路径——建议首周目专精一个部门(推荐科学——解锁更多恐龙物种)，多周目尝试不同路线。部门声誉更像"技能专精"而非"声望排名"。
