# 营销推广数据总览 — Jurassic World Evolution 3

> 游戏版本: JWE3 v1.0+ | Steam/PS5/Xbox, 2025
> 数据来源: [Frontier](https://www.jurassicworldevolution.com/en-US/3/)

---

## 一、营销系统

JWE3 **无传统广告/营销系统**——公园吸引力由恐龙和声誉自然驱动。

## 二、替代机制

| 机制 | 等效"营销" |
|------|------|
| 恐龙吸引力 | "明星产品"=天然广告 |
| 公园星级 | 高★=客流自然增长 |
| 部门声誉 | 科学/安保/娱乐声誉=口碑 |
| Ian Malcolm评价 | 名人背书效应 |

## 三、与品类对比

| 游戏 | 营销系统 |
|------|:--:|
| JWE3 | 无(恐龙即广告) |
| 动物园之星 | 无(动物+保育) |
| 过山车之星 | 有(广告活动) |
| 开罗温泉 | 有(杂志/电视) |

## 四、设计逻辑

恐龙公园的核心假设：**恐龙本身就是最好的广告**——不需要额外的营销，因为世界上唯一有活恐龙的公园天然是全地球最知名的景点。

## 五、部门合约=定向"营销任务"

三个部门的合约可以理解为不同方向的"营销努力"：
- 科学合约→"我们是最前沿的基因科学公园"（吸引恐龙爱好者）
- 安保合约→"我们是最安全的恐龙公园"（吸引家庭游客）
- 娱乐合约→"我们是最有趣的恐龙公园"（吸引大众游客）

## 六、恐龙吸引力=最纯粹的"口碑营销"

霸王龙不需要广告牌——它的存在本身就是宣传。一只新孵化的霸王龙带来的客流增长等效于一个数百万美元的营销活动。这是侏罗纪系列经营游戏最核心的经济假设——**"产品即营销"**。
