# 时间节奏数据总览 — Jurassic World Evolution 3

> 游戏版本: JWE3 v1.0+ | Steam/PS5/Xbox, 2025
> 数据来源: [Frontier](https://www.jurassicworldevolution.com/en-US/3/), [GameWatcher](https://www.gamewatcher.com/jurassic-world-evolution-3-developer-interview-campaign-length-custom-content-and-console-limitations)

---

## 一、时间控制

| 功能 | 说明 |
|------|------|
| 实时 | 正常运营 |
| 暂停 | 规划+紧急处理 |
| 加速 | 跳过等待期 |

## 二、周期

| 周期 | 说明 |
|------|------|
| 日循环 | 白天营业/夜间闭园 |
| 战役总长 | 速通15-20h / 完美80-100h |
| 恐龙生命周期 | 幼年→成年→老年 |
| 沙盒 | 无限 |

## 三、恐龙生命周期

| 阶段 | 说明 |
|------|------|
| 蛋→孵化 | 孵化场孵化 |
| 幼年 | 需特殊照顾+巢穴 |
| 成年 | 可展示+可繁殖 |
| 老年 | 效率下降→自然死亡 |

## 四、灾害频率

| 灾害 | 频率 | 严重度 |
|------|:--:|:--:|
| 恐龙逃脱 | 不定 | ★★★★★ |
| 风暴/飓风 | 中 | ★★★★ |
| 疾病 | 中 | ★★★ |
| 反派破坏 | 剧情触发 | ★★★★ |
| 电力故障 | 不定 | ★★★★★ |

---

## 五、夜间的策略意义

| 夜间特点 | 策略 |
|------|------|
| 游客减少 | 适合施工/维修 |
| 部分恐龙更活跃 | Indoraptor等夜间物种观赏价值↑ |
| 逃脱更难发现 | 安保摄像头重要性↑ |
| 电力需求变化 | 夜间可能降低非必要区域供电 |

## 六、时间管理优先级

| 优先级 | 活动 |
|:--:|------|
| 1 | 围栏安全检查(每次风暴后) |
| 2 | 恐龙健康/疾病监控 |
| 3 | 新恐龙合成/孵化 |
| 4 | 研究推进+远征 |
| 5 | 扩建/装修 |

## 七、与同品类对比

JWE3的时间节奏与双点医院(关卡制实时)和过山车之星(自由沙盒)的核心差异在于"危机驱动"——正常运营可以平稳推进，但逃脱/风暴事件会瞬间将节奏从"规划模式"切换到"紧急响应模式"。这种"双节奏"设计是所有有灾害系统的经营游戏的核心时间策略。
