## 一、"无主角"的设计分析

### 1.1 主角类型：空白主角

Hotel Architect属于**无定义主角**的经营游戏——玩家是抽象的"酒店经营者/建筑师"，没有姓名、背景或性格。这与商业经营品类标准一致。

### 1.2 "空白"的设计意图

"酒店建筑师"这个标题已经说明了玩家的身份——不是"酒店大亨"(商业角度)，而是"建筑师"(设计和运营角度)。空白主角让玩家专注于"空间创造"和"服务设计"——经营的满足感来自"我建的这家酒店运转完美"而非"我的角色成为了什么"。

### 1.3 玩家的"弧线"——从棚屋到五星级

| 阶段 | 玩家状态 | 游戏体现 |
|:--:|------|------|
| 初期 | 学徒旅馆主 | 哥德堡：学习基础→建第一个小旅馆 |
| 中期 | 专业酒店经营者 | 圣托里尼→巴黎→圣安东：应对不同场景挑战 |
| 后期 | 酒店大师 | 纽约→拉斯维加斯：管理超高+赌场→五星评级 |
| 终极 | 世界级建筑大师 | 全6地图5★+全客群满足 |

## 二、角色"属性"与能力设计

### 2.1 无玩家属性面板

Hotel Architect **没有玩家角色的属性面板**——没有建筑师等级、没有技能树、没有特质。

### 2.2 能力通过"酒店状态"体现

| "建筑师能力" | 由什么衡量 |
|------|------|
| 空间设计能力 | 酒店布局效率+美观度 |
| 经营能力 | 月度评论分数+盈利能力 |
| 客户理解 | 客群类型满足率 |
| 人力资源管理 | 员工满意度+留任率 |
| 研究/创新 | 技能树解锁进度 |

### 2.3 研究=能力的"知识化"

跨地图继承的研究解锁是"建筑师经验积累"的体现——每次新地图，你能建造的东西更多，不是因为角色属性提升了，而是因为"你已经学会了这些设计"。

## 三、角色魅力分析——员工和客人作为"角色"

### 3.1 无主角游戏的魅力来源

| 魅力来源 | 体现 |
|------|------|
| **客人的鲜活** | 6种客群各自有鲜明的视觉和行为特征 |
| **员工的人格** | 随机特质让每个员工"不同" |
| **自定义客人的趣味** | 玩家可创建自己的角色放入游戏 |
| **建筑的成就感** | "看，这是我设计的五星酒店" |
| **年龄操纵器的黑色幽默** | 牺牲一人拯救另一人的道德灰色地带 |
| **场景的多样性** | 从圣托里尼的阳光到圣安东的雪 |

### 3.2 记忆点

| # | 记忆点 |
|:--:|------|
| 1 | **第一次月度评论+1★**：一个月努力→评论家点头→星级上升 |
| 2 | **员工退休通知**：经营游戏中罕见的"人性时刻" |
| 3 | **年龄操纵器首次使用**：黑暗幽默的功能性设计→"我做了什么？" |

### 3.3 跨游戏对比

| 维度 | Hotel Architect | 双点医院 | 开罗温泉物语 |
|------|:--:|:--:|:--:|
| 角色策略 | 空白主角+有性格的员工/客人 | 空白+广播员(声音) | 全空白 |
| 客人人格化 | ★★★★ 6种客群 | ★★ 疾病名称 | ★ 客层抽象 |
| 员工人格化 | ★★★ 特质+退休 | ★★ 少量特质 | ★ |
| 自定义角色 | ✅ | ❌ | ❌ |

## 四、关键角色——员工与评论家

### 4.1 员工=有生命周期的"角色"

员工退休系统将员工从"可替换劳动力"升级为"有生命周期的个体"——当一名从哥德堡陪你到纽约的老厨师终于退休时，这是一种真实的"送别感"。

### 4.2 评论家=定期出现的"审判者"

月度评论家在叙事上充当了"导师/考官"的角色——他不是敌人，而是一个客观的评估者。每月一次的出现节奏让他成为游戏中的"反复登场角色"。

### 4.3 客群=沉默的"受众"

6种客群没有对话，但他们的行为（去哪里、消费什么、是否提前退房）讲述了他们的故事。一个空荡荡的酒吧=玩家理解"需要吸引Rowdy客人"。

---

## 五、无反派——挑战来自"内在"

### 5.1 无外部敌人

没有竞争对手酒店集团、没有黑心开发商——与传统经营游戏一致。

### 5.2 "对手"是经营挑战本身

| "对手" | 对抗方式 |
|------|------|
| 有限的资金 | 贷款+优化收入 |
| 苛刻的客群 | 满足需求+提升星级 |
| 自然的极端(高温/低温) | 空调/暖气 |
| 时间的流逝(员工退休) | 招聘替代+年龄操纵器 |
| 评论家的严格标准 | 全方位优化 |

## 七、设计启示

1. **员工生命周期=游戏时间深度的体现**：当员工退休时，玩家会回想"这个厨师是从哥德堡带过来的"——这是经营游戏中难得的叙事时刻。
2. **评论家作为"定期角色"**让反馈系统人格化——比一个UI弹出窗口更有叙事价值。
3. **6种客群的行为差异**让"吸引不同客人"成为有情感的策略选择（"我想要那群吵闹但有趣的Rowdy客人"），而非纯粹的数据优化。
