# 营销与竞争系统 — Hotel Architect

> 游戏版本: Hotel Architect v1.0 | Steam, 2025-2026
> 数据来源: [Overclockers Review](https://www.overclockers.co.uk/blog/the-suite-life-of-hotel-architect-game-review/), [DLH Review](https://www.dlh.net/en/reviews/5514/hotel-architect---early-access-version.html)

---

## 一、声誉系统

### 1.1 星级制度（1-5★）

| 星级 | 效果 |
|:--:|------|
| ★ | 基础客流量，仅吸引Backpackers |
| ★★ | 可吸引Sun Worshippers和Rowdy客 |
| ★★★ | 可吸引Sports Enthusiasts和Business |
| ★★★★ | 可吸引Upper Crust |
| ★★★★★ | 全客群可用+最高房价上限 |

### 1.2 月度评论家机制

| 参数 | 说明 |
|------|------|
| 访问频率 | 每月一次（固定节奏） |
| 检查维度 | 房间价值、清洁度、温度、睡眠质量、餐饮、服务、设施 |
| 星级变化 | **每次仅±1星**（无论表现） |
| 研究点 | 评论后获得——用于技能树 |

---

## 二、竞争系统

Hotel Architect **无AI竞争对手酒店**——玩家面对的是内在经营挑战（满足客人、提升星级、达成关卡目标）。这与大多数商业经营品类的无竞争设计一致（双点系列、开罗系列）。

---

## 三、宣传/广告

**无传统广告系统。** 酒店的吸引力由以下因素自然决定：
- 星级
- 设施种类
- 可满足的客群类型
- 位置（不同地图天然吸引不同客群）

---

## 四、关卡目标替代竞争

Career Mode的目标驱动了"竞争力"：

| 关卡目标类型 | 示例 |
|------|------|
| 星级目标 | 达成N★评级 |
| 客群目标 | 吸引X位特定类型客人 |
| 财务目标 | 累计收入达X |
| 设施目标 | 建造Y个Z类型设施 |

---

## 五、"机会"系统的声誉代价

| 机会类型 | 收入 | 声誉影响 |
|------|:--:|------|
| 接受废料堆放 | +被动时薪 | 客人不满（视觉污染） |
| 放置集装箱 | +被动时薪 | 占用空间+美观下降 |
| 广告牌出租 | +被动时薪 | 可能影响高档酒店品牌 |

## 六、设计特点分析

### 6.1 "月度评论=有节奏的反馈循环"

与实时评分不同，月度评论创造了一个自然的"规划→执行→等待反馈→调整"的经营周期。一个月的时间足够建造新设施、培训员工、等待效果显现——然后评论家告诉你好不好。

### 6.2 "仅±1星"的缓慢爬升

这避免了"一夜暴富/一夜破产"的剧烈波动——星级爬升是一个长期的、可见的进度条。每个+1星都是一个月以上的努力结晶，这让星级成就更有分量。

### 6.3 与同品类对比

| 维度 | Hotel Architect | 双点医院 | 开罗温泉物语 |
|------|:--:|:--:|:--:|
| 评分机制 | 月度评论家 | 实时声誉 | 客人反馈+年度评分 |
| 星级变化速度 | 极慢(±1/月) | 中 | 中 |
| 竞争系统 | 无 | 无 | 无(排名) |
| 广告系统 | 无 | 有(营销部) | 有(杂志/电视) |

---

## 七、设计启示

1. **月度评论=自然的经营周期节拍器**：每月一次的正式反馈让"建造→等待→评估→调整"成为玩家的自然节奏。
2. **缓慢的星级爬升=更强的成就分量**：一个月+1星→从1星到5星至少需要4个月(游戏时间)。五星不是能快速刷到的。
3. **研究点=评论奖励**将声誉和研究绑定——确保玩家始终关注"如何让评论家满意"的核心循环。
