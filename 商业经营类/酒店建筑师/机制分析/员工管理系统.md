## 一、员工类型

| 员工类型 | 职能 | 工作区域 | 关键属性 |
|------|------|------|------|
| **Receptionist（接待员）** | 登记入住、退房、客户服务 | 前台/大堂 | 服务速度、礼貌度 |
| **Chef（厨师）** | 烹饪食物 | 厨房/餐厅 | 烹饪品质、速度 |

| **Maintenance（维修工）** | 设备维修、故障处理 | 全院 | 维修速度 |
| **Construction Worker（施工队）** | 新建/翻新工程 | 施工区域 | 施工速度 |
| **Croupier（荷官）** | 赌场运营(拉斯维加斯) | 赌场 | 专业度 |

## 二、人格特质系统（Personality Traits）

每个员工拥有随机特质——正面或负面：

| 特质类型 | 示例 | 影响 |
|------|------|------|
| 正面 | Perfectionist（完美主义） | 烹饪时间↑但品质大幅↑ |
| 正面 | Efficient（高效） | 所有任务速度↑ |
| 负面 | Clumsy（笨手笨脚） | 清洁/服务时可能打碎物品 |
| 负面 | Thief（小偷） | 可能偷取酒店财物→损失 |
| 负面 | Lazy（懒惰） | 工作效率↓ |
| 中性 | Social（社交型） | 与客人互动时满意度↑ |

## 三、培训与成长系统

### 3.1 技能培训桌

| 参数 | 说明 |
|------|------|
| 设施 | 建造"技能培训桌" (Skill Training Desk) |
| 培训效果 | 员工升级→获得技能槽→学习新能力 |
| 培训代价 | 培训期间该员工离岗（不工作） |
| 培训后效果 | 薪资自动提升（需要更高工资） |

### 3.2 可学习技能

| 技能 | 效果 |
|------|------|
| Customer Service（客服） | 客人满意度↑ |
| Atmosphere（氛围） | 酒店整体环境评分↑ |
| Efficiency（效率） | 任务完成速度↑ |
| Quality（品质） | 餐饮/服务品质↑ |
| Multitasking（多任务） | 可同时处理更多工作 |

## 四、员工生命周期

### 4.1 退休系统（品类创新）

| 阶段 | 说明 |
|------|------|
| 入职 | 年轻→高效 |
| 中年 | 效率稳定→可培训 |
| 衰老 | 效率下降→即将退休 |
| 退休 | 员工职业生涯结束→需招聘替代 |

### 4.2 年龄操纵器（Age Manipulator）

| 参数 | 说明 |
|------|------|
| 解锁方式 | 研究技能树高级节点 |
| 功能 | 将一名员工的"时间"转移给另一名员工 |
| 效果 | 目标员工→年轻化；牺牲者→加速衰老/退休 |
| 伦理维度 | 黑暗幽默式的道德选择 |

| 维度 | 说明 |

## 六、设计特点分析

### 6.1 "退休系统"在经营游戏中的现实主义

经营游戏中的员工通常是"永恒劳动力"——Hotel Architect引入退休机制，让员工管理有了**时间深度**：你需要为关键员工退休做准备（培训替代者/使用年龄操纵器）。这在经营品类中极为罕见。

### 6.2 "年龄操纵器"的黑暗幽默

将一名员工的时间转移给另一名——这是一种带着黑色幽默的"道德灰色地带"设计。不是善良/邪恶的二元选择，而是一个"为了保留最好的厨师，你愿意牺牲谁？"的实用主义道德困境。

### 6.3 "培训=薪资自动提升"的经济约束

培训之后员工要求更高工资——这让培训从"无脑升级"变为需要计算ROI的投资决策。培训一个完美主义厨师=品质↑但薪资↑——值得吗？

## 七、设计启示

1. **退休系统让经营游戏有了"代际传承"维度**：不再是"雇佣后永远存在"——需要为新旧交替做准备，增加了人力资源管理的策略深度。
2. **年龄操纵器是"功能性的道德灰色"设计**：不预设善恶标签，只是提供可行的解决方案+让玩家自己面对后果。
3. **培训成本=薪资提升**让培训从无脑操作变为投资决策——经营游戏的"员工升级"常被简化为免费Buff，Hotel Architect加入了经济约束。
