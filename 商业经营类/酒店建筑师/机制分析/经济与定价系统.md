## 一、货币与收入体系

### 1.1 货币类型

游戏使用**单一货币(现金/$)**，无多货币体系。贷款系统提供了信用额度作为现金流补充。

### 1.2 收入来源及权重

| 收入来源 | 权重 | 说明 |
|------|:--:|------|
| **客房租金** | ★★★★★ 主力 | 核心收入——不同房型/星级→不同租金水平 |
| **餐饮收入** | ★★★★ 重要 | 餐厅/酒吧/咖啡厅的食品饮料销售 |
| **娱乐/设施收费** | ★★★ 补充 | 健身房/SPA/桑拿/赌场等活动收费 |
| **"机会"收入** | ★★ 辅助 | 接受负面设施（废料/集装箱）放置→被动时薪 |
| **会议/商务服务** | ★★★ 中后期 | 会议室→商务旅客带来高附加值收入 |

### 1.3 客房定价机制

| 定价因素 | 说明 |
|------|------|
| 房间面积 | 面积越大→基础价值越高 |
| 房间设施 | 家具品质+数量+浴室配置→价值加成 |
| 酒店星级 | 星级越高→可收取的房价上限越高 |
| 客人类型 | 背包客(低价)↔上层名流(高价) |
| 季节/位置 | 不同地图(圣托里尼/巴黎/圣安东)有不同客源和价格预期 |

## 二、成本结构

### 2.1 固定成本

| 成本类型 | 说明 |
|------|------|
| **员工薪资** | 持续性工资支出——随培训升级递增 |
| **建筑维护费** | 房间/设施的日常维护 |
| **水电能源** | 酒店运营的基础设施成本 |
| **贷款利息** | 如使用贷款——基于信用评级的利息 |
| **税费** | 政府税收——影响净利润 |

### 2.2 可变成本

| 成本类型 | 说明 |
|------|------|
| **新建/扩建** | 建造新房间、新楼层 |
| **装修/翻新** | 升级家具、墙纸、地板 |
| **员工培训** | 技能培训桌的培训费用 |
| **施工承包** | 雇佣施工队→材料站加速 |
| **厨房食材** | 餐厅/酒吧的食品成本 |

## 四、设计特点分析

### 4.1 "房间面积=价值"的空间经济学

与传统酒店经营游戏不同，Hotel Architect将房间的物理面积与租金价值直接绑定。上层名流要求35格+、价值$11,900+的房间——这让"空间规划"不仅是美学，更是经济决策。

### 4.2 "机会"系统的经济反讽

接受废料/集装箱等负面设施来获取被动收入——这是一种典型的"用美观/满意度换取现金"的权衡设计。类似Let's Build a Zoo中道德路线的经济权衡，但在现实设定中表现为"为了钱你能忍受多少丑陋？"

### 4.3 与同品类对比

| 维度 | Hotel Architect | 双点医院 | 开罗温泉物语 |
|------|:--:|:--:|:--:|
| 收入核心 | 客房租金+餐饮+设施 | 诊疗费 | 浴资+服务费 |
| 定价自由度 | 中（房间价值驱动） | 高（逐项定价） | 中（服务定价） |
| 贷款系统 | ✅ | 有 | ❌ |
| 负面收入来源 | ✅ "机会"系统 | ❌ | ❌ |
| 每层楼空间经济 | ✅ 多楼层 | ❌ 单层 | ❌ 单层 |

---

## 五、设计启示

1. **"房间物理面积→经济价值"让空间规划成为经济决策**：不仅是美感，更是直接的收入驱动。
2. **"机会"系统是优雅的"牺牲美观换现金"设计**：不需要复杂的道德系统，就能实现经营游戏中的难易权衡。
3. **贷款+信用评级**为经营游戏增加了一层现实财务管理维度——适用于任何想做"深度经济"的经营游戏。
