## 一、"产品"的定义

在Hotel Architect中，"产品"是多层次的：

| 层次 | 对应"产品" | 说明 |
|------|------|------|
| 核心产品 | **客房** | 不同等级/面积的房间——核心收入来源 |
| 附加服务 | 餐饮/娱乐/SPA/健身 | 提升客人消费额度 |
| 高端服务 | 商务会议/赌场 | 高附加值——吸引特定高端客群 |
| 整体产品 | 酒店品牌(星级) | 星级=品牌价值→吸引更高层客群 |

## 二、研究系统（Skill Tree）

### 2.1 研究点数获取

| 来源 | 说明 |
|------|------|
| 月度评论家评价 | 主要来源——评论后获得 |
| 达成里程碑 | 关卡目标完成奖励 |

### 2.2 技能树解锁内容

| 解锁类别 | 示例 |
|------|------|
| 新家具/设备 | 高级床、豪华浴缸、娱乐设备 |
| 新设施类型 | 电梯、赌场设备、高级SPA |
| 效率提升 | 清洁速度、服务效率 |
| 容量/功能扩展 | 更大房间选项、多楼层支持 |
| 特殊装置 | 年龄操纵器(Age Manipulator) |

## 三、设施解锁与升级

### 3.1 设施类型谱系

| 设施大类 | 基础→中级→高级 |
|------|------|
| 餐饮 | 咖啡机→小餐厅→高级餐厅 |
| 饮品 | 自动贩卖机→小吧台→高级酒吧 |
| 健身 | 哑铃→跑步机→综合健身房 |
| 放松 | 按摩椅→SPA→高级水疗中心 |
| 商务 | 桌椅→小型会议室→商务中心 |
| 娱乐 | 街机→台球桌→赌场(拉城专属) |

### 3.2 跨地图解锁

通过研究解锁的物品**跨所有酒店地图可用**——类似Galacticare的跨关卡继承。这让玩家在后期地图中有更多选择和策略空间。

## 四、客房"产品线"设计

### 4.1 客房等级

| 客房等级 | 目标客群 | 面积需求 | 设施需求 |
|:--:|------|:--:|------|
| ★ 经济房 | Backpackers | 小 | 床+储物柜 |
| ★★ 标准房 | Sun Worshippers / Rowdy | 中 | 双人床+浴室+窗户 |
| ★★★ 高级房 | Sports / Business | 中-大 | 大床+豪华浴室+办公桌 |
| ★★★★ 套房 | Upper Crust | 大(35格+) | 豪华全套+客厅区 |
| ★★★★★ 总统套房 | Elite | 极大 | 最高标准全套+专属设施 |

### 4.2 客房策略

- 客房数量vs面积的权衡
- 多类型混合vs单一类型专业化
- 升星过程中逐步淘汰低级房

## 五、设计特点分析

### 5.1 "评论家驱动研究点数"的双循环设计

月度评论不仅是评分，也是**唯一的研究点数来源**——这让"经营好→好评→研究点→更好设施→经营更好"形成了一个优雅的闭环。你不能"氪金"跳过研究——只能通过真正的经营改善来解锁新内容。

### 5.2 跨地图继承=长期投资感

解锁的家具/设备跨地图可用，创造了一种"每一个新地图都比上一个更容易"的累积效应——玩家能感受到自己的进步。

### 5.3 与同品类对比

| 维度 | Hotel Architect | 双点医院 | 开罗温泉物语 |
|------|:--:|:--:|:--:|
| 研究驱动 | 评论家评价 | 研究室+研究员 | 无研究(开罗系) |
| 解锁机制 | 技能树(跨地图) | 关卡解锁+研究 | 时间+金钱解锁 |
| "产品"层次 | 4层(房/服务/高端/品牌) | 2层(诊断+治疗) | 2层(设施+服务) |
| 跨关继承 | ✅ | ❌ | N/A |

---

## 六、设计启示

1. **"评论→研究点→更好设施→更好评论"是完美的经营闭环**：将研究点数与经营表现直接挂钩，确保玩家始终专注于"把酒店经营好"的核心循环。
2. **跨地图继承是"轻Roguelite"在经营游戏中的应用**：每次新地图从零开始但保留已解锁的家具/知识——有新鲜感也有累积感。
3. **客房等级谱系为酒店经营提供了清晰的"产品升级路径"**：从经济房到总统套房——每一步都有明确的面积、设施、投资门槛。
