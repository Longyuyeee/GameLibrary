## 一、货币体系

### 1.1 双货币系统

与其他商业经营游戏不同，共产大亨使用**双货币**反映铁幕两侧的经济现实：

| 货币 | 使用场景 | 获取方式 |
|------|------|------|
| **卢布(Rubles)** | 东方阵营贸易、国内建设(自动建造)、进口苏联商品 | 出口商品到东方阵营、初始资金 |
| **美元(Dollars)** | 西方阵营贸易、进口西方技术和商品 | 出口商品到西方阵营、旅游业 |

### 1.2 双货币的策略意义

- 不同商品在两个市场的价格不同→**套利**成为可能
- 某些高级技术/车辆只能从西方进口→需要赚取美元
- 苏联阵营的车辆/建筑更便宜但性能较差→卢布vs美元的性价比权衡

## 二、收入来源

### 2.1 出口导向经济

| 收入来源 | 权重 | 说明 |
|------|:--:|------|
| **石油/燃料出口** | ★★★★★ | 早期最可靠的外汇来源——无需工人(油泵自动运行) |
| **制成品出口** | ★★★★ | 服装/食品/电子产品/机械——需工人+完整产业链 |
| **原材料出口** | ★★★ | 铁矿石/木材/砾石——利润低但入门快 |
| **旅游业** | ★★★ | 吸引外国游客消费→赚取两种货币 |
| **过境物流** | ★★ | 利用交通网络收取过路/物流费(间接) |

### 2.2 无"门票/直接消费"收入

与传统商业经营游戏不同，W&R**没有直接的消费者支付**。公民不支付住房、医疗、教育费用(免费提供是社会主义承诺)。所有"收入"来自**出口贸易**。

## 三、成本结构

### 3.1 建设成本

| 建设方式 | 成本 | 时间 | 资源来源 |
|------|:--:|:--:|------|
| **自动建造(外国施工)** | 昂贵(卢布/美元)+运费 | 快 | 进口材料 |
| **自建(本国施工)** | 便宜(仅材料成本) | 长(需工人+车辆+材料到位) | 本地生产或进口 |

### 3.2 运营成本

| 成本类型 | 说明 |
|------|------|
| **进口商品** | 无法自产的资源→用外汇购买 |
| **建筑维护** | 所有建筑有持续维护成本 |
| **车辆燃料/电力** | 交通网络的持续消耗 |
| **冬季供暖** | 季节性大幅能源消耗(如果开启季节) |
| **公民供给** | 食品/衣物/电子产品→免费提供给公民 |

## 四、动态价格系统（核心特色）

### 4.1 "无固定价格"

所有商品价格由**动态公式**决定：原材料成本 + 劳动力成本 + 建筑折旧摊销

| 价格特性 | 说明 |
|------|------|
| 全球市场价格 | 大规模买卖影响商品市场价 |
| 自产成本 | 比进口便宜(长期)——需要前期投资建厂 |
| 套利可能 | 同一个商品在卢布和美元市场有不同价格 |

### 4.2 自给自足的经济逻辑

```
初期：出口原材料→赚取外汇→进口制成品和机械
中期：自建工厂→用本国资源→部分替代进口
后期：完整产业链→几乎自给自足→出口高附加值产品
```

## 五、设计特点分析

### 5.1 "计划经济的游戏化"

W&R是极少数将**计划经济**(而非市场经济)作为核心机制的游戏。在这个世界里：
- 没有"顾客"——公民免费获得住房/医疗/教育
- 没有"利润"——收入来自出口贸易而非消费者支付
- 没有"竞争"——你是唯一的"国家计划委员会"
- "效率"替代了"利润"作为核心经营指标

### 5.2 "动态价格=真正的经济模拟"

大多数经营游戏的商品价格是固定的数字表。W&R的每一个商品价格都是实时计算的——这让"建一个钢铁厂值不值？"成为真正的经济核算问题。

### 5.3 与同品类对比

| 维度 | 共产大亨 | 所有其他商业经营游戏 |
|------|------|------|
| 经济模式 | 计划经济(出口驱动) | 市场经济(消费者驱动) |
| 货币 | 双货币(卢布+美元) | 单货币 |
| 定价 | 动态公式计算 | 固定/半固定数值 |
| "顾客" | 无(公民是免费受益者) | 有(购票/消费) |
| 核心指标 | 自给自足+贸易平衡 | 利润最大化 |
| 套利机制 | ✅ (双市场+动态价格) | ❌ |

## 六、设计启示

1. **"计划经济模拟"为经营游戏开辟了一个全新的设计空间**：不是"满足顾客需求→赚取利润"，而是"组织生产→出口创汇→满足公民需求"。这是对商业经营品类根本假设的颠覆。
2. **双货币+动态价格=真正的经济策略深度**：不是"选择定价策略"，而是"选择出口什么→用什么货币→进口什么"。
3. **"自建vs外包"颠覆了传统经营游戏的建造逻辑**：建造本身是有深度的经济决策(用钱买时间还是用时间省钱)。
