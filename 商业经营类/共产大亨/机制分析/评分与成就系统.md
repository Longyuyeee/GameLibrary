# 评分与成就系统 — Workers & Resources: Soviet Republic

## 一、无传统"评分"系统

### 1.1 没有星级/评分

W&R**没有传统的公园/医院/酒店星级评分系统**。没有"评论家"、没有"月度评估"。这不是疏忽——在计划经济的设定中，国家不需要"评分"来衡量自己。经济的健康由硬指标(而非舆论评分)来判断。

### 1.2 替代指标：经济自主度

"你的共和国有多自立？"是玩家社区中公认的"成功指标"：

| 自主度 | 描述 |
|:--:|------|
| 完全依赖进口 | 所有商品从边境购买 |
| 部分自给 | 食品/衣物/建材自产 |
| 高度自给 | 所有消费品+建材+工业品自产 |
| 完全自给 | 零进口——甚至出口一切 |

## 二、硬指标监控

| 指标 | 最优状态 | 危险信号 |
|------|------|------|
| 人口增长 | 持续增长 | 持续下降/骤降 |
| 外汇储备(卢布+美元) | 稳定或增长 | 快速下降→无法进口 |
| 公民健康 | 高(≥90%) | <50%→死亡↑ |
| 公民幸福度 | 高(≥80%) | <30%→逃亡↑ |
| 就业率 | >95% | <70%→劳动力浪费 |
| 教育水平 | 持续提升 | 大学毕业生不足→无法升级产业 |
| 贸易平衡 | 顺差(出口>进口) | 长期逆差→外汇枯竭 |

---

## 三、"通关"——社区定义

| 里程碑 | 说明 |
|------|------|
| 完全自给自足 | 所有公民需求自产+零进口(或有持续贸易顺差) |
| 核能发电 | 建设并运行核电站 |
| 汽车工业 | 自产汽车供全体公民 |
| 全教育覆盖 | 公民100%大学教育 |
| 100,000人口 | 共和国人口突破10万 |
| 50年持续运营 | 不破产/不崩溃持续运营50游戏年 |

## 四、沙盒=终极模式

大多数玩家认为W&R的真正"游戏"在**沙盒/现实模式**中——无限地图+自定义难度+自设目标。

---

## 五、设计特点分析

### 5.1 "无评分=真实经济指标的胜利"

W&R选择用**真实的宏观经济指标**(人口/贸易平衡/外汇储备)替代**抽象的评分系统**。这在经营游戏中是罕见的——大多数游戏需要一个"星级"作为对玩家的即时反馈。但W&R的受众(硬核模拟玩家)更信任"外汇储备下降"胜过"评分掉星"。

### 5.2 "社区定义通关"的开放性

没有"你赢了"的画面——"通关"是由社区共识定义的(完全自给/核能/汽车工业)。这让每个玩家的"终点"都不同。

### 5.3 与同品类对比

| 维度 | 共产大亨 | 双点医院 | 都市天际线 |
|------|:--:|:--:|:--:|
| 评分系统 | 无(经济指标替代) | ★★★ (星级评分) | 无 |
| 通关 | 社区定义(自给/核能) | 有(每关完成) | 无 |
| 硬指标监控 | ★★★★★ (人口/外汇/贸易) | ★★ | ★★★ |
| 受众 | 硬核模拟玩家 | 休闲-中度 | 中度 |

---

## 六、设计启示

1. **真实经济指标可以替代抽象评分**——但仅适用于硬核模拟受众。大多数玩家需要"星级"作为心理奖励。
2. **"完全自给自足"是比"5★评分"更有分量的终极目标**——因为它是由玩家的生产链完整性决定的，而非一个数值门槛。
3. **社区定义的通关条件**让游戏有无限的目标多样性——适合沙盒/"无终局"游戏。
