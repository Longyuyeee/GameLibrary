## 一、"反顾客"设计

### 1.1 没有传统"顾客"

W&R**颠覆了商业经营游戏的基本假设**——没有顾客/消费者：

| 传统经营游戏 | 共产大亨 |
|------|------|
| 顾客买票/消费→产生收入 | 公民免费获得住房/医疗/教育→不直接产生收入 |
| 顾客满意度=收入 | 公民满意度=不逃亡 |
| 吸引顾客=经营目标 | 维持公民=经营底线 |

### 1.2 "公民"替代"顾客"

公民不是收入来源，而是**劳动力资源**。他们是"生产者"而非"消费者"：

| 公民属性 | 说明 |
|------|------|
| 劳动力 | 在工厂/矿山/农场工作→生产商品→出口创汇 |
| 教育水平 | 决定可从事的工作类型(基础工人→工程师→教授) |
| 健康(Health) | 过低→死亡→劳动力流失 |
| 幸福度(Happiness) | 过低→逃离国家→劳动力+人口双重流失 |
| 党派忠诚度 | 可选系统——影响私人汽车拥有权等 |

## 二、公民需求系统

### 2.1 基本需求

| 需求 | 满足方式 | 不满后果 | 备注 |
|------|------|------|------|
| 住房 | 建造住宅楼 | 无处居住→不工作 | 免费提供 |
| 供暖 | 热电厂+供热管道 | 冬季→健康↓→死亡 | 季节系统开启时关键 |
| 电力 | 发电厂+电线 | 建筑停运 | — |
| 水 | 水厂+水管 | 健康↓ | — |
| 医疗 | 诊所/医院 | 健康↓→死亡 | 免费提供 |
| 教育 | 学校/大学 | 无法从事高级工作 | 免费提供 |

### 2.2 消费需求（随时间增长）

| 需求 | 满足方式 | 影响 |
|------|------|------|
| 食品 | 食品工厂+商店 | 幸福度 |
| 肉类 | 畜牧/屠宰+商店 | 幸福度(高级需求) |
| 衣物 | 服装工厂+商店 | 幸福度 |
| 酒类 | 酿酒厂+商店 | 幸福度 |
| 电子产品 | 电子工厂+商店 | 幸福度(后期需求) |
| 休闲 | 电影院/运动场/公园/剧院 | 幸福度 |

### 2.3 需求增长曲线

公民需求不是静态的——随着时间推移和技术进步，需求会**持续增加**：
- 1960年代：基本食品+衣物满足即可
- 1970年代：需要肉类+酒类+电子产品
- 1980年代+：需求持续攀升→需要更先进的生产链

## 三、公民行为系统

### 3.1 通勤

| 交通方式 | 说明 |
|------|------|
| 步行 | 短距离(默认) |
| 公交 | 公交车线路 |
| 有轨电车/无轨电车 | 中容量公共交通 |
| 火车/地铁 | 高容量长途通勤 |
| 缆车 | 山区特殊交通 |
| 私人汽车 | 后期解锁(可被教育/党派限制) |

### 3.2 日常行为链

```
住宅 → (交通) → 工作场所(工厂/矿山/学校) → (交通)
  → 商店(获取食品/衣物/电子产品) → (交通)
  → 休闲(电影院/运动场/酒吧) → (交通)
  → 回家
```

## 四、"顾客"体系的设计反转

### 4.1 为什么这种设计是"商业经营的'反例'"？

传统商业经营的核心循环是：**顾客消费→收入→投资→更好产品→更多顾客**。

W&R的核心循环是：**公民工作→生产商品→出口→收入→投资→更好的生活条件→公民留下(不逃亡)**。

这不是"满足顾客赚钱"，而是"维持劳动力存续以维持生产以维持出口以维持收入"。

### 4.2 "幸福度=逃亡阈值"而非"幸福度=消费意愿"

这是最根本的差异：公民的幸福度不会增加你的收入(他们不付钱)，但低幸福度会导致**劳动力流失**(逃亡)，从而间接摧毁你的经济。幸福度是一个**维持性指标**而非**增长性指标**。

## 五、设计特点分析

### 5.1 "公民=劳动资产"的冷酷现实主义

W&R不掩饰公民系统的本质：从国家的视角看，公民是"劳动力资产"——你需要投资他们(住房/医疗/教育/食品)以使他们能工作(生产商品出口)。这不是温情的社会模拟，而是一个"国家人力资源管理系统"。

### 5.2 "公民需求随时间增长"的发展压力

需求增长曲线创造了持续的发展压力——昨天的"足够"是今天的"不够"。这防止了后期出现"所有需求都满足了→没有新目标"的经营游戏通病。

### 5.3 与同品类对比

| 维度 | 共产大亨 | SimCity/Cities Skylines | 双点医院 |
|------|:--:|:--:|:--:|
| "顾客"概念 | 无(公民=劳动力) | 市民=纳税人 | 病人=收入 |
| 收入来源 | 出口贸易 | 税收 | 诊疗费 |
| 满意度作用 | 维持(防逃亡) | 维持(防迁出) | 增长(更多病人) |
| 需求增长 | ✅ (随时间) | ❌ (固定) | ❌ |

## 六、设计启示

1. **"劳动力替代消费者"颠覆了经营游戏的核心假设**——这证明了"经营"可以不只是"满足顾客赚钱"，还可以是"维持生产力以维持出口"。
2. **需求随时间增长**解决了经营游戏后期"所有需求都满足了"的经典问题。
3. **幸福度=防逃亡阈值**将满意度从"增长指标"变为"维持指标"——更适合严肃/现实的模拟游戏。
