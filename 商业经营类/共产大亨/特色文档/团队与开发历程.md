# 团队与开发历程 — Workers & Resources: Soviet Republic

> 开发商: 3DIVISION (斯洛伐克Košice)
> 发行商: Hooded Horse
> 发行年份: 2024年6月20日(正式版) / 2019年3月15日(EA)
> 平台: Steam (Windows)
> 团队规模: ~4人核心团队

---

## 1. 开发团队

### 1.1 核心成员

3DIVISION是2003年成立于斯洛伐克Košice的小型独立工作室：

| 成员 | 角色 |
|------|------|
| **Peter Adamčík** | 创始人、主程序员、团队负责人 |
| **Vladimír Baloga (Zeus)** | 图形设计师(建筑/动画/车辆) |
| **Martin Konečný (Vyvo)** | 程序员(寻路/船舶/飞机/缆车/无轨电车) |
| **Michal Kuchárik (TauFrost)** | 程序员(冬季系统/建筑编辑器/渲染/Workshop) |

外部贡献者：TGR Studio(车辆模型)、社区翻译/测试/管理员、音效/图形外包。

### 1.2 工作室历史

3DIVISION在W&R之前主要制作军事模拟游戏(Air Missions: HIND, Air Conflicts系列)。W&R是从军事领域向城市建设/经济模拟的完全转向——这对于一个小型工作室来说是一次冒险但成功的类型跳跃。

## 2. 开发历程

| 时间 | 事件 |
|------|------|
| 2019年3月 | Steam Early Access上线 |
| 2019-2023 | 5年EA持续更新 |
| 2023年2月 | 因DMCA删除短暂下架(3月解决) |
| 2024年6月20日 | v1.0正式发布 |
| 2024-2025 | Biomes DLC + World Maps DLC |
| 2025年5月 | Early Start DLC ($19.99, 1930s起步) |

### 2.3 5年EA策略

W&R在Early Access中度过了5年——这是独立游戏中最成功的EA案例之一。4人团队通过持续听取社区反馈逐步打磨系统，EA期间积累了18,500+的正面评价。

### 2.4 DMCA争议

2023年2月，游戏因一个社区"现实模式"(Realistic Mode)的DMCA版权声明被Steam暂时下架。此事在社区引起巨大反弹，最终在3月解决。这是独立游戏"开放mod支持"与"IP保护"之间张力的典型案例。

---

## 3. 创意来源与设计哲学

灵感来源：Cities: Skylines(城市模拟)+ Transport Fever(交通物流)+ 冷战时期东欧的历史现实。Peter Adamčík作为斯洛伐克人，对苏联时代的经济体系有第一手的文化理解——这让W&R的"计划经济模拟"不是刻板印象，而是基于真实体验的设计。

## 5. 设计启示

1. **4人团队×5年EA=找到并深耕一个被忽视的细分市场**——计划经济模拟+硬核物流在W&R之前几乎没有竞争者。
2. **EA不是"提前变现"而是"与社区共建"**——W&R在5年EA中积累的评价和口碑是其最大资产。
3. **从军事模拟到城市建造的类型跳跃**证明小团队不应该被"已有经验"限制。
