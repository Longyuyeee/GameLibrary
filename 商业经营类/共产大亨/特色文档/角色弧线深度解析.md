# 角色弧线深度解析 — Workers & Resources: Soviet Republic

> 数据来源: [Hooded Horse Wiki](https://wiki.hoodedhorse.com/Workers_Resources_Soviet_Republic/), [Steam Community](https://steamcommunity.com/app/784150/)

## 一、"无主角"——你是"国家计划委员会"

### 1.1 主角类型：空白角色——制度化身

W&R属于**无定义主角**的经营游戏，但与其他经营游戏的空白主角不同——你扮演的不是"一个人"(店主/经理/市长)，而是一个**抽象的"国家"**。你是"国家计划委员会"的集体意志。

### 1.2 "空白"的设计意图

设计者刻意不定义"你是谁"——因为"国家"没有单一的人格。你同时是：计划者(决定建设什么产业链)、市长(决定城市布局)、贸易部长(决定出口什么)、社会福利官(决定公民获得什么)。

### 1.3 "你"的弧线——从贫困到工业强国

| 阶段 | "国家"状态 |
|:--:|------|
| 初期 | 贫困农业国——出口原材料、进口一切制成品 |
| 中期 | 工业化中——食品/衣物自给、钢铁工业萌芽 |
| 后期 | 工业强国——完全自给、出口高附加值产品、公民生活富足 |
| 终极 | 超级大国——核能+汽车工业+全民大学+贸易主导 |

这个弧线不是"个人成长"——而是**一个国家/民族的工业化历史进程**。

## 二、"角色属性"——国家的统计数据

### 2.1 无个人属性面板

W&R**没有玩家角色属性**——但"国家"的属性体现在统计面板：

| "国家属性" | 由什么衡量 |
|------|------|
| 经济实力 | 外汇储备+出口总额 |
| 工业能力 | 生产链完整性+总产量 |
| 人口活力 | 总人口+增长率+教育水平 |
| 社会稳定 | 公民健康+幸福度+犯罪率 |
| 技术进步 | 历史年代+已解锁技术 |
| 基础设施 | 公路/铁路/能源/供热覆盖率 |

## 三、角色"魅力"——无角色的魅力在哪里？

### 3.1 "无角色游戏"的魅力来源

| 来源 | 体现 |
|------|------|
| **系统优雅感** | 设计出完美运转的产业链(钢铁→机械→汽车→出口) |
| **历史叙事感** | "我领导了一个从贫困到繁荣的国家的40年" |
| **硬核挑战感** | 在现实模式中不破产=巨大的个人成就 |
| **苏联美学的独特魅力** | 粗野主义建筑+苏联车辆+东欧景观 |

### 3.2 记忆点

| # | 记忆点 |
|:--:|------|
| 1 | **第一个冬天活下来**——如果准备不足→公民冻死→重新开始 |
| 2 | **第一条铁路连通矿山和钢厂**——物流网络开始成型 |
| 3 | **第一个核电站落成**——国家进入"现代"的标志 |

## 四、"关键角色"——公民

### 4.1 公民=沉默的"被守护者"

公民没有名字、没有说话——但他们是**整个游戏的"目的"**。你建设的一切(工厂/住房/学校/医院/供热管道)都是为了让公民生存和繁衍。公民是W&R的"无声主角"。

### 4.2 公民的"戏剧功能"

| 角色 | 功能 |
|------|------|
| 健康公民 | 劳动力(生产出口商品) |
| 受过教育的公民 | 高质量劳动力(高级工业) |
| 幸福的公民 | 不逃亡的劳动力(稳定) |
| 不满的公民 | 潜在逃亡者(风险) |
| 死亡的公民 | 失去的劳动力(损失) |

---

## 五、"反派"——冬天、全球市场和物流

### 5.1 无传统反派

没有竞争对手、没有敌人国家。

### 5.2 "反派"是系统

| "反派" | 对抗方式 |
|------|------|
| 冬天 | 提前建设供暖系统+储备燃料 |
| 全球市场价格波动 | 多元化出口+减少对单一商品依赖 |
| 物流瓶颈 | 升级交通网络+多式联运 |
| 公民需求随时间增长 | 持续扩张产业链满足新增需求 |
| 技术落后 | 赚美元→进口西方科技 |

## 七、设计启示

1. **"你=国家"是经营游戏中最抽象的玩家身份**——不是一个人、不是一家公司，而是一个制度实体。这为"宏大叙事经营游戏"提供了参考范式。
2. **公民=沉默的守护对象**——他们不说一句话，但玩家的一切行为都是为了他们。这种"无声关怀"是一种独特的情感设计。
3. **冬天=最原始的反派**——不需要写剧情，季节本身就是生命威胁。这种"自然之力作为对手"在经营游戏中极为罕见且有效。
