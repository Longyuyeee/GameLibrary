# 公民数据总览 — Workers & Resources: Soviet Republic

> 游戏版本: v1.0 | Steam, 2024
> 数据来源: [Hooded Horse Wiki](https://wiki.hoodedhorse.com/Workers_Resources_Soviet_Republic/), [Steam Community](https://steamcommunity.com/app/784150/)

---

## 一、公民属性

| 属性 | 影响 | 维持方式 |
|------|------|------|
| 健康 | 过低→死亡→劳动力流失 | 医院+清洁水+食品 |
| 幸福度 | 过低→逃亡→人口流失 | 满足所有需求+休闲 |
| 教育 | 决定可从事工作 | 学校/大学 |
| 党派忠诚 | 影响特权(汽车等) | 宣传+生活条件 |

## 二、公民需求(随时间增长)

| 年代 | 基本需求 | 高级需求 |
|:--:|------|------|
| 1960s | 食品+衣物+住房+供暖 | — |
| 1970s | +肉类+酒类 | 电子产品初现 |
| 1980s | +电子产品 | 汽车+高级休闲 |
| 1990s | 全部需求最大化 | — |

## 三、需求不满足后果

| 缺失 | 后果 |
|------|------|
| 食品 | 健康↓→死亡 |
| 供暖(冬) | 快速健康↓→大规模死亡 |
| 衣物 | 幸福度↓ |
| 电子 | 幸福度↓ |
| 休闲 | 幸福度↓ |
| 医疗 | 健康↓ |
| 教育 | 劳动力质量停滞 |

## 四、公民日常行为链

住宅 → 交通 → 工作(工厂/矿山/学校) → 交通 → 商店(领物资) → 休闲 → 回家

## 五、"顾客"概念的反转

W&R没有"顾客"——公民不消费付费。收入来自出口贸易而非公民支出。公民是"劳动力资产"和"守护对象"而非"收入来源"。
