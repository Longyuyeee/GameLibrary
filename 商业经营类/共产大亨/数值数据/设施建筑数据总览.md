## 一、核心产业链建筑

| 产业 | 上游 | 加工 | 产出 |
|------|------|------|------|
| 石油 | Pumpjack | Refinery | Fuel + Bitumen |
| 钢铁 | Iron Mine + Processing | Steel Mill | Steel |
| 食品 | Farms | Food Factory | Food + Alcohol |
| 肉类 | 畜牧场 | Slaughterhouse | Meat |
| 服装 | 农场(棉花)+化工 | Clothing Factory | Clothes |
| 电子 | 多原料 | Electronics Factory | Electronics |
| 砾石 | Stone Quarry | Gravel Processing | Gravel |
| 木材 | Woodcutting Post | Sawmill | Boards |
| 机械 | Steel+Electrical | Mechanical Factory | Machinery |

## 二、基础设施建筑

| 类别 | 建筑 | 功能 |
|------|------|------|
| 能源 | 煤电/油电/核电站 | 发电 |
| 供热 | 热电厂+供热管道 | 冬季供暖 |
| 供水 | 水井/水处理厂+水泵 | 供水 |
| 排污 | 污水处理厂 | 排污处理 |
| 交通 | 公路/铁路/机场/港口 | 物流+客运 |

## 三、公民服务建筑

| 类别 | 建筑 | 功能 |
|------|------|------|
| 住宅 | 公寓楼/独栋 | 居住 |
| 教育 | 幼儿园/小学/中学/大学 | 教育(劳动力质量) |
| 医疗 | 诊所/医院 | 健康 |
| 商业 | 商店/购物中心 | 分发食品/衣物/电子 |
| 休闲 | 电影院/运动场/公园/剧院 | 幸福度 |
| 治安 | 警察局/法院/监狱 | 犯罪控制 |

## 四、物流建筑

| 类型 | 建筑 | 适应货物 |
|------|------|------|
| 存储 | 仓库/散料堆场/储罐/露天堆场 | 分别适应不同货物类型 |
| 货运 | 货运站(公路/铁路/港口/机场) | 多式联运 |
| 客运 | 公交站/火车站/机场 | 公民通勤 |
| 特殊 | 叉车车库/传送带/管道 | 短距离自动搬运 |
