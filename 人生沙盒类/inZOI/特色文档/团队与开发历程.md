# 团队与开发历程 — inZOI

> 开发商: inZOI Studio (KRAFTON旗下, 韩国)
> 发行商: KRAFTON, Inc.
> 年份: 2025年3月28日(EA)
> 团队: 未公开(推测中大型团队)

---

## 1. 开发团队

KRAFTON——韩国最大游戏公司之一(绝地求生PUBG开发商)。inZOI由旗下专门工作室开发。制作人兼总监**金亨俊(Kim Hyungjun)** 从业29年，曾参与多款韩国MMO开发。

---

## 2. 开发历程

| 时间 | 事件 |
|------|------|
| ~2020-2022 | 项目原型(UE5技术验证) |
| 2023-2024 | 核心开发+多次展示(G-Star等) |
| 2025.3.27 | Steam愿望单#1 |
| 2025.3.28 | EA首发——40分钟畅销#1 |
| 2025.4 | 首周100万份 |
| 2025.8 | macOS版 |
| 2026.3 | EA一周年——150万份 |

---

## 3. 制作人哲学

金亨俊在EA一周年的采访中坦承："终于明白《模拟人生》为何称霸30年。"——内容深度和系统间的有机互动比技术画面更重要。承诺20年更新路线图+EA期全部免费更新。

## 5. 设计启示

inZOI是"用技术挑战品类霸主"的最新案例——UE5+AI提供了模拟人生无法匹敌的视觉和智能化水平，但在系统深度上暴露了"内容需要时间积累"的真理。
