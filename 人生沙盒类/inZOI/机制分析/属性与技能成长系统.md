## 一、Zoi属性系统

### 1.1 需求系统(Needs)

| 需求 | 说明 |
|------|------|
| 饥饿(Hunger) | 需要进食 |
| 社交(Social) | 需要与人互动 |
| 睡眠/精力 | 需要休息 |
| 卫生 | 需要清洁 |
| 娱乐 | 需要休闲活动 |

(EA阶段——需求维度仍为基础版，不及模拟人生4的16维情绪系统)

## 四、设计特点

inZOI的属性系统在EA阶段是"有框架但缺深度"——需求/技能/职业的基础架构都存在，但内容远不如模拟人生4的10年积累。AI驱动的性格系统是最大差异化——用AI生成代替预设性格列表——但当前技术尚未完全实现"AI驱动的涌现性行为"的愿景。KRAFTON的20年路线图计划意味着这些系统会持续完善。
