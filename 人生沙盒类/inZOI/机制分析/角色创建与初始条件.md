## 一、角色创建——Zoi

### 1.1 极致自定义

inZOI的角色创建被视为品类当前最高水准：

| 自定义维度 | 说明 |
|------|------|
| 面部/身体 | 超高精度滑块——远超模拟人生4 |
| 服装/配饰 | 多层穿搭+AI生成图案纹理 |
| 面部捕捉 | 手机面捕/动捕→真人表情映射到Zoi |
| AI性格 | 可自定义文字描述→AI生成角色性格 |

### 1.2 Zoi=空白主角

玩家操控Zoi如同"上帝视角"——非第一人称角色扮演，而是引导和观察。这与模拟人生的"神模式"一致。

## 二、初始条件

| 设定 | 说明 |
|------|------|

| 沙盒模式 | 跳脱传统叙事——自由实验 |

## 四、设计特点

inZOI的角色创建是"技术展示"——UE5的视觉表现力+AI驱动的自定义=品类中画面最强的角色系统。但EA阶段"有广度缺深度"——可定义项极多，但Zoi的行为/情感/社会互动的深度远不如模拟人生4(16个情绪系统+自主AI+记忆系统)。与**模拟人生4**(经10年DLC积累的深度)和**Elona**(极端但粗糙的自由度)相比，inZOI的技术基础最优但内容深度最浅。
