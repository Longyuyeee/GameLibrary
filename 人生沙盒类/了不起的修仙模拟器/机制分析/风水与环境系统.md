## 一、风水核心——五行相生相克

### 1.1 五行循环(Wu Xing Cycle)

```
木(Wood) →生→ 火(Fire) →生→ 土(Earth) →生→ 金(Metal) →生→ 水(Water) →生→ 木
木 ←克← 土 ←克← 水 ←克← 火 ←克← 金 ←克← 木
```

### 1.2 风水建筑(Feng Shui Building)

每个房间有一个**风水节点**(如卧室=床、修炼房=蒲团、厨房=灶台、工坊=工作台)。

## 二、房间风水设计

### 2.1 吉凶判定

| 风水状态 | 效果 |
|:--:|------|
| **大吉(Auspicious)** | 全局效率加成——最关键 |
| 普通 | 基础效果 |
| **大凶(Inauspicious)** | 负面事件/效率惩罚 |

### 2.2 房间风水配方

| 房间类型 | 门朝向 | 材料推荐 | 节点物品 |
|------|:--:|------|------|
| 卧室(Bedroom) | **南** | 土+金 | 床 |
| 修炼房(Cultivation Room) | — | 蒲团材质=弟子属性 | 蒲团(Cushion) |
| 工坊(Workshop) | **东** | — | 工作台 |
| 炼器室(Artifact Pavilion) | **东** | — | 炼器炉 |
| 炼丹房(Alchemy Lab) | **东** | — | 丹炉 |
| 厨房(Kitchen) | **西** | — | 灶台 |
| 餐厅(Dining Room) | **西** | — | 餐桌 |
| 祖师殿(Founder's Hall) | **南** | — | 祖师像 |

### 2.3 通用技巧

- **双开门**——避免风水泄漏(Feng Shui Leakage)惩罚
- 灵气聚集物(如灵木Spiritwood)远离风水节点≥2格(如果元素冲突)
- **观星台(Observatory)** 建筑可检查每间房的风水详情

## 三、修炼房——风水系统的极致应用

修炼房的风水直接影响**金丹突破品质**：

| 修炼房要素 | 要求 |
|------|------|
| 蒲团 | 材质=弟子五行属性 |
| 蒲团周围 | 放置**相生元素**的灵气聚集物 |
| 房间温度 | 匹配季节(冬暖夏凉) |
| 整体风水 | 必须大吉(Auspicious) |

## 四、设计特点分析

风水系统是修仙模拟器**最具原创性的系统**——它将中国传统文化中的五行八卦转化为可操作的游戏机制。不是"放个装饰品+5美观"——而是**"这个木制家具放在火属性蒲团旁边=木生火=大吉"**。这让建筑布局从"效率覆盖"升级为"五行计算"。

在RimWorld中没有对等的系统(RimWorld只有"美观/清洁/空间"的基础房间评分)。风水是修仙模拟器**摆脱"RimWorld克隆"标签的最强武器**——它证明了这款游戏不只是"RimWorld修仙Mod"，而是有自己独特深度的独立作品。

与**太吾绘卷**(也有五行系统但应用于战斗/技艺)和**鬼谷八荒**(无风水)相比，修仙模拟器的风水是**唯一将建筑/空间/元素深度结合的修仙游戏**。
