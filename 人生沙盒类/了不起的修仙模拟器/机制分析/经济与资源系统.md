# 经济与资源系统 — 了不起的修仙模拟器

> 游戏版本: v1.0+ | Steam, 2019-2020
> 数据来源: [ACS Wiki](https://amazing-cultivation-simulator.fandom.com/), [Steam Community](https://steamcommunity.com/app/955900/discussions/)

---

## 一、资源类型

| 资源类别 | 核心物品 | 获取方式 |
|------|------|------|
| **灵气资源** | 灵木(Spiritwood)/灵矿/灵石 | 采集+种植+挖矿 |
| **生存资源** | 食物/水/木材/石料 | 外门弟子劳动 |
| **修炼资源** | 丹药/秘籍/法宝/地元灵液 | 炼丹+炼器+冒险+交易 |
| **风水资源** | 各元素建材(木/火/土/金/水) | 采集+制作 |

---

## 二、生产链

| 生产环节 | 说明 |
|------|------|
| 外门劳动 | 采矿/种田/伐木/建造/烹饪——一切体力劳动 |
| 内门生产 | 炼丹/炼器/画符——需要灵气和秘籍 |
| 法宝制作 | 炼器室→炼制→法宝品质取决于材料+炼器技能+风水 |
| 丹药炼制 | 炼丹房→丹炉→品质取决于材料+炼丹技能+风水 |

---

## 三、经济循环

```
外门采集资源 → 内门使用资源修炼 → 修炼提升→更好的产出(法宝/丹药)
  → 变强→更多资源获取(攻伐/冒险) → 反哺门派
```

---

## 四、设计特点

修仙模拟器的经济是"双轨制"——外门运作物质经济(食物/木材/石料)，内门运作灵气经济(丹药/法宝/秘籍)。两条轨道互相依存——没有外门的物质基础，内门无法安心修炼；没有内门的修仙产出(法宝/丹药/灵气)，门派无法抵御外敌。这与**RimWorld**(纯物质经济)和**太吾绘卷**(复杂的物物交换)不同——修仙模拟器的"双轨经济"是其"门派"结构的自然体现。
