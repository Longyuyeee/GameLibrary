## 一、战斗方式

### 1.1 法宝对战

修仙者的战斗以**法宝(Artifact)**为核心——每个内门弟子需要炼化至少一件法宝。战斗是法宝之间的对抗。

| 战斗要素 | 说明 |
|------|------|
| 法宝品质 | 影响攻击力/防御力/特殊效果 |
| 法宝属性 | 五行——相生相克在战斗中生效 |
| 灵气消耗 | 战斗消耗灵气——灵气=HP+MP |

### 1.2 非战斗冲突

| 冲突类型 | 说明 |
|------|------|
| 外敌入侵 | 声望(Reputation)越高→越强的敌人来袭 |
| 妖兽袭击 | 随机事件——需要内门弟子出战 |
| 天劫(Tribulation) | 元神突破时触发——雷劫/火劫等 |
| 门派间攻伐 | 可攻击其他门派(征伐天下DLC) |

## 二、声望与难度控制

| 声望策略 | 说明 |
|------|------|
| **低声望(推荐前期)** | 减少强敌来袭频率——专注发育 |
| 高声望 | 触发更强敌人——但有更好奖励 |

这是RimWorld"财富驱动威胁"的修仙版本——不是财富越高越危险，而是**声望越高越危险**。

## 三、冒险(Adventure)系统

| 冒险功能 | 说明 |
|------|------|
| 世界地图 | 派弟子外出探索遗迹/秘境 |
| 旧太一遗迹 | 早期推荐探索——大量免费物资 |
| 战斗遭遇 | 遭遇妖兽/敌人→自动战斗(基于法宝/属性) |
| 奇遇 | 随机事件——可能获得秘籍/丹药/法宝 |

---

## 四、设计特点

修仙模拟器的战斗不是"操作型"(不是动作/回合制操作)——而是**"养成检验型"**：你投入了多少资源培养弟子、打造法宝、布置风水——战斗结果反映了这一切。"战斗"从输入技巧变成了**输出结果**——这是修仙题材最自洽的战斗设计(修仙者靠长期的修炼积累而非瞬间的操作)。

与**鬼谷八荒**(弹幕射击=操作型)和**太吾绘卷**(回合制=策略型)相比，修仙模拟器选择了最极端的"养成决定论"——战斗是修炼的自然结果而非独立系统。
