## 一、"主角"——你不是一个人，你是一个门派

### 1.1 主角类型：集体身份——掌门

修仙模拟器在人生沙盒品类中拥有**最独特的"主角"定义**——你不是任何一个个体修仙者，你是**门派本身**。你是掌门——但掌门也可能死亡/飞升/传承——门派继续存在。

### 1.2 "集体主角"的设计意图

| 设计选择 | 原因 |
|------|------|
| 不是"一个修仙者" | 鬼谷八荒/觅长生已覆盖"个体修仙" |
| 是"一个门派" | 修仙小说的核心单位是"宗门"——不是散修 |
| 外门→内门的阶层 | 修仙世界最基础的等级制度 |
| 掌门可传承 | 门派比任何个体都长寿 |

### 1.3 门派的"弧线"

| 阶段 | 状态 |
|:--:|------|
| 起点 | 荒野中的几间草屋+3-5个外门弟子 |
| 成长 | 第一个内门弟子→第一个金丹→第一个法宝 |
| 壮大 | 多个内门弟子+炼丹/炼器产业链+风水优化 |
| 鼎盛 | 元神→飞升+征伐天下+全门派完美金丹 |
| 传承 | 掌门飞升/死亡→下一任掌门继承——门派永存 |

## 二、"属性"——门派的面板

| 门派属性 | 由什么衡量 |
|------|------|
| 修炼实力 | 最高金丹弟子Tier+飞升人数 |
| 产业链完整度 | 炼丹/炼器/阵法/符箓全链路 |
| 风水环境 | 全门派房间大吉率 |
| 外部影响力 | 声望+征服的势力数量 |
| 知识积累 | 秘籍库规模+已学法则数量 |

## 三、魅力——每一个弟子都有他的故事

| 魅力来源 | 体现 |
|------|------|
| "第一个金丹" | 那个突破时你紧张得不敢呼吸的弟子 |
| 风水大师 | 那个把每一间房都调到大吉的"门派风水师" |
| 悲剧英雄 | 那个渡劫失败灰飞烟灭的天才弟子 |
| 传承感 | 掌门飞升→新掌门接任→"门派永存"的史诗 |
| 逆袭叙事 | 从40%差评到90%好评——游戏本身的逆袭故事与游戏中门派的逆袭故事形成镜像 |

## 七、设计启示

1. **"门派=主角"是修仙模拟器最大的角色设计创新**——它从根本上重新定义了"人生沙盒中的'人'是谁"。不是一个人，是一个组织。这为所有"组织管理型"人生模拟提供了范式。
2. **阶层流动(外门→内门→长老→掌门)=最真实的修仙叙事弧线**——每一个弟子的晋升都是微型的故事。
3. **门派永存="

长生"的实现**——个体的修仙者会飞升/死亡，但门派可以延续千年。这是对"修仙追求长生"的最优雅的游戏化回应。
