# 团队与开发历程 — 了不起的修仙模拟器

> 开发商: GSQ Games (重庆吉艾斯球科技有限公司)
> 发行商: Gamera Game
> 年份: 2019年1月11日EA / 2020年正式版
> 团队: 3人创始→20+人(续作开发)

---

## 1. 开发团队

### 1.1 核心成员

| 成员 | 角色 | 背景 |
|------|------|------|
| **Black (廖秋钥)** | 制作人、主程序 | 前西山居员工，小学用学习机编程入门，毕业后只投了一份简历给西山居 |
| 美术 | 联合创始人 | 前西山居美术 |
| 策划 | 联合创始人 | 前西山居策划 |

### 1.2 工作室名称由来

"GSQ"本意是"搞事情"(工商局不给过)，后来想叫"钢丝球"(GSQ=拼音首字母——还是没过)，最终定名"吉艾斯球科技"。

## 2. 开发历程——"固守本心，以诚证道"

| 时间 | 事件 |
|------|------|
| 2017年8月 | 正式开始开发——计划2年完成 |
| 2019年1月11日 | Steam+WeGame双平台EA上线 |
| 2019年1月 | **口碑崩塌**——好评率跌至40-44%，被批"抄袭RimWorld" |
| 2019年1-12月 | 疯狂更新——开发者"三天没睡觉，看着评论哭、看着玩家鼓励哭、埋头做更新" |
| 2020年 | 1.0正式版——好评率回升至86%+ |
| 2020年11月 | 续作《修仙模拟器2》立项 |
| 2022年 | 全平台销量突破100万份 |
| 2024-2025 | Steam近期好评率90%+ |

## 3. 创意来源

| 来源 | 借鉴 |
|------|------|
| RimWorld(环世界) | 多角色殖民地管理框架 |
| 矮人要塞(Dwarf Fortress) | 模拟深度哲学 |
| 蜀山剑侠传/凡人修仙传 | 中国古典仙侠+网文修仙 |
| 金庸/古龙 | 江湖世界构建 |

制作人Black在玩RimWorld时突发灵感——**"用故事生成器的模式来讲中国修仙故事"**。

## 5. 设计启示

1. **"RimWorld框架×中国文化"的品类融合创造了新子类型**——这是中国独立游戏最成功的"框架借用+文化注入"案例。
2. **684天/205次更新/30万字日志=口碑可以逆转**——不是靠道歉/PR，而是靠**持续用产品说话**。
3. **"固守本心，以诚证道"**——制作人的座右铭也是GSQ的企业哲学：真诚对待玩家，玩家回报以真诚。
