## 一、五行相生相克

```
相生：木→火→土→金→水→木
相克：木克土、土克水、水克火、火克金、金克木
```

## 三、风水状态

| 状态 | 效果 |
|:--:|------|
| 大吉(Auspicious) | 全局效率加成 |
| 普通 | 基础 |
| 大凶(Inauspicious) | 负面事件 |

## 四、通用技巧

- 双开门→防风水泄漏
- 灵气聚集物远离节点≥2格(如果元素冲突)
- 观星台→查看每间房风水详情
- 卧室统一用土+金(通用——无需匹配个人属性)

## 五、修炼房——金丹突破风水要求

蒲团周围放置**相生元素**的灵气聚集物+房间整体大吉+温度匹配季节。
