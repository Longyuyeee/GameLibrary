## 一、基础属性

| 属性 | 影响 | 提升 |
|------|------|------|
| HP | 生存 | 等级+心法 |
| 内力(MP) | 武学施展 | 心法+经脉 |
| 攻击力 | 物理伤害 | 武器+武学+经脉 |
| 防御力 | 减伤 | 装备+心法 |
| 速度 | 行动顺序 | 轻功+装备 |

## 二、武学体系

| 类别 | 数量级(估) | 获取 |
|------|:--:|------|
| 剑法 | 数十种 | 门派+NPC+秘籍 |
| 刀法 | 数十种 | 同上 |
| 拳法/掌法 | 大量 | 同上 |
| 内功/心法 | 大量 | 修炼+秘籍 |
| 轻功 | 多种 | 门派+探索 |
| 其他(枪/棍/暗器) | 多种 | 各渠道 |

## 三、经脉系统

| 要素 | 说明 |
|------|------|
| 点数获取 | 修炼心法→获得经脉点 |
| 分配 | 分配到不同穴位→永久属性提升 |
| 内外兼修 | 外功穴(攻击)+内功穴(防御/辅助) |
