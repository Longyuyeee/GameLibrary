# 自由度与涌现性系统 — 逸剑风云决

> 游戏版本: v1.0+ | Steam, 2023
> 数据来源: [Steam](https://store.steampowered.com/app/1876890/), [GamesHub](https://www.gameshub.com/news/reviews/wandering-sword-review-a-chinese-epic-that-rivals-blockbuster-rpgs-2629469/)

---

## 一、自由度谱系

逸剑处于"线性剧情"与"开放沙盒"的中间位置：

| 行为 | 自由度 |
|------|:--:|
| 主线剧情推进 | 线性(有序章-章节结构) |
| 探索顺序 | 中高(完成序章后可自由探索5区域) |
| 武学选择 | 极高(数百种+多武器+多门派) |
| 道德/剧情分支 | 高(选择影响结局) |
| NPC交互 | 高(送礼/切磋/招募/结拜) |
| 世界改变 | 低(无法真正改变势力格局) |

---

## 二、涌现性叙事

逸剑的涌现性**较低**——故事主要通过手工编写的剧情和支线推进，而非系统间互动自发产生。NPC自主AI提供了一些动态元素(NPC会自己成长)，但不足以产生真正的涌现叙事。

---

## 三、自由与引导的平衡

| 引导方式 | 说明 |
|------|------|
| 主线任务 | 明确的主导线索 |
| 支线任务 | 大量可选内容(200+支线/隐藏) |
| 探索引导 | 75+地点——好奇心驱动 |
| 门派引导 | 加入门派→明确的武学学习路径 |

---

## 四、"越界"行为

| 行为 | 可行性 |
|------|:--:|
| 偷窃 | ❌ |
| 随意攻击NPC | 有限(切磋而非杀戮) |
| 背叛门派 | 可转投其他门派 |
| 道德选择 | ✅ (正道/邪道分支) |

逸剑的自由度是**"有边界的自由"**——你可以选择去哪里、学什么武学、和谁交朋友、走正道还是邪道，但不能做"非常规"的事(不能偷、不能随意杀戮、不能毁灭村庄)。这与**Elona**(可盗窃/开店/核弹毁灭城市)和**Kenshi**(可被卖为奴隶/偷窃/背叛)形成极端对比。逸剑的自由是"武侠RPG的自由"而非"模拟沙盒的自由"。
