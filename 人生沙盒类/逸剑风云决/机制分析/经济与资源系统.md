# 经济与资源系统 — 逸剑风云决

> 游戏版本: v1.0+ | Steam, 2023
> 数据来源: [Steam](https://store.steampowered.com/app/1876890/), [GamesHub](https://www.gameshub.com/news/reviews/wandering-sword-review-a-chinese-epic-that-rivals-blockbuster-rpgs-2629469/)

---

## 一、货币体系

单一货币(银两/Gold)——武侠RPG标准。

---

## 二、收入来源

| 来源 | 权重 | 说明 |
|------|:--:|------|
| 战斗掉落 | ★★★★★ | 核心——击败敌人获得银两+装备 |
| 任务奖励 | ★★★★ | 主线+支线任务 |
| 出售物品 | ★★★ | 多余装备/材料→商店出售 |
| 探索宝箱 | ★★★ | 开放世界75+地点有大量宝箱 |
| 锻造/制作 | ★★ | 制造的装备可出售 |

---

## 三、消费出口

| 消费 | 说明 |
|------|------|
| 购买装备/武器 | 商店购买高级装备 |
| 秘籍购买 | 部分武学秘籍需购买 |
| 丹药/消耗品 | 回复+Buff物品 |
| 锻造材料 | 制作/升级装备 |
| 送礼 | 购买礼物→提升NPC好感度 |

---

## 四、物品系统

| 物品类别 | 内容 |
|------|------|
| 武器 | 剑/刀/拳套/枪/棍/暗器等 |
| 防具 | 衣服/护腕/鞋子/饰品 |
| 消耗品 | 丹药/食物/回复药 |
| 秘籍 | 武学/内功/轻功学习 |
| 材料 | 锻造+丹药制作 |
| 礼物 | NPC好感度 |

---

## 五、锻造/制作系统

| 制作类型 | 功能 |
|------|------|
| 锻造 | 制作武器/装备(需要材料+配方) |
| 丹药炼制 | 制作回复/增益药品 |

---

## 六、设计特点

逸剑的经济系统是标准的RPG模型——战斗掉落+任务奖励→购买/锻造→更强装备→更强的战斗力。没有经营游戏的经济复杂度(无定价策略/无生产线/无贸易)，但作为人生沙盒RPG的"装备经济"已足够支撑探索和养成的循环。与**太吾绘卷**(复杂到近乎荒谬的促织经济+书籍经济)和**Elona**(极端自由的贸易+盗窃+开店)相比，逸剑的经济是"标准但清晰"的。
