# 生活与非核心系统 — 逸剑风云决

> 数据来源: [Steam](https://store.steampowered.com/app/1876890/), [GamesHub](https://www.gameshub.com/news/reviews/wandering-sword-review-a-chinese-epic-that-rivals-blockbuster-rpgs-2629469/)

## 一、生活技能

| 技能 | 功能 | 深度 |
|------|------|:--:|
| 锻造(Blacksmithing) | 制作武器/装备 | ★★★ |
| 炼丹(Alchemy) | 制作回复/增益丹药 | ★★★ |
| 钓鱼 | 待确认 | ★ |
| 采集 | 野外采集药材/矿石 | ★★ |

逸剑的生活技能围绕**战斗辅助**——锻造更好的装备、炼制更强的丹药。没有纯休闲的生活技能(没有种田/盖房/开店等)。

## 二、门派日常

| 活动 | 说明 |
|------|------|

| 切磋 | 与同门切磋→练武+好感度 |
| 门派任务 | 完成门派委托→地位提升 |

---

## 四、设计特点

逸剑的生活系统是"战斗导向"而非"生活模拟"——锻造和炼丹直接服务于战斗力提升，没有纯休闲/纯装饰的功能。这与**太吾绘卷**(促织斗蛐蛐、读书、建造等复杂生活系统)形成鲜明对比——逸剑选择把注意力集中在"武功"上，生活技能是武功的辅助。这是"武侠RPG"vs"武侠生活模拟"的路线差异——逸剑坚定地站在RPG一侧。
