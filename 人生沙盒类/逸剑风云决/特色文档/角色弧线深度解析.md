## 一、主角设计——半空白侠客

### 1.1 主角类型：固定主角+选择塑造

有预设背景(被卷入江湖恩怨的年轻侠客)但道德/武学/门派/结局由玩家选择定义。

### 1.2 Want vs Need

| 层面 | 内容 |
|------|------|
| 表面欲望(Want) | 复仇/扬名/成为武林至尊(由玩家选择偏向) |
| 深层需求(Need) | 在江湖中找到自己的"道"——是正道沧桑还是邪道快意？ |

### 1.3 弧线阶段

| 阶段 | 状态 |
|:--:|------|
| 起点 | 初入江湖的懵懂侠客 |
| 转变节点 | 重大剧情选择(正道/邪道分支) |
| 终点 | 武学大成+结局(正道=武林盟主/归隐；邪道=霸主/覆灭) |

## 二、角色属性——经脉=修行的具象化

### 2.1 属性面板

HP/内力/攻击/防御/速度+经脉穴位+武学熟练度——标准的武侠RPG属性面板。

### 2.2 属性→故事映射

| 属性选择 | 叙事影响 |
|------|------|
| 加入正派(如少林/武当) | 正道剧情线 |
| 加入邪派 | 邪道剧情线 |
| 修炼特定武学 | 影响可触发的剧情/对话 |
| NPC好感度 | 影响可招募同伴和隐藏剧情 |

## 三、角色魅力——HD-2D武侠的诗意

### 3.1 魅力来源

| 来源 | 体现 |
|------|------|
| HD-2D视觉 | 3D光影+2D像素——独特的武侠美感 |
| 江湖叙事 | 百万字文本——"恩怨情仇"的沉浸感 |
| 武学收集 | 数百种武学——"集齐天下武功"的爽感 |
| 门派归属 | 加入门派=找到"家"的情感连接 |
| 同伴系统 | 14名各有故事的伙伴 |

### 3.2 记忆点

| # | 记忆点 |
|:--:|------|
| 1 | **第一次双模式切换**——回合制切换到实时——"还有这种操作？" |
| 2 | **经脉贯通时刻**——关键穴位点亮→属性飞跃 |
| 3 | **重大道德选择**——正道/邪道分支——"我选择成为什么样的人" |

## 七、设计启示

1. **"半空白主角"是武侠RPG的最优解**——全空白(鬼谷八荒)缺乏故事驱动力，全固定(纯线性)缺乏玩家代入感。逸剑在两者之间找到了武侠叙事的最佳平衡点。
2. **百万字文本=武侠RPG的"内容护城河"**——这不是技术壁垒，是人力投入壁垒。制作人承认"选择武侠RPG带来的百万字文案负担"是开发中最难的挑战。
3. **经脉=金庸式的"修行可视化"**——将抽象的"内力/修为"变成可操作的游戏系统——这是武侠游戏最重要的设计转化。
