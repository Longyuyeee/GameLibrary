## 2. 开发历程——三次资金链断裂

| 时间 | 事件 |

| 2019-2021 | 第一次资金断裂→成员垫付积蓄发工资 |
| 2021-2022 | 第二次→天使投资注入 |
| 2022-2023 | 第三次→发行商Spiral Up加入 |
| 2023年9月15日 | Steam正式发售 |
| 2024年 | 免费南疆DLC+烟尘回响更新 |
| 2025年 | 全球销量突破100万份 |
| 2026年5月 | PS5版(云豹娱乐发行) |
| 2026年内 | Switch/Switch 2版 |

## 2.1 技术转折

最初使用Unity，后转为**虚幻引擎4**以追求HD-2D效果(3D场景+2D像素角色)。团队此前完全没有虚幻引擎经验——靠英文机翻资料自学。

## 2.2 Demo拯救

B站发布Demo后意外获得大量关注——这个反馈给了团队"继续做下去"的信心，也吸引了发行商的注意。

## 5. 设计启示

1. **3人×4年×三次资金断裂=百万销量**——中国独立游戏最励志的故事之一。证明了"把一件事做到极致"(HD-2D武侠)的长期价值。
2. **B站Demo=独立游戏最有效的中国市场营销**——不需要发行商烧钱推广，好的Demo自己会传播。
3. **"自学UE4+英文机翻"证明技术门槛可以被热情克服**——三人没有任何UE4经验，靠自学金字塔顶端引擎。
