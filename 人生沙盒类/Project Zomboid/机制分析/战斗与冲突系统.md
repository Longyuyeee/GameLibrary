# 战斗与冲突系统 — Project Zomboid

> 游戏版本: Build 41+ | Steam EA
> 数据来源: [IGN Guide](https://www.ign.com/wikis/project-zomboid/), [Steam Community](https://steamcommunity.com/app/108600/)

---

## 一、战斗核心原则

| 原则 | 说明 |
|------|------|
| **近战无声但危险** | 一次咬伤/抓伤就可致命(默认感染=必死) |
| **枪声=自爆位置** | 霰弹枪最强但吸引全地图尸群 |
| **耐力管理** | 战斗消耗耐力→无耐力=无法跑→死亡 |
| **地形利用** | 栅栏/窗户可绊倒爬过的丧尸→暴击机会 |

## 二、武器类型

| 类型 | 武器示例 | 特点 |
|------|------|------|
| 短棍 | 锤子/扳手/棒球棍 | 单手——可同时拿包 |
| 长棍 | 撬棍/斧头/长矛 | 双手——更高伤害 |
| 刀刃 | 刀/砍刀 | 可一击必杀(背后偷袭) |
| 枪械 | 手枪/霰弹枪/步枪 | 远程——巨大噪音代价 |

---

## 三、Moodles(情绪状态)——战斗中的生命线

| Moodle | 影响 |
|------|------|
| 恐慌(Panic) | 降低精准度和伤害 |
| 疲劳(Tired) | 大幅降低战斗效率 |
| 疼痛(Pain) | 降低所有属性和速度 |
| 饥饿(Hungry) | 降低力量 |
| 负重(Overencumbered) | 降低移动/战斗速度 |

---

## 四、永久死亡(Permadeath)

| 感染方式 | 致死率 |
|:--:|:--:|
| 被咬(Bite) | 100%(默认) |
| 抓伤(Scratch) | 25% |
| 裂伤(Laceration) | 7% |

死亡后角色永久消失——但世界保留(新角色可在同一世界中重生)。

---

## 五、非战斗冲突

- 饥饿/口渴→资源获取压力
- 体温→冬季低温致命
- 疾病→感冒→肺炎→死亡
- 心理压力→角色抑郁

---

## 六、设计特点

PZ的战斗"不是英雄表演，而是绝望求生"。任何战斗都可能以一次咬伤结束一切。这种**"一击必杀"的风险**让每一场遭遇都有真正的紧张感——对比鬼谷八荒的弹幕射击(爽感导向)和太吾绘卷的回合制(策略导向)，PZ的战斗是**恐怖生存导向**的。

永久死亡+世界保留=最独特的"死亡不是结束"设计——你的角色死了，但他的基地/物资/车辆还在等你下一个人物来继承。这让"死亡"从一个惩罚变成了一个**叙事转折**。
