# 属性与技能成长系统 — Project Zomboid

> 游戏版本: Build 41+ | Steam EA
> 数据来源: [IGN Guide](https://www.ign.com/wikis/project-zomboid/), [PrimaGames](https://primagames.com/tips/project-zomboid-character-creation-for-beginners)

## 一、基础属性

| 属性 | 影响 | 提升方式 |
|------|------|------|
| 力量(Strength) | 近战伤害+负重 | 体力劳动/战斗 |
| 体能(Fitness) | 冲刺耐力+战斗持久 | 跑步/战斗 |

## 二、技能系统——每项技能是"自己的兔子洞"

| 技能 | 关键用途 | 升级方式 |
|------|------|------|
| **木工(Carpentry)** | 建造墙壁/楼梯/雨水收集器(Lv6+) | 拆家具/建造 |
| **烹饪(Cooking)** | 更好的营养配方 | 烹饪食物 |
| **农耕(Farming)** | 可持续食物生产 | 种植/收获 |
| **钓鱼(Fishing)** | 食物来源 | 钓鱼 |
| **采集(Foraging)** | 野外食物/材料 | 野外搜寻 |
| **陷阱(Trapping)** | 野生动物肉/毛皮 | 设置陷阱 |
| **机械(Mechanics)** | 车辆维修/改装 | 修理车辆 |
| **电工(Electrical)** | 发电机/电器 | 拆电器/安装 |
| **金属加工(Metalworking)** | 高级防御工事 | 焊接/制作 |
| **裁缝(Tailoring)** | 衣物强化(防咬/防刮) | 修补衣物 |
| **急救(First Aid)** | 更快治疗伤口 | 治疗受伤 |
| **瞄准(Aiming)** | 枪械精准度 | 射击 |
| **装弹(Reloading)** | 换弹速度 | 装弹 |
| **潜行(Lightfooted/Nimble/Sneaking)** | 降低被丧尸发现的概率 | 潜行移动 |

## 三、技能书籍

| 书籍等级 | 效果 |
|:--:|------|
| Beginner(初级) | ×3 XP(Lv1-2) |
| Intermediate(中级) | ×5 XP |
| Advanced(高级) | ×8 XP |
| Expert(专家) | ×12 XP |
| Master(大师) | ×16 XP |

**策略**：找到技能书→阅读→再开始训练该技能——最大化XP效率。

---

## 四、设计特点

PZ的技能系统是"时间=能力"的极端体现——没有"角色升级→获得技能点→分配"的抽象层。你想学木工？去拆家具。你想学烹饪？去做饭。游戏中没有"等级"概念——角色只是他们的技能总和。

Moodles(情绪图标)是PZ最著名的UI——饥饿/压力/疲劳/恐慌/疼痛/无聊/体温——每一项都是可见的图标状态而非隐藏数值。这比鬼谷八荒的数字面板和太吾绘卷的属性表更直观、更具沉浸感。
