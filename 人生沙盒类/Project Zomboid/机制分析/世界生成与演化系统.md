## 一、世界结构

### 1.1 固定地图+手工制作

世界是**手工设计**的——路易斯维尔(Louisville)及周边城镇(Muldraugh, West Point, Riverside, Rosewood等)。非程序生成。

### 1.2 世界规模

包含完整城市/郊区/农村/森林/河流——模拟肯塔基州诺克斯郡的真实地理。

## 二、世界演化

### 2.1 水电停止

| 阶段 | 说明 |
|------|------|
| 初期(0-30天) | 水电正常运行 |
| 中期 | 水/电随机停止(可自定义天数) |
| 停水停电后 | 需要发电机+雨水收集器自给 |

### 2.2 丧尸演化

| 维度 | 说明 |
|------|------|
| 丧尸密度 | 随时间增长(峰值后趋于稳定) |
| 丧尸分布 | 从城市中心向郊区迁移 |
| Helicopter事件 | 直升机噪音→吸引大规模尸潮到你所在区域 |

### 2.3 季节

- 春夏秋冬完整循环
- 冬季：农业停止、体温管理关键、白天更短
- 夏季：高温脱水风险

### 2.4 自然侵蚀

随着时间的推移，城市被**自然侵蚀**——草木生长、建筑老化。世界不是因为"任务推进"而变化，而是因为**时间流逝**。

## 四、设计特点

PZ的世界演化核心是**"你不是世界的中心"**——水会停、电会断、草木会侵蚀城市、尸潮会迁移。玩家只是这个世界中的一个幸存者，世界不围着你转。这与**鬼谷八荒的月历演化**(NPC自主修仙)和**CK3的角色AI**(独立行为)共享"去中心化"哲学。

季节系统让生存有**节奏感**——春天播种、夏天防暑、秋天收获储备、冬天室内苦熬。四季循环=生存游戏最自然的长期规划框架。
