# 经济与资源系统 — Project Zomboid

> 游戏版本: Build 41+ | Steam EA
> 数据来源: [IGN Guide](https://www.ign.com/wikis/project-zomboid/), [Wikipedia](https://en.wikipedia.org/?curid=32162755)

---

## 一、无货币——物物交换

PZ**没有货币**。末日之后金钱失去意义。经济=**获取资源→消耗资源→获取更多**。

---

## 二、核心资源类型

| 资源类别 | 关键物品 | 获取方式 |
|------|------|------|
| 食物 | 罐头/新鲜食材/农作物 | 搜刮+农耕+钓鱼+陷阱 |
| 水 | 水瓶/水桶 | 水龙头(前期)+雨水收集器(后期) |
| 武器/工具 | 锤子/斧头/撬棍/枪械 | 搜刮+制作 |
| 建筑材料 | 木板/钉子/金属片 | 拆卸+搜刮+制作 |
| 医疗用品 | 绷带/消毒剂/止痛药 | 搜刮(医院/药店) |
| 燃料 | 汽油 | 加油站+虹吸车辆 |
| 电力 | 发电机+汽油 | 搜刮发电机+加油 |

## 三、搜索(Looting)——核心资源获取

| 建筑类型 | 主要战利品 |
|------|------|
| 民宅 | 食物/工具/衣物/书籍 |
| 超市/便利店 | 大量食物 |

| 书店/学校 | 技能书(关键) |
| 医院/药店 | 医疗用品 |

---

## 四、自给自足的进阶路径

| 阶段 | 资源获取 |
|:--:|------|
| 初期(0-7天) | 搜刮民宅+超市——快速积累 |
| 前期(7-30天) | 搜刮+基础农耕+雨水收集 |
| 中期(30-90天) | 农耕为主+钓鱼+陷阱——搜刮减少 |
| 后期(90天+) | 完全自给——水电自供+全产业链 |

---

## 五、设计特点

PZ的经济是"从消费主义到自给自足"的转变——游戏初期你依赖搜刮(消费社会的残余)，但食物会腐烂、资源会耗尽，你必须学会**自己种粮食、收集雨水、发电**。这不是数值优化——是一个文明崩塌后的真实适应过程。

与**Kenshi**(同样废土——弱肉强食的交易经济)和**Elona**(极端自由的物品经济)不同，PZ选择的是"无经济"——末日之后不需要金钱。
