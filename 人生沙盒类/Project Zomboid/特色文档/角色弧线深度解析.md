# 角色弧线深度解析 — Project Zomboid

> 游戏版本: Build 41+ | Steam EA
> 数据来源: [Steam](https://store.steampowered.com/app/108600/), [Wikipedia](https://en.wikipedia.org/?curid=32162755)

---

## 一、"主角"——你创建的任何角色都是"死者"

### 1.1 开场白即结局

"This is how you died."——游戏在角色创建前就告诉你：你创建的这个角色会死。每一次角色创建都是**一次"最后时光"的定义**。

### 1.2 弧线=从"活着"到"怎么死"

| 阶段 | 状态 |
|:--:|------|
| 起点 | 普通幸存者——恐慌、无技能、手无寸铁 |
| 挣扎 | 学习技能、建立基地、储备物资 |
| 巅峰 | 自给自足——有车、有基地、有充足储备 |
| 终结 | 一次疏忽→被咬→感染→死亡(或老死/意外) |

---

## 二、"属性"——技能即角色

PZ没有等级/经验条——角色的全部定义=13+技能的当前等级+当前Moodles状态。一个角色不是"Lv.50战士"，而是"木工6级、烹饪3级、恐慌中、饥饿中"。

---

## 三、魅力——没有英雄，只有幸存者

| 魅力来源 | 体现 |
|------|------|
| 普通人的史诗 | 不是天选之人——只是一个在末日中多活了几个月/几年的普通人 |
| 每一道伤疤都有故事 | 抓伤/裂伤→幸存→伤疤留下→身体叙事 |
| "这是我的基地" | 亲手建造的基地=最深的情感连接 |
| 死亡时的悲壮 | 每个角色的死亡都是一个小故事——可能是英勇的，可能是愚蠢的 |

---

## 四、关键角色——无NPC阶段

(注: Build 43将引入人类NPC, 目前Build 42仅有动物NPC)

当前阶段PZ**没有人类NPC**——你是孤独的(单机模式)。这反而强化了"末世孤独感"——整个世界只有你和丧尸(以及后来的动物)。

---

## 五、反派——丧尸不是反派，是"自然力"

丧尸没有意识、没有动机——它们不是"恶"，它们是**环境的一部分**。真正的"对手"是饥饿/口渴/疾病/冬天/孤独——是"活着本身"。

---

## 六、角色关系网络——单机=你与世界

```
        你(角色)
        ╱  ╲
       ╱    ╲
   基地/物资  丧尸(环境)
  (你的遗产)  (你的终结者)
```

---

## 七、设计启示

1. **"已知会死"的角色创造是PZ最独特的设计**——不是"打造英雄"，而是"定义这个人的最后时光"。
2. **技能=角色**设计让每个角色独一无二——没有人有相同的技能组合和经历。
3. **多角色在同一世界的"接力"**——死亡不是结束，你的下一个角色继承基地和物资——这创造了超越单一角色的"家族/文明传承"叙事。
