# 团队与开发历程 — Project Zomboid

> 开发商: The Indie Stone (英国/加拿大)
> 发行: The Indie Stone (自发行)
> 年份: 2011年Alpha / 2013年Steam EA至今
> 团队: 小团队(具体人数待确认)

---

## 1. 开发团队

The Indie Stone——英国独立工作室(部分成员位于加拿大)。以Project Zomboid这一款游戏持续开发超过12年而闻名。

---

## 2. 开发历程——12年EA传奇

| 时间 | 事件 |
|------|------|
| 2011 | Alpha版发布(Desura平台) |
| 2013 | Steam Early Access上线 |
| 2013-2021 | Build 25-41: 车辆/天气/多人/动画重制 |
| 2021 | Build 41稳定版——成为最受好评的Steam游戏之一 |
| 2024-2025 | Build 42 Unstable——动物NPC+制作重制+地下室 |
| 计划中 | Build 43——人类NPC |

### 2.1 被盗事件

2011年，开发者的公寓被盗——两台笔记本电脑(含游戏代码)被偷。幸运的是有备份，但导致了数周进度丢失。

### 2.2 12年EA的可持续性

The Indie Stone通过持续更新维持收入——每次大型Build更新带来新一波销量。这是一个独立游戏"不急于完成"的范本——相信只要持续做好产品，玩家会持续支持。

## 4. 设计启示

PZ是"EA不是借口"的终极证明——12年EA不是"做不完"，而是"持续进化"。每次Build都是实质性的系统重做或新增(动画→多人→动物→人类NPC)。这种"用时间换深度"的模式在高竞争的独立游戏市场中创造了一个独特的利基。
