# 角色弧线深度解析 — Cultist Simulator

> 游戏版本: v1.0+ | Steam, 2018
> 数据来源: [Wikipedia](https://en.wikipedia.org/wiki/Cultist_Simulator), [Game Developer](https://www.gamedeveloper.com/), [GameFAQs](https://gamefaqs.gamespot.com/)

---

## 一、"主角"——空白秘术师

### 1.1 主角类型: 极致空白——"你"就是那个追求飞升的人

密教模拟器的主角是**品类中最空白的**——没有姓名、没有外观、没有背景故事（仅有三种起始职业的轻微差异）。你是**一个追逐隐秘知识的秘术师**——仅此而已。

### 1.2 "空白"的设计意图

| 设计选择 | 原因 |
|------|------|
| 无姓名/外观 | "你"可以是任何人——追求飞升的欲望是普遍的 |
| 三种起始职业 | Aspirant(有志者)/Physician(医生)/Bright Young Thing(名流)——仅决定初始资源分配 |
| 无角色面板 | 你的"属性"是桌上的卡牌(Health/Reason/Passion)——不是面板中的数字 |

### 1.3 弧线——从凡人到长生者

| 阶段 | 状态 | 性相等级 |
|:--:|------|:--:|
| 起点 | 平凡的凡人——只想赚钱活下去 | Lore Lv0 |
| 觉醒 | 第一次进入漫宿(Wood)→理解了"还有另一个世界" | Lore Lv2-4 |
| 深入 | 建立教派→攀登White Door→Stag Door | Lore Lv6-10 |
| 蜕变 | 穿越孔雀门→获取最高知识→准备飞升 | Lore Lv12-14 |
| 飞升 | 打开Tricuspid Gate→成为Long(长生者) | 飞升成功 |

## 二、"属性"——桌上的卡牌就是你的全部

| 卡牌=属性 | 功能 | 失去后果 |
|------|------|------|
| Health | 体力+生存 | 归零=死亡 |
| Reason | 理性+研究 | 归零=无法学习 |
| Passion | 激情+创造 | 归零=创意枯竭 |
| Funds | 金钱 | 归零=饥饿 |
| Lore等级 | 对宇宙的理解 | 越高越接近飞升 |
| 追随者 | 你的力量延伸 | 没有他们很难生存 |
| Notoriety/Dread/Fascination | 你的"社会负担"和"精神负担" | 积累→死亡 |

## 三、魅力——"读一本书"的沉浸

| 魅力来源 | 体现 |
|------|------|
| **Kennedy的文笔** | "让最普通的句子也变得有趣"——卡牌描述=微型文学 |
| **发现的喜悦** | "我自己发现了这个规则"——无教程=每一次理解都是胜利 |
| **宇宙的深邃感** | 九大性相+司辰+漫宿——构建了一个**可信的隐秘世界** |
| **飞升的庄严** | "我穿过了孔雀门……我理解了宇宙的法则" |
| **卡牌的触感** | 拖拽、排列、计时器的滴答——卡牌让抽象概念有了**物理感** |

## 四、关键角色——追随者与赞助人

21名追随者不是"名字列表"——是**桌上的卡牌**。每张卡牌有名字、有描述、有性相图标。你"看"一张追随者卡——"她叫Rose，Edge 5, Lantern 2"——这就是你知道的全部。但这就是**足够**的。Rose不是你的朋友——她是你的**工具**。

赞助人(Patrons)=Quest giver——在密教模拟器的世界中，他们不是"帮助你的好人"——他们是**利用你的神秘人物**。

## 五、反派——猎人、自己的心智、以及"世界的冷漠"

| 反派 | 本质 |
|------|------|
| 猎人 | "正常社会"对秘教的自然反应——你不是英雄，你是罪犯 |
| Dread/Fascination | **你自己的心智**是最大的敌人 |
| 竞争对手 | 他们也在追求飞升——谁先到谁赢 |
| 世界的冷漠 | 没有人会帮你——飞升是你一个人的路 |

## 七、设计启示

1. **"空白主角+卡牌=属性"是人生沙盒中最极致的简化**——你不是在"扮演"一个角色——你的卡牌**就是**你的角色。没有面板=你的状态在桌上完全可见。
2. **"飞升"是品类中最清晰的终极目标**——不是"活得好"(模拟人生)、不是"变强"(鬼谷八荒)——是**"超越人类"**。这个目标让一切日常挣扎(赚钱/学习/招募)都有了叙事意义。
3. **"Dread/Fascination双极"是对"理智"最精妙的设计**——不是线性衰退，而是两种对立力量的微妙平衡。你同时需要恐惧和痴迷——但任何一方的过剩都会杀死你。
