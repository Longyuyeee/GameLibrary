## 二、收入来源(游戏内)

| 方式 | 说明 |
|------|------|
| Glover & Glover工作 | 稳定白领收入 |
| 绘画(Painting) | 最灵活的早期收入 |
| 体力劳动 | Health→Work→Funds |
| 赞助人任务 | Patrons委托→高额奖励 |

## 三、生存成本

Time动词自动消耗Funds(每秒1张)——持续的收入压力。
