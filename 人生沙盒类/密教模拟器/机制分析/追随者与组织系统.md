## 一、招募追随者

### 1.1 招募方式

| 方式 | 说明 |
|------|------|
| Talk+任意Lore | 谈论隐秘知识→吸引感兴趣的人 |
| 21名追随者 | 有名字、有背景、有性相 |
| 5名赞助人(Patrons) | 特殊角色——提供任务和奖励 |

### 1.2 追随者升级链

| 等级 | 性相强度 | 升级条件 |
|:--:|:--:|------|
| Believer(信徒) | 基础(性相2) | 初始招募 |
| Disciple(门徒) | 中级(性相5) | 需要教派性相≥7 |
| Exalted(升华) | 最强(性相10) | 最高升级 |

---

## 二、教派(Cult)建立

### 2.1 建立教派

| 要素 | 说明 |
|------|------|
| 建立方式 | Talk+Cult卡 |
| 选择教派性相 | 决定你的教派专长——影响追随者升级效率 |
| **推荐教派性相** | Forge(探险最强)、Lantern/Grail(平衡)、Moth(最易升级追随者) |

### 2.2 教派性相的影响

| 教派性相 | 优势 |
|:--:|------|
| Forge | 探险清理障碍最强 |
| Lantern | 知识获取加速 |
| Grail | 追随者招募/魅力 |
| Moth | 追随者最易升级→最快达到Disciple |

## 三、追随者用途

| 用途 | 说明 |
|------|------|
| 探险(Expeditions) | 派遣去Vault获取高级书籍/工具 |
| 消灭证据 | Moth追随者→销毁Evidence |
| 减少恶名 | Heart追随者→降低Notoriety |
| 战斗 | Edge追随者→消灭猎人 |
| 仪式 | 作为仪式材料(囚犯/献祭) |
| 赞助人任务 | 完成Patrons委托→获得稀有奖励 |

## 五、设计特点

密教模拟器的追随者系统是"卡牌式RPG队伍"——21名追随者不是管理面板中的名字，而是**桌上的卡牌**。每一张卡牌上有性相图标(告诉你这个人擅长什么)和文字描述(告诉你这个人是谁)。你"看"一张追随者卡——Edge 5+Lantern 2——"这个人善于战斗，也有些知识"。无需面板、无需属性表——性相即一切。

与CK3(家族/宫廷的政治关系网)和RimWorld(每个殖民者的深度心理模拟)相比，密教模拟器的追随者是**最简约但有深度的NPC系统**——几张卡牌+几个性相图标=一个有名字、有能力、有用的"人"。
