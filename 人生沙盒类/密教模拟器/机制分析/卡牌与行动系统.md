## 一、"一切皆卡牌"——品类中最独特的设计

### 1.1 卡牌即世界

密教模拟器的核心设计哲学：**游戏中一切实体都是卡牌**——不是"界面元素"，而是**卡牌=世界中的事物**。

| 卡牌类型 | 代表什么 | 示例 |
|------|------|------|
| 属性卡(Stats) | 你的身体/心智 | Health/Reason/Passion |
| 知识卡(Lore) | 隐秘的奥秘 | Lantern 2→Lantern 14 |
| 人物卡(Followers) | 教派成员 | Believer→Disciple→Exalted |
| 书籍卡(Books) | 可读的文献 | 各种神秘学书籍 |
| 工具/材料卡 | 仪式用品 | 各种法器/祭品 |
| 影响卡(Influences) | 来自漫宿的临时力量 | 各种Buff/效果 |
| 仪式卡(Rites) | 可执行的仪式 | 召唤/飞升 |
| 资金卡(Funds) | 金钱 | — |
| 动词卡(Verbs) | **你的行动本身** | Work/Study/Dream/Explore/Talk |

## 二、动词系统(Verbs)——你的双手

游戏通过**5个动词槽**与世界互动——这是你唯一能做的事：

| 动词 | 图标颜色 | 功能 | 关键用途 |
|------|:--:|------|------|
| **Work** | 蓝 | 赚钱/绘画/执行仪式 | 生存基础+仪式执行 |
| **Study** | 黄 | 读书/升级知识/提升属性 | 知识获取——"瓶颈动词" |
| **Talk** | 红 | 招募追随者/咨询赞助人/教派事务 | 建立组织 |
| **Explore** | 紫 | 派遣探险队/买卖商店 | 获取高级书籍/工具 |
| **Dream** | 白 | 进入漫宿(梦世界)/恢复理智 | 飞升的唯一途径 |

### 2.1 动词的嵌套使用

| 嵌套 | 示例 |
|------|------|
| Work+Health | 体力劳动→获得Funds+可能生成Vitality |
| Work+Passion | 绘画→获得Funds+可能生成Glimmering |
| Work+Reason | 白领工作→稳定收入 |
| Study+Vitality+Reason | 升级Health(消耗Vitality) |
| Study+Lore+Lore | 合并两个相同Lore→升级Lore |
| Talk+Lore | 谈论隐秘知识→吸引追随者 |
| Talk+Cult | 建立教派 |
| Dream+Way card | 进入漫宿 |
| Dream+Funds | 休息→获得Contentment(对抗Dread) |

## 三、"Aspect(性相)"——卡牌的DNA

### 3.1 性相系统

每张卡牌有**性相(Aspect)**——小彩色图标+数字。性相决定了卡牌如何互动：

| 性相 | 值域 | 领域 |
|:--:|:--:|------|
| Lantern(灯) | 2-14 | 知识、光明、荣耀 |
| Forge(铸) | 2-14 | 转变、创造、火焰 |
| Grail(杯) | 2-14 | 欲望、吞噬、诞生 |
| Moth(蛾) | 2-14 | 变化、任性、混沌 |
| Heart(心) | 2-14 | 坚持、生命、舞蹈 |
| Edge(刃) | 2-14 | 冲突、斗争、暴力 |
| Winter(冬) | 2-14 | 终结、死亡、沉默 |
| Knock(启) | 2-14 | 开启、伤口、通道 |
| Secret Histories(秘史) | 2-14 | 隐秘知识、平行历史 |

### 3.2 性相的逻辑

| 操作 | 说明 |
|------|------|
| **Subversion(颠覆)** | 某些Lore可转化为其他Lore(如Edge→Knock) |
| **Upgrade(升级)** | 相同Lore+Lore+Erudition/Glimmering=更高级Lore |
| **Matching(匹配)** | 许多操作需要"性相≥N"——如White Door需要4 Lantern或4 Knock |

## 四、卡牌计时器——一切都会消逝

| 计时器类型 | 说明 |
|------|------|
| 卡牌自然消失 | Influences和部分卡牌有倒计时→到期消失 |
| 暂停计时器 | Painting(Work+卡牌)/与Sulochana对话/手动按住 |
| Funds消耗 | Time动词自动消耗Funds(每秒1张) |

## 五、设计特点分析

密教模拟器的卡牌系统是**游戏UI史上最彻底的"去UI化"**——没有面板、没有数值条、没有任务日志。一切信息都在卡牌的性相图标中。你"看"一张Followers卡——上面有Edge 5、Lantern 2——你知道"这个人擅长战斗、有一些知识"——不需要任何文字面板。

这创造了一种独特的"阅读"体验——不是读文字，而是**读卡牌上的性相组合**。Expert玩家可以在几秒内扫描桌上的卡牌分布判断当前状态——比任何传统UI都高效。这就像**塔罗牌占卜**——每张牌都承载着多重含义。

与**RimWorld**(复杂UI面板)、**太吾绘卷**(属性表)、**CK3**(角色面板)相比——密教模拟器的信息呈现是**最诗意的**——也是最不透明的。
