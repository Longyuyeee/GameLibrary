## 一、时间季节系统——定时威胁

Time动词自动触发四种"季节"——每个季节消耗特定类型的负面卡牌：

| 季节 | 消耗什么 | 归零=死亡 |
|------|------|------|
| **Suspicion(嫌疑)** | Notoriety(恶名)→Evidence(证据)→审判→处决 | 被逮捕 |
| **Despair(绝望)** | Dread(恐惧)——3次Dread未被消耗=绝望死亡 | 精神崩溃 |
| **Visions(幻象)** | Fascination(痴迷)——3次Fascination未消耗=疯狂死亡 | 精神失控 |
| **Affliction(病痛)** | Illness/Sickness(疾病)——未恢复=健康下降 | 病死 |
| **Rags(贫困)** | 偿还Poppy Lascelles的债务(如果你接受过她的帮助) | 破产 |

## 二、三大内在威胁——"你的心智是最大的敌人"

### 2.1 Dread(恐惧)→Despair(绝望)→死亡

| 阶段 | 说明 | 应对 |
|:--:|------|------|
| Dread产生 | 工作失败/漫宿遭遇/卡牌效果 | Dream+Funds=Contentment(满足感)抵消 |
| 3 Dread未被消耗 | Despair季节吞噬→一次抵消一个Dread | Painting可转化Dread |
| Despair耗尽 | 没有Dread可被吞噬→**死亡** | 必须有≥3 Dread储备让Despair消耗 |

### 2.2 Fascination(痴迷)→Visions(幻象)→死亡

| 阶段 | 说明 | 应对 |
|:--:|------|------|
| Fascination产生 | 过度研究/漫宿深处 | 与Dread同归于尽(互消)/Rites消耗 |
| 3 Fascination未消耗 | Visions季节吞噬 | 需要≥3 Fascination储备 |
| Visions耗尽 | 没有Fascination可被吞噬→**死亡** | — |

### 2.3 Dread与Fascination的微妙平衡

**Dread和Fascination可以互消**——但你必须刚好同时拥有两者。这是游戏最精妙的威胁管理——你需要维持"刚好够恐惧、刚好够痴迷"的微妙精神状态。太少=季节来临时被吞噬死。太多=溢出无法控制。

## 三、外部威胁——猎人与法律

### 3.1 Notoriety(恶名)→Evidence(证据)→审判

| 阶段 | 说明 |
|:--:|------|
| Notoriety产生 | 进行可疑活动→自动生成(卡牌) |
| Evidence产生 | Hunter(猎人)将Notoriety转化为Evidence |
| 审判 | Evidence积累→审判→有罪→**游戏结束**(被处决) |

### 3.2 三类猎人

| 猎人类型 | 特点 | 应对策略 |
|------|------|------|
| **Erratic(不稳定)** | 最危险——行为不可预测 | **优先消灭** |
| **Methodical(有条理)** | 按部就班——可预测节奏 | 可控——在间隙中操作 |
| **Tenacious(执着)** | 不放弃——持续追踪 | 可下毒(Poison) |

### 3.3 应对猎人

| 方式 | 说明 |
|------|------|
| Moth追随者 | 毁掉Evidence |
| Heart追随者 | 减少Notoriety |
| Edge追随者 | 直接消灭猎人 |
| 拖延 | 卡牌计时器过→Evidence自然消失 |

## 四、设计特点分析

### 4.1 "Dread vs Fascination=理智的两极"

这是密教模拟器最独特的设计——不是"san值低=疯狂"，而是**恐惧和痴迷是两种对立的危险**，需要你维持微妙的平衡。太多Dread=绝望而死，太多Fascination=疯狂而死——但Dread可以杀死Fascination（反之亦然）。这种"双向威胁+互消"的设计是游戏史上最精妙的理智系统之一。

### 4.2 "猎人=世界的正常反应"

猎人不只是游戏机制——他们是"正常社会"对你的秘教活动的自然反应。你的Notoriety越高=你在社会的雷达上越明显。这是对"隐秘知识"主题的完美游戏化——你必须**在地下运作**，不能太张扬。

### 4.3 与品类内对比

| 游戏 | 威胁/生存系统 |
|------|------|
| 密教模拟器 | Dread/Fascination双极平衡+猎人/证据/审判 |
| Project Zomboid | 丧尸+饥饿+疾病+心理Moodles |
| RimWorld | AI叙事者驱动的随机事件+袭击 |
| CK3 | 阴谋/战争/疾病/继承危机 |

密教模拟器的威胁系统是**最内向的**——最大的敌人不是外部(猎人只是背景噪音)，而是**你自己的心智**(Dread vs Fascination)。这是对"追求隐秘知识会让人疯狂"的完美游戏化。
