# 团队与开发历程 — Dwarf Fortress

> 开发商: Bay 12 Games (美国)
> 发行商: Kitfox Games (Steam版)
> 年份: 2002年起开发 / 2006年首次发布 / 2022年Steam发行
> 团队: 2人(Tarn + Zach Adams兄弟)

---

## 1. 开发团队——史上最小的传奇

| 成员 | 角色 |
|------|------|
| **Tarn Adams** (Toady One) | 全部程序+全部设计 |
| **Zach Adams** (ThreeToe) | 全部叙事+社区管理 |

两人是兄弟。Tarn有斯坦福数学博士学位。Zach负责设计方向。23年来没有第三个核心开发者。

---

## 2. 开发历程

| 时间 | 事件 |
|------|------|
| 2002 | Tarn开始业余开发 |
| 2006 | 首次公开发布(免费ASCII版) |
| 2006-2022 | 持续16年免费更新——靠捐款($15K/月)维生 |
| 2019 | Kitfox Games接触→Steam合作 |
| 2022.12.6 | Steam版发布——首日16万份 |
| 2022-2024 | 收入从$15K/月→$7M+(两个月) |
| 2024.4 | 冒险模式Steam Beta |
| 2025.4 | Steam销量突破100万份 |

### 2.1 捐款模式=独立游戏最纯粹的可持续发展

16年间，Bay 12 Games完全靠玩家自愿捐款维持。Tarn和Zach过着极简的生活——Tarn用"买了一辆本田思域"来庆祝Steam成功。

### 2.2 Steam=从地下到主流

Kitfox Games帮助DF从"ASCII地下传奇"变为"有图形的商业成功"。Steam版加入了像素图形、鼠标操作、教程——让这个史上最深游戏真正可接触。

---

## 3. 创意哲学

Tarn Adams的核心信念：**"模拟一切"**。不是"做有趣的游戏系统"——是"模拟世界如何运作"。地质→气候→生物→文明→历史→个人——层层模拟。如果模拟够深，游戏性自会涌现。

## 5. 设计启示

DF是"独立游戏可以改变世界"的终极证明。2个人×23年×$15K/月捐款→启发了Minecraft/RimWorld/整个生存沙盒品类。这不是商业策略的成功——是**艺术执着的胜利**。
