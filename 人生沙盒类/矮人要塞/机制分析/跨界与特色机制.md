# 跨界与特色机制 — Dwarf Fortress

> 游戏版本: v50+ | Steam, 2022
> 数据来源: [DF Wiki](https://new.dwarffortresswiki.org/), [PC Gamer](https://www.pcgamer.com/), [Ars Technica](https://arstechnica.com)

---

## 一、"最深模拟"——任何品类都无可匹敌

DF是游戏史上最深、最复杂的模拟——没有之一。它不是"一个类型的游戏"——是**多项世界纪录的保持者**：

| 记录 | 说明 |
|------|------|
| 最精细身体模拟 | 每根手指/脚趾/器官/神经/动脉独立 |
| 最深世界历史 | 250年生成历史(文明/战争/神器/家族) |
| 最长持续开发 | 23年+(2002至今)单人主导 |
| 最小团队创造最大影响 | 2人→启发了Minecraft/RimWorld/整个生存沙盒品类 |

---

## 二、核心特色

### 2.1 "模拟优先"哲学

Tarn Adams的核心理念：**不是设计游戏机制——是模拟现实。如果模拟得足够深，游戏性会自然涌现。** 这与传统游戏设计(先设计玩法→后添加模拟)完全相反。

### 2.2 三模式互通

要塞(殖民地管理)+冒险(单人RPG)+传奇(历史浏览)——三个模式共享同一个世界。世界上没有"模式边界"——你在要塞里打造的铠甲可以在冒险模式中穿上。

### 2.3 社区影响——启发了整个品类

| 被DF启发的游戏 | 说明 |
|------|------|
| Minecraft | Notch公开承认DF是主要灵感来源 |
| RimWorld | "DF启发了我们想做的一切" |
| Prison Architect | 借鉴了DF的UI概念 |
| 整个生存沙盒品类 | "涌现性叙事"的概念源头 |

---

## 三、设计启示

1. **"模拟优先"vs"玩法优先"**——DF证明了"先模拟深度，玩法自会涌现"的可行性(但只适用于有耐心的创作者)。
2. **23年单人开发=持续深度的力量**——Tarn没有"做完一个游戏做下一个"，而是"持续加深同一个游戏"。这在商业上不可行但在艺术上是正确的。
3. **DF=游戏作为"世界生成器"而非"关卡编辑器"**——这是对"游戏是什么"的根本性重新定义。
