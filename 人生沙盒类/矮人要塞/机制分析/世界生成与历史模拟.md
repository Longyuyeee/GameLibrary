# 世界生成与历史模拟 — Dwarf Fortress

## 一、世界生成——不是"地图"，是"宇宙"

### 1.1 生成的维度

| 生成层 | 内容 |
|------|------|
| **地质** | 200+种岩石/矿物类型——按真实地质环境分布 |
| **气候** | 动态天气模型——风/湿度/气流→锋面/云/暴风雪/暴风雨 |
| **水文** | 河流/湖泊/海洋/地下含水层 |
| **生物圈** | 数百种动物和怪物——许多是每个世界随机生成的 |
| **文明** | 矮人/人类/精灵/地精等多个种族——各有文化/语言 |
| **文化** | 诗歌/音乐形式/乐器/舞蹈——全部程序生成 |
| **语言** | 每种文明有生成的语言(词汇/语法) |

### 1.2 历史模拟——你玩之前世界已经活了250年

| 历史要素 | 模拟内容 |
|------|------|
| 文明兴衰 | 城市建立→繁荣→战争→覆灭 |
| 神器和遗物 | 116+件——谁创造、谁使用、最后一次传世 |
| 历史人物 | 英雄/国王/恶棍——有完整生平 |
| 战争/迁徙 | 种族间战争、大规模移民 |
| 知识传播 | 亡灵术等禁忌知识的扩散路径 |
| 家族谱系 | 数百年间的家族关系 |

## 二、"传奇模式"——可浏览的世界历史

传奇模式(Legends Mode)是一个超链接历史浏览器：
- 追踪一件神器800年来的每一位持有者
- 查看一座城市从建立到被龙毁灭的全部历史
- 追溯你的矮人的祖先谱系

## 三、世界演化——游戏进行中

| 演化维度 | 说明 |
|------|------|
| 军队物理移动 | 敌军**真的**在你世界地图上行军→可在途中拦截 |
| 时间流速差异 | 要塞模式(月/年)、冒险模式(单日极长) |
| 退休/继承 | 退休一个要塞→世界继续运行→退休的要塞成为新冒险者的探索地 |

---

## 四、设计特点

DF的世界生成不是"做一个好玩的地图"——是**"模拟现实"**。Tarn Adams的哲学是：如果模拟得足够深，游戏性自然涌现。每一块岩石的类型、每一场暴风雪的形成、每一个历史人物的命运——都是系统模拟的结果，而非设计师的编排。

与**RimWorld**(AI叙事驱动但世界不持久)、**CK3**(历史设定但固定地图)、**Elona**(随机但浅层世界)相比，DF的世界是**唯一真正"模拟了一个宇宙"**的游戏。
