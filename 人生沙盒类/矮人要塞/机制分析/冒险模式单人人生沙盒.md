# 冒险模式——单人人生沙盒 — Dwarf Fortress

## 一、冒险模式=DF的"单人人生沙盒"

冒险模式将DF从殖民地管理游戏变为**回合制开放世界RPG**。你在生成的世界中扮演一个人物，自由决定去哪里、做什么。

| 可做的事 | 说明 |
|------|------|
| 探索世界 | 访问任何生成的城市/洞穴/遗迹 |
| 接受任务 | 杀死怪物/拯救村民/寻找神器 |
| 招募同伴 | 组建冒险队伍(含坐骑/宠物) |
| 战斗 | 简单模式(走进敌人→自动战斗)或战术模式(精控每个动作) |
| 对话 | 与NPC进行深度对话树——可吟诗/传谣/指控 |
| 建造 | 可建小屋(待实装) |

---

## 二、三模式互通——独一无二

| 互通方式 | 说明 |
|------|------|
| 要塞→冒险 | 要塞打造的武器/盔甲→冒险者来取 |
| 冒险→要塞 | 冒险者从亡灵塔取回禁书→放入要塞图书馆 |
| 退休/继承 | 退休一个要塞→世界继续→退休要塞=新冒险地的地下城 |
| 亡灵复活 | 亡灵法师冒险者可复活死去的冒险者→控制他们继续玩 |

---

## 三、NPC互动

| 互动类型 | 说明 |
|------|------|
| 对话树 | 深度对话——可交换信息/请求帮助/吟诗/传谣 |
| 生成式对话 | 地精讲笑话、夸对方衣服好看——由AI系统动态生成 |
| 知识限制 | NPC只知道"模拟中他们应该知道的事" |
| 吟诗/音乐 | 可在酒馆吟诗——展现生成的文化/诗歌/音乐 |

---

## 四、设计特点

冒险模式的核心是**"在一个真正活着的世界里扮演一个人"**。大多数RPG的世界是"为你设计的"——DF的世界是"为自己运行的"——你只是恰好生活在其中。当你杀死一个哥布林时，他不是"刷出来的敌人"——他是世界历史中某个哥布林文明的成员，有家谱、有个人历史。这个设计哲学让它成为人生沙盒品类的**终极边界**——"模拟的人生"。
