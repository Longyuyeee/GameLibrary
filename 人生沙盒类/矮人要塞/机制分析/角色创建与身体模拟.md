# 角色创建与身体模拟 — Dwarf Fortress

> 游戏版本: v50+ (Steam版) | 2002年起开发
> 数据来源: [DF Wiki](https://new.dwarffortresswiki.org/), [Polygon](https://www.polygon.com/24132899/dwarf-fortress-adventure-mode-beta-announcement-release-date-price), [Game Rant](https://gamerant.com/dwarf-fortress-adventure-mode-preview/)

## 一、角色创建——你扮演世界中"已存在的人"

### 1.1 不是创建，是"选择"

与大多数RPG不同——DF的冒险模式中，你**不是凭空创造角色**，而是从世界模拟中**选一个已经存在的人**。这个人已经有：家族谱系、社会关系、个人历史(在传奇模式中可追溯)。

| 创建/选择要素 | 说明 |
|------|------|
| 种族 | 矮人/人类/精灵/地精等(可通过征服解锁更多) |
| 背景 | 决定初始技能/关系/任务 |
| 属性/技能 | 数百种——记忆/社交意识/音乐感/咬合力... |
| 装备/坐骑/宠物 | 共享点数预算——选择装备还是宠物 |

### 1.2 像素化肖像

Steam版新增：角色有像素肖像——反映描述、伤口、服装、发型、遗传特征。

## 二、身体模拟——史上最深

### 2.1 每一根手指都是独立实体

| 身体层级 | 模拟内容 |
|------|------|
| 皮肤 | 可被划伤/烧伤/擦伤 |
| 脂肪层 | 可被穿透 |
| 肌肉 | 可被撕裂 |
| 骨骼 | 每根手指/脚趾/肋骨独立——可骨折 |
| 器官 | 心脏/肺/肝/肠/眼——每个独立可被损伤 |
| 神经 | 可被切断→对应部位瘫痪 |
| 血管/动脉 | 可被割断→流血致死 |

### 2.2 战斗="外科手术级"

| 战斗动作 | 可能效果 |
|------|------|
| 砍断手指 | 无法握武器 |
| 刺穿肺 | 窒息 |
| 切开动脉 | 流血致死 |
| 打碎头骨 | 脑损伤 |
| **抓住肠子** | **可丢向另一个敌人** |

这是游戏史上最精细的身体模拟——没有任何其他游戏能做到"你在战斗中被打掉三根手指，从此永远无法完整握剑"。

## 三、心理模拟

| 心理维度 | 说明 |
|------|------|
| 记忆系统 | 每个角色记住自己经历的事件 |
| 情绪状态 | 恐惧/愤怒/悲伤/快乐——由记忆和当前事件触发 |
| 人格特质 | 生成的角色有个性——影响行为和决策 |
| 压力/创伤 | 看到尸体/朋友死亡→长期精神影响 |

---

## 四、设计特点

DF的角色系统是"模拟优先"哲学的终极体现——不是"设计有趣的游戏角色"，而是**"模拟一个有完整身体和心理的人"**。如果模拟够深，有趣的故事自然涌现。这个哲学直接启发了RimWorld的AI叙事系统。
