- “代表性”“主要”“推测”“约数”和“需数据挖掘”均属于未完成证据，不能被导航整改掩盖。
- 所有文档必须从 README、品类索引、游戏概览和相邻文档连续可达。
- 《符文工房3》全部通过后，才能进入 README 中的下一款《符文工房4》。
