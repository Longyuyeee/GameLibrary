# 水系统与地形改造 — Timberborn

> 游戏版本: Timberborn v1.0 | PC/Steam
> 数据来源: [Mechanistry开发者深度解析](https://www.gamedeveloper.com/marketing/deep-dive-how-we-got-one-million-players-to-give-a-dam-about-timberborn), [社区指南](https://game.dazepuzzle.com/ultimate-timberborn-tips-and-tricks-guide/), [官方更新日志](https://store.steampowered.com/news/app/1062090)

## 一、系统概述

Timberborn的核心系统是城市建设品类中**最先进的流体物理模拟**——水不是"数值资源"，而是**有体积、有流向、会蒸发、受重力影响的物理实体**。与其他城建游戏的水系统相比（天际线：水=污染范围圈；纪元1800：水=地图边界；冰汽时代：无液态水），Timberborn的水系统是**玩法本身**——城市的生存、扩张、繁荣全部建立在你如何设计水坝、水库、灌溉渠和防洪系统之上。

## 二、水的物理模拟

### 2.1 核心规则

| 规则 | 游戏表现 |
|------|------|
| **重力流动** | 水从高流向低——填满低洼盆地直到溢出最低边缘 |
| **蒸发** | 水面积越大→蒸发越快。浅宽水库蒸发损失大，深窄水库保存更好 |
| **水源** | 地图边缘有"水源方块"持续产水（模拟河流源头） |
| **干旱** | 每约15天周期——水源停止产水，河流完全枯竭 |
| **3D水(Update 6)** | 水可以流**过**建筑、流**入**水下隧道、流过空中水渠 |

### 2.2 水利工程——核心玩法

| 结构 | 功能 | 限制 |
|------|------|------|
| **水坝** (Dam) | 部分挡水（顶部溢流），不堆叠 | 早期廉价方案 |
| **堤坝** (Levee) | **完全挡水**，可堆叠，上面可建建筑 | 核心水利工程材料 |
| **水闸** (Floodgate) | 可调高度(0.5格增量)，动态控制水位 | 精细调控必备 |
| **闸门** (Sluice, U6) | **自动化**水闸——可按设定条件开关 | 终局自动化核心 |
| **不渗水地板** (U6) | 防止水渗透——创造人工水道/水渠 | — |

## 三、干旱与恶水——"水的敌人"

### 3.1 干旱 (Drought)

| 维度 | 数据 |
|------|------|
| 触发周期 | 约15-20天(随难度) |
| 持续时间 | **逐渐延长**（首次3天→后期30天+） |
| 效果 | 所有水源停止产水→河流完全干涸→作物枯萎 |
| 生存要求 | 水库中有足够储水撑过干旱期 |

### 3.2 恶水 (Badtide, Update 5)

| 维度 | 数据 |
|------|------|
| 触发周期 | 与干旱轮换 |
| 效果 | 水源产出**毒水**而非清水——毒水污染作物、伤害海狸 |
| 应对策略 | **分流系统**——用堤坝+水闸创建独立的恶水排泄通道 |
| 核心教训 | **不能只堵死水源**——恶水需要一个出口流走 |

## 四、灌溉——"水延伸到的地方"

水不只用于饮水——它通过**灌溉半径**影响周围的农田和植物：
- 水域周边的土地自动获得"灌溉"状态→适合种植作物
- 干旱期间→河流枯竭→灌溉半径消失→作物枯死
- 需要用**灌溉塔**(Irrigation Tower)或水渠将储水分配到干旱区域

**设计意图**：灌溉系统使"水的空间分布"成为城市规划的核心约束——你的农田必须紧邻水源或灌溉设施。这比"画一块农业区"更深入地将水物理集成到城市形态中。

## 五、地形改造

### 5.1 炸药与地形

游戏中有**炸药**可以炸开地面——创造新河床、扩宽水库、开凿运河。这在城建品类中是极其罕见的——玩家可以**改变地形本身**而非仅在现有地形上建造。

## 六、设计特点分析

### 6.1 "水即地图"——城建品类中唯一的流体物理核心

在所有城市建造游戏中，Timberborn独一无二地将**流体物理本身**作为核心玩法。都市天际线有水但只是"污染传输介质"；纪元1800有水但只是"地图边界"；冰汽时代没有液态水。只有Timberborn将水变成了**你必须亲手工程化的物理实体**。

**与Factorio对比**：Factorio用传送带运输固体物品；Timberborn用堤坝和水闸"运输"和"储存"的是一种流动的、蒸发的、有毒的流体。两者都要求玩家进行"系统设计"，但Timberborn的介质是不可预测的（蒸发/天气/地形影响）——Factorio的传送带是可预测的数学问题。

### 6.2 干旱——"周期性清零"的压力节奏

每次干旱源头的"停止产水"就像为你的水利系统进行一次"压力测试"——你的水库够不够大？你的灌溉够不够持久？你的食物储备够不够？这种周期性压力测试在城建品类中是独特的——冰汽时代的大暴风雪只有一次（终局），Timberborn的干旱在每次循环中反复测试你的系统弹性。

### 6.3 恶水——"你的防御也可能变成危机"

恶水(badtide)是Timberborn最精巧的设计之一——同样的水坝/水库结构，在干旱时是你的救命稻草，在恶水季却可能变成**囚禁毒水的陷阱**。这迫使玩家设计"双模式"水利系统——既能储水又能排毒。这种"同一基础设施应对相反极端"的工程挑战在城建品类中是唯一的。
