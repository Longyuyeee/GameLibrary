# 垂直建造与派系系统 — Timberborn

> 游戏版本: Timberborn v1.0 | PC/Steam
> 数据来源: [Mechanistry开发日志](https://store.steampowered.com/news/app/1062090), [DazePuzzle指南](https://game.dazepuzzle.com/ultimate-timberborn-tips-and-tricks-guide/), [社区讨论](https://steamcommunity.com/app/1062090/discussions/)

## 一、系统概述

Timberborn的垂直建造系统是城建品类中**唯一的"向上而非向外"的城市扩展模型**。在有限的可灌溉平坦土地上，你必须通过堆叠平台(Platforms)、搭建空中走廊、架设滑索(Zipline)来向**空中**扩展城市。这与都市天际线的"超高层建筑自动生成"或庄园领主的"平面有机蔓延"不同——你是**手动一层一层地搭建垂直结构**。

## 二、平台与垂直建筑

### 2.1 平台(Platform)系统

| 平台类型 | 高度 | 造价 | 功能 |
|------|:--:|------|------|
| 单层平台 | 1格高 | 木材 | 基础——可在上面建建筑 |
| 双层平台 | 2格高 | 更多木材 | 跨越道路/河道 |
| 三层平台 | 3格高 | 大量木材 | 工业区垂直堆叠 |

**关键能力**：
- 平台可以建在**水上**——在水库上方创建"水上城市"
- 道路和动力轴在平台**下方**穿过
- 可以多层重叠——地面层=农业, 平台1=住宅, 平台2=工业

### 2.2 空中走廊与滑索

| 结构 | 功能 |
|------|------|
| 空中走廊 (Overhang, U6) | 悬挑建筑——在悬崖/水面外延伸 |
| 滑索 (Zipline) | 海狸的"快速旅行"——在远距离区域间快速移动 |
| 垂直动力轴 | 将动力从底层传递到高层平台 |

## 三、两大派系——"玩法的两极化"

### 3.1 Folktails（民俗尾巴）——自然和谐

| 维度 | 设计 |
|------|------|
| 主题 | 田园/可持续发展 |
| 繁殖方式 | **传统家庭**——住所容纳2成年+1幼崽(需幸福条件) |
| 能源 | 风力涡轮机——零污染但不可靠(风停=停电) |
| 食物 | 传统农耕——依赖灌溉和季节 |
| 视觉风格 | 田园草屋/木质风车/自然美学 |

### 3.2 Iron Teeth（铁牙）——工业效率

| 维度 | 设计 |
|------|------|
| 主题 | 工业/机械化/赛博朋克 |
| 繁殖方式 | **育种舱**——可手动暂停/加速人口增长 |
| 能源 | 蒸汽引擎——需要持续燃料(木材/坏水) |
| 食物 | 水培农场(Hydroponics)——可在平台上种植，摆脱地面依赖 |
| 视觉风格 | 金属结构/齿轮/烟囱/赛博格海狸 |

### 3.3 派系设计意图

两派不是"好vs坏"——是两种**不同的生存策略**：
- Folktails：被动适应自然→依赖可靠的水利工程
- Iron Teeth：主动征服自然→依赖稳定的燃料供应链

**设计精妙之处**：两派的差异**不是视觉皮肤**——它们改变了核心游戏方式。Iron Teeth的育种舱允许精确的人口控制（暂停/恢复），Folktails的人口随幸福度自然波动。Iron Teeth的水培农场可以在平台上种植→减少地面灌溉依赖，与垂直建造系统深度耦合。

**与Against the Storm对比**：Against the Storm的不同种族是每局的随机组合——不同种族有不同的需求和生产专长。Timberborn的两派是你**开局选择**的——决定了整个游戏的策略路线。

## 四、区域(District)系统

| 功能 | 说明 |
|------|------|
| 区域中心 | 每个区域有一个免费的"区域中心"建筑 |
| 独立经济 | 每个区域有独立的人口/资源/库存 |
| 区域连接 | 通过"区域通道"共享资源和劳动力 |
| 自动平衡 | 区域间自动调配多余资源 |

## 五、设计特点分析

### 5.1 垂直建造——"有限土地的必然解"

Timberborn的垂直建造不是"可选的创意玩法"——是**生存必须**。可灌溉的平坦土地极度稀缺（只有河岸两侧）→你必须向空中扩展。这种"地形稀缺→垂直建造"的因果链是城建品类中最有机的垂直建造驱动力——它不是告诉你"你可以建高层"——是**不建高层你就没地方了**。

### 5.2 双派系——"同一地图，两种量子态"

两派在完全相同的物理规则下，因为**系统耦合方式的差异**而产生了完全不同的最优策略。Folktails需要大片地面农田→依赖灌溉系统；Iron Teeth用水培→把种植搬到平台→解放地面空间。这不是"Folktails比Iron Teeth弱或强"——是两派**优化不同的维度**。
