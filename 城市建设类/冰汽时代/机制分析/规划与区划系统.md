# 规划与区划系统 — 冰汽时代 (Frostpunk)

> 游戏版本: Frostpunk v1.6.1 (含全部DLC) | PC/Steam
> 数据来源: [Frostpunk Wiki](https://frostpunk.fandom.com/wiki/Generator), [Game Developer分析](https://www.gamedeveloper.com/design/frostpunk-an-analysis-of-emotional-narrative-engagement), [社区指南](https://steamcommunity.com/app/323190/guides/)

## 一、系统概述

冰汽时代的规划系统与都市天际线有本质区别——没有"区划"概念，取而代之的是**发电机(Generator)中心辐射式**的建筑布局。所有建筑必须放置在发电机的环形热力区内（或蒸汽枢纽覆盖范围内），否则工人将无法生存。这创造了一种**热力驱动的城市规划逻辑**——城市形态由热效率决定，而非美学或交通。

## 二、发电机——城市的"心脏"

### 2.1 核心参数

| 发电机等级 | 热力等级 | 煤炭消耗(基础) | 技术需求 |
|:--:|:--:|:--:|------|
| Lv1 (基础) | +1 (Lv1) | 6煤/时 (144/天) | 初始 |
| Lv2 | +2 (Lv2) | 9煤/时 | 发电机功率升级I |
| Lv3 | +3 (Lv3) | 12煤/时 | 发电机功率升级II |
| Lv4 (最大) | +4 (Lv4) | 18煤/时 | 发电机功率升级III |

### 2.2 发电机范围 vs 蒸汽枢纽

| 方案 | 煤炭效率 | 覆盖面积 | 灵活性 | 推荐度 |
|------|:--:|:--:|------|:--:|
| 发电机范围升级 | **低**(煤炭消耗上升快) | 单一大圆 | 低(固定圆心) | ❌ 不推荐 |
| 蒸汽枢纽(Steam Hub) | **高**(-33%煤炭效率科技可用) | 多个小圆 | 极高(任意位置放置) | ✅ **强烈推荐** |

> **核心决策**：永远优先使用蒸汽枢纽扩展热力覆盖而非升级发电机范围。发电机范围升级的煤炭效率远低于蒸汽枢纽。

### 2.3 过载(Overdrive)

- 临时提升热力区温度 **+1级**（不消耗额外煤炭）
- 但会增加发电机**应力(Stress)**
- 应力满→发电机爆炸→游戏结束
- 最佳使用时机：夜间(市民都在家时)、暴风雪期间

## 三、温度——城市规划的终极约束

### 3.1 温度等级系统

| 温度等级 | 温度范围 | 与室外的热差 | 健康影响 |
|------|:--:|:--:|------|
| **舒适** (Comfortable) | ≥0°C | +2或以上 | 不会生病 |
| **宜居** (Livable) | -1°C ~ -10°C | +1 | 极低生病风险 |
| **微冷** (Chilly) | -11°C ~ -20°C | 0 | 低生病风险 |
| **寒冷** (Cold) | -21°C ~ -30°C | -1 | 中生病风险 |
| **严寒** (Very Cold) | -31°C ~ -40°C | -2 | 高生病风险+低概率重病 |
| **极寒** (Freezing) | ≤-41°C | -3 | 极高生病风险+截肢风险 |

### 3.2 热力计算公式

```
最终温度等级 = 室外温度修正 + 建筑保温等级 + 发电机/蒸汽枢纽热力等级
```

| 室外温度(每-10°C) | 温度修正 |
|:--:|:--:|
| 0°C ~ -10°C | 0 (基准) |
| -11°C ~ -20°C | 0 |
| -21°C ~ -30°C | -1 |
| -31°C ~ -40°C | -2 |
| -41°C ~ -50°C | -3 |
| ... | ... |
| -150°C (大暴风雪) | 极低(需满保温+过载) |

### 3.3 建筑保温等级

| 建筑类型 | 基础保温 | 升级后保温 |
|------|:--:|:--:|
| 帐篷 (Tent) | +1 | — |
| 工棚 (Bunkhouse) | +2 | +3 (升级后) |
| 房屋 (House) | +3 | +4 (升级后) |
| 医务所 (Medical Post) | +1 | +2 |
| 工作场所(基础) | +1 | +2 |
| 高级建筑 | +2 | +3-4 |

## 四、建筑布局策略——"热力棋盘"

### 4.1 环形布局原则

```
      蒸汽枢纽3
     /    |    \
  建筑  建筑  建筑
     \    |    /
发电机 ---- 蒸汽枢纽1 ---- 蒸汽枢纽2
     /    |    \
  建筑  建筑  建筑
```

- **第一环**（紧贴发电机）：关键全天建筑——医务所、伙房、工坊
- **第二环**（蒸汽枢纽覆盖）：住宅区（市民夜晚在家）
- **第三环**（另设蒸汽枢纽或独立加热器）：工作场所（仅工作时间需要供热）

### 4.2 蒸汽枢纽的两种模式

| 模式 | 供热时段 | 煤炭消耗 | 适用建筑 |
|------|------|:--:|------|
| **24小时** | 全天 | 3-6煤/时 | 住宅区、医务所 |
| **仅工作时间** (8:00-18:00) | 仅白天 | 1.5-3煤/时 | 工作场所 |

> **关键节省策略**：为纯工作区域设置"仅工作时间"蒸汽枢纽可以节省~50%煤炭。

### 4.3 加热器(Heater)

建筑**内部**供热设备——不需要依赖外部热力区覆盖。适用场景：
- 远离蒸汽枢纽的散落工作建筑
- 面积不足以放置独立蒸汽枢纽的区域
- 煤炭充足的后期补充方案

## 五、资源建筑与空间博弈

### 5.1 在"冷"与"产"之间

每个建筑占用的不仅是一个格子——它占用的是**一个热力区内的有限空间**。核心博弈：应该在这个温暖的位置放另一个住宅(容纳更多人口)还是放一个工坊(加速科技)？

### 5.2 空间效率优化

| 策略 | 说明 |
|------|------|
| 紧凑环形布局 | 每个蒸汽枢纽覆盖范围内尽可能多排建筑 |
| "填充"策略 | 在环形布局空隙中塞入小建筑(医务所/伙房) |
| 路网最小化 | 道路占用热力区格子但不产生价值——使用最短路径连接 |
| 二环住宅+一环服务 | 住宅统一放外环(同热力覆盖下占地最多)、核心服务放内环 |

## 六、设计特点分析

### 6.1 "热力=城市边界"——品类独一的设计

在都市天际线中，城市边界的约束是"你买了多少块地"。在纪元1800中，约束是"你占领了多少岛屿"。在冰汽时代中，城市边界的约束是**"你能为多少面积供热"**——这是城市建设品类中最有机、最令人信服的城市边界设计。

每当你扩大城市，你不是在"购买新土地"——你在**承担更多的煤炭消耗承诺**。这种"承诺→责任"的关联让每一次扩张都充满重量感。

**与都市天际线对比**：天际线的城市扩张是财政问题（买地+道路维护），冰汽时代的城市扩张是生存问题（供热覆盖+煤炭消耗）。前者的惩罚是赤字，后者的惩罚是死亡。

### 6.2 环形布局——强制秩序中的策略深度

所有玩家都必须接受"发电机在中心"这个约束——城市必然是圆形的。但在同一规则下，不同策略产生完全不同的城市形态：
- **"密集派"**：极小范围内紧凑排列，追求热效率最大化
- **"分散派"**：多个蒸汽枢纽集群，形成"多核城市"
- **"过渡派"**：早期紧凑→中期加蒸汽枢纽→暴风雪前全城整合

### 6.3 暴风雪的"终极空间测试"

游戏终局的大暴风雪（温度降至-150°C）是对玩家空间规划的终极测试——所有"投机取巧"的布局都会暴露。只有全程考虑供热效率的布局才能让全城在暴风雪中存活。
