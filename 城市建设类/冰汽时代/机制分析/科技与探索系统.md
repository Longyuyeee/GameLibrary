# 科技与探索系统 — 冰汽时代 (Frostpunk)

> 游戏版本: Frostpunk v1.6.1 | PC/Steam
> 数据来源: [Frostpunk Wiki - Technology Tree](https://frostpunk.fandom.com/wiki/Technology_Tree), [Frostpunk Wiki - Exploration](https://frostpunk.fandom.com/wiki/Exploration), [社区指南](https://steamcommunity.com/app/323190/guides/)

## 一、科技树——"与时间赛跑的研究"

### 1.1 科技树结构

| 层级 | 解锁条件 | 代表科技 | 关键价值 |
|:--:|------|------|------|
| Tier 0 | 初始 | 灯塔(Beacon) | 解锁侦察！ |
| Tier 1 | 画图板(Drawing Boards) | 锯木厂、钢厂、蒸汽枢纽 | 稳定资源+高效供热 |
| Tier 2 | 机械计算器 | 煤矿、墙钻、温室、诊所 | 资源升级+高级建筑 |
| Tier 3 | 差分机 | 蒸汽煤矿、高级钢厂、自动机工厂 | 生产力飞跃 |
| Tier 4 | 自动机+差分机 | 高级煤矿、工业温室 | 终局产能 |
| Tier 5 | 最高级 | 房屋重保温、发电机功率IV | 暴风雪终极准备 |

### 1.2 优先研究路径

| 优先级 | 科技 | 理由 |
|:--:|------|------|
| 1 | **灯塔** (Beacon) | 无灯塔=无侦察=无额外人口+无蒸汽核心=慢性死亡 |
| 2 | 画图板 (Tier 1解锁) | 解锁全部高级科技的前提 |
| 3 | 锯木厂/钢厂 | 资源堆耗尽前建立稳定生产 |
| 4 | 蒸汽枢纽 | 替代发电机范围升级(高效供热) |
| 5 | 猎人装备→温室 | 食物安全 |
| 6 | 煤矿/采煤机 | 稳定煤炭供应 |
| 7 | 诊所 | 医疗效率翻倍 |
| 8 | 自动机工厂 | 终局劳动力替代 |

### 1.3 研究时间机制

- 多个工坊可以**叠加研究速度**（递减效率）
- 儿童学徒(工程师)永久+研究速度
- 自动机可以在工坊工作→**24小时不间断研究**
- 应急班次可用于工坊→更快研究但有致死风险

## 二、探索与侦察——"冰原上的叙事引擎"

### 2.1 侦察系统架构

侦察是冰汽时代**最主要的叙事推进机制**。城市的边界是固定的——但冰原世界通过侦察不断扩展：

```
灯塔 → 派出侦察队(5工人)
  ├→ 发现新地点(幸存者/资源/蒸汽核心/剧情)
  ├→ 探索速度受科技影响(侦察队升级/轻型侦察雪橇)
  └→ 发现前哨站位置 → 建立前哨站(永久资源收入)
```

### 2.2 侦察的发现类型

| 发现类型 | 价值 | 例子 |
|------|:--:|------|
| **幸存者** | 最高(增加人口) | 发现一群冻僵的难民→选择是否带回 |
| **蒸汽核心** | 极高 | 废弃的发电机残骸中回收 |
| **资源** | 中 | 煤炭/木材/钢材/食物 |
| **前哨站位置** | 高 | 煤炭矿场(可建立永久前哨站, 800煤/天) |
| **自动化设备** | 极高 | 发现完整的自动机残骸→直接获得! |
| **剧情事件** | 叙事驱动 | 发现冬日之家的废墟——推动主线故事 |

### 2.3 侦察的速度与风险

- 侦察需要**时间**——往返一个远距离地点可能花费1-3天
- 侦察队可能遭遇**暴风雪被困**
- 侦察队可能遭遇**危险野生动物**(北极熊)
- 带回大量幸存者的侦察队——你的食物和住房准备好了吗？

## 三、科技与探索的耦合

### 3.1 "先有鸡还是先有蛋"

- 要研究高级科技 → 需要蒸汽核心(建高级建筑)
- 要获得蒸汽核心 → 需要侦察
- 要侦察 → 需要灯塔
- 要灯塔 → 需要研究
- 要研究 → 需要工程师+工坊

这个起步循环决定了**开局策略**——如果你不立即研究灯塔并派出侦察队，你会陷入"没蒸汽核心→没高级建筑→没效率→没资源→更没时间研究"的恶性循环。

## 四、设计特点分析

### 4.1 科技树——"已知的未知"

与许多4X/RTS游戏不同，冰汽时代的科技树**从一开始就完全可见**——你不是在"发现"科技，你是在**选择优先顺序**。这消除了科技方向的运气因素，让所有失败都归因于"你研究得太慢了"或"你研究错东西了"。

**设计意图**：让失败的责任完全归于玩家的决策优先级。如果你在暴风雪前没研究满级房屋保温——那不是运气不好，是你选了先研究煤矿效率。

### 4.2 侦察——"无战斗的探索"

冰汽时代的探索没有战斗系统——你不需要带武器、没有战斗场景。这消除了RPG元素，将焦点完全保持在**资源决策**上：带多少人出去？走多远？带回多少幸存者？

这种"无战斗探索"在城市建设品类中是罕见的——大多数有探索系统的城建游戏都有战斗(如Manor Lords/Anno 1800)。冰汽时代证明了：探索**不需要**战斗——发现幸存者和你的城市能否承受他们，本身就是足够的张力。

### 4.3 科技研究的"暴力加速"

可以叠加多个工坊+儿童学徒+自动机24h研究是一个有趣的设计选择——它意味着你可以**用大量资源"买"更快的研究速度**。在暴风雪前的最后冲刺阶段，把一个额外的蒸汽核心投入自动机研究工坊，可能是让你在暴风雪前完成房屋保温研究的唯一方式。
