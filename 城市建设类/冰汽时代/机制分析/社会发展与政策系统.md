# 社会发展与政策系统（法律之书） — 冰汽时代 (Frostpunk)

> 游戏版本: Frostpunk v1.6.1 | PC/Steam
> 数据来源: [Frostpunk Wiki - Book of Laws](https://frostpunk.fandom.com/wiki/Book_of_Laws), [Xbox Wire设计分析](https://news.xbox.com/en-us/2019/10/11/frostpunk-society-system-available-today/), [Game Developer](https://www.gamedeveloper.com/design/frostpunk-an-analysis-of-emotional-narrative-engagement)

## 一、系统概述

冰汽时代的社会发展系统是**法律之书(The Book of Laws)**——城市建设品类中公认最具设计深度的政策系统。它不是都市天际线的"可选无代价政策"，也不是Tropico的"幽默政治模拟"——它是**道德滑坡的阶梯**。每一条法律都看似在极端环境下必要且合理，但累积到终点时，你变成了暴君。

## 二、法律之书的结构

### 2.1 两大分支

法律之书分为两个独立树：

```
法律之书
├── 适应(Adaptation) —— "你愿意牺牲什么？"
│   涉及：工作条件、食物、医疗、义肢、儿童
│
└── 目的(Purpose) —— "你愿意成为什么？"
    ├── 秩序(Order) —— 威权/警察国家
    └── 信仰(Faith) —— 神权/精神控制
```

### 2.2 适应法律树

| 法律 | 前置 | 效果 | 设计意图 |
|------|:--:|------|------|
| **应急班次** (Emergency Shift) | 无 | 24小时不间断工作。**首次使用必有一人死亡**(过劳死)。之后可能再次发生。 | 游戏的"原罪"按钮——你知道会死人，但你按了。 |
| **延时班次** (Extended Shift) | 应急 | +40%工时(14小时代替10小时)。不满增加。 | 比应急班次"温和"——你开始说服自己"这只是多加4小时"。 |
| **童工** / **儿童庇护所** | 无 | 二选一：儿童可在采集站/伙房工作 **或** 儿童学徒(加速科研/医疗) | 游戏最著名的道德困境。短期劳动力vs长期效率。 |
| **汤** / **食品添加剂** | 无 | 汤：1生食→6份汤(拉伸)，不满+ 。添加剂：1生食→4份标准餐(需额外生食) | 维多利亚时代真实历史做法(sawdust in bread)。 |
| **激进治疗** / **维持生命** | 无 | 激进：重病患者→截肢(残废)。维持：保留床位→缓慢恢复。 | 留人还是留肢体？ |
| **义肢** | 激进治疗 | 截肢者恢复工作能力 | "激进的法律可以被后续法律缓和"——设计的关键智慧 |
| **器官移植** | 任一医疗法律+雪坑 | 尸体用于医疗+20%效率 | 你在说服自己"尸体反正也没用" |
| **决斗场** | 秩序or信仰 | 降低不满(暴力发泄) | — |
| **酒馆** (Public House) | — | 降低不满(酒精麻痹) | — |
| **墓地** / **雪坑** | — | 处理尸体。墓地提升希望，雪坑可用于器官移植 | — |

### 2.3 目的法律树——秩序 vs 信仰

两条路线是互斥的，但设计上完全对称：

| 功能 | 秩序路径 | 信仰路径 |
|------|------|------|
| 基础建筑 | 警卫站(Guard Station) | 教堂(Chapel) |
| 降低不满 | 巡逻(Patrol) | 晚祷(Evening Prayers) |
| 提升效率 | **工头**(Foreman, +20%效率) | **圣坛**(Shrine, +20%效率) |
| 宣传 | 宣传中心(Propaganda Center) | 神殿(Temple) |
| 控制 | 监狱(Prison) → 强制说服 | 信仰守护者(Faith Keepers) → 公开悔罪 |
| 终局法律 | **新秩序**(New Order) — "这就是你建的国家" | **新信仰**(New Faith) — "这就是你建的国家" |

**设计对称性的深意**：秩序和信仰的**数值效果完全相同**——工头=圣坛，巡逻=晚祷，监狱=信仰守护者。这个对称设计在告诉你：两条路都通往同一个终点——极端控制。唯一的区别是你用什么旗号。

## 三、"温水煮青蛙"——法律序列设计

### 3.1 首席设计师Marta Fijak的核心设计原则

> "我们不想从道德角度评判玩家……但每一条法律都应该比上一条**多一点点极端**。" —— Marta Fijak

| 法律序列 | 玩家的心理变化 |
|------|------|
| 第1条：延时班次 | "只是多工作4小时，大家能理解的" |
| 第2条：汤 | "稀释食物总比有人饿死好" |
| 第3条：童工 | "孩子在采集站工作总比全家冻死好" |
| 第4条：激进治疗 | "失去一条腿总比失去一条命好" |
| ... | ... |
| 第N条：新秩序 | "我做了什么？" |

### 3.2 不可逆性

法律一旦通过**不可撤回**。但后续法律可以"缓和"前法的后果（激进治疗→义肢、汤→后续食物法律改善）。这个设计创造了一种"向前走无法回头，但可以试图补救"的独特道德体验。

## 四、希望与不满——法律的社会反馈

每条法律都通过希望/不满数值**实时反馈**其社会影响：

| 法律类型 | 希望影响 | 不满影响 | 时间窗口 |
|------|:--:|:--:|------|
| 应急班次 | — | **+40%** | 立即→随时间衰减 |
| 延时班次 | — | +25% | 持续性(只要开启) |
| 童工 | -5% | +15% | 永久 |
| 儿童庇护所 | +10% | — | 永久 |
| 墓地 | +5%(每次葬礼) | — | 每次触发 |
| 汤 | — | +10% | 永久(只要启用) |
| 新秩序 | +30% | —(不满清零) | 终局锁定 |
| 新信仰 | +30% | —(不满清零) | 终局锁定 |

**设计分析**：终局法律"新秩序/新信仰"会**清零不满**——不是因为你的人民突然变乖了，是因为他们已经完全被控了。这种"数值清零=人性消灭"的设计是冰汽时代最黑暗的隐喻。

## 五、设计特点分析

### 5.1 "道德侵蚀的模拟器"——品类唯一

在城市建设品类中，没有一个游戏的"政策/法律"系统达到了冰汽时代的道德深度。都市天际线的政策是无代价的便利工具；Tropico的政治是有趣的讽刺；只有冰汽时代将法律系统设计为**道德侵蚀的模拟**——你每次点下"通过法律"的按钮，都在合理化一个更极端的立场。

### 5.2 历史研究驱动的设计

11 bit studios的设计团队从历史中寻找"极端情况下社会如何改变"的案例：维多利亚时代英国的童工、列宁格勒围城中的食品添加剂、极权主义逐步确立的"青蛙煮水"过程。这不是游戏设计师的想象——这是**人类历史**。

### 5.3 "没有好选择"的设计

首席设计师Kuba Stokalski明确将冰汽时代的设计哲学定义为："你愿意牺牲自己的道德或理想，来换取更好的结果吗？" 这个框架决定了法律之书中没有"好人选项"——只有不同程度的牺牲。

**与Papers, Please对比**：这是另一款以"没有好选择"著称的游戏。但Papers, Please的困境是个人的（每天盖章的选择），冰汽时代的困境是系统性的（整个社会的法律框架）。
