# 环境与灾害系统 — 冰汽时代 (Frostpunk)

> 游戏版本: Frostpunk v1.6.1 | PC/Steam
> 数据来源: [Frostpunk Wiki - Weather](https://frostpunk.fandom.com/wiki/Weather), [Frostpunk Wiki - Heat](https://frostpunk.fandom.com/wiki/Heat), [Steam社区指南](https://steamcommunity.com/app/323190/guides/)

## 一、系统概述

冰汽时代的环境系统本身**就是游戏的核心对手**——没有敌人入侵、没有怪物攻击、没有自然灾害的随机骰子。唯一的"敌人"是**持续下降的温度**。它不是随机事件——它是精确的、可预测的、但不可阻止的。你知道暴风雪会来；你不知道的是，你是否准备好了。

## 二、天气系统——"可预测的末日"

### 2.1 天气的精确可预测性

冰汽时代在左下角提供了一个**精确的未来7天天气预报**——每一天的最低温度都明确标注。这不是缺乏紧张感——这是**让你自己为失败负责**。如果你在暴风雪中冻死了，你知道那不是随机概率——是你七天前就知道暴风雪要来但没有准备足够的煤炭。

**设计哲学**：这是一种"理性的绝望"——问题在来临之前就已经预见了，但资源总是不够。你不是在对抗未知——你是在对抗你**已知但无力完全规避**的命运。

### 2.2 典型天气曲线

| 游戏天数 | 温度范围 | 阶段特征 |
|:--:|------|------|
| 1-5天 | -20°C ~ -30°C | 温和开局，让你建立基础设施 |
| 6-10天 | -30°C ~ -40°C | 第一次寒潮——测试你的供热准备 |
| 11-20天 | -40°C ~ -50°C | 持续降温，资源压力加剧 |
| 21-30天 | -60°C ~ -70°C | 深度严寒，法律树接近完成 |
| 31-40天(暴风雪前) | -70°C ~ -80°C | 备战——你还有时间准备 |
| 40-43天(大暴风雪) | **-80°C ~ -150°C** | **终局测试**——所有投机取巧的代价现在支付 |

### 2.3 温度对游戏系统的影响架构

```
室外温度 ↓
  ├→ 工作场所温度等级下降 → 疾病增加 → 医疗系统压力
  ├→ 住宅温度等级下降 → 夜间疾病 → 死亡风险
  ├→ 发电机煤炭消耗间接增加(需要更高功率)
  ├→ 猎人无法工作(极端天气)
  └→ 全城希望缓慢下降(环境恶化本身就是心理打击)
```

## 三、大暴风雪 (The Great Storm)——城建史最残酷的"最终考试"

### 3.1 暴风雪参数

| 参数 | 数值 |
|------|:--:|
| 持续时间 | 约3-4天(游戏时间) |
| 最低温度 | **-150°C** |
| 对建筑影响 | 非满保温建筑**完全冻结**(无法运作) |
| 猎人 | **全部停止工作** |
| 市民可外出 | **否**（所有人在家避难） |
| 发电机过载 | **必须使用**(否则温度无法承受) |
| 自动机 | 正常工作(它们不怕冷) |

### 3.2 暴风雪的"全景测试"

大暴风雪不只是"极端天气"——它是冰汽时代设计哲学的最高表达：**之前每一个"似乎可以偷懒"的决策，在暴风雪中会同时支付代价**。

| 你之前的"省事"决策 | 暴风雪中的代价 |
|------|------|
| 没研究满级房屋保温 | 住宅冻结→所有人无家可归→大规模死亡 |
| 依赖猎人而非温室 | 食物来源完全断绝→饥荒 |
| 没建足够煤炭储备 | 发电机在-150°C下消耗暴增→煤炭耗尽→全城冻结 |
| 用了太多应急班次 | 人口因过劳死已减少→暴风雪中劳动力不足 |
| 没建立自动机群 | 工作场所全部停止运作 |
| 选择激进治疗太多 | 大量截肢的残废人口→劳动力短缺 |

## 四、煤炭消耗——环境的直接账单

### 4.1 典型日煤炭消耗演变

| 阶段 | 日煤炭消耗(估算) | 主要消耗来源 |
|------|:--:|------|
| 开局(Day 1-5) | 100-200 | 发电机Lv1+采集站 |
| 早期(Day 6-15) | 300-800 | 发电机Lv2+2-3蒸汽枢纽+加热器 |
| 中期(Day 16-30) | 800-1,500 | 发电机Lv3+5-8蒸汽枢纽+多加热器 |
| 暴风雪前(Day 31-40) | 1,500-3,000 | 全城满供热+满级发电机 |
| 暴风雪(Day 40-43) | **3,000-5,000+** | 发电机满级+过载+所有蒸汽枢纽24h |

### 4.2 "煤炭焦虑"的设计力量

煤炭消耗是持续的——它不会等你。你可以储存食物、囤积钢材，但**煤炭不够就意味着今天就要有人冻死**。这种"即时性"让煤炭资源具有其他资源所没有的**紧迫感**。

## 五、设计特点分析

### 5.1 "可预测的灾难"——品类中的独特设计

大多数城市建造游戏的灾难是"随机的"（SimCity的火灾/地震）或"由玩家错误引发的"（都市天际线的水污染）。冰汽时代的灾难是**精确预知但不可阻止的**——你知道哪天暴风雪会来，你知道会降到多少度，但你可能就是准备不够。

这种设计将玩家从"熵的对抗者"转变为"时间的对抗者"——你不是在对抗系统的不可预测性，你是在对抗**时间的不够用**。

**与Frostpunk 2对比**：二代的环境压力从"温度暴降"变为"资源枯竭"——一代是对抗自然，二代是对抗人性（派系冲突）。

### 5.2 暴风雪——"支付技术债"的时刻

暴风雪的设计在城建品类中是独一的——它迫使你为你在整个游戏过程中所做的**每一个便利决策**支付代价。你在第5天偷懒没研究房屋保温？暴风雪时支付。你在第15天把钱全花在装饰而非煤炭储备？暴风雪时支付。

这创造了一种"道德记账"的设计体验——你做的每一个决策都在一个不可见的"暴风雪账单"上被记录。当暴风雪来临时，账单到期。
