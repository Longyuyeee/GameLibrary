# 团队与开发历程 — 冰汽时代 (Frostpunk)

> 开发商: 11 bit studios (波兰华沙) | 发行商: 11 bit studios
> 发行年份: 2018年4月24日 | 平台: PC (后移植PS4/Xbox One) | 团队规模: ~40-60人

## 一、开发团队

### 1.1 11 bit studios

| 维度 | 信息 |
|------|------|
| 成立 | 2010年，波兰华沙 |
| 创始人 | Grzegorz Miechowski 等 |
| 前作 | **This War of Mine** (这是我的战争, 2014)——平民视角的战争生存游戏 |
| 团队规模(冰汽时代期间) | ~40-60人 |
| 核心设计师 | Kuba Stokalski (首席设计师), Marta Fijak (高级设计师) |
| 公司定位 | "有意义娱乐"(Meaningful Entertainment)——不做纯娱乐，要做让玩家思考的游戏 |

### 1.2 团队哲学

11 bit studios不是"游戏工作室"——他们自称为"有意义娱乐公司"。从This War of Mine开始，他们确立了公司的设计信条：**游戏应该触及严肃主题**（战争、道德困境、社会崩溃），而不是逃避现实。

首席设计师Kuba Stokalski曾说："我们不关心品类(Genre)——我们追求的是体验(Experience)，以及玩家从游戏中获得的情感和感受。"

## 二、开发历程

### 2.1 从This War of Mine到Frostpunk

| 时间 | 里程碑 |
|------|------|
| 2014 | This War of Mine发布——大获成功(900万份销量)，确立了11 bit的"严肃游戏"声誉 |
| 2015-2016 | 开始Frostpunk预开发——团队想"从一个人的故事扩展到整个社会的故事" |
| 2016 | 正式开发启动 |
| 2017 | 公布首支预告——蒸汽朋克末日城市的独特美学引起广泛关注 |
| 2018.4.24 | **正式发售**——首日即盈利 |
| 2018-2020 | DLC开发(最后的秋天/边缘/裂缝等) |
| 2021 | Frostpunk 2公布 |
| 2024 | Frostpunk 2发售 |

### 2.2 设计理念的进化

This War of Mine问的是："**一个人**在战争中会做多可怕的事？"
Frostpunk问的是："**整个社会**在绝境中会变成什么？"

这是从"个人道德"到"社会系统"的尺度跃迁。团队解释说他们想创造一个"城市规模的This War of Mine"——不是控制几个平民，而是**管理一整个社会的道德**。

### 2.3 关键设计决策

| 决策 | 说明 |
|------|------|
| **法律之书的不可逆性** | 最初设计是可撤回法律，但团队发现这让选择"没有重量"。改为不可逆后，每次点击"通过法律"都有了真实的焦虑感。 |
| **希望/不满双轴** | 取代传统"幸福度"。灵感来自真实世界的生存研究——登山事故和极端环境中，**幸存者的心理状态**比物质条件更能预测存活率。 |
| **"青蛙煮水"序列** | 每条法律只比前一条极端一点点——玩家在"合理化"中一步步滑入专制。灵感来自历史上的极权主义崛起过程。 |
| **无战斗设计** | Frostpunk故意不做战斗——团队认为引入外部敌人会分散玩家对"真正敌人(严寒)"的注意力。 |

### 2.4 开发挑战

- **道德系统的调校**：如何让玩家感到内疚但不至于退出游戏？团队花了大量时间在"法律之间距离"的迭代上——每条法律必须"感觉合理"但累积起来必须"令人不安"。
- **暴风雪的难度曲线**：如何确保暴风雪对所有水平的玩家都有挑战性但不至于无法通关？答案：暴风雪前40天的准备周期可以吸收不同水平的差异。

## 五、设计启示

### 5.1 对城市建设品类的贡献

1. **"紧绷式城建"是可行的商业方向**：冰汽时代证明了城市建造不需要"沙盒自由"——"高压生存"有巨大的、独特的市场。

2. **道德系统可以成为核心而非附加**：法律之书不是"可选的政策面板"——它是游戏的灵魂。这表明建筑建造和资源配置不是城建游戏唯一的核心。

3. **天气可以是主要反派**：不需要敌人、不需要战斗——**温度**本身就是一个足够复杂的对手。

### 5.2 对独立游戏的启示

- **主题大于品类**：11 bit studios不以"我们做城市建设游戏"定义自己——他们以"我们做让玩家思考的游戏"定义自己。品类是工具，主题是目标。
- **"有意义娱乐"的市场可行性**：This War of Mine和Frostpunk合计销量超过1200万份——严肃游戏在商业上可以和娱乐游戏一样成功。

### 5.3 冰汽时代 vs 都市天际线——同品类相反极的并存

| 维度 | 都市天际线 | 冰汽时代 |
|------|:--:|:--:|
| 核心体验 | 创造的满足感 | 生存的紧张感 |
| 失败压力 | 无 | **极高** |
| 道德维度 | 无 | **核心** |
| 城市扩张 | 无限沙盒 | 固定地图 |
| 商业成功 | 1200万份 | 300万份 |
| 验证的假设 | "人们喜欢无限建造" | "人们也喜欢被逼到极限" |

两者共同验证了城市建设品类的巨大光谱——从完全自由的创造性满足，到完全紧绷的生存焦虑，都有庞大的市场。
