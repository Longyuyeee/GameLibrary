# 角色弧线深度解析 — 王权：幻想王国 (Majesty)

> 游戏版本: Majesty Gold Edition v1.4 | PC/Steam
> 数据来源: [GameFAQs攻略](https://gamefaqs.gamespot.com/pc/250542-majesty-the-fantasy-kingdom-sim/faqs/54780), 游戏内观察

## 特别说明

王权是城建品类中一个极特殊的案例——**英雄是"角色"（有姓名/等级/人格/装备），但不是"主角"（你的主体性不附着在他们身上）。** 你是国王，不是冒险者——英雄是你的代理人，不是你的化身。这是"玩家与可玩角色分离"在策略游戏中的最早实现之一。

## 一、"主角"设计：国王——有权力但无控制力

### 1.1 你是谁？

你是阿尔达尼亚(Ardania)的君主(Sovereign)。你有王宫、有国库、有法术——但你没有军队。你必须依赖独立的英雄公会为你提供"自愿"的军事服务。你不是"控制英雄的人"——你是**英雄的客户**。

| 维度 | 传统RTS | 王权 |
|------|:--:|:--:|
| 身份 | 指挥官 | 国王/客户 |
| 对单位的控制 | 绝对(点选+右键) | 零(只能挂赏金) |
| 权力来源 | 系统授予 | 经济购买(赏金=购买英雄的注意力) |
| 失败时 | 你的军队被消灭 | **没人愿意为你战斗了** |

### 1.2 故事的"涌现"

王权没有脚本化剧情——但每局游戏都自然产生故事：盗贼第一个响应赏金但中途逃跑→战士们赶到接管战斗→法师在后方安全升级→一场Boss战需要凋零术(Wither)+野蛮人冲锋的精确配合。这不是设计师写的故事——是**英雄AI之间的互动涌现出的故事**。

## 二、角色属性与能力设计——英雄的属性面板

### 2.1 英雄的"RPG式属性"

王权的每个英雄拥有传统RPG的完整属性面板：

| 属性 | 含义 |
|------|------|
| 力量(STR) | 近战伤害 |
| 敏捷(DEX) | 远程伤害/命中 |
| 智力(INT) | 法术伤害/法力池 |
| 生命值(HP) | — |
| 等级(LV) | 1-10+(经验值累积) |
| 装备 | 武器/护甲——在铁匠铺购买 |
| 药水 | 治疗/法力——在市场购买 |

### 2.2 "属性→行为"的映射

英雄的属性不是静态数值——它们通过AI人格参数驱动英雄的**行为**：
- 高等级+高属性 → 英雄在恐惧检定中更自信 → 主动挑战更强怪物
- 低等级+弱装备 → 英雄频繁逃跑 → 玩家失去对局面的控制
- 铁匠铺的装备水平 → 英雄的战斗力上限 → 决定了你可以挑战的怪物等级

## 三、角色魅力分析

### 3.1 为什么没有"脸"的英雄仍然有魅力？

王权的英雄没有配音、没有过场动画、没有个人故事——**但每个职业都有极端鲜明的个性化AI**。盗贼的贪婪让它们成为"那个总是抢第一但总是第一个跑的混蛋"，野蛮人的无畏让它们成为"那个永远不会背弃你的战士"。这种**人格通过行为而非对话传达**的设计是品类中最早的成功案例。

### 3.2 记忆点

1. **第一个响应的盗贼**——你的第一个赏金挂着时，那个盗贼从阴影中窜出——你感受到了"王国真的在运作"
2. **法师第一次活过LV1**——你知道这意味着你的战略投资终于开始回收
3. **野蛮人的非致命击倒**——在全员阵亡的绝望中，那个蛮子又爬起来了

## 四、配角——"你的代理人们"

英雄是"被委托者"而非"下属"。国王与英雄之间的关系是——我给赏金、你自愿接单。这种**契约式的关系**在城建品类中是独一无二的。

## 五、"反派"设计——怪物是国王的竞争对手

怪物巢穴不断地在争夺英雄的注意力——你的赏金 vs 怪物的存在，两者在英雄的AI决策循环中互相竞争。你不是在"打败怪物"——你是在**比怪物更吸引英雄的注意力**。

## 六、关系网络——国王-公会-英雄三角

```
国王(你) — 提供资金/赏金/法术
  ↓(建造)           ↓(赏金)
公会(建筑) → 产生 → 英雄(自主Agent)
  ↓(升级)           ↓(消费)
铁匠铺/市场 ←——— 英雄购物(产生税收)
```

## 七、设计启示

### 7.1 "人格驱动的Agent"比"脚本化的NPC"更具叙事潜力

王权证明了：一个没有台词、没有面部表情、只有AI人格参数的英雄，可以产生比有完整脚本的NPC更丰富的"故事"。因为AI人格的行为是不可预测的——每一次"逃跑"或"冲锋"都不是脚本决定的，是**模拟决定的**。

### 7.2 城建品类中"玩家与角色分离"的价值

在都市天际线中，你是城市本身。在冰汽时代中，你是道德决策者。在王权中，你是**委托者**——你请求别人为你冒险。这种"委托关系"赋予了城建品类一种独特的"无力感"——你是国王，但你的权力完全取决于别人是否愿意为你服务。
