# 间接控制与英雄AI系统 — 王权：幻想王国 (Majesty)

> 游戏版本: Majesty Gold Edition v1.4 (Gold HD) | PC/Steam
> 数据来源: [GameFAQs完整攻略](https://gamefaqs.gamespot.com/pc/250542-majesty-the-fantasy-kingdom-sim/faqs/54780), [TV Tropes](https://tvtropes.org/pmwiki/pmwiki.php/VideoGame/Majesty), [社区速通指南](https://www.speedrun.com/majesty1/guides), [Stage1st怀旧帖](https://stage1st.com/2b/forum.php?mod=viewthread&tid=2278790)

## 一、系统概述

王权：幻想王国的"间接控制"是**整个策略游戏史上最激进的设计实验之一**——你无法右键点击任何单位、无法下达移动/攻击指令、无法编队。你只能通过三种方式影响英雄：①在地图上**挂悬赏旗帜**(Reward Flag) ②建造/升级公会和神庙(决定产生什么英雄) ③释放君主法术(Sovereign Spells)。英雄的一切行为都由**人格驱动的自主AI**决定。

这个设计在2000年——RTS黄金时代（星际争霸/帝国时代2/C&C）——是**反品类**的。它不是"简化版RTS"——它是**一个全新的品类原型**。

## 二、悬赏旗帜——"你唯一的控制手段"

### 2.1 两种旗帜

| 旗帜类型 | 功能 | 设计意图 |
|------|------|------|
| **攻击旗** (Attack Flag) | 放在敌人/建筑上→英雄看到赏金后自主决定是否攻击 | 你只能"诱惑"英雄去攻击——不能命令 |
| **探索旗** (Explore Flag) | 放在未探索区域→英雄自主决定是否前往探索 | 你不能派斥候——能开出多少价码让人自愿冒险 |

### 2.2 悬赏金的经济学

| 金额 | 吸引的英雄类型 | 效果 |
|:--:|------|------|
| 100-200金 | 盗贼（贪婪度最高） | 立即响应但可能半路逃跑 |
| 300-500金 | 游侠/战士 | 稳定响应 |
| 500-800金 | 精灵/法师 | 高价才能打动"不愿意冒险"的英雄 |
| **>800金** | **所有人** | **不要超过**——过高的赏金造成浪费且吸引非最优英雄类型 |

**核心设计**：赏金不是"费用"——是**信号**。低赏金="谨慎处理这件事"（盗贼去就够了），高赏金="这是我需要现在就解决的严重威胁"。

## 三、英雄AI——"十六种人格的涌现叙事"

### 3.1 AI决策树

每个英雄在每一步（约每秒）执行以下循环：
```
"检查周边"(Check Nearby) → 看到什么？
  ├→ 看到敌人 → 恐惧检定(失败=逃跑, 成功=攻击)
  ├→ 看到悬赏旗 → 贪婪检定 → 去追赏金
  ├→ 看到商店 → 购物检定 → 进去消费
  ├→ 看到酒店 → 疲劳检定 → 进去休息
  ├→ 看到未探索区域 → 好奇检定 → 去探索
  └→ 无 → 漫游
```

**关键设计**：英雄**不在任何玩家的控制队列中**——他们每秒都在自己做所有这些决定。你只能通过旗帜价格、建筑位置和公会类型来**影响这个循环的概率**。

### 3.3 AI的"漏洞"——玩家社区的利用

这些AI行为在20年+的社区研究中被精妙利用：
- **"激怒利用"**: 如果英雄走出公会时在"检查周边"范围看到怪物→**跳过所有正常AI直接狂暴攻击**
- **"公会叠怪穴"**: 把游侠公会直接盖在怪穴上→游侠见怪就冲
- **"酒馆删除"**: 英雄逃跑到酒馆后→手动删除酒馆→英雄重新执行恐惧检定("你不许休息，再打一次！")
- **"侏儒建造漏洞"**: 先放建筑蓝图→再招募侏儒→侏儒的决策树优先处理建造(无视周围怪物)

**设计哲学**：这些不是"Bug"——它们是AI人格复杂性的**自然涌现行为**。玩家不是在"利用Bug"——是在**学习英雄的心理**。

## 四、设计特点分析

### 4.1 为什么"不能控制"比"能控制"更强大？

在传统RTS中，单位是工具——你下达一个命令，单位执行。在王权中，英雄是**有主见的个体**——你给出一个**激励**（赏金），英雄基于自己的**人格**选择是否接受。这不是"指令→执行"——是"委托→谈判"。这种间接控制让每个英雄的行动都有了**叙事意义**：盗贼抢先去追赏金不是因为"你让他去的"——是因为**他贪婪**。

**与RimWorld对比**：RimWorld也使用"间接控制"——你设定工作优先级，殖民者自主选择做什么。但RimWorld的殖民者是"优先队列下的自主"——你定义了优先级框架。王权的英雄是**完全自主**——你连优先级框架都没有。RimWorld用的是"间接引导"，王权用的是"纯粹激励"。

### 4.2 2000年的异类——为什么王权在当时"失败"了但被后人记住了？

2000年是RTS的黄金时代（星际1/帝国2/C&C红警2/魔兽3在开发中）——玩家期望的是"精准控制大队军队"。王权要求的是**放手和信任**——这在当时是反直觉的。商业上它不是失败（50万+销量），但"品类开创者"的地位是在后来的独立游戏浪潮(Dwarf Fortress→RimWorld→Kenshi)中才被回溯性地认可的。

**品类地位**：王权是"自主Agent城市建造/策略游戏"这一整条品类树的**根节点**。Dwarf Fortress(2006)和RimWorld(2018)在"间接控制+涌现叙事"上继承了它的基因——尽管这两款游戏的直接灵感来源可能是Rogue-like而非王权。
