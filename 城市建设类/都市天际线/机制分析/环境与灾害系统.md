# 环境与灾害系统 — 都市天际线 (Cities: Skylines)

> 游戏版本: Cities: Skylines v1.17.1 (含Natural Disasters DLC) | PC/Steam
> 数据来源: [Paradox Wiki - Pollution](https://skylines.paradoxwikis.com/Pollution), [Paradox Wiki - Natural Disasters](https://skylines.paradoxwikis.com/Natural_Disasters), [Paradox Wiki - Beginner's Guide](https://skylines.paradoxwikis.com/Beginner%27s_guide)

## 一、系统概述

都市天际线的环境系统分为两个层面：原版的**污染管理**（空气/水/噪音三种污染的生成、扩散与治理）和Natural Disasters DLC中的**灾害系统**（地震/海啸/陨石等随机或手动触发的灾难）。两者共同构建了城市面临的"环境压力"。

## 二、污染系统

### 2.1 空气污染

| 污染源 | 污染强度 | 扩散范围 | 影响 |
|------|:--:|------|------|
| 煤电厂 | 极高 | 大范围(顺风扩散) | 周边市民健康下降→生病 |
| 燃油电厂 | 高 | 大范围 | 同上 |
| 通用工业区 | 中 | 局部 | 低密度住宅区受影响大 |
| 石油/矿石专业化工业 | 高 | 中范围 | 周边地价暴跌 |
| 焚烧厂 | 高 | 中范围 | — |
| 交通拥堵路段 | 低-中 | 沿道路 | 高密度区域累积效应严重 |

**扩散机制**：空气污染从源头向周围扩散，受**风向**影响。地图有固定风向(信息面板可查看)，污染物向下风方向扩散更远。

**治理方式**：
- 林业/农业绿色缓冲带(零污染的工业专业化)
- 将污染源置于城市下风方向
- 植树(After Dark DLC：行道树减少局部空气污染)
- Green Cities DLC：太阳能/地热等零污染电源

### 2.2 水污染

| 污染源 | 污染强度 | 影响 |
|------|:--:|------|
| 污水排放管 | 极高 | 下游水域全部污染 |
| 通用工业区(地面污染渗入) | 中 | 渗透至地下水 |
| 水处理厂 | 低 | 85%净化(仍有15%污染残留) |

**最严重的设计陷阱**：如果水塔建在被地面污染的土地上→水塔产出的饮用水**直接变成毒水**→全城居民饮用污染水→大规模生病→医疗系统崩溃→死亡潮。这是都市天际线玩家最常见的"城市瞬间崩溃"场景之一。

**治理方式**：
- 污水排放管必须放在**下游**
- 水塔远离工业区
- 升级到水处理厂
- Green Cities DLC：生态水处理厂(零污染出水)

### 2.3 噪音污染

| 污染源 | 强度 | 影响范围 |
|------|:--:|------|
| 高速公路 | 极高 | 两侧各约8格 |
| 六车道道路 | 高 | 两侧各约6格 |
| 商业区(高密度) | 高 | 周边 |
| 工业区 | 中 | 周边 |
| 地铁站 | 中 | 出入口周边 |
| 公交站 | 低 | 局部 |
| 公园 | **负噪音**(减噪) | 周边 |
| 行道树道路 | 噪音减半 | — |

**治理方式**：
- 高速公路旁建**隔音墙**(道路升级选项)
- 办公区作为商业区和住宅区之间的"噪音缓冲"（办公区对噪音有一定容忍度）
- 行道树道路大幅降噪
- 公园降低周围噪音

## 三、地价与环境

### 3.1 地价影响因素

| 正向因素 | 负面影响 |
|------|------|
| 公园和绿化 | 空气污染 |
| 教育设施(学校/图书馆) | 水污染 |
| 公共交通站点 | 噪音污染 |
| 公共服务覆盖 | 垃圾堆积 |
| 滨水/高地位置 | 犯罪率 |
| 行道树道路 | 火葬场/垃圾场/监狱 |

> **设计要点**：地价不是独立的数值——它是所有环境与服务因素的总和反应。高地价=市民愿意付更多税=高等级建筑解锁=城市财政收入增加。

## 四、自然灾害系统 (Natural Disasters DLC)

### 4.1 灾害类型

| 灾害 | 触发方式 | 可预警 | 破坏范围 | 可防御 |
|------|:--:|:--:|:--:|:--:|
| **地震** | 随机/手动 | 有(提前数秒) | 圆形区域 | 无(只能灾后重建) |
| **海啸** | 随机/手动 | 有(提前) | 沿海岸线 | 海堤/运河可引导水流 |
| **陨石撞击** | 随机/手动 | 有(极短) | 圆坑+冲击波 | 无 |
| **雷暴** | 随机 | 无 | 散点建筑 | 避雷针(几率防御) |
| **森林火灾** | 随机/雷暴引燃 | 无 | 蔓延至周边树木 | 消防直升机+防火带 |
| **龙卷风** | 随机 | 有(极短) | 条带状随机路径 | 无(只能提前疏散) |
| **天坑** (Sinkhole) | 随机 | 无 | 局部塌陷 | 无 |
| **建筑倒塌** | 建筑老化 | 可检查 | 单栋建筑 | 定期维护/重建 |

### 4.2 预警与响应建筑

| 建筑 | 功能 |
|------|------|
| 气象雷达 | 提前预警部分灾害 |
| 地震传感器 | 地震提前预警(数秒) |
| 海啸预警浮标 | 海啸提前预警 |
| 紧急避难所 | 灾害时市民前往避难 |
| 消防直升机坪 | 空中灭火(应对森林火灾) |
| 灾害响应中心 | 灾后派遣救援队清理废墟、恢复服务 |

### 4.3 应急广播系统

灾害预警后可以通过应急广播系统指示市民疏散到避难所。避难所有容量限制和食物/水供应——需要提前储备。

## 五、场景模式(Scenario Mode)

Disasters DLC引入的场景模式为环境系统增加了"目标导向"层：

| 场景类型 | 示例 |
|------|------|
| 灾后重建 | 在地震废墟上重建城市 |
| 持续灾害 | 不断受到陨石袭击的城市需要坚持到目标人口 |
| 预防型 | 在海啸多发区建立防御并达到目标 |

## 六、设计特点分析

### 6.1 污染系统的"隐形教学"

都市天际线的污染系统实际上在**无声地教授城市规划原则**——城市的下风方向=工业区、上游=取水口、高速公路=噪音走廊。这些是现实中城市规划师需要学习的内容，但游戏通过"数值惩罚"而非"文字教程"来教授。这是城市建设品类中最优雅的隐性教学案例之一。

### 6.2 灾害系统的设计哲学：可选压力

与Frostpunk将环境压力作为**核心驱动**不同，都市天际线的灾害系统是**可选附加层**。默认情况下玩家可以完全忽略灾害（甚至不购买DLC），游戏仍然是完整的城市建造体验。这个设计决策非常关键——它将"压力"从必需品变为调味品。

**与Frostpunk对比**：
| 维度 | Cities: Skylines | Frostpunk |
|------|:--:|:--:|
| 环境角色 | 背景/可选挑战 | **核心驱动/必须对抗** |
| 灾害频率 | 低频/手动触发 | 持续/不断升级 |
| 失败后果 | 局部破坏→修复 | **全城覆灭** |
| 设计重心 | 建设>防御 | 建设=防御 |
| 情感体验 | 创造满足感 | 生存紧张感 |

### 6.3 水污染——"最致命的新手陷阱"

都市天际线的水污染系统设计了一个几乎每个新手都会踩的陷阱：水塔污染。这个陷阱的优雅之处在于——它不是瞬间的game over，而是渐进的。市民慢慢生病→医疗系统逐渐超载→尸体开始堆积→地价下降→税收减少→无法支付服务→死亡螺旋。整个过程可能需要几个游戏年，给玩家足够的时间去"发现问题并修复"——前提是他们知道往哪里看。这个设计让"发现问题→排查→修复"本身成为一种有教育意义的核心循环。
