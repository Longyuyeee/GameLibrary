# 人口与需求系统 — 都市天际线 (Cities: Skylines)

> 游戏版本: Cities: Skylines v1.17.1 | PC/Steam
> 数据来源: [Paradox Wiki - Population](https://skylines.paradoxwikis.com/Population), [Game Developer - Traffic & Citizens](https://www.gamedeveloper.com/design/how-traffic-works-in-cities-skylines), [Steam社区指南](https://steamcommunity.com/sharedfiles/filedetails/?id=514431247)

## 一、系统概述

都市天际线采用**基于个体的市民模拟(Agent-Based Simulation)**——每个市民是一个持久存在的独立个体，拥有姓名、住址、工作地点、教育水平、年龄、健康状态和家庭关系。这意味着城市中的"人口"不是统计数字，而是可追踪的独立生命。

## 二、市民生命周期

### 2.1 五个生命阶段

| 阶段 | 年龄段 | 行为特征 | 交通方式 |
|------|------|------|------|
| **儿童** (Child) | 0-12岁 | 不工作，需要小学教育 | 步行(由成年人接送) |
| **青少年** (Teen) | 13-17岁 | 不工作，需要高中教育 | 步行/自行车 |
| **青年成人** (Young Adult) | 18-35岁 | **主要劳动力**，偏好高密度住宅 | 公交/地铁/汽车 |
| **成人** (Adult) | 36-60岁 | 主要劳动力，偏好低密度住宅 | 汽车/自行车 |
| **老年人** (Senior) | 60+岁 | 退休/少量工作，消费需求低 | 汽车(减少) |

### 2.2 生命周期设计分析

**关键发现**：青年成人和成人的住宅偏好不同——前者倾向于高密度公寓（便宜、靠公交），后者倾向于低密度独栋（养家、开车）。这意味着：
- 大量高密度住宅的城市 → 青年成人比例高 → 劳动力充沛 → 经济活跃 → 但对教育和低密度升级需求低
- 大量低密度住宅的城市 → 成人家庭比例高 → 需要更多学校 → 公共交通使用率低 → 交通压力大

**与SimCity (2013)对比**：SimCity采用"工人/购物者/学生"三种抽象Agent，每天随机重新分配到最近的工作/商店/学校。都市天际线的每个市民记住自己的家和工作——这更真实，但也是计算瓶颈（需要追踪每个Agent的状态）。

## 三、家庭(Household)结构

### 3.1 家庭组成

每个住宅建筑容纳若干**家庭(Household)**。每个家庭包含：
- 最多2名**成年工作者**（青年成人或成人）
- 若干**儿童/青少年**（接受教育）
- 可能有**老年人**（低消费、低出行）

### 3.2 各密度住宅容纳量（Lv5建筑）

| 建筑尺寸 | 低密度住宅(户数) | 高密度住宅(户数) | 高/低倍率 |
|:--:|:--:|:--:|:--:|
| 1×1 | 1.0 | 1.6 | ×1.6 |
| 2×2 | 2.5 | 9.6 | ×3.8 |
| 3×3 | 4.4 | 17.0 | ×3.9 |
| 4×4 | **6.7** | **25.6** | **×3.8** |

**设计分析**：4×4高密度住宅容纳25.6户——每户按2名工作者+2名依赖者计算，一栋楼承载约100人。一个满铺4×4高密度住宅的街区（约20栋楼×100人=2000人）相当于一个低密度郊区社区的20-30倍人口。这种密度差带来的交通/服务压力是指数级而非线性的——这是新手最常踩的坑。

## 四、人口增长里程碑

### 4.1 关键解锁里程碑

| 里程碑 | 人口 | 解锁内容 |
|------|:--:|------|
| 小型村庄 | 440 | 税收、贷款、垃圾场、诊所、小学 |
| 舒适村庄 | 850 | **区域系统**、政策面板、林业/农业专业化 |
| 小镇 | 1,300 | 高中、公园工具、装饰品 |
| 大型城镇 | 2,600 | 消防站、警察局、公交系统 |
| 小型城市 | 4,500 | 大医院、大消防站、地铁系统 |
| 繁忙社区 | 7,000 | **高密度区划开放**、办公区、大学、地铁、税收政策调整 |
| 大城市 | 15,000 | 火葬场、水处理厂、货船港口 |
| 首都 | 28,000 | 游船、港口、国际机场 |
| 巨型城市 | 48,000 | 核电站、货运枢纽 |
| 超级都市 | 70,000+ | 纪念碑建筑、国际机场(如果未在28K解锁) |

**设计分析**：关键节点在**7,000人口**——高密度区划+办公区+大学+地铁同时解锁，意味着从这一刻起城市形态发生根本变化。在此之前，城市是有机蔓延的；在此之后，城市开始垂直生长。这是游戏最危险的转型期——如果交通系统没准备好，高密度建筑会导致局部拥堵崩溃。

**与Frostpunk对比**：Frostpunk的人口是稀缺资源（每增加一个人都可能救活一座城）；都市天际线的人口是引擎燃料（越多越好，只要服务跟得上）。两种设计哲学截然不同——前者制造"每一个生命都很宝贵"的紧张感，后者创造"看着人潮涌动的满足感"。

## 五、人口停滞问题与解决

### 5.1 常见停滞原因

| 现象 | 原因 | 解决方案 |
|------|------|------|
| R需求条很低但人口不增长 | **过剩空置区划**压制需求信号 | 取消未使用的区划 |
| 住宅区划已满但没人搬进来 | 地价/维护费过高 | 降低周边服务密度或升级道路 |
| 工业区划满但缺少工人 | 教育水平不匹配——高教育市民不愿做工厂工人 | 发展办公区/高教产业，或控制教育普及 |
| 人口快速增长后突然停滞 | 死亡潮(Death Wave) | 分批区划住宅，避免同批次市民同时老死 |

### 5.2 "死亡潮"(Death Wave)机制

这是都市天际线最著名的设计问题之一：如果玩家在短时间内大面积区划住宅，大量同年龄市民会同时入住。由于市民寿命大致相同，这批人会在同一时段集中死亡——导致短时间内大量建筑被废弃、殡葬服务崩溃。

**设计师的处理方式**：官方未修复此问题，因为这是"真实的人口统计现象"的意外模拟结果。Mod社区提供了年龄随机化补丁。

## 六、健康与福祉

| 维度 | 机制 |
|------|------|
| 健康值 | 0-100，受污染(空气/水/噪音)、医疗覆盖、年龄影响 |
| 疾病 | 生病市民需要医疗设施，否则健康持续下降→死亡 |
| 平均寿命 | 约6游戏年(受医疗覆盖影响) |
| 医疗设施 | 诊所→医院，救护车需要通畅道路到达市民 |
| 殡葬 | 墓地→火葬场，尸体不处理会降低周边地价和健康 |

## 七、设计特点分析

### 7.1 Agent-Based vs 统计模型

都市天际线的市民个体模拟是品类中最精细的之一。每位市民有：
- 姓名 + 住址 + 工作地点（持久）
- 年龄 + 教育水平 + 财富水平
- 健康状态 + 幸福度
- 家庭关系（属于哪个Household）

**但**：并非所有市民同时被物理渲染。游戏有一个"模拟上限"——超出上限的市民以统计方式存在（不参与交通/不消费/不占用服务），直到其他市民"下线"才被激活。这是一种不得已的性能折中，但玩家通常感知不到。

**与RimWorld对比**：RimWorld每个殖民者都有完整心理模型(心情/记忆/人际关系/创伤)，都市天际线的市民个体模型在"城市尺度的人口模拟"中已经是品类最深。但比起RimWorld的"小群体深模拟"，天际线是"大群体浅模拟"——这是尺度差异决定的必然选择。

### 7.2 里程碑解锁：正向激励的节奏设计

人口里程碑不只是"解锁新建筑"——它们构建了城市建设的节奏曲线。每个里程碑解锁的内容恰好是当前阶段出现的新问题所需要的工具：
- 440人→诊所（之前不需要医疗）
- 2,600人→消防+警察（人口密集到需要治安）
- 7,000人→高密度（低密度开始占太多地）
- 15,000人→火葬场（墓地不够用）

这种"先让你感受痛点→再给你工具"的节奏设计是城市建设品类的经典模式。

### 7.3 教育-就业错配的隐性压力

市民不会"降级就业"——一个大学毕业的市民**不会**去工厂做工人。这意味着如果城市生产了过多的高教育人口而没有足够的办公区/高教产业，就会出现"教育性失业"。这模拟了现实中的"学历贬值"现象，是都市天际线最接近社会模拟的子系统。
