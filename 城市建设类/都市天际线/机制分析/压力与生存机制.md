# 压力与生存机制 — 都市天际线 (Cities: Skylines)

> 游戏版本: Cities: Skylines v1.17.1 | PC/Steam
> 数据来源: [Paradox Wiki](https://skylines.paradoxwikis.com), [Game Developer分析](https://www.gamedeveloper.com/design/how-traffic-works-in-cities-skylines), 社区玩家共识

## 一、系统概述

都市天际线是一个**无强制失败条件**(可选)的沙盒游戏——本质上是"纯建造"型城市建造游戏。压力来源不是外部威胁（如Frostpunk的暴风雪），而是**玩家自身的规划错误**导致的内部系统崩溃。游戏提供了从"零压力沙盒"到"硬核模式"的压力梯度选择。

## 二、沙盒模式 — 零压力

### 2.1 内置Mod选项

| Mod选项 | 效果 |
|------|------|
| 无限金钱 | 资金无限，无财政压力 |
| 全部解锁 | 所有里程碑内容从开局可用 |
| 无限石油/矿石 | 不可再生资源永不耗尽 |
| 无污染 | 移除所有污染系统 |

### 2.2 设计意图

沙盒模式不是"作弊"——它是都市天际线设计哲学的一部分：让玩家自主选择体验类型。许多硬核城市美化玩家使用"无限金钱"来专注创造完美城市。

## 三、内部压力来源（"软失败"）

### 3.1 财政崩溃

最经典的压力源头。连锁反应：

```
过度扩张(建太多服务) → 维护费超过税收 → 赤字
→ 降低服务预算 → 服务效率下降 → 市民不满意
→ 人口流失 → 税收进一步减少 → 更严重赤字
→ 破产(可选游戏结束或无限金钱)
```

**设计特点**：破产不会突然结束游戏——它会询问玩家是否开启无限金钱继续。这个设计很关键：它把"失败"变成"选择"，不强制惩罚。

### 3.2 交通崩溃

```
人口密集区域 → 道路容量不足 → 交通拥堵
→ 服务车辆无法到达(消防车/救护车/灵车被堵)
→ 火灾蔓延/病人死亡/尸体堆积
→ 地价暴跌 → 建筑被废弃 → 人口流失 → 税收减少
```

交通崩溃是都市天际线最独特的压力形式——因为它**视觉可见**。你看到红色的拥堵路段在蔓延，就像看到城市在"窒息"。

### 3.3 死亡螺旋(Death Spiral)

这是都市天际线著名的系统崩溃连锁：

```
污染水/空气 → 市民大规模生病
→ 医疗系统超载(医院满床+救护车堵车)
→ 大批市民死亡
→ 殡葬系统超载(墓地满+灵车堵车)
→ 未处理的尸体降低地价
→ 建筑废弃 → 人口暴跌 → 税收归零
```

**设计分析**：死亡螺旋不需要外部敌人——它是城市系统自身脆弱性的体现。一旦触发，即使发现问题也可能来不及挽救，因为修复速度赶不上崩溃速度。这是最接近"Roguelike式不可逆失败"的都市天际线体验。

### 3.4 人口停滞

见"人口与需求系统"文档——人口不增长导致无法解锁新内容、税收增长停滞、劳动力短缺。

### 3.5 资源枯竭压力（Industries DLC）

石油/矿石耗尽后的产业转型压力。资源型城市如果不提前布局替代产业（林业/农业/办公），会在资源耗尽时经历"产业空心化"。

## 四、外部压力来源

### 4.1 自然灾害（Natural Disasters DLC）

见"环境与灾害系统"文档。灾害是唯一的外部破坏性压力。但即使在灾害DLC中，玩家也可以**手动触发或禁用特定灾害**——这是保持"可选择的压力"设计哲学。

### 4.2 外部连接中断

如果城市唯一的高速公路连接被破坏（或玩家自行拆除），外部贸易完全中断→商品短缺→商业区崩溃。

## 五、压力梯度设计

| 模式 | 财政压力 | 交通压力 | 灾害压力 | 资源压力 |
|------|:--:|:--:|:--:|:--:|
| **完全沙盒**(无限金钱+全解锁) | 无 | 仅交通 | 可选 | 无 |
| **标准模式**(默认) | 中(早期紧，后期松) | **核心压力** | 无(无DLC) | 低 |
| **标准+Disasters DLC** | 中 | 核心压力 | 中(随机) | 低 |
| **标准+Industries DLC** | 中 | 核心压力 | 可选 | 中(资源枯竭) |
| **Hard Mode Mod** | 高(税收减半/维护加倍) | 核心压力 | 可选 | 高 |

## 六、无"军事/战斗"压力

与许多城市建设游戏不同，都市天际线**完全没有战斗系统**——没有敌人入侵、没有城防、没有战争。这是重要的设计决策：

| 有战斗的城建游戏 | 都市天际线 |
|------|------|
| Manor Lords（战术RTS战斗） | 无战斗 |
| Anno 1800（海战/海盗） | 无战斗 |
| Kingdoms and Castles（维京入侵） | 无战斗 |
| Frostpunk（虽无战斗，生存压力等同） | 无战斗 |
| Against the Storm（女王急躁度） | 无战斗 |

**设计意图**：去除外部威胁是为了让玩家**100%专注于建造和优化**。交通拥堵本身已经提供了足够的"敌人"。

## 七、设计特点分析

### 7.1 "失败是选项"不是"失败是终点"

都市天际线最核心的设计决策是：**失败从来不是终局**。财政崩溃→开启无限金钱继续玩。交通崩溃→拆除重来。死亡螺旋→开新档。游戏从一开始就假定玩家会犯错误，并确保错误导致的"失败"是可恢复的。

这与Frostpunk形成鲜明对比——在Frostpunk中，一个错误的政策选择会让你的城市在暴风雪中覆灭，没有回头路。两种设计服务于不同的体验目标：Frostpunk让你感受到"决定的重量"，都市天际线让你享受"从混乱中学习秩序"。

### 7.2 交通拥堵——品类中最优雅的"内部敌人"

都市天际线将交通拥堵设计为**唯一的持续压力来源**——它永远不会被"解决"，只会被不断优化。随着城市增长，新的瓶颈不断出现，强迫玩家持续迭代路网设计。这创造了一种独特的"永无完美"驱动力——总有可以优化的地方。

将交通置于压力系统核心的决策反映了现实：**真正的城市永远不会"完成"，它们只是不断地重新规划**。

### 7.3 "可选的灾害"——尊重不同玩家群体

都市天际线将灾害系统放在付费DLC中的决策曾引发争议，但从设计角度看是精明的——它确保了基础游戏服务于最广泛的玩家群体（建造者），同时为寻求挑战的玩家提供了可选的压力层。这与Anno 1800将海盗/战争作为可选设置的设计思路一致。
