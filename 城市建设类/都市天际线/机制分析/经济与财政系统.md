# 经济与财政系统 — 都市天际线 (Cities: Skylines)

> 游戏版本: Cities: Skylines v1.17.1 | PC/Steam
> 数据来源: [Paradox Wiki - Economy](https://skylines.paradoxwikis.com/Economy), [Paradox Wiki - Beginner's Guide](https://skylines.paradoxwikis.com/Beginner%27s_guide), [Game Developer分析](https://www.gamedeveloper.com/design/how-traffic-works-in-cities-skylines)

## 一、系统概述

都市天际线的经济系统基于**税收驱动的市政财政**模型。城市收入主要来自各区划类型的税收，支出则是所有市政建筑和道路的维护费。没有复杂的生产链或贸易网络——经济设计的核心是**"规模=收入"与"服务=支出"的平衡**。

## 二、收入来源

### 2.1 税收（核心收入，占85%+）

| 税种 | 税率范围 | 默认税率 | 说明 |
|------|:--:|:--:|------|
| 住宅税 | 1%-29% | 9% | 低密度和高密度可分开设定（7K人口解锁） |
| 商业税 | 1%-29% | 9% | 同上 |
| 工业税 | 1%-29% | 9% | 同上 |
| 办公税 | 1%-29% | 9% | 办公区算作工业税收分类 |

| 税率 | 满意度影响 | 备注 |
|------|------|------|
| 1%-11% | 无负面影响 | "安全区" |
| 12% | 市民开始微词 | 多数玩家使用的上限 |
| 13%-29% | 满意度持续下降 | 市民可能离开城市 |

### 2.2 人口里程碑奖励

每次达到人口里程碑时获得一次性现金奖励。早期是重要的"启动资金"补充。

### 2.3 公共交通收入

- 公交、地铁、火车、轮渡等收费交通产生票务收入
- 设计良好的线路可以**盈利**
- 免费公交政策会取消此项收入，但能提升地价和满意度

### 2.4 区域专业化产业收入

- 石油、矿石、林业、农业专业化产生可出口原材料
- 加工品（塑料、金属、家具等）出口价值更高

## 三、支出结构

### 3.1 维护费（约占总支出70%+）

所有市政建筑都有**持续性维护费用**（每周扣除）。主要包括：

| 类别 | 典型建筑 | 维护费范围(₡/周) |
|------|------|:--:|
| 电力 | 风力发电机→核电站 | ₡8-8,000 |
| 供水/污水 | 水泵→水处理厂 | ₡15-640 |
| 医疗 | 诊所→医院 | ₡20-1,200 |
| 教育 | 小学→大学 | ₡16-1,200 |
| 治安 | 警察局→大警察局 | ₡24-1,200 |
| 消防 | 消防站→大消防站 | ₡30-1,200 |
| 殡葬 | 墓地→火葬场 | ₡16-800 |
| 垃圾 | 垃圾场→回收中心 | ₡40-960 |
| 交通 | 公交/地铁/火车 | 按线路长度和车辆数 |

### 3.2 道路维护费

- 每条道路按长度和类型收取维护费
- 高速公路维护费 > 大道 > 普通路 > 土路
- 这是隐藏的大额支出——大面积城市中道路维护费可能占总预算的15%-25%

### 3.3 贷款

| 贷款等级 | 解锁人口 | 贷款金额 | 利率 | 还款期 |
|:--:|:--:|:--:|:--:|:--:|
| 基础 | 440 | ₡20,000 | 5% | 52周 |
| 中级 | 18,000 | ₡100,000 | 4% | 130周 |
| 高级 | 40,000 | ₡500,000 | 3% | 260周 |

## 四、预算面板(Budget Panel)

### 4.1 预算调节机制

每个服务部门可以**独立调节预算比例**(50%-150%)：

| 预算比例 | 服务效率 | 维护费 | 使用策略 |
|:--:|:--:|:--:|------|
| 50% | 25% | 最低 | **开局常用**——小城市不需要满额服务 |
| 100% | 100% | 正常 | 标准设置 |
| 125% | 125% | 1.25× | 服务不足时的快速扩容替代方案 |
| 150% | 150% | 1.5× | 紧急情况下的临时措施 |

> **核心策略**：游戏早期将水/电预算降至50%可大幅节省开支（维护费减半但提供25%服务，对初期小镇足够）。中后期通过**新增建筑**而非提高预算来扩容——新建一个诊所比把三个诊所都调到150%更经济。

### 4.2 夜间预算（After Dark DLC）

| 时间段 | 需求变化 |
|------|------|
| 白天 (6:00-18:00) | 正常需求 |
| 夜晚 (18:00-6:00) | 工业/办公活动减少，商业消费减少 |

## 五、经济平衡设计

### 5.1 "规模经济"陷阱

玩家最常见的财务危机模式：

```
1. 人口增长 → 服务需求增加 → 新建服务建筑
2. 新建筑维护费增加 → 当期税收不变 → 赤字
3. 以为需要"更多人口" → 区划更多住宅
4. 更多人口 → 更多服务需求 → 更大赤字
```

**设计意图**：这个陷阱是故意的。它迫使玩家学会"先让现有区划升级到高等级再扩张"——因为高等级建筑=更多人口/更高税收=同样区划面积下更强财政。

### 5.2 税收的经济调节功能（不止于收入）

税收不仅是收入来源，也是**城市形态的调节工具**：
- 高住宅税 → 驱离低财富居民 → 低密度住宅无法升级 → 城市"卡在低端"
- 低商业税 → 吸引商业投资 → 商业区繁荣 → 但可能挤占工业/办公空间
- 低工业税+高住宅税 → 工业城市形态（低端就业驱动型城市）

**与Tropico系列对比**：都市天际线的税收主要影响"量"（居民是否留下/离开），Tropico的税收/政策主要影响"质"（各派系满意度/政治后果）。前者的经济是"市政会计"，后者是"政治经济学"。

## 六、进口/出口系统

| 维度 | 内容 |
|------|------|
| 进口 | 城市无法生产的商品自动从外部购买（有运输费用和货车流量） |
| 出口 | 过剩产品自动出售（产生收入和出城货车流量） |
| 平衡策略 | 自给自足可减少货车流量；完全出口导向可赚取额外收入但增加道路压力 |
| 专业化出口 | 石油/矿石/农业/林业专业化城市可成为"单一产业出口型"城市 |

## 七、设计特点分析

### 7.1 "简单化"的经济哲学

都市天际线的经济系统刻意简化——没有通货膨胀、没有股市、没有生产线、没有供应链。只有一个闭环：市民工作→市民消费→建筑产生税收→税收支付服务→服务提升地价→地价推动建筑升级→升级产生更多税收。

**设计意图**：Colossal Order明确表示经济不是核心——**交通才是**。简化经济是为了让玩家专注于交通规划。这与其他城市建设游戏（如Anno 1800的复杂供应链）形成鲜明对比，是深思熟虑的设计选择而非能力不足。

### 7.2 预算面板的"新手陷阱"

50%-150%的调节范围看似给了玩家"精细管理"的错觉——实际上，降低预算到50%来省钱几乎只在游戏的前30分钟有意义。之后的服务需求增长会使得"新建建筑"比"调高预算"更划算。但新手不知道这一点，会不断调低预算而导致服务崩溃。

**设计评价**：预算面板是"留给玩家去发现的优化空间"——它给有经验的玩家提供了精细优化手段，但不会阻碍新手的基础体验。这是一种好的"深度隐藏"设计。

### 7.3 与SimCity (2013)对比

| 维度 | Cities: Skylines | SimCity (2013) |
|------|:--:|:--:|
| 经济复杂度 | 简单（税收+维护费） | 复杂（全球市场+资源开采+贸易） |
| 收入来源 | 税收为主 | 税收+资源出口+贸易利润 |
| 支出驱动 | 服务建筑维护费 | 服务建筑+进口+债务利息 |
| 设计重心 | 交通管理 | 经济链管理 |
