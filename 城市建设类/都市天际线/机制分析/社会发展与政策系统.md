# 社会发展与政策系统 — 都市天际线 (Cities: Skylines)

> 游戏版本: Cities: Skylines v1.17.1 | PC/Steam
> 数据来源: [Paradox Wiki - Districts](https://skylines.paradoxwikis.com/Districts), [Paradox Wiki - Policies](https://skylines.paradoxwikis.com/Policies), [Steam社区指南](https://steamcommunity.com/sharedfiles/filedetails/?id=431364517)

## 一、系统概述

都市天际线的社会发展系统通过**区域(District)系统**和**城市政策(City Policies)**实现。它没有Frostpunk的法律选择树或Tropico的派系政治——设计哲学更轻量，专注于"空间差异化"而非"道德/政治选择"。核心循环是：用画笔绘制区域→在区域上应用政策→创造不同的城市形态。

## 二、区域系统 (District System)

### 2.1 区域绘制

- 解锁：850人口
- 工具：区域画笔（三种尺寸）
- 操作：在地图上自由绘制封闭区域边界
- 一个地块可属于多个同名区域（非连续区域合并）

### 2.2 区域功能

| 功能 | 说明 |
|------|------|
| 区域命名 | 给城市不同片区命名（唐人街/金融区等） |
| 政策应用 | 在特定区域实施差异化政策 |
| 专业化 | 工业/商业/办公/住宅指定专业化类型 |
| 税收分区（解锁后） | 对不同区域的各类型区划设定不同税率 |
| 风格选择 | 指定区域使用特定建筑风格（欧式/现代等，需对应CCP） |

### 2.3 区域叠加

多个区域可以重叠——一栋建筑可能受到多个重叠区域政策的影响。

## 三、城市政策系统

### 3.1 全市政策

| 政策 | 解锁 | 效果 | 代价 |
|------|:--:|------|------|
| **节水** | — | 全市用水-15% | 无 |
| **节电** | — | 全市用电-11% | 无 |
| **禁烟** | 850 | 市民健康+，减少疾病 | 犯罪率微升 |
| **宠物禁令** | — | 减少噪音 | 幸福度微降 |
| **回收计划** | — | 减少垃圾产生量 | 回收中心维护费 |
| **免费公共交通** | Fin. Districts | 公交/地铁免费 | 零交通收入，大幅增加客流 |
| **教育促进** | 850 | 优先录取高教育市民学校 | 教育预算+25% |
| **学校外出禁令** | — | 学生不逃学 | 幸福度微降 |
| **高速重型车禁行** | — | 货车不能上高速 | 可能影响货运效率 |
| **鼓励骑车** | After Dark | 市民更多骑车 | 无（需自行车道配合） |
| **老城区** | — | 区域内建筑不升级 | 无（用于保护低密度社区） |
| **高层建筑禁令** | — | 区域内禁止高层建筑 | 无 |
| **公园维护** | Parklife | 公园维护费用提升 | 公园吸引力+ |
| **自动化收费站** | Mass Transit | 高速公路收费 | 收取过路费 |
| **娱乐合法化** | After Dark | 增加税收 | 犯罪率上升 |

### 3.2 区域级政策

画好区域后，可对区域单独应用以下政策：

| 政策 | 效果 | 适用场景 |
|------|------|------|
| **工业专业化** | 指定工业类型(石油/矿石/林业/农业) | 在自然资源上方的工业区 |
| **商业专业化** | 休闲/旅游/有机农产品 | 景区/大学城/农业区旁 |
| **办公专业化** | IT集群 | 高教育区域替代工业 |
| **重型车禁行** | 货车不能进入该区域 | 住宅区隔离货车 |
| **仅限本地交通** | 过境车辆绕行 | 社区内部道路 |
| **绿化城市** | 建筑周围自动种树 | 提升地价 |
| **高密度住宅** | 只允许高密度住宅 | 市中心 |
| **自建住宅** | 区域内的低密度住宅地块留给市民自建 | 有机增长实验 |
| **免费公共交通(区域)** | 区内公交/地铁免费 | 大学城区/商业中心 |
| **学校选择制度** | 学生可跨区入学 | 教育不均衡地区 |

## 四、税收政策（分区差异化）

7,000人口解锁后，可以对每个区域**独立设定四类税收**：

| 可调节税率 | 范围 |
|------|:--:|
| 低密度住宅 | 1%-29% |
| 高密度住宅 | 1%-29% |
| 低密度商业 | 1%-29% |
| 高密度商业 | 1%-29% |
| 工业 | 1%-29% |
| 办公 | 1%-29% |

**策略应用**：
- 金融区：降低办公税率(吸引企业)+提高商业税率(高消费力承受)
- 大学城：降低高密度住宅税率(吸引青年成人)+公共交通免费
- 工业园：降低工业税率(吸引工厂)+重型车禁行周边住宅区

## 五、独特建筑与纪念碑

### 5.1 独特建筑(Unique Buildings)

每个独特建筑有解锁条件（如"城市有50%的大学教育率"）和放置费用。它们是城市成就的视觉象征：

| 类别 | 示例 | 解锁条件 |
|------|------|------|
| 交通类 | 中央车站 | 多条铁路线汇聚 |
| 教育类 | 歌剧院 | 高教育率 |
| 健康类 | 医学中心 | 大医院+诊所覆盖 |
| 商业类 | 证券交易所 | 高商业税收 |

### 5.2 纪念碑(Monuments)

终局超级建筑，建设条件极其苛刻（需要整个城市为它"服务"），建成后提供城市级巨大加成：

| 纪念碑 | 建成效果 |
|------|------|
| 伊甸园计划 | 全市地价大幅提升 |
| 核聚变电厂 | 无限零污染电力 |
| 医学中心 | 全市健康上限+ |
| 强子对撞机 | 全市教育水平+ |

> **设计意图**：纪念碑是"完美城市"的终极挑战——它们需要城市在各项指标上接近完美才能建造。对于沙盒型玩家，这是"完成游戏"的标志。

## 六、设计特点分析

### 6.1 "画笔区域"——空间政策的最小可行设计

都市天际线用"画笔涂区域→选政策"这个极简的交互，实现了城市建造品类中最灵活的空间差异化。与SimCity 2013的"固定区块"或Anno 1800的"岛"相比，区域系统让玩家可以用任意形状来定义城市的不同功能片区——一条沿着河边画出来的"滨河娱乐区"、一个沿着高速公路的"物流走廊"、一块被低密度环绕的"历史老城区"。

### 6.2 政策的"无代价/小代价"设计哲学

与其他城市建设类游戏中政策往往伴随重大权衡不同，都市天际线的大部分政策**无负面代价或代价极小**。节水/节电/教育促进几乎是免费福利。这不是设计疏忽——这是刻意的设计哲学：政策在都市天际线中的角色是**空间差异化工具**而非**道德选择**。玩家不需要在"好/坏"之间纠结，只需要在"A好/B也好"之间根据城市需求选择。

**与Frostpunk法律树对比**：
| 维度 | Cities: Skylines | Frostpunk |
|------|:--:|:--:|
| 政策本质 | 空间优化工具 | 道德/生存抉择 |
| 代价结构 | 零/极小代价 | 重大代价(希望/不满) |
| 决策压力 | 低(可随时取消) | 高(不可逆/长期后果) |
| 设计目标 | 让玩家创造不同风格的城市 | 让玩家面对道德困境 |

### 6.3 纪念碑——"隐性通关条件"的设计

都市天际线没有官方的"通关"——它是一个永无止境的沙盒。但纪念碑系统创造了一个**隐性的终局目标**：达到能够建造纪念碑的城市状态。这给硬核玩家提供了"我完成了这个城市"的心理节点，同时不强制休闲玩家面对任何终局压力。
