## 二、区域政策

| 政策 | 适用场景 | 效果 |
|------|------|------|
| **工业专业化** (石油/矿石/林业/农业) | 自然资源上方工业区 | 建筑转换为专业工厂 |
| **商业专业化** (休闲/旅游/有机农产品) | 特定商业区 | 商业类型转换 |
| **办公专业化** (IT集群) | 高教育办公区 | 生产数字商品，无需货车 |
| 重型车禁行 | 住宅区 | 货车不得进入 |
| 仅限本地交通 | 社区内部 | 过境车辆绕行 |
| 绿化城市 | 任何区域 | 自动种树→地价↑ |
| 高层建筑禁令 | 低密度保护 | 禁止高层 |
| 老城区 | 历史街区 | 建筑不升级 |
| 自建住宅 | 低密度住宅区 | 市民自主建造 |
| 免费公共交通(区域) | 大学城/市中心 | 区内免费乘车 |
| 学校选择 | 教育不均区域 | 学生可跨区入学 |

## 三、税收政策灵活性

7,000人口解锁后，每个区域可独立设定六类税率（1%-29%）：低密度住宅/高密度住宅/低密度商业/高密度商业/工业/办公。

## 四、里程碑与解锁节奏

| 里程碑 | 人口 | 关键解锁内容 |
|------|:--:|------|
| 小型村庄 | 440 | 税收/贷款/诊所/小学/垃圾场 |
| 舒适村庄 | 850 | 区域/政策/林业农业/禁烟/教育促进 |
| 小镇 | 1,300 | 高中/图书馆/公园 |
| 大型城镇 | 2,600 | 消防/警察/公交/出租车 |
| 小型城市 | 4,500 | 大医院/大消防/高级风电/地铁 |
| 繁忙社区 | 7,000 | **高密度+办公+大学+税收调节** |
| 大城市 | 15,000 | 火葬场/水处理/货船港 |
| 首都 | 28,000 | 游船/港口/国际机场 |
| 巨型城市 | 48,000 | 核电站/货运枢纽 |
| 超级都市 | 70,000+ | 纪念碑 |

> **设计节奏分析**：解锁节点恰好对应"玩家刚需要这个功能时"——440人需要诊所(之前没人)，2,600人需要消防(密度到了着火才有威胁)，7,000人需要高密度(低密度开始占太多地)。
