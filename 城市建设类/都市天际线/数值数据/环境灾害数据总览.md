| 污染源 | 强度 | 扩散方式 |
|------|:--:|------|
| 污水排放管 | 极高 | 随河流/水流扩散(下游) |
| 水处理厂 | 低(15%残留) | 同上 |
| 工业区地面渗透 | 中 | 渗透到地下水(垂直) |

### 1.3 噪音污染源

| 污染源 | 强度 | 影响距离(格) |
|------|:--:|:--:|
| 高速公路 | 极高 | ~8 |
| 六车道道路 | 高 | ~6 |
| 高密度商业区 | 高 | ~4 |
| 工业区 | 中 | ~4 |
| 地铁站 | 中 | 出入口周边~3 |
| 公交站 | 低 | ~2 |

### 1.4 污染治理

| 手段 | 效果 |
|------|------|
| 林业/农业区划(零污染) | 作为缓冲带替代有污染工业 |
| 行道树道路 | 降低道路噪音 |
| 隔音墙(道路升级) | 消除道路噪音 |
| Green Cities生态建筑 | 零污染替代品(太阳能/生态水处理/回收中心) |
| 城市植树/公园 | 局部空气净化+减噪 |

## 三、环境指标对地价的影响梯度

| 环境状况 | 地价修正 | 视觉表现 |
|------|:--:|------|
| 零污染+多公园+滨水 | +100%+ | 深绿色(高价值) |
| 低污染+有公园 | +20%~+50% | 浅绿色 |
| 无特殊环境(标准) | 基准 | 灰色 |
| 空气/噪音污染 | -20%~-50% | 浅红色 |
| 水污染+地面污染 | -50%~-80% | 深红色 |
| 污染+高犯罪+垃圾 | -90%+ | 废弃风险 |

## 四、数据局限说明

- 污染扩散距离为社区测试估算
- 灾害参数为游戏设计数值，有随机波动
- 灾后恢复成本高度依赖城市规模和受灾位置
