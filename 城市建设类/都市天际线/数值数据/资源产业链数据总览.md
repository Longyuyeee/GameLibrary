# 资源产业链数据总览 — 都市天际线 (Cities: Skylines)

> 游戏版本: Cities: Skylines v1.17.1 (含Industries DLC) | PC/Steam
> 数据来源: [Paradox Wiki - Industries](https://skylines.paradoxwikis.com/Industries), [Paradox Wiki - Natural Resources](https://skylines.paradoxwikis.com/Natural_resources), [Steam社区](https://steamcommunity.com)

## 一、自然资源分布

| 资源 | 地图出现率 | 可再生 | 主要分布区域 |
|------|:--:|:--:|------|
| 森林 | 高(几乎所有地图) | ✅ 可再生(植树恢复) | 树木密集区 |
| 肥沃土地 | 高 | ✅ 永久 | 浅绿色平原区域 |

| 矿石 | 中 | ❌ 不可再生(耗尽) | 灰色/棕色纹理区域 |

## 二、Industries DLC供应链

### 2.1 林业链

| 阶段 | 建筑/产出 | 原材料→产品 |
|:--:|------|------|
| 采集 | 植树场/砍伐场 → 原木 | — |
| 加工 | 锯木厂 → 木材 | 原木 → 木材 |
| 制造 | 家具厂 → 家具 | 木材 → 家具(高价值出口) |

### 2.2 农业链

| 阶段 | 建筑/产出 | 原材料→产品 |
|:--:|------|------|
| 采集 | 农田/牧场 → 作物/牲畜 | — |
| 加工 | 磨坊/屠宰场 → 面粉/肉 | 作物 → 面粉; 牲畜 → 肉 |
| 制造 | 食品厂 → 食品 | 面粉+肉 → 食品 |

### 2.3 石油链

| 阶段 | 建筑/产出 | 原材料→产品 |
|:--:|------|------|
| 采集 | 油井 → 原油 | — |
| 加工 | 炼油厂 → 石油/塑料 | 原油 → 石油; 原油 → 塑料 |
| 制造 | 塑料厂/燃料厂 → 商品/燃料 | 塑料 → 商品; 石油 → 燃料 |
| 高级制造 | 汽车厂/电子厂 | 塑料+金属+玻璃 → 汽车/电子(最高价值) |

### 2.4 矿石链

| 阶段 | 建筑/产出 | 原材料→产品 |
|:--:|------|------|
| 采集 | 矿场 → 矿石 | — |
| 加工 | 玻璃厂/冶金厂 → 玻璃/金属 | 矿石 → 玻璃; 矿石 → 金属 |
| 制造 | 机械厂/电子厂 → 机械/电器 | 金属 → 机械; 金属+塑料 → 电子 |

## 三、产业建筑升级数据

| 建筑类型 | 升级条件 | 升级效果 |
|------|------|------|
| 采集器(Extractor) | 持续生产积累 | 采集效率↑, 污染↓(部分类型) |
| 加工厂(Processor) | 持续加工积累 | 加工效率↑, 建筑外观升级 |
| 独特工厂(Unique Factory) | 达到产业等级+所有前置 | **城市级地标**, 高产+高就业 |

## 四、仓库与物流

| 仓库类型 | 功能 | 货运生成 |
|------|------|:--:|
| 原材料仓库 | 储存未加工资源 | 低-中 |
| 半成品仓库 | 储存加工中间产品 | 中 |
| 成品仓库 | 储存最终产品(待出口/销售) | 中-高 |
| 货运火车站 | 铁路物流中转 | **极高** |
| 货运港口 | 水路物流中转 | 极高 |
| 货运机场(Industries) | 空运高价值产品 | 高 |

## 五、进口/出口价值估算

| 产品类型 | 出口价值(相对) | 货车流量 |
|------|:--:|:--:|
| 原材料(原木/矿石/原油) | ★ (低) | 中 |
| 半成品(木材/面粉/金属) | ★★☆ | 中 |
| 普通成品(家具/食品) | ★★★ | 中-高 |
| 高级成品(汽车/电子产品) | ★★★★★ (最高) | 高 |
| 数字商品(IT集群办公) | ★★★★ | **零(无需货车!)** |

> **策略要点**：IT集群的"数字商品"不产生货车流量——这是唯一"高价值+零物流"的产品类型。

## 六、原版区划专业化vs Industries DLC

| 维度 | 原版专业化 | Industries DLC |
|------|------|------|
| 交互方式 | 在资源上画区划(自动) | 手动放置每个建筑 |
| 供应链 | 抽象(自动生产商品) | **完整四层供应链** |
| 物流复杂度 | 低 | 高(需仓库/货运站规划) |
| 玩家成就感 | 低(自动化) | 高(亲手搭建产业链) |
| 适合玩家 | 休闲/新玩家 | 硬核/产业规划爱好者 |

## 七、资源枯竭后的残余产出

| 资源 | 耗尽后残余 | 建议策略 |
|------|------|------|
| 石油 | 少量原油(效率~20%) | 转型林业/农业/办公 |
| 矿石 | 少量矿石(效率~20%) | 同上 |
| 森林 | 植树恢复(全恢复) | 循环砍伐/种植 |
| 肥沃土地 | 永不枯竭 | 永久运营 |

## 八、数据局限说明

- 各产品的具体出口价格未公开(游戏内为动态计算)
- 建筑升级的具体经验值累积要求未公开
- 车辆物流的具体吞吐量受道路状况影响差异极大
- 部分DLC建筑数据为社区采集
