> 开发商: Colossal Order (芬兰) | 发行商: Paradox Interactive
> 发行年份: 2015年3月10日 | 平台: PC/Mac/Linux (后移植PS4/Xbox One/Switch) | 团队规模: 13人(首发)

## 二、开发历程

### 2.1 前身：Cities in Motion (2011-2013)

Colossal Order不是凭空做出都市天际线的。他们之前开发了两款专注于**公共交通模拟**的游戏——Cities in Motion 1&2。虽然这些游戏销量一般（各几十万份），但它们：
- 积累了交通路径规划的核心技术（直接复用到都市天际线）
- 建立了与Paradox的长期合作关系
- 验证了团队在"城市"题材上的能力

### 2.2 机遇：SimCity (2013) 的灾难

EA Maxis于2013年3月发布SimCity——这是城市建造品类的鼻祖系列的回归。但发布后出现灾难性问题：
- **强制在线**：单人游戏也要求全程联网，服务器崩溃导致无法游玩
- **城市规模极小**：单个城市仅2km×2km（远小于SimCity 4）
- **Agent系统虚假**：居民不会记住住址/工作地点，每天随机重分配
- **玩家愤怒**：Metacritic用户评分暴跌至1.5/10

Paradox CEO Wester在一次采访中说："Maxis为我们做了最好的市场调研。"2013年SimCity的失败创造了一个**几百万饥渴的城市建造玩家等待替代品**的市场。Colossal Order立即开始全力开发他们的城市建造游戏。

### 2.3 开发周期：约2年（2013中→2015.3）

| 阶段 | 时间 | 关键决策 |
|------|------|------|
| 原型 | 2013中 | 基于Cities in Motion引擎，叠加城市建设层 |
| 核心开发 | 2013-2014 | 2名程序员全力开发；1人全职做Mod工具 |
| 公布 | 2014年8月Gamescom | 首支预告，社区反应热烈 |
| 打磨+社区反馈 | 2014末-2015初 | 与核心玩家群体(Youtuber/Modder)密切沟通 |
| 首发 | 2015年3月10日 | Steam首发，**24小时售出30万份** |

### 2.4 关键决策

1. **Mod支持从Day 1做起**：在一个只有2名程序员的13人团队中，分出一个人全职做Mod工具一整年——这在商业上是疯狂的，但在战略上是天才的。Mod支持是都市天际线超越SimCity的最关键差异化。

2. **Unity引擎**：选择了Unity而非自研引擎——让非技术型设计师也能快速迭代内容。

3. **坚持PC优先**：在那个"主机/移动优先"的时代，坚持PC独占首发。

4. **定价策略**：首发$29.99（比AAA低40%），但DLC策略后来引发争议。

## 三、技术与工具

| 维度 | 选择 |
|------|------|
| 引擎 | **Unity** (版本迭代：5→2017→2018→2019) |
| 核心语言 | C# |
| 交通模拟 | 基于Cities in Motion的节点-线段图算法，重写后集成 |
| Mod API | 完整的Unity C# Modding API + 资产管道 |
| 创意工坊 | **Steam Workshop深度集成**（首发即支持） |
| 地图编辑 | 内置地图编辑器 + terrain.party高度图导入 |
| 资产管道 | 支持FBX/OBJ 3D模型导入 |

**技术限制**（因Unity单线程特性）：
- Agent模拟上限（约65,535个可见Agent，社区推测）
- 大后期城市（10万+人口）帧率下降
- 交通路径计算非多线程

## 五、设计启示

### 5.1 对小团队的启示

1. **在已有技术基础上创新，而非从零开始**：都市天际线的交通系统直接来自Cities in Motion，城市建设层是附加的。Colossal Order没有试图发明一切。

2. **Mod支持是回报率最高的投资**：花一个程序员一整年做Mod工具，换来20万+免费资产、近乎无限的玩家留存、和"玩家替你营销"的病毒效应。这是小团队对抗大厂的最有效武器。

3. **等待市场窗口**：Colossal Order没有在SimCity 4之后立刻推出竞品——他们等到SimCity (2013)彻底失败，然后满足了一个巨大的未满足需求。

### 5.2 对城市建设品类的参考价值

1. **交通作为核心系统**：都市天际线证明了城市建设品类的核心不一定是"经济"或"人口"——可以是"交通"。这个洞察影响了后续几乎所有同类游戏。

2. **"无失败"沙盒模式的商业可行性**：与Frostpunk的"高压力生存"模式不同，都市天际线证明了"零压力纯建造"模式也有巨大的市场——1200万销量证明了两种设计方向都能成功。

3. **DLC生态的长期价值**：14个扩展包×8年的持续更新=玩家从$30变成潜在的$200+客户——但这也引发了关于"DLC过多"的争议。

### 5.3 团队规模与游戏品质的关系

都市天际线是"13人团队做出品类霸主"的教科书案例。关键不是团队大小——是在正确的时间(SimCity失败后)、用正确的策略(PC独占+Mod优先)、在正确的技术基础上(Cities in Motion交通系统)做正确的事。
